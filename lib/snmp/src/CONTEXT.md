# snmp — Source Tree (`lib/snmp/src`)

## Intent
Erlang sources of the `snmp` application (OTP's SNMP agent + manager toolkit), split into five build subdirectories: a MIB compiler, the agent, the manager, shared modules and the application glue.
Compiled into `lib/snmp/ebin` and installed into `$(RELEASE_PATH)/lib/snmp-<VSN>` by the per-dir `release_spec` targets.

## API Surface
- `compile/` — the `snmpc` MIB compiler (SMIv1/v2 `.mib` → compiled `.bin` MIB + `.hrl`); also builds the `snmpc` escript into `../../bin`.
- `app/` — application glue: public umbrella API `snmp`, `application` callback `snmp_app`, root supervisor `snmp_app_sup`, `snmp.app.src`/`snmp.appup.src` templates, example `snmp.config`, internal `snmp_internal.hrl`.
- `misc/` — modules shared by agent and manager: PDU codec `snmp_pdus`/`snmp_pdus_basic`, config handling `snmp_conf`/`snmp_config`, logging `snmp_log`, `snmp_usm`, `snmp_verbosity`, `snmp_note_store`, `snmp_misc`, `snmp_mini_mib`, plus shared headers.
- `agent/` — the SNMP master agent: public API `snmpa`/`snmpa_conf`, `snmpa_*` internals, the 11 pluggable behaviours with their defaults, the standard MIBs (`snmp_*_mib`) and generic MIB helpers.
- `manager/` — the SNMP manager (client): public API `snmpm`/`snmpm_conf`, `snmpm_*` internals, the user/network-interface behaviours and their defaults.
- Public, user-facing headers live in `../include/` (`snmp_types.hrl`, `snmp_tables.hrl`, `SNMPv2-TC.hrl`), not here.

## Build Scheme
- `Makefile` is the coordinator: includes `$(ERL_TOP)/make/target.mk`, `$(ERL_TOP)/make/$(TARGET)/otp.mk`, then `subdirs.mk`, and finally `$(ERL_TOP)/make/otp_subdir.mk` (which recurses into `SUB_DIRECTORIES`).
- `subdirs.mk`: `SUB_DIRECTORIES = compile app misc agent manager` — this is both the build and (for the first three) the load order of added-vs-existing modules.
- Every child dir carries `Makefile` (or `Makefile.in`), `modules.mk` (`MODULES`, `BEHAVIOUR_MODULES`, `MIB_MODULES`, `HRLS`/`INTERNAL_HRL_FILES`, `ASN1_SPECS`, `PARSER_SRC`, `ESCRIPT_SRC`) and `depend.mk` (per-module dependency lists).
- Child Makefiles conventionally set `EBIN = ../../ebin`, `BIN = ../../bin`, `include ../../vsn.mk`, `VSN = $(SNMP_VSN)`, `RELSYSDIR = $(RELEASE_PATH)/lib/snmp-$(VSN)`.
- Common `ERL_COMPILE_FLAGS`: `-I../../include` (plus `-I../app -I../misc`), `-Dversion=\"$(VSN)$(PRE_VSN)\"`, `+'{parse_transform,sys_pre_attributes}'`, `-Werror` (disable with `SNMP_WARNING_AS_ERROR=false`), `+warn_unused_vars` (disable with `WARN_UNUSED_VARS=false`), `+nowarn_deprecated_catch`.
- Versioning: `../vsn.mk` defines `SNMP_VSN` (currently `5.20.5`), `PRE_VSN`, `APP_VSN`. `-Ddefault_verbosity=$(SNMP_DEFAULT_VERBOSITY)` (default `silence`); `SNMP_DEBUG=d`, `SNMP_QC`, `SNMP_EXT_VERBOSITY`, `SNMP_EMPTY_PDU_SIZE` feed `SNMP_FLAGS`.

## Generated Code (never edit the generated file)
- `agent/Makefile` — GENERATED by `../../configure` from `agent/Makefile.in`; only `Makefile.in` is tracked (git-ignored via `../.gitignore`). The other four dirs track `Makefile` directly.
- `compile/snmpc_mib_gram.erl` — GENERATED by yecc from `compile/snmpc_mib_gram.yrl` (`YRL_FLAGS = -o .`, `+deterministic` when `ERL_DETERMINISTIC=yes`); removed by `make clean`.
- `../bin/snmpc` — GENERATED escript from `compile/snmpc.src` (`%VSN%` substitution).
- `misc/snmp_pdus_basic.erl` (+ `.asn1db`) — GENERATED via the `asn1` app from `misc/snmp_pdus_basic.asn` / `.set.asn` (git-ignored under `../.gitignore`).
- `app/snmp.app` and `app/snmp.appup` — GENERATED into `../../ebin` from the `.app.src`/`.appup.src` templates (`%VSN%` → `$(SNMP_VSN)`).

## Design Decisions
- One OTP application covers both the agent and manager sides; `app/snmp_app_sup` has no static children and adds `snmpa_supervisor`/`snmpm_supervisor` dynamically based on the `agent`/`manager` app env keys.
- Agent and manager are cleanly separated (`agent/` vs `manager/`) and share only `misc/`; the only cross-references are through the shared modules and their headers.
- Both sides are built around pluggable behaviours (network interface, MIB storage/data, access control, GET/SET mechanisms, error reporting, user, filters) so callers can replace parts without patching core code.
- The MIB compiler is standalone (`compile/`) and emits the compiled-MIB format consumed at runtime by `misc/snmp_mini_mib`, the agent's MIB server and the manager.

## Constraints
- Respect compile ORDER: within `agent/`, `snmpa` and `MIB_MODULES` define types consumed by later modules (incl. behaviour modules) and must be built first; `opt` builds `BEHAVIOUR_MODULES` before `MODULES`. Other dirs are independent of each other apart from `misc/` headers.
- `-Werror` is on by default: any new warning breaks the build.
- Internal `.hrl` files here are not public API; only `../include/*.hrl` are exported to users. Cross-dir header use is via `-I../misc` / `-I../app`.
- Adding a subdirectory requires updating `subdirs.mk`; the parallel build assumes the fixed order `compile app misc agent manager`.

## Notes for Agents
- The five child dirs are leaves (flat module files, no nested src dirs); each has its own `CONTEXT.md` with the detailed module-by-module routing.
- The `snmp_*_mib` modules (standard MIBs) live in `agent/`, not in `misc/`, despite the shared `snmp_` prefix.
- `snmp_usm` (in `misc/`) holds the shared USM primitives; `snmpa_usm`/`snmpm_usm` are the agent-/manager-specific wrappers around it.
- `lib/snmp/configure` (at the app dir, not here) generates `agent/Makefile`; the app has no other per-dir configure.

## Routing Table
- `compile/` → MIB compiler `snmpc` (+ escript), yecc grammar, `snmpc_lib`/`snmpc_tok`/`snmpc_mib_to_hrl`/`snmpc_misc`
- `app/` → `snmp` umbrella API, `snmp_app`/`snmp_app_sup`, `snmp.app.src`/`.appup.src`, `snmp.config`, `snmp_internal.hrl`
- `misc/` → shared PDU/config/logging/USM/verbosity modules and their headers
- `agent/` → SNMP master agent, `snmpa` API, behaviours + defaults, standard MIBs, generic MIB helpers
- `manager/` → SNMP manager/client, `snmpm` API, user/net-if behaviours + defaults
- `../include/` → public headers (`snmp_types.hrl`, `snmp_tables.hrl`, `SNMPv2-TC.hrl`) (sibling — read-only, escalate writes to `..`)
- `../test/` → Common Test suites for all five areas (sibling — read-only, escalate writes to `..`)
- `../doc/` → guides and ExDoc sources (sibling — read-only)
