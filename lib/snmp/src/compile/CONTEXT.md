# SNMP MIB Compiler (`snmpc`)

## Intent
The SNMP MIB compiler: translates SMIv1/SMIv2 MIB text files (`*.mib`) into Erlang terms (compiled `*.bin` MIB binaries, a `#mib{}` record written with `term_to_binary/1`), and generates `.hrl` constant files from a compiled MIB.
Also provides the standalone `snmpc` escript (driven from the OS command line, or via `erlc` invocation of `.bin` files) and the `erlc` compile callback used when compiling MIBs from Erlang.

## API Surface
Public module `snmpc` (`-moduledoc` documented in `snmpc.erl`):
- `compile/1,2` — compile a MIB file (or list of files) to `.bin`; `compile/3` is the `erl_compile` callback form.
- `mib_to_hrl/1` — generate `<MibName>.hrl` from an already-compiled MIB; `mib_to_hrl/3` is the internal/`erlc` form.
- `is_consistent/1` — check for duplicate OIDs/traps across a list of MIBs.
- `init/3` — internal `erl_compile` hook; `look_at/1` — debug helper (`-doc false`).
`snmpc` escript (`snmpc.src`): `-mode(compile)`, `main/1` argument parser (`--o`, `--i`, `--il`, `--db`, `--dep`, `--desc`, `--ref`, `--imp`, `--mi`, `--mc`, `--ac`, `--mod`, `--nd`, `--rrnac`, `--version`, `--verbosity`, `--warnings|--W`, `--Werror|--wae`), dispatching to `snmpc:compile/2` (MIB→bin) or `snmpc_mib_to_hrl:convert/3` (bin→hrl).

## Compilation Pipeline
`snmpc:compile/2` → `snmpc:parse/1` starts the tokenizer `snmpc_tok:start_link(reserved_words(), ...)`, collects all tokens with `get_all_tokens/1`, sets the SNMP version (`MODULE-IDENTITY` present ⇒ v2 else v1), initializes compiler state with `snmpc_lib:make_cdata/1`, then runs the yecc parser `snmpc_mib_gram:parse(Toks)`, and finally semantics/validation and `save/3` (`term_to_binary`) write the `.bin`.
- `snmpc_tok` — hand-written tokenizer (a `gen_server`), NOT a leex `.xrl`; there is no `snmpc_tok.xrl`. Emits `{Category, Line, Value}` tuples; supports `get_token/1`, `get_all_tokens/1`, `tokenize/2`, pluggable `{get_line_function, {M,F,A}}`.
- `snmpc_mib_gram` — LALR grammar generated by yecc from `snmpc_mib_gram.yrl`; `Expect 2.` declares two accepted shift/reduce warnings.
- `snmpc_lib` — main semantics: OID resolution, table/entry/index checks, version-consistency and group checks, error/verbosity reporting (`error/2,3`, `vprint/6`).
- `snmpc_mib_to_hrl` — `.bin` → `.hrl` generation (`convert/1,3`, `compile/3`).
- `snmpc_misc` — shared helpers (e.g. `assq/2`, `bits_to_int/2`, `check_file/1`, `read_mib/1`, `to_upper/1`).

## Constraints
- `snmpc_mib_gram.erl` is GENERATED from `snmpc_mib_gram.yrl` at build time (yecc) — never edit the generated file; edit the grammar and rebuild (it is git-ignored and removed by `make clean`).
- `../../bin/snmpc` (the escript) is GENERATED from `snmpc.src` by substituting `%VSN%`; never edit the generated binary. Edit `src` and rebuild.
- `snmpc.hrl`, `snmpc_lib.hrl`, `snmpc_misc.hrl` are INTERNAL headers (`INTERNAL_HRL_FILES`), NOT a public API — they are installed only under `$(RELSYSDIR)/src/compiler`.
- Build compiles with `-Werror` + `+warn_unused_vars` by default (relax via `SNMP_WARNING_AS_ERROR=false` / `WARN_UNUSED_VARS=false`), so any new warning breaks the build.
- `-Dversion=\"$(VSN)$(PRE_VSN)\"` is injected at build time; `snmpc:version`-style output depends on it.
- This directory is TRACKED (a real `Makefile`, not generated from `Makefile.in`).
- Compiler build outputs go to `../../ebin/` (`$(EBIN)`) and `../../bin/` (`$(BIN)`).

## Design Decisions
- Hand-written tokenizer (`snmpc_tok`) rather than a leex lexer — the MIB grammar needs loose/contextual lexing (case-insensitive keywords handled as reserved words, `forget_stringdata` option) that leex handles poorly.
- Strict separation between the generic parser + semantics (`snmpc`, `snmpc_lib`, `snmpc_mib_gram`, `snmpc_tok`, `snmpc_misc`) and the `.hrl` generation concern (`snmpc_mib_to_hrl`).
- MIB version (v1/v2) is decided before parsing based on the presence of `MODULE-IDENTITY`, letting a single grammar accept both SMI versions.
- The escript frontend is kept deliberately thin: it only maps CLI args to `snmpc`/`snmpc_mib_to_hrl` options, so the same logic serves `erl_compile`/`erlc`.

## Routing Table
| File | Role |
| --- | --- |
| `snmpc.erl` | Public API + driver (`compile`, `mib_to_hrl`, `is_consistent`, `init/3`, `parse/1`, `save/3`) |
| `snmpc.src` | Escript source; `%VSN%`-substituted into `../../bin/snmpc` |
| `snmpc_mib_gram.yrl` | Yecc LALR grammar for SMIv1/SMIv2 MIBs (source of the generated `snmpc_mib_gram.erl`) |
| `snmpc_lib.erl` | Semantics, OID resolution, table/group/version validation, diagnostics |
| `snmpc_mib_to_hrl.erl` | `.bin` → `.hrl` constant-file generation |
| `snmpc_misc.erl` | Small shared helpers |
| `snmpc_tok.erl` | Hand-written gen_server tokenizer |
| `snmpc.hrl` | Internal records: parser output (`pdata`) and compiler state (`cdata`, `mc_*`) |
| `snmpc_lib.hrl` | Internal verbosity/warning macros (`?vinfo`, `?vwarning`, …) |
| `snmpc_misc.hrl` | Internal macros (`?read_mib/1`, `?verify_format_version/2`) |
| `Makefile`, `modules.mk`, `depend.mk` | Build definitions and dependencies |
| `../misc/` | Sibling (read-only): shared runtime PDUs; compiled MIB `.bin`s are loaded by the agent/manager at runtime — escalate writes to parent |
| `../app/` | Sibling (read-only): application resource, `snmp_internal.hrl` included by `snmpc.erl` |
| `../../include/snmp_types.hrl` | Shared `#mib{}` record + type definitions used across the app |
| `../../bin/` | Build output dir where the generated `snmpc` escript lands |

## Test Strategy
- Compiler behaviour is exercised by `lib/snmp/test/snmp_compiler_SUITE.erl` (sibling `test/` dir — read-only; escalate writes to parent); run via `ts:run(snmp, snmp_compiler_SUITE, [batch])`.
- `lib/snmp/test/snmp_to_snmpnet_SUITE.erl` and `lib/snmp/test/test-mibs/` are also MIB-compiler consumers.
