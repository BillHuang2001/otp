# Crypto Application Documentation

## Intent
Holds the hand-written documentation sources for the `crypto` OTP application (app page, guides, release notes).
Module reference docs are NOT here — they are generated by ExDoc from `-moduledoc`/`-doc` attributes in `../src/crypto.erl` and `../src/crypto_ec_curves.erl`.

## API Surface
- `docs.exs` — ExDoc config; `extras:` lists the pages to render, in listing order: `guides/fips.md`, `guides/engine_load.md`, `guides/engine_keys.md`, `guides/algorithm_details.md`, `guides/new_api.md`, `crypto_app.md`.
- `crypto_app.md` — the application-level page (`# Crypto Application`), a `*_app.md` file built as the `crypto_app(6)` man page; covers DEPENDENCIES (OpenSSL/libcrypto versions, FIPS-capable OpenSSL, LibreSSL) and CONFIGURATION (app env `fips_mode`, `rand_cache_size`).
- `guides/fips.md` — FIPS mode guide (supported versions, usage).
- `guides/engine_load.md` — how to load an OpenSSL engine.
- `guides/engine_keys.md` — using keys stored in an OpenSSL engine.
- `guides/algorithm_details.md` — reference listing of supported ciphers/hashes/public-key algorithms and OpenSSL version/availability details (largest guide).
- `guides/new_api.md` — overview of the "new" (OTP 22+) crypto API and how it relates to the older one.
- `notes.md` — Crypto Release Notes (`# Crypto Release Notes`, one `## Crypto <vsn>` section per app version) — per-release change history.
- `Makefile` — thin doc build driver: includes `../vsn.mk` (`VSN=$(CRYPTO_VSN)`), sets `APPLICATION=crypto`, includes `$(ERL_TOP)/make/doc.mk`.

## Constraints
- The order of entries in `docs.exs` `extras:` IS significant — it controls the order pages are listed in the generated docs; add a new guide to `extras:` or it will not be published.
- Each source file carries the SPDX `%CopyrightBegin%`/`%CopyrightEnd%` header; `.md` files use the HTML-comment form (`<!-- ... -->`).
- Do not add module reference pages here; module docs live with the Erlang sources in `../src/`.

## Notes for Agents
- There is NO `doc/src/` or `doc/references/` directory in `crypto` (unlike e.g. `../../ssl/doc/src/`); do not look for module docs here.
- `notes.md` is release-notes content maintained alongside "Prepare release" commits — edit it as normal prose, it is not generated by the doc build.
- `crypto_app.md` is picked up by `make/doc.mk` via the `*_app.md` glob → man section 6.
- Guides are included as ExDoc `extras` only; they are not compiled or versioned per release.

## Dependencies
- Doc build requires `ERL_TOP` set, `$(ERL_TOP)/make/doc.mk`, ExDoc, and `../vsn.mk` for `CRYPTO_VSN`.
- Content documents linkage to `open_ssl`/OpenSSL, `public_key`, `kernel` (`app(3)`, `system_principles`) via ExDoc cross-reference syntax (`m:`, `e:`).
