# Common Test — Runtime Assets (priv)

## Intent
Static assets shipped as `lib/common_test-<vsn>/priv`: the stylesheet, JavaScript libraries, background image and the CSS/JS used to render CT's HTML logs (index, suite/testcase pages, log tables).
The CT log renderer (`../src/ct_logs.erl`, `../src/erl2html2.erl`) copies/references these files (via `code:priv_dir(common_test)`).

## API Surface
- `ct_default.css` — the default stylesheet for CT HTML logs (selected via the `ct_run -stylesheet` / `ct:run` `stylesheet` option).
- `jquery-latest.js`, `jquery-migrate.js`, `jquery.tablesorter.min.js` — JavaScript libraries enabling sorting/filtering of the log tables in the generated HTML.
- `tile1.jpg` — background image referenced from the CSS.
- `Makefile.in` → generated `Makefile` — the real build file; `Makefile` (in-tree) is a thin wrapper including `$(ERL_TOP)/make/run_make.mk`.
- `vendor.info` — SPDX metadata for the vendored third-party files (jQuery 4.0.0 MIT, jQuery Migrate 4.0.2 MIT, tablesorter 2.32 BSD-3-Clause OR GPL-2.0-only); `*.license` sidecars carry the verbatim licenses.

## Constraints
- `Makefile.in` is the source of truth: it is configured by `../configure.ac` (`AC_CONFIG_FILES([priv/$host/Makefile:priv/Makefile.in])`), so edit the `.in` file, never the generated `Makefile`.
- `release_spec` installs `*.css`, `*.js`, `tile1.jpg` (via the `CSS`/`JS`/`IMAGES` variables) into `$(RELEASE_PATH)/lib/common_test-$(VSN)/priv` on both Unix and Win32.
- Vendored JS must keep its `.license` file and `vendor.info` entry in sync (the repo license scanner checks this).

## Notes for Agents
- Dropping or renaming a file here breaks the HTML log output silently — the JS/CSS names are referenced from `ct_logs`/`erl2html2` and from the log templates.
- `priv/$host/` is generated by the top-level `./configure`; do not commit it.

## See Also
- `../src/ct_logs.erl`, `../src/erl2html2.erl` — consumers of these assets (read-only sibling).
- `../doc/assets/` — unrelated GIFs used by the *user documentation*, not by the logs.
- `../../CONTEXT.md` — the app's own directory index; the top-level `configure`/`priv` mechanism.

## Routing Table
Flat directory, no subdirectories.
- `ct_default.css`, `tile1.jpg` → log styling
- `*.js` (+ `.license`) → table sorting/filtering in HTML logs
- `Makefile.in` / `Makefile` → configure template / in-tree wrapper
- `vendor.info` → SPDX provenance for vendored JS
