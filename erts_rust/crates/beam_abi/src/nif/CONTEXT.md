# `src/nif/` — NIF host layer (contract A.3)

## Intent
The **NIF C ABI host half**: every `enif_*` function a NIF `.so` imports, the `NifHost`/`NifEnv` seam those bodies are written against, the dynamic NIF loader and the `erlang:load_nif/2` load-time validation contract — over the frozen `nif::term`/`nif::types`/`nif::api` shapes owned by the crate root (`../CONTEXT.md` → *Frozen layout table*).
The boundary's *shape* is the parent's contract; its *behaviour* is this node's.

Ground truth (read-only, never modify): `erts/emulator/beam/erl_nif.h`, `erl_nif_api_funcs.h`, `erl_drv_nif.h`, `erts/emulator/beam/erl_nif.c`, and `erts/lib_src/common/erl_printf_format.c` for the `*printf` subset (paths are repo-root relative).

## The host seam (`nif::host`) — the runtime services behind the `enif_*` layer
The *internal* boundary the `enif_*` bodies are written against (not part of the C ABI; `nif::host.rs`).
- `pub trait NifHost` — **required** `heap() -> &mut beam_alloc::Heap`, `intern_atom(&str) -> Option<Eterm>`, `atom_name(Eterm) -> Option<String>`; **defaulted** (default = unsupported): `self_pid`, `term_to_binary`, `binary_to_term`, `make_ref`, `existing_atom`, `priv_data`, `system_info`, `unique_integer`, `consume_timeslice`, `is_process_alive`, `is_port_alive`, `is_current_process_alive`, `send`, `port_command`, `whereis_pid`, `whereis_port`, `monitor_process`, `demonitor_process`, `select`, `schedule_nif`, `alloc_env`, `free_env`, `make_copy`, `dynamic_resource_call`. The ETF hooks give `beam_abi` **no** `beam_codec` edge.
- `pub struct NifEnv` — the env behind the C-facing opaque `*mut ErlNifEnv`: `new(&mut dyn NifHost)`, `host()`, `heap()`, `as_ptr()`, `unsafe from_opaque(*mut ErlNifEnv) -> Option<&mut NifEnv>`, the pending-exception slot (`pending_exception`/`set_exception`/`clear`), and a **bounded per-call atom record** (`record_atom`; read back by `recorded_atom_name`/`recorded_atom`; `MAX_RECORDED_ATOMS = 256`, first-wins dedupe) — atoms commit lazily, so `NifHost::atom_name` (committed table only) cannot see one interned earlier in the *same* call. Re-exported as `beam_abi::{NifEnv, NifHost}`. `enif_clear_env` does **not** touch the exception slot (as the C, `erl_nif.c:700-723`).
- **Thread-local current-host stack + per-call atom record:** `NifEnv::new` pushes the host and its `Rc<RefCell<Vec<(Eterm, String)>>>` record; `Drop` pops exactly its own entry (an out-of-order drop restores the enclosing host). Readers `with_current_host<R>(f) -> Option<R>` (behind env-less `enif_alloc_env`) and `current_recorded_atom_name(atom) -> Option<String>` (innermost env wins; behind every env-less name resolution). Sound: `NifEnv` is `!Clone`/`!Send` (raw host pointer, never moved across threads), and the `Rc<RefCell<…>>` record stays readable while the env is borrowed — no `unsafe`, no `&mut` aliasing.

## `enif_*` functions (`src/nif/enif/`)
Every one is `#[no_mangle] pub unsafe extern "C"` with the exact signature of its matching `nif::api` field, driving the `NifEnv`/`NifHost` seam (`beam_term`, `beam_alloc::Heap`, `NifHost::intern_atom`). By family:
- **`mem`** — libc-backed `enif_alloc`/`enif_free`/`enif_realloc`; the binary family (`enif_alloc_binary`, `enif_realloc_binary`, `enif_release_binary`, `enif_make_new_binary`, `enif_make_binary`, `enif_make_sub_binary`, `enif_inspect_binary`, `enif_inspect_iolist_as_binary`); the ETF pair `enif_term_to_binary`/`enif_binary_to_term` via `NifHost` (the C's failure `0` without the hook). Binary I/O shapes are **oracle-exact** (`erl_nif.c`, `erts_inspect_iolist_as_binary`, `erts_copy_bits_fwd`, `erts_build_sub_bitstring`):
  - `enif_inspect_iolist_as_binary` — a byte integer only in head (CAR) position, a proper list, a byte-sized binary/bitstring, or the empty list; `[]`/`nil` **succeeds** (`size = 0`, non-NULL dummy `data` = `(unsigned char*)&bin->data`, `erl_nif.c:1400`); a bare integer, a non-nil non-list tail (`[1|2]`), a non-byte integer (`256`, `-1`) or a non-byte-sized bitstring (`<<1:7>>`) are **failures → `0`** (`size = 0`, `data = -1`).
  - `enif_inspect_binary` — a bit-offset, byte-sized bitstring ok (`TAIL_BITS(size) == 0` ⇒ `1`); an unaligned start is copied by `copy_bits_fwd` and handed back **owned** (null `__spare__[0]`, freed once by `enif_release_binary`).
  - `enif_make_sub_binary` — windows **any bitstring by bits**: offset `source_bit_offset + pos*8`, span `size` bits; `size == 0` ⇒ `<<>>` for any `pos`; ≤ `ERL_ONHEAP_BITS_LIMIT` (512) bits copies into an `ErlHeapBits`, above it an `ErlSubBits` window; `badarg` only for a non-bitstring source or `pos*8 + size*8 > source_bit_size` with `size > 0` (`checked_mul`).
- **`get`** — `enif_get_int/uint/long/ulong/double/list_cell/tuple/list_length/string/string_length/atom/atom_length`; the `ERL_NIF_UTF8` arm of `enif_get_string` is **byte-faithful** to `erts_unicode_list_to_buf` (`utils.c:2862-2942`): byte budget `len-1`, char budget `len`, an incompletely fitting multibyte char dropped **whole** — `buf[written] = '\0'` + negative `-(written+1)`, else `buf[0] = '\0'` + `0`; `enif_get_string_length` agrees.
- **`make`** — `enif_make_int/uint/long/ulong/double/atom(_len)/new_atom(_len)/existing_atom(_len)/string(_len)/list_cell/reverse_list/ref/tuple_from_array/list_from_array`; the four make-atom entry points **record** each interned atom on the env, `enif_make_existing_atom(_len)` consults that record first then `NifHost::existing_atom` (else `0` with `*atom` untouched); `enif_make_ref` raises `badarg` when `NifHost::make_ref` is absent.
- **`map`** — `enif_get_map_size`, `enif_get_map_value`, `enif_make_new_map`, `enif_make_map_from_arrays`, `enif_make_map_put`, `enif_make_map_update`, `enif_make_map_remove`
- **`pred`** — `enif_is_*`, `enif_compare`, `enif_is_identical`, `enif_hash`, `enif_term_type`, `enif_term_size`. `enif_compare` is the C's `CMP` = `erts_cmp(a, b, 0, 0)` (**arithmetic** mode: `enif_compare(1, 1.0) == 0`) and orders an atom pair by **name** (`erts_cmp_atoms`, `erl_utils.h:193-215`), each name resolved *current env atom record → `NifHost::atom_name` → raw atom index* — which is what makes in-call `enif_make_atom` atoms resolvable. `enif_is_identical` = `EQ` (exact mode); `enif_hash` = PHASH2 over the term word. Atom pairs are resolved at **top level** only — see *Known gaps*.
- **`proc`** — `enif_self`, `enif_get_local_pid`, `enif_get_local_port`, `enif_set_pid_undefined`, `enif_is_pid_undefined`, `enif_get_atom_cache_index`, `enif_max_atom_cache_index`
- **`process`** — `enif_monitor_process`/`demonitor_process`/`compare_monitors`/`make_monitor_term`, `enif_is_process_alive`/`is_current_process_alive`/`is_port_alive`, `enif_send`, `enif_port_command`, `enif_whereis_pid`/`whereis_port` (0 when the `NifHost` hook is absent), `enif_schedule_nif`; all drive existing hooks, no new state. Monitor payload = the C's 3-word reference block in the 32-byte `ErlNifMonitor` (bytes 24..32 zeroed).
- **`exception`** — `enif_make_badarg`, `enif_raise_exception`, `enif_has_pending_exception`, `enif_clear_env`.
- **`threads`** — the 34 mutex/cond/rwlock/tsd/thread slots: cast-and-forward facades over `crate::sync`; only `enif_thread_type` and `enif_thread_name`/`erl_drv_thread_name` (the `*_name` accessors) do more.
- **`ioq`** — `enif_ioq_create`/`destroy`/`enq_binary`/`enqv`/`size`/`deq`/`peek`/`peek_head` + `enif_inspect_iovec`/`enif_free_iovec`; a `VecDeque` of buffers preserving the vector *count* rule (one `SysIOVec` per non-empty enqueued buffer).
- **`mapiter`** — the seven `enif_map_iterator_*` slots over the frozen 56-byte `ErlNifMapIterator`, in the map's **storage order** (`hashmap_iterator_next`). The hash arm's `ErtsDynamicWStack` is a boxed pair list; `get_pair` answers the same sequence.
- **`time`** — `enif_monotonic_time`/`enif_time_offset`/`enif_convert_time_unit`/`enif_now_time`/`enif_cpu_time`/`enif_system_info`/`enif_getenv`/`enif_make_unique_integer`/`enif_consume_timeslice`/`enif_dlopen`/`enif_dlsym`; the monotonic-time / time-offset relation is reproduced and covered by Rust unit tests in `src/nif/enif/time.rs` (`monotonic_time_is_monotone_and_unit_consistent`, `monotonic_plus_offset_is_wall_time`) — there is no `erl`-oracle pin for `enif_time_offset/1`; `enif_system_info` (no env) reaches the host via `with_current_host` and prefers `NifHost::system_info`; `enif_make_unique_integer` prefers `NifHost::unique_integer`.
- **`resources`** — the eleven slots over a crate-internal type registry + a real refcounted allocation (`enif_open_resource_type`, `_x`, `init_resource_type`, `alloc_resource`, `release_resource`, `keep_resource`, `make_resource`, `make_resource_binary`, `get_resource`, `sizeof_resource`, `dynamic_resource_call`). A resource *term* is a reference **minted here** (`make_ref`, `None`), recorded term-word → object. An exporting call (`enif_make_resource`/`enif_make_resource_binary`) takes **its own reference** as the C magic ref does, so a released-but-term-wrapped object stays alive and `enif_get_resource` keeps resolving it (oracle-verified). Deviations (no GC): that reference is never dropped, so an ever-exported object is retained (block + payload) for the process lifetime and its destructor never runs, while a never-exported object is destroyed on its last release with the destructor run **synchronously** (the C schedules it on a misc aux-work thread) — counts/ordering and the callback's environment/payload match the oracle, only the timing differs. The asynchronous form **cannot be reproduced safely** (`Send`, `*mut dyn NifHost`).
- **`select`** — `enif_select`/`enif_select_x`: the C's argument handling and return codes, handed to `NifHost::select` (the poller is `beam_io`'s); `-1` when no host can service the request.
- **`envs`** — `enif_alloc_env` (thread-local current-NIF-host → `NifHost::alloc_env()`, else `NULL`), `enif_free_env` (→ `NifHost::free_env`; `NULL` and foreign pointers are no-ops — this crate never frees memory it did not allocate), `enif_make_copy` (`NifHost::make_copy`; `THE_NON_VALUE` when unsupported), `enif_priv_data` (`priv_data`, `NifLibrary::call`, `NifHost::priv_data`). A use-after-`enif_free_env` is a caller-contract violation the raw-pointer ABI cannot detect.
- **`variadic`** — the seven C-variadic slots via the C shim (see *The C-variadic shim*). `pub fn enif_api_table() -> &'static ErlNifApi` returns the `#[used] static ENIF_API` built by the family `populate` chain from `ErlNifApi::empty()`; the `#[used]` static keeps the `#[no_mangle]` symbols in the final link.

## Dynamic loader (`src/nif/loader.rs`)
`load(path, module, host, load_info) -> Result<NifLibrary, NifLoadError>` does `dlopen(path+".so", RTLD_NOW|RTLD_LOCAL)`, `dlsym("nif_init")` (fallback `_nif_init`), validates in the oracle's exact order (the table above) and invokes `entry.load`. `NifLibrary::call(env, name, arity, args)` looks the function up by `(name, arity)`, calls `fptr(env.as_ptr(), arity, args.as_ptr())`, and turns a pending env exception into `NifCallError::Raised`; for the call's duration it publishes the library's `priv_data` on a crate-private thread-local stack with the same push/pop-token discipline as the host stack — the only source of `enif_priv_data`'s `env->mod_nif->priv_data`. `Drop` runs `entry.unload` then `dlclose`. `Reload`/`Upgrade`/`OldCode` exist for surface completeness but `load()` never produces them (no module-instance / old-code state here).

## Symbol-export mechanism (load-bearing)
A NIF `.so` leaves `enif_*` and a driver `.so` leaves `driver_*`/`erl_drv_*` **undefined**; the dynamic linker binds them, at `dlopen(RTLD_NOW)`, against the **loading process's** dynamic symbol table, so `build.rs` emits `cargo::rustc-link-arg-tests=-Wl,--export-dynamic` for each `beam_abi` test binary. Proven: `nm -D --undefined-only test_nif.so` lists the used `enif_*` as `U` and `test_driver.so` lists its `driver_*`/`erl_drv_*` as `U`; the same names appear `T` in the test binary's `.dynsym`; loading the same `.so` from a process that does **not** export them fails with `undefined symbol: enif_make_int`. The `cargo::rustc-link-arg-bins` counterpart must **not** be emitted: this package has no `[[bin]]` target and cargo hard-errors on it.

## The C-variadic shim (mechanism)
- The seven slots (`enif_make_tuple`, `enif_make_list`, `enif_set_option`, `enif_fprintf`, `enif_snprintf`, `enif_vfprintf`, `enif_vsnprintf`) live in `csrc/nif_variadic.c`.
- Rust cannot read a `va_list`, so it *drives* the extraction: for the `*printf` family the shim calls `beam_abi_enif_fmt_analyze` (a Rust format-string parser), then pulls exactly the varargs the parser reported into a flat `u64` slot array and calls `beam_abi_enif_fmt_{snprintf,fprintf}`, which render the string — parser and extractor share one grammar, so they cannot disagree.
- The supported `*printf` subset is a faithful port of `erts/lib_src/common/erl_printf_format.c`; anything outside it returns a **negative error** (`-EINVAL`), never a wrong string.
- `build.rs` emits `cargo::rustc-check-cfg=cfg(beam_abi_variadic_shim)` unconditionally (so the cfg is known on the degraded path) and sets it only when the shim compiled.

## Oracle behavior: `erlang:load_nif/2` load-time contract
Ground truth `erts/emulator/beam/erl_nif.c` (`erts_load_nif`, line 4729) — the checks validating an `ErlNifEntry` (the fields this crate declares), to be reproduced by the runtime. Verified empirically against the system OTP 29.1.1 / erts-17.1 (scratch NIF in `$TMPDIR`, read-only C).
- **Not a plain BIF.** Registered in `bif.tab:527` as `erlang:load_nif/2`; the compiler rewrites a `call_ext` to it into the loader-only instruction `i_load_nif` (`emu/ops.tab:854-865`, JIT `jit/x86/ops.tab:561-569`). The BIF body `load_nif_2` (`erl_nif.c:4643`) is only a stub rejecting `apply(erlang, load_nif, ...)`: `{error,{bad_lib,"load_nif/2 must be explicitly called from the NIF module. It cannot be called through apply/3."}}`. **No `erts_internal` variant exists.**
- **Calling module derivation** (`erl_nif.c:4764-4770`): `caller = erts_find_function_from_pc(I)` (`I` = the PC of the `i_load_nif` instruction), then `mod_atom = caller->module` — a per-code-range binary search over the module's `BeamCodeHeader` function table (`beam_ranges.c:245-305`), *not* a stack-frame scan. The module is whichever module's code contains the call site.
- **`nif_init` symbol** (`erl_nif.h:407-409`; `ERL_NIF_INIT` 422-444): dynamic NIF exports `ErlNifEntry* nif_init(void)` (fallback `_nif_init`, `erl_unix_sys_ddll.c:230-242`); `STATIC_ERLANG_NIF` uses `<module>_nif_init`. The filename argument gets `FILE_EXT` (`.so` on Linux, `erl_unix_sys_ddll.c:48`) appended by `erts_sys_ddll_open`.
- **Validation order & exact return shapes** — success is the atom `ok`; every failure is `{error,{Reason,Text}}` (built by `load_nif_error`, `erl_nif.c:4551`):

## Known gaps (honest, never a wrong result)
The driver-side gaps are `../driver/CONTEXT.md`'s; the cross-cutting ones (undeclared header names, the malformed-term guard) are `../CONTEXT.md`'s.

- **`enif_alloc_env` answers `NULL`** only with the host's `alloc_env` at its trait default, or with no `NifEnv` live (outside a NIF call). `beam_rt`'s `NifHostImpl` implements `alloc_env`/`free_env`/`make_copy` (`beam_rt/src/nif.rs`) over the one shared pooled BIF heap, so the runtime's message-env idiom works and `make_copy` is the identity (a crate-owned env would carry unusable atoms).
- **NIF host hooks the runtime does not implement.** `NifHostImpl` overrides only `heap`/`intern_atom`/`atom_name`/`self_pid`/`alloc_env`/`free_env`/`make_copy`; the rest sit at their default `None`/`false`/`null`, so the matching `enif_*` entries answer the C's failure (or raise `badarg`, for `enif_make_ref`) where the oracle succeeds — the hook list is in *The host seam*. Closing each is a `beam_rt` change: `term_to_binary`/`binary_to_term` over `beam_codec`; `make_ref`; `existing_atom` over the committed table **and** the in-flight `PendingInterner`; `whereis_pid` over the process registry; `system_info` with the real `erts_version`/`otp_release`/`scheduler_threads`/`dirty_scheduler_support` (the built-in fallback rounds the last to `0` where the C reports `1`). The `beam_abi` side is complete.
- **No scheduler threads.** `enif_thread_type` reports only `ERL_NIF_THR_UNDEFINED` (foreign thread) or `ERL_NIF_THR_OTHER` (`sync::thread_create`), never a scheduler/dirty-scheduler type; `*_name` reproduces the C's `no_name` = `"unknown"` for a **live** NULL-named handle (`sync::no_name()`/`sync::thread_created_unnamed`, driver `erl_drv_thread.c:99,135`; `enif_*` forwards `erl_nif.c:2438-2441`) and answers `NULL` for a **foreign or already-joined** tid (the C's `drv_thr == 0` path, `erl_drv_thread.c:664-684`).
- **`sync::tsd_*` passes the key straight to pthreads unchecked** (no `used_tsd_keys[]` validation); an invalid/destroyed key makes `set`/`get` a safe no-op (`NULL`) where the C aborts.
- **`enif_ioq_is_empty` does not exist in this OTP tree** (`enif_ioq_*`, `api.rs`, `ioq.rs`, `enif_inspect_iovec`, `enif_free_iovec`).
- `enif_make_map_*`/`enif_compare`/`enif_is_identical`/`enif_hash` take no env; identical terms take a raw-word fast path. `enif_compare` resolves an atom pair by **name** — a *top-level* pair through `current_recorded_atom_name`/`NifHost::atom_name`, and a pair **nested** (tuple/list/map) inside a compound through the current host's atom table (`NifHost::atom_table`, a defaulted hook). Only with no host, or a host that exposes no table, does a nested pair fall back to `beam_term`'s raw atom-index order — pinned by `tests/nif_compare.rs::a_nested_atom_pair_orders_by_name`. Exact for non-atom keys. **Cross-crate need:** `beam_rt`'s `NifHostImpl` (`erts_rust/crates/beam_rt/src/nif.rs`, which holds `Rc<beam_term::AtomTable>`) must override `NifHost::atom_table()` to return `Some(&*self.atoms)` for the runtime path to benefit.
- Integers: small ints + one-limb bignums; a wider value makes the accessor return `0`, never truncate.
- **On-heap vs off-heap refc binaries (F5-class, audited — not closable inside `beam_abi`).** `enif_alloc_binary`/`enif_make_new_binary`/`enif_make_binary` always build an **on-heap** binary (`ref_bin == NULL`, `orig_size`/`orig_bytes` only), where the oracle keeps the payload off-heap with an `ERL_REFC_BITS_SIZE` 8-word refc pair (`ERL_REFC_BITS_SIZE == 8`, `copy.c:219-242`). Measured against OTP 29.1.1 / erts-17.1: **agree** for `size ≤ ERL_ONHEAP_BINARY_LIMIT` (64 B) — 2/3/4/10 words for 0/1/10/64 B — and differ above (65 B: oracle 8 words / `flat_size` 64 vs **11 words / 88** here; the oracle's `b.ref_bin` is non-NULL at every `enif_alloc_binary` size); both are valid binaries of the same size/bytes, only the representation — and with it `enif_term_size`/`erts_debug:flat_size` — differs. Not closable here (`beam_alloc::RefcBinary`, `BinRef.val`, `beam_process`): closure touches `src/nif/host.rs`, `src/nif/enif/mem.rs`, `beam_rt`'s `impl NifHost for NifHostImpl` (`beam_rt/src/nif.rs`, `beam_rt/src/context/mod.rs:1677-1694`) and `beam_gc::OffHeap`; adjacent, `enif_release_binary` differs from the oracle only under `#ifdef DEBUG` (`erl_nif.c:1451-1461`). Pinned by the `mem.rs` unit tests and `tests/nif_bitslice.rs`/`tests/nif_subbin.rs`.

## Test Strategy
- **Per-family end-to-end tests** — each `tests/nif_*.rs` compiles a real C fixture at test time with the system `cc` against the system OTP headers and `dlopen`s it (`RTLD_NOW`) through this crate's own loader, so a single unresolved `enif_*` import fails the load; `nif_variadic.rs` is gated on `cfg(beam_abi_variadic_shim)` and `nif_threads.rs` carries the extended `*_name` matrix (`"unknown"`).
- **Oracle cross-checks that really run** (they skip loudly without `erl`/`erlc`/`cc`): `nif_threads.rs` loads the *same* fixture `.so` from the system Erlang and compares the printed tuple (`thread_type/0`); `nif_mapiter.rs`'s `the_oracle_agrees_on_the_flat_map_key_order` runs the real `erl` over `maps:from_list/1` → `maps:keys/1` and requires the fixture's C-side walk order to equal it; `nif_resource.rs`'s expected `load_status`/`roundtrip`/`roundtrip_value`/`post_release` tuples are the **measured oracle values** (OTP 29.1.1 / erts-17.1, `post_release/0` = `{1,42,0}`), and `dtor_probe/0` + `dtor_state/0` are **Rust-only** (the oracle's C `enif_release_resource(NULL)`/`enif_keep_resource(NULL)` dereference the operand and segfault); `nif_compare.rs`'s `the_same_fixture_agrees_under_the_erl_oracle` requires the Rust order points to equal the oracle's for the *same* fixture `.so`; `nif_priv_data.rs` cross-checks under `erl`/`erlc`.
- **Term-lifetime pitfall (host arena).** A NIF's result term lives on the **host arena** behind the call's `NifEnv`, readable only while that arena is alive (`tuple_size == 0`); `nif_variadic.rs`'s `Session` therefore owns the host (boxed), the loaded library and the term.
- In-module `#[cfg(test)]` unit tests: `src/nif/enif/tests.rs`, `src/nif/enif/process_tests.rs`, `src/nif/enif/mapiter_tests.rs`, `src/nif/enif/resources_tests.rs`, plus `src/nif/enif/time.rs`'s own monotonic/time-offset relations.
- `tests/nif_compare.rs::a_nested_atom_pair_orders_by_name` pins the nested-atom ordering rule (*Known gaps*).
- Gate: `../../../scripts/cargo.sh test -p beam_abi`; behavioural cross-checking against real ERTS is `erts_rust/tools/differential`'s job (sibling — read-only, escalate writes to this node).

## Notes for Agents
- `erts/emulator/beam/global.h` line ~57 holds the real `struct enif_environment_t` body — emulator-internal and **not** to be replicated: `ErlNifEnv` stays opaque here, its Rust analogue for a live call being `nif::host::NifEnv`, reached only through `as_ptr`/`from_opaque`.
- A NIF fixture must reference **only** `enif_*` slots the crate populates (`Some`), or `dlopen(RTLD_NOW)` fails on the unresolved import.
- **Term lifetime:** a term produced by a NIF lives on the host arena; keep the host (and the loaded library) alive while inspecting it, or read a use-after-free (see *Test Strategy*).
- The seven C-variadic slots need `csrc/nif_variadic.c` compiled (`build.rs` sets `cfg(beam_abi_variadic_shim)`); without a C compiler they are `None` and a `dlopen` that imports one fails loudly.
