# `beam_gc` — Per-Process Garbage Collector (Stage 4)

## Intent
Owns the **per-process collector** of the Rust ERTS rewrite: a **generational semi-space Cheney copying** collector over the per-process heap, the off-heap **refcounted large-object (MSO / refc-binary)** interface and the process **heap-size policy**.
It is **barrier-free by construction**: terms are immutable ⇒ *no term on the mature heap may refer to a term on the young heap*, so the mutator pays zero per-store overhead.
Reproduce the collector semantics of the legacy C (`../../../erts/emulator/beam/erl_gc.c` + `copy.c`) without its C structure; the design source is `../../ERTS_RUST_REWRITE_DEEPDIVE.md` §D and the Stage-4 row of §H.
Consumed by `beam_process`, which drives collections at safepoints (wave 1); it depends downward only on `beam_common`, `beam_term`, `beam_alloc` and `libc`.
Honours the crate-layer contracts of `../CONTEXT.md`: the root-set contract (no frame liveness maps), the frozen term layout (§2) and the return-based error strategy (§3).
MMTk/Boehm are **rejected**; GenImmix is a **measurement-gated** mature-generation option selected by the **measurement-derived automatic rule** (`selection.rs`) or an explicit pin.
**How it is built** — the design decisions, the collector-internal gaps, the observational-forensics rules, the handoff seams and the module-by-module routing — lives in `src/CONTEXT.md` (the implementation node).

## API Surface (the seam shape a dependent designs against)
Everything is re-exported at the crate root and via `beam_gc::prelude::*`.
**The rustdoc in `src/` is authoritative for every signature and its full contract** — this section gives names and the one-line semantic contract only.
- `space.rs` — `HeapSpace` (one copying semi-space over `beam_alloc::Heap`; `contains`/`contains_term`/`reset`/`base`/`top`/`limit`, capacity/used/available words; it **never reallocates**) and `FromSet` (the from-space ranges of one collection, kept sorted by `lo` so a per-reference `contains` is one binary search).
- `copy.rs` — the Cheney copy engine: `Copier` (`new`/`forward_roots`/`complete`/`run`) and `collect(from, to, roots)`; the `pub(crate)` evacuation primitives (`Target`, `EvacDest`, `forward_slot`, `move_size`, `for_each_ref`) are shared with `immix/`, the promotion driver and `live.rs`.
- `collector.rs` — `CollectionKind { Minor, Major }`, `Collection { kind, stats }`, and `Collector` (the young nursery **chain** + a mature `HeapSpace` + the `HeapPolicy`): `should_collect(need)` (occupancy-only), `collection_debt()`, `collect`/`collect_minor`/`collect_major`/`collect_kind(kind, roots)`, `ensure_capacity`/`grow_nursery`, `young`/`young_mut`/`mature`, `young_contains(ptr)`/`young_space_count()`, `stats`/`minor_gcs`, `for_each_reachable_object`/`…_view`, `scanned_bounds()`, `impl HeapObservable`.
  `collect` picks minor vs major and escalates a would-not-fit minor; `collect_kind` runs exactly the kind it is given and **never escalates**; a capacity pre-check returns the typed `heap_exhausted` *before* any copy.
- `live.rs` — the `pub(crate)` **exact-live counter** (`live`, `live_full`, `Live { words, lines }`): counts the exactly reachable from-set graph without mutating it, so a fullsweep can size itself from it.
- `reachable.rs` — `ReachableObject` (the public safe view: `header()`/`words()`/`word(i)`/`len()`/`address()`) over the `pub(crate)` read-only whole-heap walk (each reachable boxed object once, cons cells traversed but not reported, no forwarding marker).
- `immix/mod.rs` + `immix/collect.rs` — `ImmixSpace`: a line/block mark-region mature generation (`LINE_WORDS` 16, `LINES_PER_BLOCK` 16, `BLOCK_WORDS` 256), line-granular `alloc_words`, `mark`/`collect`, the `release_*` rollback primitives, `ImmixStats`/`ImmixCounters`, and its `EvacDest` impl.
- `immix_collector.rs` (+ `immix_collector/promote.rs`) — `GenImmixCollector`: the same copying nursery paired with an `ImmixSpace` mature and the same call set, plus `last_immix_stats()`; its minor promotes through the **atomic** two-phase driver in `promote.rs` (`promote`, `PromoteOutcome`).
- `any_collector.rs` — `AnyCollector { Copying, Immix }`: a **complete drop-in for the concrete `Collector`** (whole call set incl. `collect_kind`), `new`/`from_config`/`kind`/`mature_choice`/`heap_info`, plus mature **geometry accessors** (`mature_base`/`mature_capacity_words`/`mature_used_words`/`mature_available_words`/`mature_contains`) because the two mature spaces are differently typed. Forwarding only.
- `config.rs` + `selection.rs` — the mature-generation decision: `GcConfig { policy, selection }` (`new`/`auto`/`copying`/`immix`/`growable`/`with_selection`/`with_mature`/`mature()`/`mature_choice()`), `MatureKind`, `MatureSelection { Auto, Explicit }`, `MatureSource`, `MatureChoice`, and the rule itself — `IMMIX_BREAK_EVEN_WORDS = 8 * BLOCK_WORDS` (2048), `IMMIX_BREAK_EVEN_BLOCKS`, `select_mature`, `mature_words_of`, `resolve_mature`, `choice_for`.
- `policy.rs` — `HeapPolicy`: `min_heap_words`, `max_heap_words` (0 = unbounded), `fullsweep_after` (65535), `min_bin_vheap_words` (46422 = the C `BIN_VH_MIN_SIZE`), `initial_young_words` (233), `initial_mature_words`, `need_reserve_words`; `default`/`from_min_max`/`unbounded`/builder, `from_spawn_opts`, `fullsweep_due`, the sizing rules (`next_words`, `size_after_fullsweep`, `mature_after_fullsweep`, `young_after_collection`, `young_after_fullsweep`, `should_grow`, `should_shrink`), `DEFAULT_MIN_HEAP_WORDS`, `heap_sizes()`, `next_heap_size`.
- `heap_info.rs` — `HeapInfo { minor_gcs, fullsweep_after, min_heap_size, min_bin_vheap_size, max_heap_size, heap_size, total_heap_size }` — the `erlang:process_info(Pid, garbage_collection)` item (`new`, `values()`, `items()`, `of(&collector)`); `HeapObservable` — `minor_gcs`/`heap_size_words`/`total_heap_size_words` (the **capacity** pair), `heap_used_words`/`total_heap_used_words` (the **occupancy** pair — chain-summed, so a space a `grow_nursery` retired keeps counting), `heap_policy`, implemented by `Collector`, `GenImmixCollector` and `AnyCollector`.
  `GARBAGE_COLLECTION_KEYS` — the oracle's key order (`max_heap_size`, `min_bin_vheap_size`, `min_heap_size`, `fullsweep_after`, `minor_gcs`), defaults `0`/`46422`/`233`/`65535`.
  `heap_size` = the nursery capacity (C `HEAP_SIZE`); `total_heap_size` = nursery + mature capacity (C `heap_sz + old heap`); the message buffer is `beam_message`'s.
  The runtime surfaces these itself — `beam_rt` builds `HeapInfo` directly (`HeapInfo::new` and `HeapObservable`) for `erlang:process_info(Pid, garbage_collection)` and `system_info(garbage_collection)`, in `GARBAGE_COLLECTION_KEYS` order (`beam_rt/src/native/memory/mod.rs`, `src/info/memory.rs`); `AnyCollector::heap_info()` itself is called only from tests — this module is the memory-accounting consumer's source of truth.
- `footprint.rs` — `HeapFootprint` (the one-call per-process account): `of(&collector, &off_heap)`, `capacity_words`/`used_words`/`capacity_bytes`/`used_bytes`, `heap_bytes` (**allocator-visible** = reserved capacity + live off-heap payload) and `total_bytes` (that + the off-heap roster's reserved slot array, which no allocator type records); module const `WORD_BYTES`. The `//!` doc states the three-way split (reserved capacity · live payload, **already counted by `erlang:memory(binary)`** — never add it to `processes` on top of `binary` · the roster array), and that it is a reserved-capacity + payload account, not an RSS estimate: no mailbox/queue bytes, no carrier retention beyond live payload, no runtime text/data. `tests/heap_accounting.rs` pins it (the `heap_bytes() <= Σ live_bytes` invariant is the honesty gate).
- `mso.rs` — `RefCount` (**re-exported** from `beam_alloc`, the workspace's single `erts_refc_*` primitive), `Mso`/`MsoHandle` (an off-heap immutable refcounted payload and its clonable owning handle), `OffHeapEntry { Mso, Binary }` (`overhead_bytes`/`apparent_size`/`as_mso`/`as_binary`) and `OffHeap` — the per-process list (`MSO(p)`), **slot-stable for its whole lifetime**: `push`, `insert -> slot`, `get`, `iter`, `len`/`is_empty`/`overhead_bytes`, the retained-array accessors `slot_count`/`slot_bytes` (the reserved slot array itself — retained footprint neither `overhead_bytes` nor any `beam_alloc` type reports), and `sweep(is_live) -> usize` releasing dead entries in place (never shifting, reordering, compacting or reusing a slot).
- `offheap.rs` — the **off-heap reclaim half** (the C `sweep_off_heap`): `for_each_reachable_binary_payload(collector, roots, visit)` (the read-only walk reporting the payload pointer of every reachable `BinRef`) and `sweep_unreachable_binaries(&mut OffHeap, collector, roots) -> Result<usize>` (drops every `OffHeapEntry::Binary` no reachable `BinRef` names, keeps every `Mso`, slot-stable, releases nothing on a walk error).
- `bin_vheap.rs` — the **trigger half** (the C `bin_vheap_sz`): `BinVheap { limit_words }` with `new(&HeapPolicy)` (floored at `min_bin_vheap_words`), `limit_words()`, `triggered(overhead_words)` (the C's strict `off_heap.overhead > bin_vheap_sz`), `triggered_for(&OffHeap)` and `record_collection(&HeapPolicy, surviving_overhead_words)` (the C `next_vheap_size` grow-at-1.618 / halve / hold rule).
  **An off-heap refc-binary roster is reclaimed by reachability (`offheap.rs`, the C `sweep_off_heap`) and triggered by the binary-virtual-heap rule (`bin_vheap.rs`, the C `ERTS_IS_GC_DESIRED_INTERNAL` `off_heap.overhead > bin_vheap_sz` clause)** — the two halves together are what make an off-heap-building loop flat in the number of calls; the roster's owner performs the adoption (`src/CONTEXT.md`).
- `bounds.rs` — `ScannedBounds`: the covering interval of **every** live scanned region of a collector plus a monotone geometry epoch (`new`/`at`, `EMPTY`, `base`/`limit`/`generation`/`is_empty`, `may_contain`, `definitely_unscanned`, `span_words`); a **fast-REJECT filter, never a containment claim** (a false `may_contain` is harmless, a false reject would be a memory-safety bug), built from each space's **reserved** extent so a cached value cannot go stale, and consumed by `beam_rt`'s unscanned-root valve.
- `stats.rs` / `error.rs` — `GcStats { words_copied, words_reclaimed, objects_copied, minor_collections, major_collections }`; `error.rs` holds `pub(crate)` allocation-failure constructors only (no crate-local error enum).

## Constraints
- **Errors:** `beam_common::{Result, BeamError}` only.
  Heap exhaustion while copying a term is `BeamError::Alloc(AllocFailure::new(AllocKind::Heap, bytes))` — never panic, never a crate-local error enum, never `unwrap()` on runtime data.
  `beam_term::TermError` is reconciled to `BeamError` upstream, so `?` crosses the boundary.
- **`unsafe` confinement:** production `unsafe` lives only in the word-level code — `copy.rs` (the Cheney copier), `immix_collector*` (the promotion driver), `reachable.rs` (the read-only whole-heap walk and its one-bit-per-word visited set), `live.rs` (the exact-live counter), `immix/` (the mark-region mark/evacuation walks) and the two narrow `NonNull`-deref / `Box::from_raw` blocks in `mso.rs`.
  Every `unsafe fn` carries a `# Safety` section and every `unsafe` block a preceding `// SAFETY:` rationale; `unsafe_op_in_unsafe_fn` stays clean.
  `space.rs`, `policy.rs`, `heap_info.rs`, `footprint.rs`, `stats.rs`, `bounds.rs`, `config.rs`, `offheap.rs`, `bin_vheap.rs` and the `Collector`/`GenImmixCollector`/`AnyCollector` driving logic are safe Rust.
- **Do NOT modify `beam_term` or `beam_alloc`** — build on their public APIs only.
  Do not touch `../../../erts/` (read-only ground truth) or `../../tools/`.
- **Never break the frozen term layout or the barrier-free invariant** (a minor must not leave a mature→young pointer).
- Files target ~1000 lines; split by responsibility.
- Licensing Apache-2.0; deps `beam_common`, `beam_term`, `beam_alloc`, `libc` only.

## Measured
Every figure, table and caveat is in **`MEASURED.md`**; this section keeps only the load-bearing headlines and the section to read them in.
- The `gc_bound/churn` shape allocates **806 words/op** against **2.00 collections/op** in-crate (1.50 minor + 0.50 major) and 7.00 on the real runtime at a 376-word nursery, copies **1 269 words/op = 1.58×** the allocated volume, and never hands out ≈0.70 of every admitted young word — `MEASURED.md`, "Per-op attribution of the `gc_bound/churn` shape".
- A `perf` profile of that shape puts this crate's copy loop at **4.2 %** of samples (interpreter 20 %, libc malloc/free/memmove 15 %), so the dominant terms are the interpreted recursion and `beam_bifs`' `Vec` churn, not the copy loop (Handoffs in `src/CONTEXT.md`) — same section.
- The two-step post-fullsweep nursery sizing eliminates the per-op space install (growths/op **1.0004 → 0.0004**) and cuts the collection count a third (**2.000 → 1.500/op**), at a mildly higher copy volume (1 269.5 → 1 283.5 words/op) — paired A/B ratios **0.964 / 0.960 / 0.929**, with the `perf stat -e task-clock` pass the stable signal on this perturbed host — `MEASURED.md`, "Post-fullsweep nursery sizing (the `gc_bound/churn` win)".
- Against the **oracle** at a matched heap policy (`+hms 233`, the C `H_DEFAULT_SIZE`), the minor count grows linearly with the loop count at **2.5×** the oracle's per-op slope on a small live set and **18×** on a live-set-protected one, at `total_heap_size` **4 039** vs **3 286** words — so the two-step rule **cuts footprint and makes the capacity track the live set**; it does **not** realign the cadence, which is dominated by fullsweep frequency and by the nursery size the heap policy installs (`beam_rt`'s `DEFAULT_HEAP_WORDS` sizes only its term-construction heaps, never a process nursery) — `MEASURED.md`, "The cadence against the oracle with a matched heap policy".
- Folding the young heap's occupancy into the fullsweep's size request is what makes the mature generation reachable at the default policy: the copying default runs **147 minors : 73 fullsweeps** — `MEASURED.md`, "The mature-generation room policy (generational cadence)".
- GenImmix wins **copy work on long-lived data** but pays footprint and pause on the small-heap/high-churn shape, so **`MatureKind::Copying` remains the default**; Immix is auto-selected at ≥ `IMMIX_BREAK_EVEN_WORDS` (2048, from the construction-time `initial_mature_words`) or by an explicit pin (`BEAM_RT_GC_STRATEGY=immix`) — `MEASURED.md`, "The long-lived break-even sweep" and "The two-axis selection curve".
- Under a fixed demand both capacities converge: nursery/mature **233/376** for Copying and **233/512** for Immix — `MEASURED.md`, "Heap-sizing measurements" (`tests/steady_state.rs`).
- Off-heap retention is measured as a **counter** contract, never a clock: with the trigger + the reachability sweep, `binary` live bytes and the roster length are identical at N = 500 and N = 1000 (flat in N), while the same loop with the sweep omitted retains one 64 KiB payload and one roster entry per call — `MEASURED.md`, the off-heap retention section, and `tests/offheap_retention.rs`.

## Test Strategy
- Per-crate in-module `#[cfg(test)]` unit tests plus a `tests/` integration suite; **each integration file's `//!` module doc states the contract it pins and why**.
- The suite is organised around six invariants (exact copy correctness per term shape; generations/cadence/sizing; the nursery chain; the aggregate scanned bounds; Immix; off-heap reclaim), plus cross-cutting adversarial coverage — the detail, per-file map and the mutation-verified cases live in `src/CONTEXT.md`.
- Gate (GREEN required): `erts_rust/scripts/cargo.sh test --manifest-path erts_rust/Cargo.toml -p beam_gc` and `erts_rust/scripts/cargo.sh build --manifest-path erts_rust/Cargo.toml --workspace`.
- Cross-checks against the real system ERTS belong to `../tools/differential/`, not here.
