# `beam_bifs` — BIF Registry (`bif.tab` Surface) & Implementations

## Intent
Owns the **Built-In Function layer** (Stage 5, Part II §H): the `(module, function, arity)` → implementation registry
plus the curated BIF surface. Contract **Part I §A.7** — names/modules/arities reproduce
`../../erts/emulator/beam/bif.tab`; none is invented. `beam_rt` adapts `BifRegistry` into the engine's
`ExecutionContext::call_bif(module, function, arity, args) -> Result<Eterm>` seam (`../beam_engine/CONTEXT.md`).
Failure is **return-based** (`../CONTEXT.md` §3): `BadArg`/`BadArith`/`BadArity`/`SystemLimit`, plus `BeamError::Raise`
for `error`/`exit`/`throw`/`nif_error`/`undef`/`unsupported_bif`, which the engine turns into a BEAM raise (exception
tag in `x(0)`) — no `setjmp`/`longjmp`. **A typed error always beats a wrong result**: a shape that cannot be derived
faithfully returns the typed gap, never a fabricated value. Ground truth (read-only):
`../../erts/emulator/beam/` (files in the Routing Table), `../../erts/emulator/sys/common/erl_float_short.cpp`, and the
stdlib sources `erlang.erl`/`erts_internal.erl`/`ets.erl`/`lists.erl`/`maps.erl`/`io_lib*.erl`/`unicode.erl`/`string.erl`.

## API Surface (FROZEN — `beam_rt` and tests design against this; additive-only changes)
Root + `beam_bifs::prelude::*`: `BifRegistry`/`BifFn`/`default_registry`; `BifContext` + its fifteen seams;
`RecordDefinitionView`/`RecordFieldView`; `StdoutSink`/`NullSink`/`BytesSink`; `NifLoadError`;
`raise_error`/`raise_exit`/`raise_throw`; `exit_reason_from_term`/`reason_term_from_exit_reason`; `TableRegistry`; the
`hook_sets.rs` tables + `needs_*` predicates. `beam_bifs::bif_tab` is **not** in the prelude (validation tooling).
- **`registry.rs`** — `BifFn = fn(&mut BifContext<'_>, &[Eterm]) -> Result<Eterm>`; `BifRegistry` (nested `module → function → [(arity, BifFn)]` maps, so `lookup`/`contains` are allocation-free); `with_core_bifs()` (the 648-key roster) = `default_registry()`; `register(...)` (replaces on repeat); `call(...)` (unknown key ⇒ `error::undefined_bif`; wrong arg count ⇒ `BadArity`). Operator BIFs keep their *quoted* `bif.tab` names (`"+"`, `"=<"`, `"=:="`, `"!"`, `"++"`, `"not"`, …); the per-module `pub(crate) fn register` calls run in a fixed order (`ets` wiring `ets::{matches,specs,extra,adopt,nav,reverse}`; `runtime` last).
- **`context.rs`** — `BifContext<'a>`, the single per-call context: `heap`/`atoms`/`self_pid`/`current_module`, one optional slot per seam (a `with_<seam>()` builder + accessor), the constructors `int`/`atom`/`intern_atom`/`boolean`/`ok`/`make_float`/`tuple`/`cons`/`list`, `pub(crate) atom_and_heap` (the one route that borrows the table *and* the destination heap at once), the `ProcessInfoItem` enum and the `OutputSink` impls.
- **The fifteen optional seams:** `OutputSink` (`write_str`); `SendHook` (`send`); `AtomInterner` (`intern`); `FunCaller` (`call_fun` + the **defaulted** `call_fun_with_tables(fun, args, tables: Option<&mut TableRegistry>)`); `PortHook` (`open_port`/`close_port`/`port_info`); `DictHook` (`put`/`get`/`erase`/`get_keys`/`get_keys_for_value` + defaulted `get_all`/`erase_all`); `PersistentTerm` (`get`/`put`/`erase`/`get_all`/`info`); `NifLoader` (`load_nif`); `RecordSource` (`record_definition`); `LocalNode` (`local_node` + the **defaulted** `local_node_hash(&mut self) -> Option<u32>`, used by `term_to_binary(T,[local])`/`erlang:external_size(T,[local])`); `LocalFunIdentity` (`local_fun_identity`); `ModuleInfo` (`module_info`); `ProcessHook` (`whereis`/`register`/`unregister`/`registered`/`is_process_alive`/`processes`/`ports`/`process_info_keys`/`process_info_item`/`process_flag`/`group_leader`); `MemoryHook` (`memory`); `RuntimeHooks` (`call`).
- **Every hook is defaulted:** with none installed the BIF answers the typed `unsupported_bif` gap (or a documented `Ok(None)`/fallback for a value-returning seam) — **never** a fabricated empty list, `undefined`, `false`, zero or made-up count. Unset defaults: stdout for `io:format`; `unsupported_bif` for `send/2`/`"!"/2`/`send/3`, the port/dict/`PersistentTerm`/`ProcessHook`/`ModuleInfo` BIFs, `load_nif/2` and the fun-taking `lists`/`maps` BIFs **for a valid fun** (an invalid fun is rejected by the clause guard first); `TermNotFound` for a new-atom BIF; `Ok(None)` for `record_definition`/`local_fun_identity`/`module_info`/`local_node_hash`; `(nonode@nohost, 0)` for `local_node`, else `None`.
- **`hook_sets.rs`** is the one authoritative home of the *seam-consumer* key sets: a `&'static` table per seam + an allocation-free `needs_*` predicate, re-exported at the root and in the prelude, `contains`-checked against the live registry. Sizes: `MEMORY_HOOK_BIFS` 2, `LOCAL_FUN_IDENTITY_BIFS` 4, `DICT_HOOK_BIFS` 7, `PROCESS_HOOK_BIFS` 11, `PORT_HOOK_BIFS` 4, `SEND_HOOK_BIFS` 3, `NIF_LOADER_BIFS` 1, `RECORD_SOURCE_BIFS` 1, `MODULE_INFO_BIFS` 2, `PERSISTENT_TERM_BIFS` 7, `FUN_CALLER_BIFS` 24, `LOCAL_NODE_BIFS` 6, `RUNTIME_HOOKS_BIFS` **172** (asserted *equal* to `runtime::register`'s seam roster) — the 13 tables total **244** keys, dedup union **240**; the module doc's per-row counts *and* its aggregate are pinned by `the_module_doc_table_counts_match_the_tables`. `AtomInterner` deliberately has **no** table (its consumer set is unbounded). A host gates its seams through these, never a private copy.
- **`error.rs`** — `pub(crate)` `badarg`/`badarith`/`badarity`/`system_limit`/`undefined_bif`/`unsupported_bif`/`function_clause`; public `raise_error`/`raise_exit`/`raise_throw` over `beam_common::{Raise, ExitReason, ExceptionClass}`; `raise_term`/`raise_error_term` set `reason = ExitReason::Structured` with the term in the opaque `Raise::with_live_reason`/`LiveReason` slot (`as_atom()` stays `None`); `structured_error` builds `{Tag, Elements…}`, degrading to plain `badarg()` when `tag` cannot be interned.
- **`reason.rs`** — `exit_reason_from_term(term, &AtomTable) -> ExitReason` (`normal`/`shutdown`/`noproc`/`noconnection`/`killed`/`aborted` ⇒ their variants, any other atom ⇒ `Atom(name)`, non-atom/unknown ⇒ `Structured`); `reason_term_from_exit_reason` rejects `Structured` with `BadArg`; the `error/1,2,3`, `exit/1`, `throw/1`, `nif_error/1,2` BIFs run their argument through it — an **atom** reason keeps its exact `ExitReason` with **no** live slot, a **non-atom** one is `Structured` carrying the term.

## Per-module contracts
One entry per module: what it registers plus its oracle-verified traps. Algorithm detail lives in the module's rustdoc
and, for the sub-nodes (`src/ets/`, `src/re/`, `src/packet/`, `src/runtime/`, `src/unicode/`), in that node's `CONTEXT.md`.
### `re` (`src/re/`) — the 8 `re:*` BIFs, served for real
All 8 declared keys (`version/0`, `compile/1,2`, `run/2,3`, `internal_run/4`, `inspect/2`, `import/1`) are real `BifFn`s (`src/runtime/other.rs` calls `crate::re::register`). Self-contained safe-Rust engine, **no third-party regex crate**, no `unsafe`; the compiled pattern's element 5 is our own versioned image, never PCRE2's `#Ref<…>`. `{newline,crlf}` is positional (only `\r\n`); `{newline,none}` is `badarg`. Contract + gaps: `./src/re/CONTEXT.md`.
### `records` (native records, `records.rs`) — 8 BIFs
OTP-29 native records; frozen interior `beam_term::record`; ground truth `erl_record.c`. `create/4`'s cached definition word is the real `beam_term::hashing::compute_record_definition_hash` (recomputed, not read, so `phash2` is unaffected). `update/4` takes a flat **or** HAMT map, accepts `'_'` as the module/name wildcard, returns the record unchanged for an empty map, and requires every key to name an existing field (`=:=`) in declaration order. `get_definition/2` needs `RecordSource` ⇒ `{#{is_exported => B}, Fields}` (no hook ⇒ `badarg`); `is_record/2` is true for a tuple **or** a native record; structured reasons carry their term (`{badrecord,T}`, `{badfield,{{M,N},K}}`, `{badmap,M}`).
### Maps (`maps.rs`) — both representations, no pair-count ceiling
Flat (≤ `MAP_SMALL_MAP_LIMIT` = 32 distinct keys) **and** HAMT above it, both `beam_term::map`; every reader (`map_get/2`/`map_size/1`/`is_map_key/2`, the `maps:*` BIFs, the printers, `records:update/4`) and every producer handles either. The writer matches ERTS (≤32 ⇒ flat in `erts_cmp_flatmap_keys` order, else a HAMT keyed by `erts_map_hash`), duplicates last-wins; key identity is exact (`=:=`), pair order is the *stored* order, a missing key / non-map raises `{badkey,K}`/`{badmap,M}`. `maps:with/2`/`without/2` classify both arguments together (`error_type(M)`: the MAP alone decides — non-list Keys ⇒ `badarg`, improper Keys ⇒ bare `function_clause`). The fun-taking fast paths (`map/2`/`fold/3`/`filter/2`/`foreach/2`) and `to_list/1` accept a **map *or* a `maps` iterator** — `maps:iterator/1,2`'s `[Path|Map]`, a `maps:next/1` `{K,V,Iter}` look-ahead, or the atom `none` (but not `[]`) — through the one `walk_map_or_iter`, which applies the fun for pair *i* **before** the `next/1` that yields pair *i+1* (`maps.erl:948`) and reports any `next/1` failure as the structured `{badmap, <original argument>}`; `maps:iterator/2`, `filtermap/2`, `update_with/3,4` and `merge_with/3` are deliberately unregistered (served by the real `maps.beam`). Deviation: the HAMT `iterator/1`/`next/1` chunking differs from the C's reducer-count-driven chunking (identical `{K,V,Next}` sequence).
### Exact integer arithmetic (`arith.rs`), the bit operators, `lists:sum/1`
`+ - * div rem abs` and unary `-`/`+` are arbitrary-precision (an out-of-60-bit result becomes a heap bignum via the **safe** `beam_codec::term::make_big`); `div`/`rem` are Knuth D; `add_terms` is shared with `lists:sum/1`, and `int_from_mag`/`int_from_i64`/`int_from_f64` are the single promotion path for every integer-producing BIF. The bit operators are **integer-only** (`1 band 1.0` ⇒ `badarith`), two's-complement arbitrary-precision, and a negative count flips `bsl`⇄`bsr` (`8 bsl -2` ⇒ `2`); `bnot(A)` = `-A-1`. Cap `BIG_ARITY_MAX = (1<<16)-1` limbs = 4_194_240 bits ⇒ `system_limit`, an oversized left shift rejected before allocation.
### `math` (24 keys) / the strict booleans (`bool.rs`)
`math` are real BIFs over `f64` (coercion exactly as C `math_call_1`; a post-call domain error or overflow ⇒ `badarith`, never a wrong float); `atanh/1` is bit-exact, `erf`/`erfc` approximate. `bool`: `not/1`/`and/2`/`or/2`/`xor/2` are strict (`true`/`false` only, else `badarg`); `andalso`/`orelse` are **not** BIFs (the compiler lowers them to jumps).
### `erlang:phash/2` + `phash2/1,2` (`compare.rs` — thin adapters)
The hashes are the LCA's compatibility-pinned `beam_term::hashing::{make_hash, make_hash2}` (transcriptions of `erl_term_hashing.c`) — never re-implemented here; these BIFs only build the `Range` and reduce (`phash/2` = `1 + hash % Range`, `phash2/1` = `hash & 0x07FF_FFFF`, `phash2/2` = `hash % Range`; `Range = 0` ⇒ `hash + 1` / the whole hash; a non-integer/negative/`>0xFFFF_FFFF` Range is `badarg`). Every `TermError` maps to the typed `unsupported_bif`, never a `?`-collapsed `badarg`. Goldens: `tests/phash.rs`.
### List operators (`lists.rs`)
`'++'/2` requires a **proper-list LEFT operand** and uses the RIGHT operand **verbatim with no check** (`[1,2] ++ x` ⇒ `[1,2|x]` — an intentional bug-compatibility); `'--'/2` removes from the left the first remaining occurrence of each right element by **exact `=:=`**. The 45 registered keys = 5 declared + 40 `lists.erl` fast paths. Comparison order is per function, pinned to the oracle: exact (`eq`) for `member/2`/`delete/2`/`keymember/3`/`keysearch/3`/`'--'/2`, arithmetic (`cmp_arith`) for `keyfind/3`/`sort/1`/`usort/1`/`keysort/2`/`max/1`/`min/1`. `sort/2`/`usort/2`/`mapfoldl/3`/`mapfoldr/3` are faithful `lists.erl` ports over `BifContext::call_fun`, so a degenerate comparator reproduces the oracle's reversal (`lists:sort(fun(_,_) -> false end, [1,2,3])` ⇒ `[3,2,1]`, strict-key ties descending) and a non-2-tuple fun result raises `{badmatch, Value}`.
### iolist / bitstring BIFs (`binary.rs`)
`iolist_to_binary/1`/`iolist_size/1` are the Unit-8 walk, `list_to_bitstring/1` the Unit-1 walk; `split_binary/2` is the position-based split (`{Before,After}`), distinct from the pattern-based `binary:split/2,3`. `binary:compile_pattern/1` mirrors `maybe_binary_match_compile`: a non-empty byte-aligned binary (or list of them) in a module-local process-global registry, the handle an on-heap `Ref` thing; 1 "word" ⇒ `{bm,Ref}`, more ⇒ `{ac,Ref}`, and there is **no** `am` tag. Any other argument (an integer, an empty list/binary, an improper list, a non-binary element) is `badarg`.
### `erlang:convert_time_unit/3` (`time.rs`) — a stdlib fast path, not a `bif.tab` entry
The oracle implements it as Erlang code (`../../erts/preloaded/src/erlang.erl:5338-5384`), so it is registered here like the sibling `erlang:memory/0,1`; it is what closes `timer:tc/1,2,3,4`. Body `TU * Time div FU` after an identity arm (`FU =:= TU` and an integer `Time` ⇒ `Time` unchanged, bignum included); `native`/`perf_counter` resolve to `1_000_000_000`, every other atom to its units-per-second ratio (`UnitRatio::Small`), a positive integer unit to `UnitRatio::Big`; a negative `Time` uses the C floor `(TU * Time - (FU - 1)) div FU`. Bignum ratios re-enter the **registered** `'*'/2`/`'-'/2`/`'div'/2` (`big_ratio_conversion`/`big_ratio_chain`). `erlang.erl` wraps the body in `try … catch _:_ -> error_with_info(badarg, …)`, so **every** failure (an unknown unit atom, a zero/negative unit, a non-atom non-integer unit, a non-integer `Time`, a product past the bignum cap — `trap_arith_class`) is `badarg`.
### `zlib` (`src/zlib.rs`, `src/deflate.rs`) — the six self-contained fast paths
`zlib` is preloaded and its stream interface (`open`/`deflateInit`/`inflate`/`close`, `*_init`/`*_reset`) is `erlang:nif_error(undef)` stubs for the statically linked `erl_zlib.c` NIF this runtime does not carry, so six self-contained functions are registered instead — none a `bif.tab` entry. All six take iodata (a bare integer, an atom, an element outside `0..=255` and a non-byte-aligned bitstring are all `badarg`). `compress/1` emits one RFC 1950 stream (header + deflate + Adler-32) at `DEFAULT_COMPRESSION_LEVEL` = 6 over `beam_codec::compress` (**no new dependency edge**); `uncompress/1` needs ≥ `MIN_UNCOMPRESS_LENGTH` = 8 bytes and every other failure is `data_error`, never `badarg`; it inflates through `decompress_bounded` with the DEFLATE format's own `MAX_DEFLATE_EXPANSION` = 1032:1 bound. `zip/1`/`unzip/1` are the **raw DEFLATE (RFC 1951)** pair (*not* gzip: `zlib.erl` opens them with `-MAX_WBITS`), `unzip/1` the safe-Rust decoder in `src/deflate.rs`; `gzip/1`/`gunzip/1` are the **RFC 1952** pair (fixed 10-byte header + raw DEFLATE + LE CRC-32 + LE ISIZE), and `gunzip/1` validates the header (reserved `FLG` bits, `FEXTRA`/`FNAME`/`FCOMMENT`, `FHCRC`), verifies both trailers and loops so concatenated members concatenate. Every malformed input is the bare-atom `error:data_error`; `badarg` only for non-iodata; `unzip/1` is the one function with a `MAX_UNCOMPRESSED` (32 MiB) ceiling, and the CRC-32 is `checksum.rs`'s `crc32_step`.
**Divergence:** the deflate payload is miniz_oxide's, so byte identity with the oracle's stream is **not** promised — `compress/1` is byte-identical for short bodies but diverges in **size/block choice** on repetitive bodies (the oracle's zlib emits a fixed-Huffman block where miniz_oxide emits a dynamic one); not closable without a zlib-exact encoder (a new dependency). No `unsafe`.

### `erlang:raise/3`'s stacktrace forwarding (`convert.rs`)
`raise(Class, Reason, Stacktrace)` **decodes** its valid 3rd argument into the returned raise's `beam_common::StackTrace` (beside the `is_stacktrace` validity predicate the returned-`badarg` gate uses), and the engine renders a non-empty supplied trace **verbatim** in place of its own raise-snapshot trace (`beam_engine`'s supplied-frame latch) — together they reproduce the oracle's `build_stacktrace`.
The mapping: `{Module,Function,Arity[,Location]}` → `StackFrame`, with `Module`/`Function` atoms read from the shared table by **name**, the 3rd element the `arity: u8` only when it is an integer in `0..=255`, an absent 4th element or `[]` a `location: None`, and `Location` exactly `[{file,FileNameCharList},{line,N}]` in that order (a char list of Unicode scalar values; `N` in `0..=u32::MAX`); `[]` decodes to the **empty** `StackTrace`, leaving the latch unarmed.
The reason handling is the orthogonal `reason.rs` rule above (both arms additionally carry the decoded frames).
**Never fabricated.** A trace element the oracle echoes verbatim but a `StackFrame` cannot express — an `erl_eval`-style `{Fun,Args}`/`{Fun,Args,Location}` call frame, a 3rd element that is an argument list or any other non-`0..=255` value, an unnameable `Module`/`Function` atom, or a location not exactly the shape above — is the typed `unsupported_bif` **raise**, never the returned `badarg` (the argument is valid, so it is a capability gap).
The returned-`badarg` cases are untouched: a bad class, a non-list/improper/non-frame trace, or a location that is not a list.
### The port BIFs (`port.rs`) and the `PortHook` seam
A port is OS process + driver + port-table slot (Stage-5 machinery, never a BIF), so every port *operation* routes
through the optional `PortHook` — `unsupported_bif` with none. `port_close/1` returns `true` (never `ok`); `port_info/1`
emits the oracle's seven items in order and `port_info/2` returns `{Item,Value}` or `badarg` for an unknown item;
`open_port/2` forwards `Name`/`Options` to the hook (which validates the grammar, incl. `open_port(_, [list])` ⇒
`badarg`); `list_to_port/1`/`port_to_list/1` are pure (`#Port<0.Num>`). `port_command/2,3` and `port_info/1,2` on a port
the runtime does not hold go to `../beam_rt/src/native/port.rs`.
### Fun-taking `lists`/`maps`/`ets` BIFs (the `FunCaller` seam)
The 18 `lists`, 4 `maps` and 2 `ets` (`foldl/3`/`foldr/3`) fun-taking functions delegate to the optional `FunCaller` (a
BIF cannot invoke a fun). The fun argument is validated **exactly as the oracle's clause guards do, before any list/map
inspection**: `lists` raises the bare `error:function_clause` for a non-fun or wrong-arity fun (the `lists.erl` head),
`maps`' raise plain `error:badarg` (the `maps.erl` fallback clause); a **valid** fun with no hook is the typed
`unsupported_bif`. `zipwith/3` raises `error:function_clause` on a length mismatch; `all/2`/`any/2` short-circuit;
`maps:filter/2` treats a non-boolean result as `BadArg`. `BifContext::call_fun` reaches the hook through
`FunCaller::call_fun_with_tables`, `take`ing the `ets` registry out of itself and restoring it afterwards (the error path included), so a callee that runs `ets:*` — the fun of `ets:foldl/3`/`foldr/3` — receives the one live `&mut TableRegistry`: two live borrows are structurally impossible. The default body ignores `tables` and calls `call_fun`, so implementors that run no nested `ets` code (incl. the in-crate test doubles) are unaffected.
### `erlang:term_to_binary/1,2` and `binary_to_term/1,2` (`binconv.rs`)
- **The decode table image is memoized:** `decode_term_bif` decodes into `DECODE_SCRATCH`, a per-thread image of `ctx.atoms()` reused only when `prefix_matches` names every index the same atom and then extended to an **exact** image (a novel atom's index equals the `AtomInterner` prediction); any other table shape (moved/shorter, or a scratch left ahead by a failed/`safe` decode) forces a rebuild, so **no BIF clones the whole `AtomTable` per call**. `tests/decode_hot_path.rs` pins the steady-state allocation count as table-size-**independent**.
- **Options.** `compressed`/`{compressed,0..=9}` deflate a version-less body and wrap it `[131][80][len][zlib]` only when
  the stream fits the C's `body_len - 5` budget (bare atom = level 6); `{minor_version,0|1|2}` selects the tag set
  byte-identically; `iovec`/`fragment` are `badarg`; `[deterministic]` is fully honoured
  (`Encoder::with_deterministic`, re-sorting every flat/HAMT/nested map into full term order). `[local]` is honoured
  whenever the runtime installs `LocalNode::local_node_hash`: the image is the `[131][121][hash:4 BE][body]` `LOCAL_EXT`
  wrapper (`Encoder::with_local_ext`/`finish_local(hash)`), byte-identical to the oracle's apart from those four
  node-local, per-VM-start bytes — the typed `unsupported_bif` gap with no seam (or a hook answering `None`), never a
  fabricated hash. `[local,compressed]` deflates the *local body* (wrapper included), as `erts_term_to_binary_simple`
  does; `[deterministic,local]`/unknown ⇒ `badarg`; `/3` does not exist (oracle `undef`). `binary_to_term/2` takes
  `safe`/`used` (the count includes the `131` byte); on a top-level `COMPRESSED` image `[used]` is the compressed
  image's own length (trailing bytes ignored *and* uncounted). `[safe]` is the **codec's** flag, fed in as
  `DecodeOptions{ safe, local_node, local_hash: None }` through `decode_term_with_options_used`: a wire atom **name**
  not already interned is `badarg` raised by the codec **before** any interning (C `erts_atom_get`), so nothing
  reaches the receiver's atom table; the flag-free path is unchanged and still commits the names the decoder appends
  via `AtomInterner`. The one remaining `[safe]` half is the C's `EXPORT_EXT` **active-export** check
  (`external.c:5032-5036`), which stays in `beam_rt` (it owns the code server's loaded-module registry).
- **The local-node identity is installed on BOTH directions** (`LocalNode`; `(nonode@nohost, 0)` fallback): encoding
  yields a byte-exact `NEW_PID_EXT`/`V4_PORT_EXT`/`NEWER_REFERENCE_EXT`, and decoding demotes such a wire id to the
  INTERNAL form when it fits the M1 slot, so `binary_to_term(term_to_binary(self())) =:= self()` and the `make_ref()`
  form both hold; an id that does not fit keeps the faithful **external** form (byte-exact round-trip).
- **Binary/bitstring payloads round-trip** (`BINARY_EXT`/`BIT_BINARY_EXT`, on-heap `ErlHeapBits` and off-heap refc
  `BinRef`/`ErlSubBits`, at any nesting, under `compressed` and every `minor_version`); the encoder's
  `unsupported_external_term` fires only for an internal pid/port/ref with no resolvable local node and for a non-Latin-1
  atom under the Latin-1 flavour — never for a binary. A runtime-made `Local` fun encodes as its `NEW_FUN_EXT` image once
  `LocalFunIdentity` answers (read *before* the atom-table borrow; the consumer is lazy — asked only for a `Local` fun),
  else the typed `unsupported_local_fun`. `float_to_list/2`/`float_to_binary/2`'s `short` is the
  `sys_double_to_chars_short` port with the oracle's **exact-tie rule** (~738k doubles, 0 mismatches);
  `{decimals,N}`/`{scientific,N}`/`compact` too.
### `io`/`io_lib` directive set and the printer (`src/io.rs`, `src/io_ts.rs`, `src/print.rs`)
- **Directives:** `~w ~p ~W ~P ~s ~ts ~c ~tc ~n ~~ ~i ~b ~B ~x ~X ~+ ~# ~e ~f ~g`, the `~k`/`~K` map-print-order modifiers (`~k` takes the order without consuming an argument, `~K` from the next one), prefix `-` (left adjust), width (`*`), precision (`.`/`*`), pad character and the `t`/`l` modifiers. `~+`/`~#` render the base with the `Base#` prefix its own base implies, sign first (`~.16#` of `-255` ⇒ `"-16#FF"`), and every integer directive renders arbitrary-precision values; `~c` carries the integer's **low byte**, `~tc` the **full code point verbatim**. `badarg`: `~d`, a base outside `2..=36`, too small a precision, a wrong arg type/count, unconsumed or trailing arguments, left-adjusted `~-<n>p`, `~P`/`~W` without a depth.
- **Format argument:** a list, a binary and an atom are all accepted (`format_items` mirrors `io_lib_format:scan/2`+`collect/2`); `1`/`{}`/`5`/`[1|2]`/`<<1:3>>` are `badarg`. `~s` (Latin-1) walks nested chardata like `~ts`, but `~s` of an atom with a code point >255 is `badarg` where `~ts` accepts. `io_lib:printable_list/1` is the oracle's proper-list-of-printable-latin1 rule (no unicode arm — `io:printable_range/0` reports `latin1`), the same rule as `~p`/`~P`'s printable-string test.
- **`io_lib:format/2,3`** return the oracle's DEEP segment list (literals as individual small ints, the "small" controls splicing flat, every other control one sub-list element). `/3` ignores all options except `{chars_limit,N}`, implemented for `~w`/`~p`/`~W`/`~P` and **both** string arms, reproducing `control_limited`'s elision (`N < 4` ⇒ `"..."`, else the first `N-3` **grapheme clusters**); a negative limit is the byte-identical unlimited path.
- **The printer.** `src/print.rs` is the leaf renderer (registers no BIFs); `src/print/pretty.rs` + `pretty/cind.rs` are the full `io_lib_pretty` port, and **`~W` stays on the flat path** (the C `control_limited($W,…)` is a flat depth renderer). Floats render through the same `format_short` port as `float_to_list(F,[short])`, atoms as `io_lib:write_atom_as_latin1/1`, non-byte-aligned bitstrings as leading bytes then `Value:K`, binaries by `write_binary/3`'s depth rule; depth semantics reproduce `io_lib:write1/4`. Internal pids/ports/refs render, an **external** one is the typed gap, and a **fun** renders its `erlang:fun_to_list/1` text (`src/fun_info.rs`) — only a `make_fun3` (`FunKind::Local`) fun is the typed `unsupported_bif` gap. The per-element container walks are **iterative** in both paths — one native stack frame per *container*, byte-identical output; nesting **depth** is still recursive.
### The `ets` bridge
`bif.tab` declares 51 `ets:*` keys, the crate registers 59 (51 + 8 `ets.erl` fast paths) and serves 58. Load-bearing invariants: a **statically key-preserving `select_replace/2` body** is required (checked *before* traversal, so a rejected body and a `bag` are `badarg` even when the spec matches nothing); **no returned term aliases table storage** (every table-derived term is copied via `beam_message::copy_struct_simple`); the **match-spec evaluation seams** are installed scoped and depth-counted by the one aggregate guard `src/ets/self_hook.rs`'s `SpecEval` (this crate's `beam_ets` `SelfHook` for `self/0`, holding `src/ets/arith_hook.rs`'s `PrecisionArith` for the arithmetic); `ets:match_spec_compile([])` is `error:badarg` while the select family legitimately accepts `[]`. `TableRegistry`, owner/access gating, the `ets:new/2` option parser, `ets:info/1,2` (incl. the `stats` gap) and every remaining typed gap: **`./src/ets/CONTEXT.md`**.

  failures; the typed `unsupported_bif` **raise** for a capability gap. A capability gap is never reported as `badarg`

  `src/access.rs` (term/int/float/bignum/bitstring/flatmap/native-record wrappers) and `src/calendar/localtime.rs` (the

## Known Issues / typed capability gaps
**No known silent wrong *values*.** Every capability gap returns a typed `BeamError`, and every argument error matches
the oracle's class. Entries marked *divergence* are honest but not byte-identical.
### Divergences
- **`math:erf/1`/`erfc/1` are approximate** (`src/math.rs`): `erf` ≤ 4 ULP, `erfc` up to ~506 ULP — enough to change a `~w` shortest render; Rust has no `f64::erf`/`erfc` and glibc fdlibm is not Apache-2.0, so `tools/differential` does not pin the pair (it does pin the bit-exact `atanh/1`).
- **`erlang:display/1` writes a printable latin-1 char ≥ `16#80` as UTF-8, not the oracle's raw code unit** (≤ `16#7F` byte-identical; `io:format("~p",…)`/`display_string/2` unaffected). Needs a byte-oriented `OutputSink` (`src/context.rs` + `beam_rt`), not a local fix.
- **A `FunKind::Local` (`make_fun3`) fun is the typed `unsupported_bif` gap** in the printer and in `erlang:fun_to_list/1` (shared): its frozen descriptor is only `(uniq, index)`, so the module/name a `#Fun<…>` needs is not in the term and any text would be a silently-wrong result.
- **A non-small-integer `{chars_limit,N}` is rejected up front**, where the oracle fails only when arithmetic *reaches* the value; in-range small-integer limits are byte-identical.
- **`get_module_info`'s `exports`** lists loader-order exports, not the oracle's global export-table order (same set, order only — accepted at `../beam_rt/src/context/module_info.rs`); every other item matches.
- **`erts_internal:term_type/1` reports `export` for an `Imported` fun** where the oracle reports `fun` (yet `fun_info/2`'s `type` reports `local` for the same term).
- **Reject-where-the-oracle-succeeds / class mismatch:** `re:inspect/2` of a non-`namelist` item is the typed gap where the oracle raises `badarg`; `lists` of a non-list/improper argument raises `badarg` where the oracle raises `function_clause`/`case_clause`/`{bad_generator,_}`. No differential case covers these.
### Typed capability gaps (`unsupported_bif`, never a fabricated value)
- **External (remote-node) pid/port/ref textual ids and rendering:** `pid_to_list`/`ref_to_list`/`port_to_list`, the `*_to_binary` forms and the printer's external branch (`src/term_conv.rs::external_channel_gap`). The oracle's channel is `atom_val(x->sysname)` — the node-name atom's index in the **running VM's** atom table, state the frozen term does not carry. Needs a node-identity seam **and** a node-atom → dist-channel provider (both `beam_rt`, a new edge — Handoffs). An internal port DOES render (`#Port<0.N>`).
- **`term_to_binary/2`'s `local`** is seam-backed (image and options in the per-module contract above): the typed gap until the runtime installs `LocalNode::local_node_hash`; `erlang:external_size/2`'s `local` inherits the seam.
- **`erlang:raise/3`'s unrepresentable stacktrace elements** answer the typed gap while the argument is valid (the exact list is in the per-module contract above); the oracle echoes every such shape verbatim.
- **Fun identity — `fun_info_mfa/1` of a `Local`/`Imported` fun only** (it needs the lambda's true code arity, which no seam carries). Every identity item IS real: `name` (either kind, from `LocalFunIdentity`) and, for a `FunKind::Local` fun, `module`/`new_uniq`/`index`/`uniq`/`pid` plus `new_index` from the term; an `Imported` fun's items come from its own wire descriptor. **`phash2/1,2`/`phash/2`** of a `Local` fun and of an internal reference (`RefIdentityUnavailable`), and **`erts_debug:flat_size/1`** of an external pid/port/ref, are the same gap (the LCA's `TermError`); every other term is computed.
- **`ets:info(T, stats)`** (needs `beam_ets` interior counters — Handoffs) and **`ets:internal_request_all/0`**.
- **Seam-backed until `beam_rt` installs the hook:** the eleven `proc_reg` BIFs, `get_module_info/1,2`, `persistent_term:*`, `erlang:get/0`/`erase/0` (until `DictHook::get_all`/`erase_all`), `list_to_atom`/`binary_to_atom`/`binary_to_existing_atom` without an `AtomInterner` (`TermNotFound`), and `erlang:load_nif/2` without the `NifLoader` **and** `with_current_module`.
- **The 172 `RuntimeHooks` seam keys:** 32 served by `beam_rt` via `RuntimeHooksBridge`, ~41 by its native floor and 36 *shadowed* by it (dispatched before the registry); **~99 unserved** (`erts_debug`/`erl_debugger` internals; distribution/tracing/code-loading/spawn/monitor machinery; the NFC tables for `prim_file:internal_normalize_utf8/1`). Re-derive by counting the `RuntimeHooks::call` match arms in `beam_rt/src/context/runtime_hooks.rs`; detail: `./src/runtime/CONTEXT.md`.
- **`erlang:statistics/1` is a pure `RuntimeHooks` seam-key forwarder here** (`src/runtime/erlang.rs`, pinned by its `erlang_statistics_is_a_roster_seam_key_forwarder` test) — every value comes from the host, `beam_rt`'s `RuntimeHooksBridge::statistics`; value table + owning node: `./src/runtime/CONTEXT.md`.
- **`records:get_definition/2` without a `RecordSource` hook is `badarg`** (the oracle resolves in-module), and `records:create/4`'s error precedence differs for `[{1,1},5]` (oracle `{badfield,{{m,r},1}}`, here `badarg`).
- **Integer/text limits:** `list_to_integer`/`binary_to_integer` of an over-long string ⇒ `SystemLimit` (> ~1.26M digits); `list_to_integer/1,2` requires byte-sized elements; quoted atoms are not re-escaped and non-ASCII output is UTF-8 (ASCII byte-exact). **Sub-binaries are copied, not shared:** `binary:part`/`binary_part`/`binary:copy`/`split_binary` return a fresh on-heap binary (no `BinRef`/`SUB_BITS`) and a 1-limb bignum count the oracle accepts is rejected, so `binary:referenced_byte_size/1` reports its own byte size (oracle `100000`, here `50000`) — a `beam_term::refc` accessor is the missing piece.
- **The M1 internal-reference `id` is a single 60-bit small**, so an id that does not fit is kept external: a `NEW_REFERENCE_EXT`/`NEWER_REFERENCE_EXT` image whose third number is `>= 2^28` decodes to the faithful external form (a byte-exact round-trip); `list_to_ref/1` accepts only `#Ref<0.0.0.N>`. Widening the slot spans `beam_term::boxed` + `beam_codec::ref_wire` + `beam_gc` copy sizing.
- **`match_spec_test/3`'s `trace` dialect** needs a trace-programme runner, and the `table` dialect's compile-rejection gap turns the oracle's semantic-lint `{error,[…]}` into a raise — neither fixable here.
- **The `erl_ddll` keys' remaining honest gaps** — the pending-**reload** state machine ⇒ typed `unsupported_bif`, no `not_loaded_by_this_process`/`already_loaded`-`inconsistent` check, immediate (unstaged) unload, a non-UTF-8 name/path ⇒ `badarg` — and the three statically linked built-ins, which ARE modelled and oracle-pinned (`tests/erl_ddll.rs`): `./src/runtime/CONTEXT.md`.
- **Deep *nesting* still recurses in the printer** — an unbounded-*depth* concern; the per-element walks are iterative, so a long flat container no longer aborts.
### Environment-bounded values and bounded M1 leaks
- **`ets:all/0` answers only this crate's registry, ascending-id** (the oracle also lists the node's system tables, in no order) — the only `ets` value divergence.
- **Never-reclaimed registries (bounded M1 leak):** the compiled-pattern, `ets` continuation/compiled-spec and `atomics`/`counters` cell registries have no off-heap finalizer; the one *stale-word* hazard is the `ets` compiled-spec registry (`TableRegistry::insert_spec`/`spec_raw` store the caller's spec **`Eterm` verbatim** in a non-root registry that outlives the call), whose fix needs table-owned storage (a `beam_rt`/`beam_ets` change, Handoffs). The compiled-pattern registry deep-copies.
- **`time` native units are fixed** (ns `monotonic_time/0` over a process-global `Instant` origin; `unique_integer >= 0`); `time_unit` accepts the oracle's atom set and a **positive bignum** unit IS supported (`crate::time::{convert_unit_big,int_from_i128}`, floor semantics; past `BIG_ARITY_MAX` is `badarg`). **`error/2` ignores its second argument**, `nif_error/2`'s is crash-report metadata, `error/3` mirrors `error/2`; **`prim_*`** modules are otherwise unimplemented (only the three `os_bif.rs` `prim_file` helpers).
- **The printer cannot emit a `beam_term::ops: class: invalid boxed header subtag …` panic** — that is a
  corrupted/stale-term symptom (a flat-map render with a **non-atom** key, `../beam_rt/M1_GAPS.md`), not a printer input:
  no `src/print.rs`/`src/print/pretty/` path calls `beam_term::ops::class` or panics.

## Design Decisions
- **`BifFn` is a plain `fn` pointer** — `Copy`, allocation-free, closes over nothing (all state flows through `BifContext`).
- **`BifContext` holds optional seams, not concrete runtime types** (testable over a bare heap + atom table), keeping the Stage-1/Stage-5 DAG acyclic (no `beam_engine` edge).
- **Stateful/global BIFs route through seams** — the crate owns neither global state nor OS machinery.
  The two real seam-free families are the `atomics`/`counters` cells and the `erl_ddll` driver registry + error table; a resource handle is an on-heap `Ref` thing over a module-local registry (`./src/runtime/CONTEXT.md`).
- **`function_clause` is a bare-atom raise**; `create`/`update` recognize the by-name atoms (`is_exported`, `'_'`) with a local helper, not fixed `AM_*` indices.
- **Bignums come from the safe `beam_codec::term::make_big`, not `beam_term::thing::write_big`** (which needs `unsafe`; no cycle).
- **`self/0` reads `BifContext::self_pid`, not a global** (the engine is a pure state machine); all BIF allocation is on `beam_alloc::Heap` (`beam_term::heap::Heap` a test arena only).
- **A match spec's `self/0` is resolved through a scoped install of that pid, never a global.** `beam_ets` owns no process identity, so `src/ets/self_hook.rs`'s `SpecEval` installs a `PidHook` carrying the calling `ProcessId` (`to_eterm()` is a `const fn` internal-pid immediate — no heap, no GC root) for every spec-running BIF's duration; the pids live on a thread-local stack, so a nested evaluation answers its own pid and only the outermost drop restores the seam's default.
- **`BifContext::heap()` is the caller's *destination* heap** — `beam_rt`'s pooled, never-reset `Runtime::bif_heaps` arena (`take_bif_heap`/`put_bif_heap`, default `1<<24` words) **outside** the GC-scanned spaces, so a result built there is unscanned, the runtime's unscanned-root valve *declines* such a collection, and heap exhaustion surfaces as `error:system_limit`.
  This crate never re-roots or copies down.
- **The fun-taking fast paths publish **no** GC roots, deliberately** (measured): their live `Eterm`s in Rust locals cannot see a collection, because the latch is armed only for the slice's own machine (every nested run has `gc_armed == false`, `beam_rt/src/context/bridges.rs::FunBridge`) **and** the process is `relocation_exempt` for the whole run (`RuntimeContext::apply_fun`) — two independent refusals.
  A stale-word hazard is a runtime-level store, not a BIF local (Handoffs).
- **The `ets` table handle is an on-heap `Ref` thing** (the M1 `tid()` substitution) for a normal table, the **name atom** for a `named_table`; a BIF takes the table out of the registry to release the `ctx.atoms()`/`ctx.tables()` borrow, and continuations/compiled specs are `Ref` things over registry keys likewise.
- **A capability gap is a `raise`, an argument error is `BadArg`** — never conflated: the external-identifier refusal is the typed `unsupported_bif` (the argument is valid) while a wrong-type argument stays the oracle's plain `badarg` on the same BIF (pinned by `tests/term_conv.rs`).

## Performance Notes (per-BIF-call hot path)
- **The registry lookup is allocation-free:** the nested maps hash borrowed `&str`s via `Borrow<str>` (no key built) and
  scan the 1–2 element arity `Vec`; a `beam_rt` dispatch reaches it twice (`contains`, then `call`→`lookup`), allocating
  nothing.
- **Arithmetic widens even small ints to a heap `Big`:** `erlang:'-'/2` of two small ints does ~4 small `Vec`
  allocations (a `Big::from_i64` per operand, then `sub`/`add`/`neg`) with no checked-`i64` fast path.
- **The `AtomTable` deep clone is copy-on-write** (`beam_rt`'s `CodeServer::atoms_mut`): only an interning call pays it.
- **The decode scratch revalidates in O(1) in the steady state:** the per-thread *exact image* of the caller's table
  (`DECODE_SCRATCH`'s `memo`) carries a `beam_term::AtomSnapshot` witness **taken from the shared table itself**
  (`DecodeScratch::witness`; a clone's fresh identity can never satisfy it), so `memo.len() == witness.len()` plus
  `shared.appended_since(witness)` proves index-identity with **zero** name reads — only names appended since are copied.
- **`prefix_matches` is the fallback, not the hot path:** its Θ(atom-table) `name` reads run only for a replaced or
  shrunk instance, or a memo left **longer** than the shared table by a failed/`safe` decode (rejected by that length
  check alone); a rejected memo is rebuilt with one `AtomTable::clone` and the witness refreshes either way.
- **`beam_rt/src/nif.rs` still revalidates its own decode memo index by index** (a private `prefix_matches`): the O(1)
  witness is **unadopted** there (Handoffs).
- **`term_to_binary/1` and `binary_to_term/1` allocation inventory** (one 5-key-map round trip): encode = 2 `Vec<u8>`
  (the `Encoder`'s 128-byte `Writer` + `plain_image`'s `body.len()+1` image) + the on-heap binary block
  (`beam_alloc` bump, O(size)); decode = 1 `Vec<u8>` (`access::binary_bytes`'s `to_vec`) + 1 `Vec<(Eterm,Eterm)>`
  (the codec's map `pairs`) + the map block on the context heap; **no** per-call `HashMap`/`HashSet`/`String`/`format!`.
