# `beam_bifs` — BIF Registry (`bif.tab` Surface) & Implementations

## Intent
Owns the **Built-In Function layer** (Stage 5, Part II §H): the `(module, function, arity)` → implementation registry plus the curated BIF surface, contract **Part I §A.7** — names/modules/arities reproduce `../../erts/emulator/beam/bif.tab`, none invented.
`beam_rt` adapts `BifRegistry` into the engine's `ExecutionContext::call_bif(module, function, arity, args) -> Result<Eterm>` seam (`../beam_engine/CONTEXT.md`).
Failure is **return-based** (`../CONTEXT.md` §3 — inherited, obey): `BadArg`/`BadArith`/`BadArity`/`SystemLimit` plus `BeamError::Raise` for `error`/`exit`/`throw`/`nif_error`/`undef`/`unsupported_bif`.
**A typed error always beats a wrong result**: an unfaithful shape returns the typed gap, never a fabricated value.
Ground truth (read-only): `../../erts/emulator/beam/`, `../../erts/emulator/sys/common/erl_float_short.cpp`, and the stdlib sources (`erlang.erl`/`erts_internal.erl`/`ets.erl`/`lists.erl`/`maps.erl`/`io_lib*.erl`/`unicode.erl`/`string.erl`).

## Roster census (authoritative; code-derived, pinned by `tests/roster_audit.rs`)
`bif.tab` declares **556** entries = `bif` **476** + `ubif` **73** + `hbif` **7**, `MISSING_DECLARED` **0** — pinned by `tests/bif_tab.rs` (`IMPLEMENTED_DECLARED` 556, `MISSING_DECLARED` 0, `FAST_PATHS` 111, `REGISTRY_SIZE` 667); `tests/roster_audit.rs` (`:106-142`) builds the seam union from the fourteen public tables (never a hard-coded list) and asserts the partition, the union size, the per-table/per-module declared counts and every union member's `needs_*` predicate.
`default_registry()` = `BifRegistry::with_core_bifs()` = **667 keys** = **556 declared + 111 stdlib fast paths** (the fast-path set re-derived from `bif_tab::census(..).fast_paths`, never from this prose).
The 111 fast paths by module: `lists` 40 (18 fun-taking), `zlib` **25** (six one-shots + the 19 NIF-level stream keys), `erlang` 15, `maps` 12, `ets` 8, `binary` 3, `io_lib` 3, `unicode` 3, `io` 2; `binary:referenced_byte_size/1` and the OTP-30 `pid_to_binary`/`ref_to_binary`/`port_to_binary` are **declared** (`bif.tab:561`, `:866-868`), and none of the 19 `zlib` stream keys is hook-gated.
**Declared ≠ registered ≠ adopted.** The declared surface is a **disjoint partition**: **367** `DECLARED_IN_CRATE` (unconditional in-crate) + **189** `DECLARED_SEAM_BACKED` = 556 — each seam-backed key answers the typed `unsupported_bif`/`TermNotFound` until a host installs one of the **fifteen** hook seams that gate a roster key (the fourteen `hook_sets.rs` tables plus `AtomInterner`, which has no table because its consumer set is unbounded); of the 189, **139** are `RuntimeHooks` forwarders and **50** distribute over the other thirteen tables.
The `BifContext` seam count is **seventeen** — the fifteen hook seams plus `OutputSink` (the `io:format` sink, defaulting to stdout instead of gating a key; it is the destination of this runtime's **own** output stream only — an `io` output call whose `group_leader()` is a real io device is driven by `beam_rt` through the OTP `{io_request, …}`/`{io_reply, …}` protocol and never reaches this crate's `io:format`, see `../../beam_rt/src/context/io_route.rs`) and `TableAliasing` (the `ets` table-alias witness, which gates **no** roster key).
The dedup **seam union is 222** (`SEAM_UNION`) = **226** raw keys in the **fourteen** public tables − **4** `SHARED_UNION_KEYS` (the four external-term encoders, which read both `LOCAL_FUN_IDENTITY` and `LOCAL_NODE`); **33** union members are `UNDECLARED_SEAM_MEMBERS` (registered stdlib fast paths, not table declarations).
**208** keys are registered under `src/runtime/` (asserted at `src/runtime/mod.rs:159`) — separate from the 189/367 partition, never conflated with it; there are **no dead registrations**.
**Never infer "served" from "registered": a key can be shadowed** — `beam_rt`'s native floor answers **before** this registry (`../beam_rt/src/native.rs::try_native`), so an in-crate implementation of a floor-shadowed key is dead code; `./src/runtime/CONTEXT.md` § *Seam-key disposition* splits the 139 into **40 bridge-served + 43 floor-shadowed + 56 unserved**.

### The oracle cross-check behind "556 = 556" (the enumeration method)
`erlang:system_info(bif_list)` is **`badarg`** on OTP 29.1.1 / erts-17.1, so the roster was enumerated through `code:all_available()` → `beam_lib:chunks(File, [exports])` (or `M:module_info(exports)` for a `preloaded` module), keeping every `(M,F,A)` with `erlang:is_builtin/3` `true`: **exactly 556 keys over the same 25 modules** as `bif.tab`.
The asymmetries are version- or instruction-related, none a gap: `apply/2,3`/`yield/0` are `is_builtin`-true instructions with no `bif.tab` row, the three OTP-30 `*_to_binary/1` are additions, and the 29 quoted operator rows are invisible to an ASCII-only `exports` scan on either side.
Re-derive any per-module split from `tests/registry.rs`'s `MODULE_KEY_COUNTS`, never from prose.

## API Surface (FROZEN — `beam_rt` and tests design against this; additive-only changes)
Root + `beam_bifs::prelude::*`: `BifRegistry`/`BifFn`/`default_registry`; `BifContext` + its seventeen seams; `RecordDefinitionView`/`RecordFieldView`; `StdoutSink`/`NullSink`/`BytesSink`; `NifLoadError`; `raise_error`/`raise_exit`/`raise_throw`; `exit_reason_from_term`/`reason_term_from_exit_reason`; `ErrorMeta`/`error_meta` (the `error/2,3` stacktrace payload, modelled — see Known Issues); `ErrorCause`/`error_cause` (the innermost BIF item's `cause` value, decided where the arguments and this crate's own state suffice — see *Known Issues*); `TableRegistry`; `serves_local_call`; `snifs`/`Snif` (the generated static-NIF roster, crate root only); the `hook_sets.rs` tables + `needs_*` predicates (`beam_bifs::bif_tab` is **not** in the prelude — validation tooling).
- **`registry.rs`** — `BifFn = fn(&mut BifContext<'_>, &[Eterm]) -> Result<Eterm>`; `BifRegistry` (nested `module → function → [(arity, BifFn)]`, so `lookup`/`contains` are allocation-free); `with_core_bifs()` = `default_registry()` (the 667-key roster); `register(...)` replaces on repeat; `call(...)` (unknown key ⇒ `error::undefined_bif`, wrong arg count ⇒ `BadArity`); operator BIFs keep their *quoted* `bif.tab` names (`"+"`, `"=:="`, `"!"`, …); registration order is fixed per module with `runtime` last.
- **`serves_local_call(module, function, arity) -> bool`** — `module == "zlib"` plus the 19 `(name, arity)` rows of `zlib.erl`'s non-exported NIF stubs, alongside `prim_tty`'s. A `zlib` stub is reached **two** ways and both must be served: as a local `call` (`beam_rt/src/context/execution.rs::resolve_local_call`) and as a local `make_fun3` closure (`zlib.erl` stores `fun deflate_nif/4` in a `#zlib_opts{}` record), which `beam_rt/src/context/apply.rs::served_local_key` declines through the same predicate and dispatches via `call_bif`.
- **`context.rs`** — `BifContext<'a>`, the one per-call context: `heap`/`atoms`/`self_pid`/`current_module`, one optional slot per seam, the constructors `int`/`atom`/`intern_atom`/`boolean`/`ok`/`make_float`/`tuple`/`cons`/`list`, `pub(crate) atom_and_heap` (the one borrow-table-and-heap route), `ProcessInfoItem`, the `OutputSink` impls.
- **The seventeen optional seams** (each a `with_<seam>()` builder + accessor): `OutputSink`; `SendHook`; `AtomInterner`; `FunCaller` (+ the **defaulted** `call_fun_with_tables(fun, args, tables: Option<&mut TableRegistry>)`); `PortHook`; `DictHook` (+ the defaulted `get_all`/`erase_all`); `PersistentTerm`; `NifLoader`; `RecordSource`; `LocalNode` (+ the **defaulted** `local_node_hash(&mut self) -> Option<u32>`); `LocalFunIdentity`; `ModuleInfo`; `ProcessHook`; `MemoryHook`; `RuntimeHooks`; `ExportGate` (a **shared** `&'a dyn beam_codec::ExportGate`, the `[safe]` `binary_to_term/2` active-export predicate, skipped entirely with none installed).
  The seventeenth is `TableAliasing` — a **shared** `&'a std::cell::Cell<bool>` witness (`with_table_aliasing`, crate-internal `alias_table_storage`) that `src/ets.rs`'s `copy_out`/`copy_out_list` consult: with one installed they hand back the table's own terms and set the cell instead of copying onto `ctx.heap()`, so the host's copy-out is the only copy; with none the copying path runs unchanged (`./src/ets/CONTEXT.md`).
- **Every hook is defaulted** — with none installed the BIF answers the typed `unsupported_bif` gap (or a documented `Ok(None)`/fallback for a value-returning seam), **never** a fabricated empty list, `undefined`, `false`, zero or made-up count.
  Unset defaults: stdout for `io:format`; `unsupported_bif` for `send/2`/`"!"/2`/`send/3`, the port/dict/`PersistentTerm`/`ProcessHook`/`ModuleInfo` BIFs, `load_nif/2` and the fun-taking `lists`/`maps` BIFs **for a valid fun** (an invalid fun fails the clause guard first); `TermNotFound` for a new-atom BIF; `Ok(None)` for `record_definition`/`local_fun_identity`/`module_info`/`local_node_hash`; `(nonode@nohost, 0)` for `local_node`, else `None`.
- **`hook_sets.rs`** — the one home of the *seam-consumer* key sets: a `&'static` table per seam + an allocation-free `needs_*` predicate, `contains`-checked against the live registry; `RUNTIME_HOOKS_BIFS` **139** is asserted *equal* to `runtime::register`'s seam roster, the fourteen tables total **226** keys (union **222**), and `AtomInterner` deliberately has **no** table — a host gates its seams through these, never a private copy.
  `PROCESS_HOOK_BIFS`'s 12 keys are `proc_reg::register`'s whole roster (`whereis/1`, `register/2`, `unregister/1`, `registered/0`, `is_process_alive/1`, `processes/0`, `ports/0`, `process_info/1,2`, `process_flag/2`, `group_leader/0` and `bump_reductions/1` — the one member whose answer is a mutation).
  `LOCAL_FUN_IDENTITY_BIFS`'s 12 keys are the two encoders, the four fun renderers (`erlang:fun_to_list/1`, `erlang:display/1`, `io:format/2`, `io_lib:format/2,3`) and the two legacy hash ports (`phash/2`, `phash2/1,2`); `PORT_HOOK_BIFS`'s 8 are the 4 declared C spellings (`erts_internal:{open_port/2,port_close/1,port_info/1,2}`) plus the 4 undeclared `erlang` wrappers.
- **`error.rs`** — `pub(crate)` `badarg`/`badarith`/`badarity`/`system_limit`/`undefined_bif`/`unsupported_bif`/`function_clause`; public `raise_error`/`raise_exit`/`raise_throw` over `beam_common::{Raise, ExitReason, ExceptionClass}`; `raise_term`/`raise_error_term` set `reason = ExitReason::Structured` with the term in the opaque `Raise::with_live_reason`/`LiveReason` slot (`as_atom()` stays `None`); `structured_error` builds `{Tag, Elements…}`, degrading to plain `badarg()` when `tag` cannot be interned.
- **`reason.rs`** — `exit_reason_from_term(term, &AtomTable) -> ExitReason`; `reason_term_from_exit_reason` rejects `Structured` with `BadArg`; the `error/1,2,3`/`exit/1`/`throw/1`/`nif_error/1,2` BIFs run their argument through it — an **atom** reason keeps its exact `ExitReason` with **no** live slot, a **non-atom** one is `Structured` carrying the term.
- **`reason.rs` raise payloads** — `error/2`, `error/3` and `nif_error/2` attach `Raise::saved_args` = their **verbatim** second argument (`bif.c:1448-1452`/`:1525`: stored, never validated).
  `error/3` additionally attaches `Raise::error_info` = the **last** `{error_info, Map}` of a wholly-valid proper option list (`scan_error_info`), and nothing at all on any deviation — non-list, `[]`, improper, non-2-tuple, wrong key atom, non-map value, or a valid pair followed by anything invalid — the C's silent `error/2` fallback, never `badarg` (`bif.c:1462-1501`).
  `nif_error/2`'s payload is stored but **unobservable** in the oracle's trace (the genuine-BIF-frame path rebuilds `Args` from the BIF arity).
  Both are **live `Eterm` words on the caller's heap** and out-of-band (ignored by `Raise`'s `PartialEq`/`Eq`, never printed by `Debug`), so nothing between reading them and returning the raise may allocate on a BEAM heap, intern an atom or call the host; the engine renders them into the innermost stacktrace item.
  `ErrorMeta { args, error_info }` + `error_meta(args, Option<options>, &AtomTable)` are the **host-facing model** of the same payload over the same rule (`scan_error_info_at`, which `scan_error_info` delegates to); pinned row-for-row against the live oracle by `tests/error_meta.rs`.
- **`print::c_printf::term_text`** — the crate's one **public** renderer outside the `pub use` list + `prelude`: `term_text(ctx, term, precision: i64) -> Result<String>`, `precision` the C `dcount` **byte** budget (`i64::MAX` = the `INT_MAX` form); it registers no BIFs and moves no roster figure. Detail: `./src/CONTEXT.md` § *The `%T` renderer*.

## Map writes: path copy for the four incremental BIFs, from-scratch build for the rest
- **Path-copying writers** — `maps:put/3` (`src/maps.rs:502`, registry `:1130`), `maps:update/3` (`:526`, `:1131`), `maps:remove/2` (`:551`, `:1132`) and `maps:take/2` (`:579`, `:1133`) rewrite **only the nodes on the key's hash path** and share every off-path subtree with the source map by word, through `access::map_put_cow`/`map_remove_cow` (`src/access.rs:907`/`:936`, the crate's only `unsafe` map writers) → `beam_term::map::{map_put_cow,map_remove_cow}` (the C's `erts_maps_put`/`erts_maps_update`/`hashmap_delete`/`erts_maps_take`) — flat in n, against the O(log n)-shape C and the Θ(n log n) rebuild it replaced.
- **Reservation rule** (`src/access.rs:851`/`:866`): a **flat** map's path holds no collision node, so the size-only capacity bound is exact (`map_put_cow_words_capacity`, `map_remove_cow_words_capacity`, and through it `map_words_capacity(33)` = 711 on the flat→HAMT conversion); a **hash** map's path may cross a collision node, whose cell count the size cannot bound, so the figure comes from the writer's own read-only, plan-sharing descent (`map_put_cow_words_required`/`map_remove_cow_words_required`, 0 for an absent remove). That descent refuses a malformed map (`BadMap` → `BadArg`, the class the old pair walk reported) **before** anything is reserved, and it is a second descent the writer repeats — the fusion lever ERTS gets for free from its `*sz` out-parameter (see Handoffs).
- **Arena lifetime.** The reservation is `ctx.heap()`, the BIF working arena — never the source map's storage — and the result is copied onto the process heap by the dispatch tail before `beam_rt` rewinds the arena; that copy walks every reachable node, so the shared subtrees are materialized first. Reasoning and the `# Safety` notes: `src/access.rs:880-945`.
- **One atom namespace.** Both writers get the caller's **live** `AtomTable` (`build` → `access::make_map` `src/access.rs:823` via `BifContext::atom_and_heap`, `src/context.rs:1190`), as `beam_engine`'s `put_map_*` already did. It decides only a **compound** key's atom-element tie-break (`cmp_flatmap_keys` keeps *atom* keys in raw-index order, C-faithful); an empty table would order those by index — an order ERTS never produces (`erts_cmp_atoms` compares names, `../../erts/emulator/beam/erl_utils.h:193-220`). Pinned by `tests/maps_cow.rs::a_compound_key_whose_atom_element_sorts_differently_matches_the_rebuild`.
- **The retained Θ(n) from-scratch builders** keep `access::make_map` → `beam_term::map::write_map` (`map_words_capacity` `21*n + 18` words → `alloc_words` → hash/sort/build/serialize): `new/0`, `from_list/1`, `from_keys/2`, `merge/2` (`:640`), `with/2` (`:722`), `without/2` (`:771`), and the one build each that `map/2` (`:981`) and `filter/2` (`:1024`) end with. They are inherently Θ(n + m) key-set operations, so a path copy has no analogue; `with`/`without` additionally pay O(n·|Keys|) for the per-pair key scan.
- **`maps:update_with/2,3,4` is not a BIF here** (deliberately unregistered): it runs as `../../lib/stdlib/src/maps.erl:635`/`:665`, whose `Map#{Key := Fun(V)}` is the engine's `put_map_exact` — `beam_engine`'s writer, not this crate's.
- **Reads path-descend:** `erlang:map_get/2` / `is_map_key/2` reach `beam_term::map::map_get` (`src/access.rs:980`: HAMT nibble descent, ≤32 flat scan), so reads were never the problem.

## Constraints
- **Errors:** `beam_common::{Result, BeamError}` only — never a crate-local error enum, never `panic!`, never `unwrap()` on runtime data, never a wrong result.
  `BadArg`/`BadArith`/`BadArity`/`SystemLimit` for argument/numeric/arity/size failures; the typed `unsupported_bif` **raise** for a capability gap — a capability gap is never reported as `badarg` (the argument is valid), and a `badarg` is never reported as a capability gap.
- **Never re-implement term order/size/hashing/construction.** Comparison ⇒ `beam_term::compare::{cmp, cmp_arith}`; hashing ⇒ `beam_term::hashing` (`term_hash` + the pinned `make_hash`/`make_hash2`); construction/inspection ⇒ `beam_term` accessors only (via `access.rs`); allocation ⇒ `beam_alloc::Heap`.
- **`unsafe` confinement.** `#![deny(unsafe_code)]`; the only two `#[allow(unsafe_code)]` modules are `src/access.rs` and `src/calendar/localtime.rs` (the C time-library bridge); `unsafe_op_in_unsafe_fn` stays clean.
- **Deps (fixed by `Cargo.toml`):** `beam_common`, `beam_term`, `beam_alloc`, `beam_abi`, `beam_process`, `beam_message`, `beam_codec`, `beam_deflate` (the workspace's zlib 1.3.2 port), `beam_ets`, `beam_gc`, `libc`; **no `beam_loader` edge** (record definitions arrive through `RecordSource`); a new dependency edge must be reported to `../`.
- **Files target ~1000 lines**, exceeded only via in-module `#[cfg(test)]` suites; the printer and the `ets` bridge are **split by responsibility**; **licensing Apache-2.0**, every `*.rs` carrying the OTP `// %CopyrightBegin% … // %CopyrightEnd%` block.

## Notes for Agents
- **No module-loading BIF lives here — do not look for one.** `code:ensure_loaded/1`, `code:load_binary/3`, `code:is_loaded/1` and `code:get_object_code/1` have **no `bif.tab` row**; they are `code.erl` functions served by `beam_rt`'s native floor (`../beam_rt/src/native.rs:424-427`, consulted **before** this registry). The only **declared** `code:*` BIFs are the seven coverage keys (`bif.tab:792-797,813` → `src/runtime/other.rs:86-92`), all `RuntimeHooks` seam keys (3 served); `erlang:module_loaded/1` is floor-shadowed, `erts_internal:prepare_loading/2` registered but unserved.
- **`access.rs` and `bits.rs` are PRIVATE** (`mod access;`/`mod bits;`); the cross-crate public surface is exactly the `pub use` list in `src/lib.rs` + `prelude` plus the one public renderer module `print::c_printf`, with **no public term construction/destruction helper module**.
- **Two routes to destructure/construct boxed terms from safe Rust:** (a) the registered BIFs through `BifRegistry::call`; or (b) the sibling **safe** helpers `beam_engine::terms::*` / `beam_codec::term::*` (`make_float`/`make_big`/`make_flatmap`/`make_binary`/`make_bitstring`, `flatmap_parts`/`tuple_arity`/`cons_head`/`bitstring_bytes`). `BifContext` builds floats, lists, tuples, cons, small ints and atoms safely but has **no** binary/bitstring, bignum, map or record constructor.
- **The `erts_debug` family is 20 keys / 16 real / 4 seam**, the real ones including the two self-contained decoders — `dist_ext_to_term/2` (`src/binconv.rs::decode_dist_ext_image`) and `instructions/0` (the generated `src/runtime/instructions.rs`, skew rows in `./src/runtime/CONTEXT.md`); the 4 seam keys are `breakpoint/2`, `dirty/3`, `dirty_cpu/2`, `dirty_io/2`. `prim_file:internal_normalize_utf8/1` is **real** — the composition-only normalizer behind `src/unicode/normalize/`, a `REAL_BIFS` member, not a seam key.
- **Oracle cross-checks back every hard algorithm.** Bare BIF names are **not** auto-imported under `-eval` (fully qualify); several probes need a **compiled module** (`erlc` on a fixture) — e.g. `erts_debug:flat_size/1` and `lists:sort/2`'s degenerate comparator; the tests shelling out to system `erl` are **fail-loud**.
- **The recorded `erlang:list_to_existing_atom/1` divergence is NOT this crate's** (`../../tools/differential/divergences.md` misattributes it; it is a pure `BifContext::atom` lookup that never interns): on the `-eval` route the name is already in the runtime's ONE shared `AtomTable`, which `beam_rt` eagerly fills from `start.boot`'s `{primLoad,…}` names and each module's `Atoms` chunk — owner `beam_rt`.
- **Build env:** sandbox `$HOME` is read-only — run cargo only via `erts_rust/scripts/cargo.sh … --manifest-path erts_rust/Cargo.toml -p beam_bifs`; CI is `.github/workflows/erts_rust.yml`. `cargo clippy -p beam_bifs --all-targets` **exits 0**, and pre-existing warnings (`print/pretty*`, `lists.rs`, `re/*`, golden-float `excessive_precision` rows that must NOT be "fixed") are a separate workstream — keep new code free of diagnostics.

## Test Strategy
- Per-module `#[cfg(test)]` unit tests build a `BifContext` over a real `beam_alloc::Heap` + a seeded `beam_term::AtomTable` with a `BytesSink`/`NullSink` capture.
  Run the crate with `erts_rust/scripts/cargo.sh test --manifest-path erts_rust/Cargo.toml -p beam_bifs --no-fail-fast` and re-derive the lib/integration split from the per-suite `test result` lines, never a hand-maintained table; the suite is green and has **no** `#[ignore]`d test anywhere.
- **Roster pins:** `tests/roster_audit.rs` (the census above), `tests/bif_tab.rs` (`IMPLEMENTED_DECLARED` 556, `MISSING_DECLARED` 0, `FAST_PATHS` 111, `REGISTRY_SIZE` 667), `src/runtime/erlang.rs::is_builtin_sweeps_…` (the same figures in-crate), `tests/registry.rs`'s `MODULE_KEY_COUNTS` (`zlib` 25) and `tests/seam_census.rs` (**249** rows = A closed in-crate **4** + B seam-blocked **211** + C out of scope **23** + D documented seam defaults **11**, `:1432-1435`, with a run-time coverage guard so a seam key or default cannot drift silently) — none of them alters dispatch.

## Known Issues / typed capability gaps
**No known silent wrong *values*.** Every capability gap returns a typed `BeamError`, and every argument error matches the oracle's class; entries marked *divergence* are honest but not byte-identical.
### Divergences
- **The `maps` no-op identity is built here but lost at the host's result copy.** `maps:put/3`, `maps:update/3`, `maps:remove/2` and `maps:merge/2` hand back the argument term itself whenever the ERTS arms say the call changes nothing (`src/maps.rs`: put/update on a word-identical value for an existing key, remove of an absent key, `merge` with an empty side or with `Map1`'s keys all present in `Map2` — `erl_map.c:1256-1372`/`:2221`/`:2524`; the identity test is **word** equality, never structural), and the returned `Eterm` is literally the argument's word — but on the scheduled/`calls` route `beam_rt` then copies the result onto the process heap with no "already on the destination" pass-through (`../beam_rt/src/context/calls.rs::copy_result_fresh`, `:2319`, called from `move_result_into_process_heap` `:1831`; the `-eval` route needs the equivalent on `Runtime::eval_heap`), so an observer sees a `=:=`-equal but distinct map and `erts_debug:same/2` answers `false` where the oracle answers `true`. Content (`=:=`) is unaffected; the fix is a destination-containment short-circuit in `beam_rt`, not here. Residual of the same class: `merge/2`/`with/2`/`without/2` still rebuild from scratch (the four single-key writers path-copy), so the C's partially-shared HAMT merges have no analogue — only the six whole-map arms above are modelled.
- **`erlang:error/2,3`'s stacktrace-side payload is modelled but not attached**, so a caught `S` loses it: the oracle's innermost item renders `{M, F, [1,2], [{file,…},{line,N},{error_info,#{…}}]}` where this runtime renders `{M, F, Arity, [{file,…},{line,N}]}`. The raise **class and reason** are oracle-exact in every shape (`error:foo`, `error:{bad,x}`, …); what is missing is `Args` and the `error_info` map, reproduced by `error_meta` (`src/reason.rs`) yet unloadable because `beam_common::Raise` carries only `class`/`reason`/`stacktrace`/`live_reason` and `StackFrame` is metadata-only — the one opaque slot is the *reason* term by convention. Blocked on an additive slot on `Raise`; the reader is `beam_engine`'s `families/exceptions/stacktrace.rs::symbolic_stacktrace` (the first frame's `A` slot, `ItemShape::args`, which already carries the `function_clause` list) plus `beam_rt`'s report renderer. Matrix pinned crate-side and against the live oracle by `tests/error_meta.rs`.
- **`math:erf/1`/`erfc/1` are approximate** (`src/math.rs`): `erf` ≤ 4 ULP, `erfc` up to ~506 ULP — enough to change a `~w` shortest render; glibc fdlibm is not Apache-2.0, so `tools/differential` pins only the bit-exact `atanh/1`.
- **`erlang:display/1` writes a byte ≥ `16#80` of a printable list or binary as UTF-8**, not the oracle's raw latin-1 code unit — bytes `<= 16#7F` are byte-identical; the fix is a byte-oriented `OutputSink` (`src/context.rs` + `beam_rt`).
- **`binary:referenced_byte_size/1`: the reader is C-faithful and the producer now mints real windows; what is still missing is a payload the everyday producer can share, and a host that keeps the window.** `src/term_conv.rs::referenced_byte_size_1` → `src/access.rs::refc_payload_bytes` answers an off-heap window's **parent** payload capacity and an on-heap `ErlHeapBits`/match context's own byte size.
  `src/binary.rs::part_slice` — the one producer behind both `binary:part/2,3` and `erlang:binary_part/2,3` (`src/binconv.rs::binary_part_range` delegates) — writes above `ERL_ONHEAP_BITS_LIMIT` (512 bits) the 8-word `[BinRef][ErlSubBits]` window over an off-heap parent via `access::make_sub_binary` → `beam_term::refc::{sub_binary_words, write_sub_binary}`, so a part of a part composes to the **root** payload's width (a 1025-byte payload windowed at 510 bytes answers `1025`, matching the oracle's compiled-construction figure).

- **A non-small-integer `{chars_limit,N}` is rejected up front** where the oracle fails only when arithmetic *reaches* the value; in-range small-integer limits are byte-identical.
- **`get_module_info`'s `exports`** lists loader-order exports, not the oracle's global export-table order (same set, order only); **`erts_internal:term_type/1`** reports `export` for an `Imported` fun where the oracle reports `fun`.

- **`ets:all/0` answers only this crate's registry, ascending-id** (the oracle also lists the node's system tables, in no order) — the only `ets` value divergence.

## Design Decisions
- **Stateful/global BIFs route through seams** — the crate owns neither global state nor OS machinery; the two seam-free families are the `atomics`/`counters` cells and the `erl_ddll` driver registry + error table, and a resource handle is an on-heap `Ref` thing over a module-local registry (`./src/runtime/CONTEXT.md`).
- **`function_clause` is a bare-atom raise**; `create`/`update` recognize the by-name atoms (`is_exported`, `'_'`) with a local helper, not fixed `AM_*` indices. **`self/0` reads `BifContext::self_pid`, not a global** (the engine is a pure state machine); a match spec's `self/0` is resolved by a scoped `PidHook` install (`src/ets/self_hook.rs`'s `SpecEval`).
- **`BifContext::heap()` is the caller's *destination* heap** — `beam_rt`'s pooled, never-reset `Runtime::bif_heaps` arena (`take_bif_heap`/`put_bif_heap`, default `1<<24` words) **outside** the GC-scanned spaces, so a result built there is unscanned, the runtime's unscanned-root valve *declines* such a collection, and heap exhaustion surfaces as `error:system_limit`. The one exception is an `ets` result under the table-alias witness, handed back pointing into `beam_ets`'s `TermStore`; `beam_rt` copies it in `call_registered`'s tail onto the running process's scanned young heap, or on the table-less `-eval`/`compile:file/2` route onto `Runtime::eval_heap`.
- **The fun-taking fast paths deliberately publish *no* GC roots** (measured): their live `Eterm`s in Rust locals cannot see a collection, because the latch is armed only for the slice's own machine (every nested run has `gc_armed == false`, `beam_rt/src/context/bridges.rs::FunBridge`) **and** the process is `relocation_exempt` for the whole run (`RuntimeContext::apply_fun`).
- **The `ets` table handle is an on-heap `Ref` thing** (the M1 `tid()` substitution) for a normal table and the **name atom** for a `named_table`; a BIF takes the table out of the registry to release the `ctx.atoms()`/`ctx.tables()` borrow, and continuations/compiled specs are `Ref` things over registry keys likewise.

## Performance Notes (per-BIF-call hot path)
- **The registry lookup allocates nothing** (nested maps hashing borrowed `&str`s via `Borrow<str>` + a 1–2 element arity `Vec`); a `beam_rt` dispatch reaches it twice (`contains`, then `call`→`lookup`), and the comparison BIFs resolve the local node once per call, never per element (`src/compare.rs::local_node_id`).
- **The measured allocation/cost inventory lives in `./src/CONTEXT.md`** § *Per-BIF-call cost inventory*: the small-int `+`/`-`/`*` path, `list_to_binary/1`, `length/1`/`list_to_tuple/1`, the `term_to_binary`/`binary_to_term` buffers, the `bits::bytes`-vs-`with_bytes` reader split, the `ets` copy-out words-per-op and the baseline JIT's `byte_size`/`bit_size`/`length` inlining — read the figures there, never a copy here.
- **Every binary this crate *builds* stays on-heap, above the 64-byte `ERL_ONHEAP_BINARY_LIMIT` too** (`src/bits.rs` module doc, `src/access.rs::make_heap_bitstring`) — a documented placement-policy deviation from C (layout byte-identical): a 256-byte `list_to_binary/1` result is an `ErlHeapBits` block, not an off-heap `RefcBinary`.
- **The `AtomTable` deep clone is copy-on-write** (`beam_rt`'s `CodeServer::atoms_mut`): only an interning call pays it, and the decode scratch revalidates its index-identity against a `beam_term::AtomSnapshot` witness in O(1) (full mechanism: `./src/CONTEXT.md` § *Per-BIF-call cost inventory*).
