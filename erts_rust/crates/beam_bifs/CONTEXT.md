# `beam_bifs` — BIF Registry (`bif.tab` Surface) & Implementations

## Intent
Owns the **Built-In Function layer** (Stage 5, Part II §H): the `(module, function, arity)` → implementation registry plus the curated BIF surface, contract **Part I §A.7** — names/modules/arities reproduce `../../erts/emulator/beam/bif.tab`, none invented.
`beam_rt` adapts `BifRegistry` into the engine's `ExecutionContext::call_bif(module, function, arity, args) -> Result<Eterm>` seam (`../beam_engine/CONTEXT.md`).
Failure is **return-based** (`../CONTEXT.md` §3 — inherited, obey): `BadArg`/`BadArith`/`BadArity`/`SystemLimit` plus `BeamError::Raise` for `error`/`exit`/`throw`/`nif_error`/`undef`/`unsupported_bif`.
**A typed error always beats a wrong result**: an unfaithful shape returns the typed gap, never a fabricated value.
Ground truth (read-only): `../../erts/emulator/beam/`, `../../erts/emulator/sys/common/erl_float_short.cpp`, the stdlib sources (`erlang.erl`/`erts_internal.erl`/`ets.erl`/`lists.erl`/`maps.erl`/`io_lib*.erl`/`unicode.erl`/`string.erl`).

**Declared ≠ registered ≠ adopted:** the declared surface is a **disjoint partition** of **367** `DECLARED_IN_CRATE` + **189** `DECLARED_SEAM_BACKED` = 556, a seam key answering the typed `unsupported_bif`/`TermNotFound` until a host installs one of the **fifteen** hook seams that gate a roster key (the fourteen `hook_sets.rs` tables plus `AtomInterner`, table-less because its consumer set is unbounded); of the 189, **139** are `RuntimeHooks` forwarders and **50** spread over the other thirteen tables.
The `BifContext` seam count is **seventeen** — the fifteen plus `OutputSink` (`io:format`'s sink, defaulting to stdout instead of gating a key; it serves this runtime's **own** output stream only, an `io` call whose `group_leader()` is a real device running in `beam_rt` over OTP's `{io_request,…}`/`{io_reply,…}` protocol, `../../beam_rt/src/context/io_route.rs`) and `TableAliasing` (the `ets` table-alias witness, gating **no** roster key).
The dedup **seam union is 222** (`SEAM_UNION`) = **226** raw keys in the **fourteen** public tables − **4** `SHARED_UNION_KEYS` (the four external-term encoders, reading both `LOCAL_FUN_IDENTITY` and `LOCAL_NODE`); **33** members are `UNDECLARED_SEAM_MEMBERS` (registered stdlib fast paths). **208** keys are registered under `src/runtime/` (asserted at `src/runtime/mod.rs:159`) — separate from the 189/367 partition; no dead registrations.
**Never infer "served" from "registered": a key can be shadowed** — `beam_rt`'s native floor answers **before** this registry (`../beam_rt/src/native.rs::try_native`), so an in-crate implementation of a floor-shadowed key is dead code; `./src/runtime/CONTEXT.md` § *Seam-key disposition* splits the 139 into **40 bridge-served + 43 floor-shadowed + 56 unserved**.

## API Surface (FROZEN — `beam_rt` and tests design against this; additive-only changes)
Root + `beam_bifs::prelude::*`: `BifRegistry`/`BifFn`/`default_registry`; `BifContext` + its seventeen seams; `RecordDefinitionView`/`RecordFieldView`; `StdoutSink`/`NullSink`/`BytesSink`; `NifLoadError`; `raise_error`/`raise_exit`/`raise_throw`; `exit_reason_from_term`/`reason_term_from_exit_reason`; `ErrorMeta`/`error_meta` (the `error/2,3` stacktrace payload — Known Issues); `ErrorCause`/`error_cause` (the innermost BIF item's `cause` — Known Issues); `TableRegistry`; `serves_local_call`; `snifs`/`Snif` (the generated static-NIF roster, crate root only); the `hook_sets.rs` tables + `needs_*` predicates (each one bit test of `hook_flags`' build-once flag table); `beam_bifs::bif_tab` and the crate-private `hook_flags` are **not** in the prelude — validation tooling and the internal membership engine respectively.
- **`registry.rs`** — `BifFn = fn(&mut BifContext<'_>, &[Eterm]) -> Result<Eterm>`; `BifRegistry` (nested `module → function → [(arity, BifFn)]`, so `lookup`/`contains` allocate nothing); `with_core_bifs()` = `default_registry()` (the 667-key roster); `register(...)` replaces on repeat; `call(...)` (unknown key ⇒ `error::undefined_bif`, wrong arg count ⇒ `BadArity`); operator BIFs keep their *quoted* `bif.tab` names (`"+"`, `"=:="`, `"!"`, …); registration order is fixed per module, `runtime` last.
- **`serves_local_call(module, function, arity) -> bool`** — `module == "zlib"` plus the 19 `(name, arity)` rows of `zlib.erl`'s non-exported NIF stubs, alongside `prim_tty`'s; a `zlib` stub is reached **two** ways, both served — a local `call` (`beam_rt/src/context/execution.rs::resolve_local_call`) and a local `make_fun3` closure (`zlib.erl` stores `fun deflate_nif/4` in a `#zlib_opts{}` record), which `beam_rt/src/context/apply.rs::served_local_key` declines through the same predicate and dispatches via `call_bif`.
- **`context.rs`** — `BifContext<'a>`: `heap`/`atoms`/`self_pid`/`current_module`, one optional slot per seam, `int`/`atom`/`intern_atom`/`boolean`/`ok`/`make_float`/`tuple`/`cons`/`list`, `pub(crate) atom_and_heap` (the one borrow-table-and-heap route), `ProcessInfoItem`, the `OutputSink` impls.
- **The seventeen optional seams** (a `with_<seam>()` builder + accessor each): `OutputSink`; `SendHook`; `AtomInterner`; `FunCaller` (+ defaulted `call_fun_with_tables(fun, args, tables: Option<&mut TableRegistry>)`); `PortHook`; `DictHook` (+ defaulted `get_all`/`erase_all`); `PersistentTerm`; `NifLoader`; `RecordSource`; `LocalNode` (+ defaulted `local_node_hash(&mut self) -> Option<u32>`); `LocalFunIdentity`; `ModuleInfo`; `ProcessHook`; `MemoryHook`; `RuntimeHooks`; `ExportGate` (the shared `&'a dyn beam_codec::ExportGate`, the `[safe]` `binary_to_term/2` active-export predicate, skipped with none installed); `TableAliasing` (the shared `&'a Cell<bool>` witness `with_table_aliasing`/`alias_table_storage` that `src/ets.rs`'s `copy_out`/`copy_out_list` consult: installed they return the table's own terms and set the cell instead of copying onto `ctx.heap()`, absent the copying path runs — `./src/ets/CONTEXT.md`).
- **Every hook is defaulted** — none installed ⇒ the typed `unsupported_bif` (or a documented `Ok(None)`/fallback for a value-returning seam), **never** a fabricated empty list, `undefined`, `false`, zero or made-up count: stdout for `io:format`; `unsupported_bif` for `send/2`/`"!"/2`/`send/3`, the port/dict/`PersistentTerm`/`ProcessHook`/`ModuleInfo` BIFs, `load_nif/2` and the fun-taking `lists`/`maps` BIFs **for a valid fun** (an invalid fun fails the clause guard first); `TermNotFound` for a new-atom BIF; `Ok(None)` for `record_definition`/`local_fun_identity`/`module_info`/`local_node_hash`; `(nonode@nohost, 0)` for `local_node`, else `None`.
- **`hook_sets.rs`** — the one home of the *seam-consumer* key sets: a `&'static` table per seam plus an allocation-free `needs_*` predicate, `contains`-checked against the live registry; `RUNTIME_HOOKS_BIFS` **139** is asserted *equal* to `runtime::register`'s seam roster and the fourteen tables total **226** keys (union **222**), `AtomInterner` deliberately table-less (`PROCESS_HOOK_BIFS` 12 = `proc_reg::register`'s roster, `bump_reductions/1` the one mutating member; `LOCAL_FUN_IDENTITY_BIFS` 12 = the two encoders, the four fun renderers (`erlang:fun_to_list/1`, `erlang:display/1`, `io:format/2`, `io_lib:format/2,3`) and the two legacy hash ports (`phash/2`, `phash2/1,2`); `PORT_HOOK_BIFS` 8 = the four declared C spellings `erts_internal:{open_port/2,port_close/1,port_info/1,2}` + the four undeclared `erlang` wrappers). Per-table rosters: `./src/CONTEXT.md`.
- **`hook_flags.rs`** — the one membership engine behind all fourteen `needs_*` predicates: `flags(module, function, arity) -> u16` reads a build-once `OnceLock` flag table (`pub(crate)`) — an 8 KiB, 1024-slot open-addressed linearly probed array of 8-byte `{ tag, flags, key }` buckets plus a separate identity array of one `{ module, function, arity }` per distinct key, read only when a bucket's tag matches the queried fingerprint (so a probe stays in L1).
  The fingerprint is a bounded-load one — the two names' lengths, the arity and the leading/trailing eight-byte window of each name avalanched once — so a whole key costs two multiplies instead of one `imul` per name byte; `flags`, `FlagTable::lookup` and the fingerprint are `#[inline]`, so a host's dispatch check carries the probe in its own body.
  The table is built **exclusively** from the fourteen `pub` tables of `hook_sets.rs` through a fixed-length `(bit, table)` roster `FlagTable::build` destructures exhaustively, so `flags(..) & FLAG != 0` ⇔ the key is listed by that table's keys **by construction** and a key in no table has `flags == 0`; compile-time assertions pin the fourteen bits pairwise distinct and filling `0..14`, the 226 raw keys fitting the probe array (which is what makes a probe sequence terminate) and a key index fitting `u16`.
  **Soundness never depends on the fingerprint**: a lookup compares the full `(module, function, arity)` before trusting a slot's flags, so a collision — including a name longer than sixteen bytes that differs only in its middle, which neither window sees — costs a probe, never a wrong answer; there is deliberately no per-thread/last-key cache, whose pointer-keyed form is unsound across calls.
  Pinned by `the_flags_agree_with_a_linear_scan_of_every_table` (every `default_registry()` key at its own and `arity + 1` plus near-miss names against a linear scan of its table), plus `a_short_name_and_a_long_name_both_probe_correctly`, `a_deliberate_fingerprint_collision_still_answers_correctly` and `the_probe_array_is_eight_kilobytes_and_its_indices_are_in_range`.
  **Measured (`bench run --quick --runtime rust --workloads copy_bound`, `taskset -c 3`, `perf stat cpu_core/instructions/u`, five interleaved A/B rounds): the roster walk cost ≈1 540 instructions per operation and the flag table ≈0 — −4.4 % on whole-run instructions (`119 568 366 455 → 114 303 616 086`, ±0.05 %) and −5.3 % on cycles**, the pre-change `binary_search_by` (`4.62 %`) and `__memcmp_avx2_movbe` (`7.59 %`) cycle shares collapsing to `2.3 %` of `memcmp` and no `binary_search_by`; that session's `ns_per_op` rows are **not** evidence on this host (a 109 → 34 one-minute load swing), so read the deterministic instruction count.
  **The residual is budget in the caller:** `beam_rt`'s dispatch prologue asks **twelve** predicates about one key (≈4.7 % of `copy_bound` cycles at ≈1.5 memo-miss dispatches per operation), and collapsing that to one probe needs `beam_rt` to call `flags(..)` once and hand the bits to the twelve readers.
- **`error.rs`** — `pub(crate)` `badarg`/`badarith`/`badarity`/`system_limit`/`undefined_bif`/`unsupported_bif`/`function_clause`; public `raise_error`/`raise_exit`/`raise_throw` over `beam_common::{Raise, ExitReason, ExceptionClass}`; `raise_term`/`raise_error_term` set `reason = ExitReason::Structured` with the term in the opaque `Raise::with_live_reason`/`LiveReason` slot (`as_atom()` stays `None`); `structured_error` builds `{Tag, Elements…}`, degrading to plain `badarg()` when `tag` cannot be interned.
- **`reason.rs`** — `exit_reason_from_term(term, &AtomTable) -> ExitReason`; `reason_term_from_exit_reason` rejects `Structured` with `BadArg`; `error/1,2,3`/`exit/1`/`throw/1`/`nif_error/1,2` run their argument through it (an **atom** keeps its exact `ExitReason` with **no** live slot, a **non-atom** becomes `Structured` carrying the term).
- **`reason.rs` raise payloads** — `error/2`, `error/3` and `nif_error/2` attach `Raise::saved_args` = their **verbatim** second argument (`bif.c:1448-1452`/`:1525`); `error/3` also attaches `Raise::error_info` = the **last** `{error_info, Map}` of a wholly-valid proper option list (`scan_error_info`), nothing on any deviation (non-list, `[]`, improper, non-2-tuple, wrong key atom, non-map value, a valid pair followed by anything invalid) — the C's silent `error/2` fallback, never `badarg` (`bif.c:1462-1501`); `nif_error/2`'s payload is stored but **unobservable** in the oracle's trace (the genuine-BIF-frame path rebuilds `Args` from the BIF arity). Both are **live `Eterm` words on the caller's heap**, out-of-band (ignored by `Raise`'s `PartialEq`/`Eq`, never printed by `Debug`): nothing between reading them and returning the raise may allocate on a BEAM heap, intern an atom or call the host. `ErrorMeta { args, error_info }` + `error_meta(args, Option<options>, &AtomTable)` model the same payload over the same rule (`scan_error_info_at`), pinned row-for-row by `tests/error_meta.rs`.
- **`print::c_printf::term_text`** — the crate's one **public** renderer outside the `pub use` list + `prelude`: `term_text(ctx, term, precision: i64) -> Result<String>`, `precision` the C `dcount` **byte** budget (`i64::MAX` = the `INT_MAX` form); it registers no BIFs and moves no roster figure. Detail: `./src/CONTEXT.md` § *The `%T` renderer*.

## Constraints
- **Errors:** `beam_common::{Result, BeamError}` only — never a crate-local error enum, never `panic!`, never `unwrap()` on runtime data, never a wrong result; `BadArg`/`BadArith`/`BadArity`/`SystemLimit` for argument/numeric/arity/size failures, the typed `unsupported_bif` **raise** for a capability gap — a capability gap is never reported as `badarg` (the argument is valid), and a `badarg` is never reported as a capability gap.
- **Never re-implement term order/size/hashing/construction.** Comparison ⇒ `beam_term::compare::{cmp, cmp_arith}`; hashing ⇒ `beam_term::hashing` (`term_hash` + the pinned `make_hash`/`make_hash2`); construction/inspection ⇒ `beam_term` accessors only (via `access.rs`); allocation ⇒ `beam_alloc::Heap`.
- **`unsafe` confinement.** `#![deny(unsafe_code)]`; the only two `#[allow(unsafe_code)]` modules are `src/access.rs` (the raw map/term writers) and `src/calendar/localtime.rs` (the C time-library bridge); `unsafe_op_in_unsafe_fn` stays clean.
- **Deps (fixed by `Cargo.toml`):** `beam_common`, `beam_term`, `beam_alloc`, `beam_abi`, `beam_process`, `beam_message`, `beam_codec`, `beam_deflate` (the workspace's zlib 1.3.2 port), `beam_ets`, `beam_gc`, `libc`; **no `beam_loader` edge** (record definitions arrive through `RecordSource`); a new dependency edge must be reported to `../`.
- **Files target ~1000 lines**, exceeded only via in-module `#[cfg(test)]` suites; the printer and the `ets` bridge are **split by responsibility**; **licensing Apache-2.0**, every `*.rs` carrying the OTP `// %CopyrightBegin% … // %CopyrightEnd%` block.

## Notes for Agents
- **No module-loading BIF lives here — do not look for one.** `code:ensure_loaded/1`, `code:load_binary/3`, `code:is_loaded/1` and `code:get_object_code/1` have **no `bif.tab` row**; they are `code.erl` functions served by `beam_rt`'s native floor (`../beam_rt/src/native.rs:424-427`, consulted **before** this registry). ## Known Issues / typed capability gaps
**No known silent wrong *values*.** Every capability gap returns a typed `BeamError`, and every argument error matches the oracle's class; entries marked *divergence* are honest but not byte-identical.
### Divergences
- **The `maps` no-op identity is built here but lost at the host's result copy.** `maps:put/3`, `maps:update/3`, `maps:remove/2`, `maps:merge/2` hand back the argument map **term** itself whenever the ERTS arms say the call changes nothing (`src/maps.rs`; a word-identical value for an existing key, remove of an absent key, `merge` with an empty side or with `Map1`'s keys all present in `Map2` — `erl_map.c:1256-1372`/`:2221`/`:2524`; the identity test is **word** equality, never structural), but on the scheduled/`calls` route `beam_rt` copies the result onto the process heap with no destination pass-through (`../beam_rt/src/context/calls.rs::copy_result_fresh`, `:2319`, from `move_result_into_process_heap` `:1831`; the `-eval` route needs the same on `Runtime::eval_heap`), so `erts_debug:same/2` answers `false` where the oracle answers `true` (content `=:=` unaffected) — the fix is a destination-containment short-circuit in `beam_rt`, not here. Same class: `merge/2`/`with/2`/`without/2` still rebuild (only the four single-key writers path-copy), so the C's partially-shared HAMT merges have no analogue — only the six whole-map arms above are modelled.
- **`erlang:error/2,3`'s stacktrace-side payload is modelled but not attached**, so a caught `S` loses it: the oracle's innermost item renders `{M, F, [1,2], [{file,…},{line,N},{error_info,#{…}}]}` where this runtime renders `{M, F, Arity, [{file,…},{line,N}]}` — the raise **class and reason** are oracle-exact in every shape (`error:foo`, `error:{bad,x}`, …), missing are `Args` and the `error_info` map, reproduced by `error_meta` (`src/reason.rs`) yet unloadable because `beam_common::Raise` carries only `class`/`reason`/`stacktrace`/`live_reason` and `StackFrame` is metadata-only. Blocked on an additive slot on `Raise`; the reader is `beam_engine`'s `families/exceptions/stacktrace.rs::symbolic_stacktrace` (the first frame's `A` slot, `ItemShape::args`) plus `beam_rt`'s report renderer; matrix pinned crate-side and against the live oracle by `tests/error_meta.rs`.
- **`math:erf/1`/`erfc/1` are approximate** (`src/math.rs`): `erf` ≤ 4 ULP, `erfc` up to ~506 ULP — enough to change a `~w` shortest render; glibc fdlibm is not Apache-2.0, so `tools/differential` pins only the bit-exact `atanh/1`.
- **`erlang:display/1` writes a byte ≥ `16#80` of a printable list or binary as UTF-8**, not the oracle's raw latin-1 code unit — bytes `<= 16#7F` are byte-identical; the fix is a byte-oriented `OutputSink` (`src/context.rs` + `beam_rt`).
- **`binary:referenced_byte_size/1`: the reader is C-faithful and the producer mints real windows; what is missing is a payload the everyday producer can share, and a host that keeps the window.** `src/term_conv.rs::referenced_byte_size_1` → `src/access.rs::refc_payload_bytes` answers an off-heap window's **parent** payload capacity and an on-heap `ErlHeapBits`/match context's own byte size; `src/binary.rs::part_slice` — the one producer behind `binary:part/2,3` and `erlang:binary_part/2,3` (`src/binconv.rs::binary_part_range` delegates) — writes above `ERL_ONHEAP_BITS_LIMIT` (512 bits) the 8-word `[BinRef][ErlSubBits]` window via `access::make_sub_binary` → `beam_term::refc::{sub_binary_words, write_sub_binary}`, so a part of a part composes to the **root** payload's width (a 1025-byte payload windowed at 510 bytes answers `1025`, the oracle's compiled-construction figure).
  Two residuals, each with its owner: (a) `beam_rt`'s `copy_result_fresh` gives `beam_message::copy_struct` an **empty** source `OffHeapTable`, so a minted window is flattened on the way to the process heap — the host fix is to hand the copier the owning `OffHeapTable` (or adopt by payload data pointer); (b) this crate's own producers (`binary:copy/1,2`, `list_to_bin/1`, `iolist_to_binary/1`, `split_binary/2`) build `ErlHeapBits` at any size, so `binary:referenced_byte_size(binary:part(binary:copy(<<1>>,100),0,65))` answers `65` where the oracle answers `100` — that needs a refc-producing seam this crate does not have.
  The measured matrix (a **compiled** construction answers `1025`, `-eval` `2050` — the C reports the payload's *allocated* size), the `erts_debug:same/2` controls and the `no_case_pins_referenced_byte_size` guard are `../../tools/differential/divergences.md` §A.7.
- **A non-small-integer `{chars_limit,N}` is rejected up front** where the oracle fails only when arithmetic *reaches* the value; in-range small-integer limits are byte-identical.
- **`get_module_info`'s `exports`** lists loader-order exports, not the oracle's global export-table order (same set, order only); **`erts_internal:term_type/1`** reports `export` for an `Imported` fun where the oracle reports `fun`.

## Design Decisions
- **Stateful/global BIFs route through seams** — the crate owns neither global state nor OS machinery; the two seam-free families are the `atomics`/`counters` cells and the `erl_ddll` driver registry + error table, and a resource handle is an on-heap `Ref` thing over a module-local registry (`./src/runtime/CONTEXT.md`).
- **`function_clause` is a bare-atom raise**; `create`/`update` recognize the by-name atoms (`is_exported`, `'_'`) with a local helper, not fixed `AM_*` indices. **`self/0` reads `BifContext::self_pid`, not a global** (the engine is a pure state machine); a match spec's `self/0` is resolved by a scoped `PidHook` install (`src/ets/self_hook.rs`'s `SpecEval`).
- **`BifContext::heap()` is the caller's *destination* heap** — `beam_rt`'s pooled, never-reset `Runtime::bif_heaps` arena (`take_bif_heap`/`put_bif_heap`, default `1<<24` words) **outside** the GC-scanned spaces, so a result built there is unscanned, the runtime's unscanned-root valve *declines* such a collection, and heap exhaustion surfaces as `error:system_limit`. The exception is an `ets` result under the table-alias witness, returned pointing into `beam_ets`'s `TermStore`; `beam_rt` copies it in `call_registered`'s tail onto the running process's scanned young heap, or on the table-less `-eval`/`compile:file/2` route onto `Runtime::eval_heap`.
- **The fun-taking fast paths deliberately publish *no* GC roots** (measured): their live `Eterm`s in Rust locals cannot see a collection, because the latch is armed only for the slice's own machine (every nested run has `gc_armed == false`, `beam_rt/src/context/bridges.rs::FunBridge`) **and** the process is `relocation_exempt` for the whole run (`RuntimeContext::apply_fun`).
- **The `ets` table handle is an on-heap `Ref` thing** (the M1 `tid()` substitution) for a normal table and the **name atom** for a `named_table`; a BIF takes the table out of the registry to release the `ctx.atoms()`/`ctx.tables()` borrow, and continuations/compiled specs are `Ref` things over registry keys likewise.
- **No long-lived slot holds a caller-heap word — audited slot by slot**: every registry stores immediates, owned `String`/`Vec`/`u64` data, or a `beam_ets::TermStore` deep copy (`spec_store`, `spec_input_store`, the compiled-pattern bytes, the `atomics`/`counters` limbs keyed by the handle `id`, `erl_ddll`'s `String`s + `ProcessId`, `erts_debug`'s call-scoped `size_shared/1` set); `ets:delete/1` is the one **permanent** removal (`TableRegistry::remove`, dropping the table's continuations with its store) while `take`/`restore_table` keeps both. The one hazard left is `beam_ets`'s `Cursor::Anchor` under `ets:delete_all_objects/1` — `beam_ets`'s to close (`./src/CONTEXT.md` § *Heap lifetime*).

## Performance Notes (per-BIF-call hot path)
- **The registry lookup allocates nothing** (nested maps hashing borrowed `&str`s via `Borrow<str>` + a 1–2 element arity `Vec`); a `beam_rt` dispatch reaches it twice (`contains`, then `call`→`lookup`), and the comparison BIFs resolve the local node once per call, never per element (`src/compare.rs::local_node_id`).
- **The measured allocation/cost inventory is `./src/CONTEXT.md`** § *Per-BIF-call cost inventory* (small-int `+`/`-`/`*`, `list_to_binary/1`, `length/1`/`list_to_tuple/1`, the `term_to_binary`/`binary_to_term` buffers, the `bits::bytes`-vs-`with_bytes` split, the `ets` copy-out words-per-op, the baseline JIT's `byte_size`/`bit_size`/`length` inlining) — read the figures there, never a copy here.
- **Every binary this crate *builds* stays on-heap, above the 64-byte `ERL_ONHEAP_BINARY_LIMIT` too** (`src/bits.rs` module doc, `src/access.rs::make_heap_bitstring`) — a documented placement-policy deviation from C (layout byte-identical): a 256-byte `list_to_binary/1` result is an `ErlHeapBits` block, not an off-heap `RefcBinary`.
- **The `ets` copy-out is the measured `ets_copy` cost** (`tests/ets_table_alias.rs`): pooled-heap words per op are `lookup/2` of one `{k,42}` object **5 → 2**, `tab2list/1` of 3 objects **15 → 6**, `lookup_element/3` of a boxed element **3 → 0**, a miss/empty result **0 → 0**.
- **The `AtomTable` deep clone is copy-on-write** (`beam_rt`'s `CodeServer::atoms_mut`): only an interning call pays it.
- **The decode scratch revalidates in O(1) in the steady state:** the per-thread `DECODE_SCRATCH` memo carries a `beam_term::AtomSnapshot` witness **taken from the shared table itself**, so `memo.len() == witness.len()` plus `shared.appended_since(witness)` proves index-identity with **zero** name reads; `prefix_matches` is the fallback, its Θ(atom-table) reads running only for a replaced or shrunk instance or a memo left longer by a failed/`safe` decode, and `beam_rt/src/nif.rs` shares the same witness so both decoding hosts cannot drift.
- **`term_to_binary/1`/`binary_to_term/1` allocation inventory** (one 5-key-map round trip): **encode reuses the thread's `ENCODE_SCRATCH`** (`src/binconv.rs:695-728`), so a warm call allocates **no** buffer — the image is the recycled `Writer`'s own bytes (`Encoder::with_writer` writes `VERSION_MAGIC` first, `take_writer` moves the `Vec` out) and `make_bin` copies it **once** into the on-heap binary block (`src/access.rs:484-509`);
  only the first call on a thread pays the 128 B `EncodeScratch` reservation, and `term_to_binary/2` does not use the scratch at all (`src/binconv.rs:740-744` → `Encoder::new`).
  **Decode reads the image by borrow** (`decode_term_bif` → `bits::with_bytes`, `src/binconv.rs:1612`), so there is no input-image copy; a ≤ 32-pair map stages on a stack array (`beam_codec`'s `decode_map`, `STACK_STAGE` 32) and `beam_term::map::write_map`'s `pairs.to_vec()` is the one `Vec<(Eterm,Eterm)>`; **no** per-call `HashMap`/`HashSet`/`String`/`format!` (the atom memo makes `fresh` empty, so `names_since` and the interner commit are skipped).

  Measured with `tests/binconv_alloc.rs`'s deterministic per-thread allocator: a 101-byte image encodes in **1 alloc / 128 B** (that one allocation is the scratch's cold reservation) and a 4102-byte image in **2 / 4102 B**; the file's live decode pins are **bands**, not numbers (`map` decode ≤ 16 alloc / ≤ 1024 B, `big` decode ≤ image + 1024 B — the latter sized for one input-image copy the borrow-based read no longer makes), and its header table's older `4 / 285 B` decode figures are not re-derived.
- **`term_to_binary/1,2` carry a dispatch-route seam a codec-side change cannot remove.** Both keys are `LOCAL_FUN_IDENTITY_BIFS` members (`src/hook_sets.rs:171-172`), so `beam_rt` builds a `FunIdentityBridge` per call (one `Rc` clone plus a caller-first `position()` scan of the cached loaded-module snapshot), and this crate hands the codec a per-fun `beam_codec::FunIdentityResolver` — `CtxFunIdentity` over the context's `LocalFunIdentity` seam (`src/binconv.rs:1062-1075`) — which the encoder consults **only for a `FunKind::Local` fun** (`beam_codec/src/encode/fun.rs:84`), so a map or any other non-fun argument pays no seam call at all.

  Cost detail and the `Rc`-cached snapshot live at the owner: `../beam_rt/src/context/pool/CONTEXT.md`.

### Binary/bitstring BIF cost inventory (30-byte subject)
- **Readers copy the whole payload out of the term by default.** `bits::bytes` → `access::binary_bytes` (`src/access.rs:549`, `.to_vec()`) is the owned form at ~67 non-test call sites; the borrowing `bits::with_bytes` (`src/bits.rs:157` → `src/access.rs:600`, zero allocation) has **six**: `src/binconv.rs:440` (`erlang:binary_part/2,3`), `src/binconv.rs:1612` (`decode_term_bif`, the `binary_to_term/1,2` image), `src/binary.rs:630` (`binary:at/2`), `:671` (`binary:part/2,3`), `:1019` (`binary:bin_to_list/2,3`) and the iolist walk itself (`src/iolist.rs:210`).

- **The byte flattening is `crate::iolist` — one walk, everywhere.** `list_to_binary/1`, `erlang:iolist_to_binary/1` (`src/binary.rs:864`, a bare byte-aligned binary is returned as-is), `binary:list_to_bin/1` (`:709`) and `iolist_size/1` (`:885`) all run it, and `iolist_size/1` **allocates nothing** (a measuring walk). `BitBuf` survives only for the two shapes that genuinely differ: `list_to_bitstring/1`'s `Unit = 1` bit assembly (`:927`, `collect_bitstring_pieces`) and `split_binary/2` (`:945`).
- **Size/length helpers are 0-alloc** (`byte_size/1` `src/binconv.rs:405`, `bit_size/1` `:397`, `size/1` `src/term_ops.rs:195`, `binary:referenced_byte_size/1` `src/term_conv.rs:277`), and `erlang:byte_size/1`, `erlang:bit_size/1` and `erlang:length/1` are **all three** inlined by the baseline JIT — the value half of its six-BIF inline set (the pure aggregate accessors `hd/1`, `element/2` with a compile-time small-int index and `tuple_size/1` reuse the aggregate in-block lowerings; these three are matched as `("byte_size" | "bit_size" | "length", [source])` in `../beam_engine/src/jit/baseline/emit/bif.rs:264` and evaluated by the Rust helper `jit_bif_value`, `../beam_engine/src/jit/baseline/bif_helper.rs:180`), so no size/length call crosses a BIF door on the default tier. `bit_size/1` and `byte_size/1` share the **one** bit-length read `bitstring_bits` (`bif_helper.rs:217`; `bit_size_value` `:237` returns it verbatim, `byte_size_value` `:248` rounds it `div_ceil(8)`). Measured worth: `emqx_base62:decode/1` **76 999 → 62 484** instructions/call (**−18.9 %**), that kernel crossing the door 16 times per call for `bit_size/1`.
- **Three semantics under one name:** `byte_size/1` rounds **up** (`bit_size.div_ceil(8)`), `size/1` and `binary:referenced_byte_size/1` **truncate**, and `bits::byte_size` (`src/bits.rs:125`) is dead *and* alignment-requiring.
- **Unary `+`/`-` allocate:** `identity`/`negate` (`src/arith.rs:522`, `:514`) widen through `number` → `Big::from_i64` (`src/arith.rs:732`, `vec![…]`) — one `Vec` per small-int call, deliberately off the `+`/`-`/`*` fast path (`src/arith.rs:412`, `:442`).
