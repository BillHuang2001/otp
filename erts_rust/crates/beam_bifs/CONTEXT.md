# `beam_bifs` — BIF Registry (`bif.tab` Surface) & Implementations

## Intent
Owns the **Built-In Function layer** (Stage 5, Part II §H): the `(module, function, arity)` → implementation registry plus the curated BIF surface, contract **Part I §A.7** — names/modules/arities reproduce `../../erts/emulator/beam/bif.tab`, none invented.
`beam_rt` adapts `BifRegistry` into the engine's `ExecutionContext::call_bif(module, function, arity, args) -> Result<Eterm>` seam (`../beam_engine/CONTEXT.md`).
Failure is **return-based** (`../CONTEXT.md` §3 — inherited, obey): `BadArg`/`BadArith`/`BadArity`/`SystemLimit` plus `BeamError::Raise` for `error`/`exit`/`throw`/`nif_error`/`undef`/`unsupported_bif`.
**A typed error always beats a wrong result**: an unfaithful shape returns the typed gap, never a fabricated value.
Ground truth (read-only): `../../erts/emulator/beam/`, `../../erts/emulator/sys/common/erl_float_short.cpp`, and the stdlib sources (`erlang.erl`/`erts_internal.erl`/`ets.erl`/`lists.erl`/`maps.erl`/`io_lib*.erl`/`unicode.erl`/`string.erl`).

## Roster census (authoritative; code-derived, pinned by `tests/roster_audit.rs`)
`bif.tab` declares **556** entries = `bif` **476** + `ubif` **73** + `hbif` **7**, `MISSING_DECLARED` **0** — pinned by `tests/bif_tab.rs` (`IMPLEMENTED_DECLARED` 556, `MISSING_DECLARED` 0, `FAST_PATHS` 111, `REGISTRY_SIZE` 667); `tests/roster_audit.rs` (`:106-142`) builds the seam union from the fourteen public tables (never a hard-coded list) and asserts the partition, the union size, the per-table/per-module declared counts and every union member's `needs_*` predicate.
`default_registry()` = `BifRegistry::with_core_bifs()` = **667 keys** = **556 declared + 111 stdlib fast paths** (the fast-path set re-derived from `bif_tab::census(..).fast_paths`, never from this prose).
The 111 fast paths by module: `lists` 40 (18 fun-taking), `zlib` **25** (six one-shots + the 19 NIF-level stream keys), `erlang` 15, `maps` 12, `ets` 8, `binary` 3, `io_lib` 3, `unicode` 3, `io` 2; `binary:referenced_byte_size/1` and the OTP-30 `pid_to_binary`/`ref_to_binary`/`port_to_binary` are **declared** (`bif.tab:561`, `:866-868`), and none of the 19 `zlib` stream keys is hook-gated.
**Declared ≠ registered ≠ adopted.** The declared surface is a **disjoint partition**: **367** `DECLARED_IN_CRATE` (unconditional in-crate) + **189** `DECLARED_SEAM_BACKED` = 556 — each seam-backed key answers the typed `unsupported_bif`/`TermNotFound` until a host installs one of the **fifteen** hook seams that gate a roster key (the fourteen `hook_sets.rs` tables plus `AtomInterner`, which has no table because its consumer set is unbounded); of the 189, **140** are `RuntimeHooks` forwarders and **49** distribute over the other thirteen tables.
The `BifContext` seam count is **seventeen** — the fifteen hook seams plus `OutputSink` (the `io:format` sink, defaulting to stdout instead of gating a key) and `TableAliasing` (the `ets` table-alias witness, which gates **no** roster key).
The dedup **seam union is 222** (`SEAM_UNION`) = **226** raw keys in the **fourteen** public tables − **4** `SHARED_UNION_KEYS` (the four external-term encoders, which read both `LOCAL_FUN_IDENTITY` and `LOCAL_NODE`); **33** union members are `UNDECLARED_SEAM_MEMBERS` (registered stdlib fast paths, not table declarations).
**209** keys are registered under `src/runtime/` (asserted at `src/runtime/mod.rs:159`) — separate from the 189/367 partition, never conflated with it; there are **no dead registrations**.
**Never infer "served" from "registered": a key can be shadowed** — `beam_rt`'s native floor answers **before** this registry (`../beam_rt/src/native.rs::try_native`), so an in-crate implementation of a floor-shadowed key is dead code; `./src/runtime/CONTEXT.md` § *Seam-key disposition* splits the 140 into **40 bridge-served + 43 floor-shadowed + 57 unserved**.

### The oracle cross-check behind "556 = 556" (the enumeration method)
`erlang:system_info(bif_list)` is **`badarg`** on OTP 29.1.1 / erts-17.1, so the roster was enumerated through `code:all_available()` → `beam_lib:chunks(File, [exports])` (or `M:module_info(exports)` for a `preloaded` module), keeping every `(M,F,A)` with `erlang:is_builtin/3` `true`: **exactly 556 keys over the same 25 modules** as `bif.tab`.
The asymmetries are version- or instruction-related, none a gap: `apply/2,3`/`yield/0` are `is_builtin`-true instructions with no `bif.tab` row, the three OTP-30 `*_to_binary/1` are additions, and the 29 quoted operator rows are invisible to an ASCII-only `exports` scan on either side.

## API Surface (FROZEN — `beam_rt` and tests design against this; additive-only changes)
Root + `beam_bifs::prelude::*`: `BifRegistry`/`BifFn`/`default_registry`; `BifContext` + its seventeen seams; `RecordDefinitionView`/`RecordFieldView`; `StdoutSink`/`NullSink`/`BytesSink`; `NifLoadError`; `raise_error`/`raise_exit`/`raise_throw`; `exit_reason_from_term`/`reason_term_from_exit_reason`; `TableRegistry`; `serves_local_call`; the `hook_sets.rs` tables + `needs_*` predicates (`beam_bifs::bif_tab` is **not** in the prelude — validation tooling).
- **`registry.rs`** — `BifFn = fn(&mut BifContext<'_>, &[Eterm]) -> Result<Eterm>`; `BifRegistry` (nested `module → function → [(arity, BifFn)]`, so `lookup`/`contains` are allocation-free); `with_core_bifs()` = `default_registry()` (the 667-key roster); `register(...)` replaces on repeat; `call(...)` (unknown key ⇒ `error::undefined_bif`, wrong arg count ⇒ `BadArity`); operator BIFs keep their *quoted* `bif.tab` names (`"+"`, `"=:="`, `"!"`, …); registration order is fixed per module with `runtime` last.
- **`serves_local_call(module, function, arity) -> bool`** — `module == "zlib"` plus the 19 `(name, arity)` rows of `zlib.erl`'s non-exported NIF stubs, alongside `prim_tty`'s. A `zlib` stub is reached **two** ways and both must be served: as a local `call` (`beam_rt/src/context/execution.rs::resolve_local_call`) and as a local `make_fun3` closure (`zlib.erl` stores `fun deflate_nif/4` in a `#zlib_opts{}` record), which `beam_rt/src/context/apply.rs::served_local_key` declines through the same predicate and dispatches via `call_bif`.
- **`context.rs`** — `BifContext<'a>`, the one per-call context: `heap`/`atoms`/`self_pid`/`current_module`, one optional slot per seam, the constructors `int`/`atom`/`intern_atom`/`boolean`/`ok`/`make_float`/`tuple`/`cons`/`list`, `pub(crate) atom_and_heap` (the one borrow-table-and-heap route), `ProcessInfoItem`, the `OutputSink` impls.
- **The seventeen optional seams** (each a `with_<seam>()` builder + accessor): `OutputSink`; `SendHook`; `AtomInterner`; `FunCaller` (+ the **defaulted** `call_fun_with_tables(fun, args, tables: Option<&mut TableRegistry>)`); `PortHook`; `DictHook` (+ the defaulted `get_all`/`erase_all`); `PersistentTerm`; `NifLoader`; `RecordSource`; `LocalNode` (+ the **defaulted** `local_node_hash(&mut self) -> Option<u32>`); `LocalFunIdentity`; `ModuleInfo`; `ProcessHook`; `MemoryHook`; `RuntimeHooks`; `ExportGate` (a **shared** `&'a dyn beam_codec::ExportGate`, the `[safe]` `binary_to_term/2` active-export predicate, skipped entirely with none installed).
  The seventeenth is `TableAliasing` — a **shared** `&'a std::cell::Cell<bool>` witness (`with_table_aliasing`, crate-internal `alias_table_storage`) that `src/ets.rs`'s `copy_out`/`copy_out_list` consult: with one installed they hand back the table's own terms and set the cell instead of copying onto `ctx.heap()`, so the host's copy-out is the only copy; with none the copying path runs unchanged (`./src/ets/CONTEXT.md`).
- **Every hook is defaulted** — with none installed the BIF answers the typed `unsupported_bif` gap (or a documented `Ok(None)`/fallback for a value-returning seam), **never** a fabricated empty list, `undefined`, `false`, zero or made-up count.
  Unset defaults: stdout for `io:format`; `unsupported_bif` for `send/2`/`"!"/2`/`send/3`, the port/dict/`PersistentTerm`/`ProcessHook`/`ModuleInfo` BIFs, `load_nif/2` and the fun-taking `lists`/`maps` BIFs **for a valid fun** (an invalid fun fails the clause guard first); `TermNotFound` for a new-atom BIF; `Ok(None)` for `record_definition`/`local_fun_identity`/`module_info`/`local_node_hash`; `(nonode@nohost, 0)` for `local_node`, else `None`.
- **`hook_sets.rs`** — the one home of the *seam-consumer* key sets: a `&'static` table per seam + an allocation-free `needs_*` predicate, `contains`-checked against the live registry; `RUNTIME_HOOKS_BIFS` **140** is asserted *equal* to `runtime::register`'s seam roster, the fourteen tables total **226** keys (union **222**), and `AtomInterner` deliberately has **no** table — a host gates its seams through these, never a private copy.
  `LOCAL_FUN_IDENTITY_BIFS`'s 12 keys are the two encoders, the four fun renderers (`erlang:fun_to_list/1`, `erlang:display/1`, `io:format/2`, `io_lib:format/2,3`) and the two legacy hash ports (`phash/2`, `phash2/1,2`); `PORT_HOOK_BIFS`'s 8 are the 4 declared C spellings (`erts_internal:{open_port/2,port_close/1,port_info/1,2}`) plus the 4 undeclared `erlang` wrappers.
- **`error.rs`** — `pub(crate)` `badarg`/`badarith`/`badarity`/`system_limit`/`undefined_bif`/`unsupported_bif`/`function_clause`; public `raise_error`/`raise_exit`/`raise_throw` over `beam_common::{Raise, ExitReason, ExceptionClass}`; `raise_term`/`raise_error_term` set `reason = ExitReason::Structured` with the term in the opaque `Raise::with_live_reason`/`LiveReason` slot (`as_atom()` stays `None`); `structured_error` builds `{Tag, Elements…}`, degrading to plain `badarg()` when `tag` cannot be interned.
- **`reason.rs`** — `exit_reason_from_term(term, &AtomTable) -> ExitReason`; `reason_term_from_exit_reason` rejects `Structured` with `BadArg`; the `error/1,2,3`/`exit/1`/`throw/1`/`nif_error/1,2` BIFs run their argument through it — an **atom** reason keeps its exact `ExitReason` with **no** live slot, a **non-atom** one is `Structured` carrying the term.
- **`print::c_printf::term_text`** — the crate's one **public** renderer outside the `pub use` list + `prelude`: `term_text(ctx, term, precision: i64) -> Result<String>`, `precision` the C `dcount` **byte** budget (`i64::MAX` = the `INT_MAX` form); it registers no BIFs and moves no roster figure. Detail: `./src/CONTEXT.md` § *The `%T` renderer*.

## Constraints
- **Errors:** `beam_common::{Result, BeamError}` only — never a crate-local error enum, never `panic!`, never `unwrap()` on runtime data, never a wrong result.
  `BadArg`/`BadArith`/`BadArity`/`SystemLimit` for argument/numeric/arity/size failures; the typed `unsupported_bif` **raise** for a capability gap — a capability gap is never reported as `badarg` (the argument is valid), and a `badarg` is never reported as a capability gap.
- **Never re-implement term order/size/hashing/construction.** Comparison ⇒ `beam_term::compare::{cmp, cmp_arith}`; hashing ⇒ `beam_term::hashing` (`term_hash` + the pinned `make_hash`/`make_hash2`); construction/inspection ⇒ `beam_term` accessors only (via `access.rs`); allocation ⇒ `beam_alloc::Heap`.
- **`unsafe` confinement.** `#![deny(unsafe_code)]`; the only two `#[allow(unsafe_code)]` modules are `src/access.rs` and `src/calendar/localtime.rs` (the C time-library bridge); `unsafe_op_in_unsafe_fn` stays clean.
- **Deps (fixed by `Cargo.toml`):** `beam_common`, `beam_term`, `beam_alloc`, `beam_abi`, `beam_process`, `beam_message`, `beam_codec`, `beam_deflate` (the workspace's zlib 1.3.2 port), `beam_ets`, `beam_gc`, `libc`; **no `beam_loader` edge** (record definitions arrive through `RecordSource`); a new dependency edge must be reported to `../`.
- **Files target ~1000 lines**, exceeded only via in-module `#[cfg(test)]` suites; the printer and the `ets` bridge are **split by responsibility**; **licensing Apache-2.0**, every `*.rs` carrying the OTP `// %CopyrightBegin% … // %CopyrightEnd%` block.

## Known Issues / typed capability gaps
**No known silent wrong *values*.** Every capability gap returns a typed `BeamError`, and every argument error matches the oracle's class; entries marked *divergence* are honest but not byte-identical.
### Divergences
- **`math:erf/1`/`erfc/1` are approximate** (`src/math.rs`): `erf` ≤ 4 ULP, `erfc` up to ~506 ULP — enough to change a `~w` shortest render; glibc fdlibm is not Apache-2.0, so `tools/differential` pins only the bit-exact `atanh/1`.
- **`erlang:display/1` writes a byte ≥ `16#80` of a printable list or binary as UTF-8**, not the oracle's raw latin-1 code unit — bytes `<= 16#7F` are byte-identical; the fix is a byte-oriented `OutputSink` (`src/context.rs` + `beam_rt`).
- **A non-small-integer `{chars_limit,N}` is rejected up front** where the oracle fails only when arithmetic *reaches* the value; in-range small-integer limits are byte-identical.
- **`get_module_info`'s `exports`** lists loader-order exports, not the oracle's global export-table order (same set, order only); **`erts_internal:term_type/1`** reports `export` for an `Imported` fun where the oracle reports `fun`.
- **Reject-where-the-oracle-succeeds:** `re:inspect/2` of a non-`namelist` item is the typed gap where the oracle raises `badarg`; `lists` of a non-list/improper argument raises `badarg` where the oracle raises `function_clause`/`case_clause`/`{bad_generator,_}`.
- **Mixed internal/external `pid`/`port`/`ref` ordering** is only as faithful as the frozen layout allows (`beam_term`'s, not this crate's): an external id whose node **name** equals the local one but whose `creation` differs, and a mixed port pair at equal nodes, follow `beam_term`'s documented total convention.
### `[safe]` `EXPORT_EXT` over-accepts (accept-where-the-oracle-rejects)
- **A `[safe]` decode materializes an `EXPORT_EXT` for any `M:F/A`**, where C's `erts_decode_ext` requires an **active** export entry (`external.c:5032-5036`) and otherwise `badarg`; oracle-verified, `[safe]` accepts `lists:map/2` and rejects `lists:map/3`, `erlang:no_such_bif_xyz/1` and an unloaded `mnesia:start/0`, so the right predicate is `erlang:function_exported/3`'s. The rule exists **only** on the `binary_to_term/2` route (`erts_decode_dist_ext` passes `flags = 0`, `external.c:1296`; `NEW_FUN_EXT` has no safe arm).
- Both halves are wired: the codec's `Decoder::with_export_gate` and this crate's `BifContext::export_gate` (`EXPORT_GATE_BIFS`/`needs_export_gate`, consulted only by `decode_term_bif`, which falls back byte-identically without a gate); `beam_rt` supplies `context/export_gate.rs::ExportGateBridge` (`runtime_hooks::is_active_export` **OR** `registry.contains(m,f,a)`) in `binary_to_term/2`'s dispatch arm, so a host with no gate still over-accepts.
- Adjacent, same owner: `decode_export` reads its atoms through `Decoder::decode_node_atom`, which accepts the `NIL_EXT` marker in `[local]` mode, while C's `EXPORT_EXT` uses plain `dec_atom` (`external.c:5014`, `:5017`) — a `[local]`-wrapped `EXPORT_EXT` whose module is `NIL_EXT` is `badarg` on the oracle and materialized here.
### A.3 NIF ABI surface — implemented in `../beam_abi`; the runtime host half is `../beam_rt`
The `enif_schedule_nif` trampoline, the three-step `enif_alloc_env` host resolution (`ThreadEnvHostFactory`) and the `enif_select` `stop`-callback verdict matrix live in `../beam_abi` (`src/nif/enif/{schedule,thread_env,select,resources_stop,stop}.rs`); transcripts `HANDOFF_A3_NIF_HOST.md`, fixtures `tests/fixtures/a3_*.{c,erl}` with `tests/nif_a3_{oracle_replay,abi_assertions}.rs`.
### Typed capability gaps (`unsupported_bif`, never a fabricated value)
- **External (remote-node) pid/port/ref textual ids** (`pid_to_list`/`ref_to_list`/`port_to_list`, the `*_to_binary` forms, the printer's external branch — `src/term_conv.rs::external_channel_gap`): the oracle's channel is the node-name atom's index in the **running VM's** atom table, state the frozen term does not carry, so it needs a node-identity seam **and** a node-atom → dist-channel provider (Handoffs); an internal port renders (`#Port<0.N>`).
- **`term_to_binary/2`'s `local`** is seam-backed (`LocalNode::local_node_hash`), the typed gap only with **no** seam installed; `beam_rt` answers the hash per OS process (`context/node_hash.rs`, the C's Bob-Jenkins block hash over `[time_offset:8 LE][hostname][pid]`), the decoder demotes a `NIL_EXT` marker unconditionally, and the per-VM-start hash means a differential case must mask those four bytes; `external_size/2`'s `local` inherits the seam.
- **`erlang:raise/3`'s unrepresentable stacktrace elements** answer the typed gap while the argument is valid (the list is in `./src/CONTEXT.md`'s `raise/3` entry); the oracle echoes every such shape verbatim.

### Environment-bounded values and bounded M1 leaks
- **`ets:all/0` answers only this crate's registry, ascending-id** (the oracle also lists the node's system tables, in no order) — the only `ets` value divergence.
- **Never-reclaimed registries (bounded M1 leak):** the compiled-pattern, `ets` continuation/compiled-spec and `atomics`/`counters` cell registries have no off-heap finalizer; two are also stale-word hazards — `TableRegistry`'s compiled-spec (`src/ets.rs:612-624`) and continuation (`src/ets.rs:533-586`) maps keep the caller's raw `Eterm` words and are no GC root, so a relocated heap makes `match_spec_run/2`/`_r/3` and a continuation resume read freed words. Full mechanism: `./src/CONTEXT.md` § *Heap lifetime*; the fix needs stable, table-owned copies (`beam_rt`/`beam_ets`).
- **`monotonic_time/0,1` reports the ERTS monotonic epoch** (native unit fixed at ns): `-576460752000000000` plus the process-global elapsed time (`erl_time.h:235-239,312-323`), a large **negative** reading inside `erlang:system_info(start_time)..(end_time)`; `/1` units are floored divisions, so `monotonic_time(U) == erlang:convert_time_unit(monotonic_time(), native, U)`, and `time_offset/0,1` is a bignum with `system_time() == monotonic_time() + time_offset()`.
  `unique_integer >= 0`; `time_unit` accepts the oracle's atom set and a **positive bignum** unit (past `BIG_ARITY_MAX` is `badarg`); **`error/2` ignores its second argument**, `nif_error/2`'s is crash-report metadata; **`prim_*`** modules are otherwise unimplemented (only the three `os_bif.rs` `prim_file` helpers).

### The A.9 `list::car` dangling cons is not this crate's
A `beam_term::list::car` SIGSEGV on the A.9 in-process-compile route is an **incomplete root set at a collection door**: no walker here consumes a container an earlier BIF call built, and no BIF here builds an off-heap `RefcBinary`, so the bin-vheap prune cannot free anything this crate hands out.
Ranked suspects, each recorded at its owning node: the runner's unpublished entry args (`../beam_engine/CONTEXT.md`, `../beam_rt/src/runner/CONTEXT.md`) and `beam_gc`'s non-atomic `Collector::collect_major` error path (`../beam_gc/CONTEXT.md`).
This crate's own raw-`Eterm` stores are the two above — real use-after-rewind landmines, but off the compile route (`beam_lib` uses only `ets:new/insert/lookup/lookup_element/tab2list/delete`).

## Design Decisions
- **Stateful/global BIFs route through seams** — the crate owns neither global state nor OS machinery; the two seam-free families are the `atomics`/`counters` cells and the `erl_ddll` driver registry + error table, and a resource handle is an on-heap `Ref` thing over a module-local registry (`./src/runtime/CONTEXT.md`).
- **`function_clause` is a bare-atom raise**; `create`/`update` recognize the by-name atoms (`is_exported`, `'_'`) with a local helper, not fixed `AM_*` indices. **`self/0` reads `BifContext::self_pid`, not a global** (the engine is a pure state machine); a match spec's `self/0` is resolved by a scoped `PidHook` install (`src/ets/self_hook.rs`'s `SpecEval`).
- **`BifContext::heap()` is the caller's *destination* heap** — `beam_rt`'s pooled, never-reset `Runtime::bif_heaps` arena (`take_bif_heap`/`put_bif_heap`, default `1<<24` words) **outside** the GC-scanned spaces, so a result built there is unscanned, the runtime's unscanned-root valve *declines* such a collection, and heap exhaustion surfaces as `error:system_limit`. The one exception is an `ets` result under the table-alias witness, handed back pointing into `beam_ets`'s `TermStore`; `beam_rt` copies it in `call_registered`'s tail onto the running process's scanned young heap, or on the table-less `-eval`/`compile:file/2` route onto `Runtime::eval_heap`.
- **The fun-taking fast paths deliberately publish *no* GC roots** (measured): their live `Eterm`s in Rust locals cannot see a collection, because the latch is armed only for the slice's own machine (every nested run has `gc_armed == false`, `beam_rt/src/context/bridges.rs::FunBridge`) **and** the process is `relocation_exempt` for the whole run (`RuntimeContext::apply_fun`).
- **The `ets` table handle is an on-heap `Ref` thing** (the M1 `tid()` substitution) for a normal table and the **name atom** for a `named_table`; a BIF takes the table out of the registry to release the `ctx.atoms()`/`ctx.tables()` borrow, and continuations/compiled specs are `Ref` things over registry keys likewise.

## Performance Notes (per-BIF-call hot path)
- **The registry lookup allocates nothing** (nested maps hashing borrowed `&str`s via `Borrow<str>` + a 1–2 element arity `Vec`); a `beam_rt` dispatch reaches it twice (`contains`, then `call`→`lookup`), and the comparison BIFs resolve the local node once per call, never per element (`src/compare.rs::local_node_id`).
- **Small-integer arithmetic allocates nothing:** `erlang:'+'/2`, `'-'/2`, `'*'/2` take a machine-arithmetic fast path when **both** operands are small ints (`src/arith.rs::small_operand`), measured **0 alloc / 0 B**; the exact result is range-tested against `MIN_SMALL..=MAX_SMALL` **before** materialization, so bignum promotion is bit-identical (`MAX_SMALL+1`, `MAX_SMALL*2`, `MIN_SMALL-1` each cost the single widened `Big` allocation). `div`/`rem`/`abs`/the unary and six bit operators stay on the `Big` path; a mixed int/float operand widens for the correctly-rounded `big_to_double`.
- **`list_to_binary/1` allocates one byte buffer and nothing else** (`src/binconv.rs::iolist_bytes`: two passes over **one** `WalkStack`, `iolist_byte_len` validating *and* measuring, then `append_iolist` filling one `Vec::with_capacity`); measured in `tests/binconv_alloc.rs`, the crate's one named allocation pin: flat 64-element list **1 / 64**, mixed ints + binary + sublist **1 / 133**, `[]` **0 / 0**, a 200-deep nest 7 / 1025 (the one spill, inherent to an iterative walk of unbounded depth); `iolist_to_binary/1` has its own walk (`src/binary.rs::collect_byte_unit`) and `make_bin` copies once into the on-heap `ErlHeapBits`.
- **`length/1` allocates nothing and `list_to_tuple/1` allocates once** (`tests/term_ops_alloc.rs`): `src/term_ops.rs::proper_list_len` is an allocation-free count walk, `proper_list` that count plus one exact-capacity `Vec` fill — 1000-element `length/1` **0 / 0**, 100-element `list_to_tuple/1` **1 / 800**.
- **Every binary this crate *builds* stays on-heap, above the 64-byte `ERL_ONHEAP_BINARY_LIMIT` too** (`src/bits.rs` module doc, `src/access.rs::make_heap_bitstring`) — a documented placement-policy deviation from C (layout byte-identical): a 256-byte `list_to_binary/1` result is an `ErlHeapBits` block, not an off-heap `RefcBinary`.
- **The `ets` copy-out is the measured `ets_copy` cost** (`tests/ets_table_alias.rs`): pooled-heap words per op are `lookup/2` of one `{k,42}` object **5 → 2**, `tab2list/1` of 3 objects **15 → 6**, `lookup_element/3` of a boxed element **3 → 0**, a miss/empty result **0 → 0**.
- **The `AtomTable` deep clone is copy-on-write** (`beam_rt`'s `CodeServer::atoms_mut`): only an interning call pays it.
- **The decode scratch revalidates in O(1) in the steady state:** the per-thread `DECODE_SCRATCH` memo carries a `beam_term::AtomSnapshot` witness **taken from the shared table itself**, so `memo.len() == witness.len()` plus `shared.appended_since(witness)` proves index-identity with **zero** name reads; `prefix_matches` is the fallback, its Θ(atom-table) reads running only for a replaced or shrunk instance or a memo left longer by a failed/`safe` decode, and `beam_rt/src/nif.rs` shares the same witness so both decoding hosts cannot drift.
- **`term_to_binary/1`/`binary_to_term/1` allocation inventory** (one 5-key-map round trip): encode = **1** `Vec<u8>` (the `Encoder`'s own `Writer`, moved out by `Encoder::finish`; `compressed_image` takes the image **by value** and hands the same buffer back on the compress-but-not-profitable revert) + the on-heap binary block; decode = 1 `Vec<u8>` + 1 `Vec<(Eterm,Eterm)>` + the map block; **no** per-call `HashMap`/`HashSet`/`String`/`format!`. Measured: a 101-byte image encodes in **1 alloc / 128 B** and decodes in 4 / 285 B; a 4102-byte image in **2 / 4102 B** and 1 / 4102 B; `[local]` costs a **second** image buffer inside `beam_codec` — 4 alloc / 8241 B for the 4102-byte image.
