# `baseline/emit/bitstr_inline` — the native bitstring shapes
## Intent
The baseline tier's native lowerings of the bitstring family's small, allocation-free shapes: fifteen match-context shapes plus the private-append construction shape.
Sixteen shapes are lowered: `bs_get_position`, `bs_set_position`, `bs_test_tail2`, `bs_skip_bits2`, `bs_start_match3`, `bs_start_match4`, `bs_get_integer2`, a fully static `bs_match`, `bs_match_string`, `bs_skip_utf32`, `bs_get_utf32`, `bs_skip_utf16`, `bs_get_utf16`, `bs_skip_utf8`, `bs_get_utf8` and the `bs_create_bin` accumulator build.
The fifteen match-context shapes are straight-line guarded x86-64 sequences over the frozen `ErlSubBits` match-context words — `[thing_word, base_flags, start, end, orig]` (`erts/emulator/beam/erl_bits.h:60-82`) — that emit **no** helper call: `match_string.rs` contributes `bs_match_string` (the module's string table is copied out at compile time), and `utf32.rs`/`utf16.rs`/`utf8.rs` contribute the three fixed-width character pairs.
The construction shape has three routes, each one positioned helper call plus that route's own writes: `Route::Aligned` proves the accumulator's term shape inline as refusal-only branches (`create_door.rs`), makes one positioned `runtime::jit_append_cursor` call that answers the byte cursor, and then emits straight-line byte stores; `Route::BitGranular` makes one positioned `jit_open_append_bin_any`/`jit_open_append_bin_any_y` call that answers the payload base and then writes its fields **in-block** (`create_field.rs`) whenever every field is at most `MAX_INLINE_FIELD_BITS` (57) bits, keeping a positioned `jit_write_bit_field` call per field only for a plan with a wider one; the whole-binary `binary all` tail (`create_binary.rs`) is one positioned `jit_append_binary_all` call, which performs the copy **and** the build's single window-end commit, so that route has no tier-side field phase and no tier-side commit.
Nothing on any route's up-front path writes a term word (the aligned proof stores nothing, `jit_append_cursor` is a `&Machine` query, and the bit-granular openers and `jit_write_bit_field` touch payload bytes only), so every guard that can reach `fallback` runs against the state the interpreter step will see.
No sequence here allocates and none raises, so none runs an interpreter step and no moving collection can interleave inside one.
**A shape the emitter cannot prove safe is refused at compile time**: its `*_shape` predicate answers `None`, the `try_inline_bs_*` entry answers `Ok(false)` having emitted **zero bytes**, and `emit/block.rs`'s arm falls through to `emit_bitstr(...)` — the family helper, i.e. exactly the tier's behaviour for every other `Bs*` variant.
**An addressable operand whose run-time value is wrong** (not a match context, a position outside the small range, a window too short, a subject form the extractor cannot read) branches to a local `fallback` label that runs exactly one interpreter step (`emit_step_and_continue`), so the process sees the family's own typed error and never a fabricated value.
The sixteen `emit/block.rs` arms sit **above** the `_ if bitstrings::claimed(instr) => emit_bitstr(...)` guard arm, because a `match` arm after a `_ if` guard arm is unreachable.
Ground truth is the interpreter's own family body — `crate::families::bitstrings::{matching, commands, raw}` — which is the in-tree oracle; this node adds no semantics of its own.
The tier's width/flag rule has **one** definition here (`integer.rs::field_width_supported`/`field_is_unsupported`), consulted by the shape predicates and by `emit/test/refusal_census.rs`, so the attribution cannot drift from the decision.

## The construction shape (`bs_create_bin { dst, segments }`) — `create.rs::try_inline_bs_create_bin`
The compiler's **linear accumulator** build: a `bs_create_bin` whose first segment is a `private_append` of the accumulator itself and whose remaining segments are constant-width unsigned big-endian `integer` fields — a whole number of bytes or not, the widths alone deciding which of the two static field routes the sequence is emitted on — and `string` constants.
A remaining segment may instead be exactly one whole-binary `binary all` tail, whose width is a run-time figure: the seam accepts it only as the plan's last and only segment, and that shape is route (c).
It is the binary-construction hot loop of every encoder, so the shape is lowered in place rather than left on the family loop.
The predicate `CreateBinShape::of(module, dst, segments)` is **label-free** (no `LabelMap`, no fail label), so `emit/regalloc.rs`'s four mirrors, `emit/arith.rs::uses_y`, the emitter and the refusal census derive one answer from one call.
Two shape facts come from the construction seam `families::bitstrings::create::seam`: `append_plan` answers *whether this instruction is that shape and what its fields are*, and the append door answers *whether the accumulator has room and where its window's bytes start* — on the aligned route the block proves the accumulator's term shape itself (inline, refusal-only, `create_door.rs`) and leaves `open_append`'s machine-private remainder to `runtime.rs`'s `jit_append_cursor`, while the bit-granular route calls `open_append_any` through `runtime.rs`'s `jit_open_append_bin_any`/`jit_open_append_bin_any_y` (shared private body `open_append_any_cursor`).
`seam::open_append` is the aligned route's byte-aligned **reference answer**: `#[cfg(test)]`, and kept as the oracle the JIT door is pinned against.
`source` and every `Field::Bits` value resolve to a `Loc` — an in-bound x-register **or an addressable `Y` slot** (`Loc::of`, whose `Y` half is `operands.rs::y_addressable`) — so `uses_y()` is `source.is_y() || dst.is_y() || any Field::Bits value is a Y Loc`, and no `Y` slot is ever charged to `registers()`/`reads()`/`writes()`.
- Run-time guards, in order: (1) `dst`'s frame-window guard (`Loc::guard_store`), so a rejected destination writes nothing; (2) the `Y` accumulator's frame-window **guard only** (`Loc::guard_load` → `operands.rs::guard_y_read`), emitted before every write because the post-helper re-reads address `y_base + k*8` directly; (3) one guarded `Loc::load` plus one `is_small` guard per `Field::Bits` value — `and` with `IMMED1_MASK`, `cmp` to `SMALL_TAG` — because a bignum is legal in a wide field and a non-integer is the family's `badarg`, so a non-small value MUST deopt, and every such guard runs before any write; (4) the route's append door — on the aligned route the inline term-shape proof plus one positioned `jit_append_cursor` call (`create_door::emit_append_cursor`, which publishes the instruction's own `(func, pc)` before the call and whose own last two instructions are the `test rax, rax; jz fallback` pair), on the bit-granular one a positioned `jit_open_append_bin_any`/`jit_open_append_bin_any_y` call (which also take the plan's `unit`, through `emit_positioned_helper_call`, so the pre-call spill happens and the instruction's own `(func, pc)` is published), on the whole-binary route one positioned `jit_append_binary_all` call (the accumulator slot, the source slot and the flags word as immediates, so the same spill and position store apply) — then `test rax, rax; jz fallback` — the **last up-front** guard, after which each field write of the bit-granular route is an in-block store (every field at most `MAX_INLINE_FIELD_BITS` bits) or a `jit_write_bit_field` call that re-checks its own room with the same pair.
- **A run-time term reaches no helper as a word; the routes differ in what they hand over.** `emit/mod.rs::emit_helper_invoke` adds every argument as a `movabs` immediate, so on the **bit-granular** route the accumulator crosses as its **slot index** — `jit_open_append_bin_any` reads it from `machine.x`, `jit_open_append_bin_any_y` through the bounds-checked `Machine::y` (`None ⇒ 0 ⇒ the same je fallback`, never an out-of-frame read) — and so does every field value (plus one flags word naming which file holds it).
  The **aligned** route needs no index at all, because it proves the term shape **in the block**: the accumulator is loaded from its x-register or its `Y` slot inline, and the three run-time values the door then needs are loaded from the accumulator's own block — the payload base into `rsi`, the window end into `rdx` — with only the compile-time `tail_bits` written as an immediate (`rcx`), so `jit_append_cursor` is an ordinary positioned call with nothing live across it.
  The bit-granular `extern "C"` pair shares one private body (`runtime.rs::open_append_any_cursor`), so neither duplicates the seam query or the cursor arithmetic.
- **Every post-helper `Y` re-read is unguarded, and the once-up-front guard is what makes it sound.** The helper clobbers every caller-saved register, so the `Y` accumulator and a `Y` destination are re-derived after the call — four instructions each (`mov scratch,[rsp+RUNTIME_SLOT_DISP]` / `mov scratch,[scratch+RUNTIME_YBASE_DISP]` / `lea scratch,[scratch+y_offset(k)]` / `mov dst,[scratch]`), factored into `create.rs`'s `emit_y_slot_address`/`emit_y_slot_value`; on the aligned route a `Y` field value is re-read the same way, once per field rather than once per byte, while on the bit-granular route a `Y` field value instead crosses to `jit_write_bit_field` as a slot index and is read by the helper through `Machine::y`. They emit **no** second guard because the frame cannot move between the guard and them — the helper only reads machine state and runs no interpreter step — and that guard is nonetheless load-bearing, because those reads address `y_base + k*8` directly.
- Lowering after the helper, by route: the **aligned** route emits field byte stores at `cursor + field_offset`, where a `Field::Bits` field is `nbytes` stores of `sar_ri(value_re_read, 4 + 8*(nbytes-1-i))` then `mov_mr8`, and a `Field::ConstBytes` field is 8-byte `mov_ri` + `mov_mr` chunks then a `mov_ri` + `mov_mr8` byte tail; the **bit-granular** route instead has no byte cursor at all: when every field of the plan is at most `MAX_INLINE_FIELD_BITS` (57) bits it writes them **in-block** (`create_field.rs`'s `emit_bit_field_store`, driven by `create.rs`'s `emit_bit_fields_inline`), keeping the door's payload base in a register, deriving the window end from the accumulator term once and storing each field's bytes straight-line at the absolute bit `end + field_offset_bits` with no per-field room re-query, and only a plan carrying a wider field keeps one positioned `jit_write_bit_field(acc_slot, field_offset_bits, value_slot, nbits, flags)` call per field (`flags` = `WRITE_ACC_IN_Y`/`WRITE_VALUE_IN_Y` naming which machine file holds each term), which re-derives the payload base and the window end from the general door, asks it for `field_offset_bits + nbits` bits of room and writes them at that **absolute bit**; the **whole-binary** route has no field phase at all, its one `jit_append_binary_all` call performing both the copy and the commit.
  Every value is re-read after the helper (it clobbers every caller-saved register): an x-register from `machine.x`, a `Y` slot through its unguarded address re-derivation.
  Then the single window-end commit — `mov_mr` of `old_end + tail_bits` into `SUB_BITS_END_DISP` — emitted **inline**, and nothing after it may fail.
  Then the accumulator word (re-read the same way) into `dst` — its cache register, charged in `cacheable_writes`, or a `Y` slot whose address is likewise re-derived — and the in-block continue.
- Fallback: one interpreter step for the **whole** instruction. There is no fail arm — `bs_create_bin`'s `fail`-vs-`NO_FAIL` discrimination stays in the family.
- **The mutation order is the whole correctness argument.** The family's build performs exactly one mutation beyond the field bytes, C's `sb->end = new_position`; committing that word *before* the field stores would make the `fallback` (one whole-instruction interpreter step) append the tail a **second** time, because the window would already cover the bytes — a wrong result. So the commit is emitted last, and every door a route calls (`jit_append_cursor` on the aligned route, `jit_open_append_bin_any`/`jit_open_append_bin_any_y` on the bit-granular one, `jit_append_binary_all` on the whole-binary one) plus `jit_write_bit_field` **mutate nothing** (`&Machine` throughout) so every guard that can reach `fallback` runs against the state the interpreter step will see. The payload bytes are the one thing written before the commit, and they are written at the same offsets with the same values on every attempt, so even a post-payload deopt re-produces them.
- **The aligned route's extraction is arithmetic (`sar`), never logical (`shr`).** The bit-granular route needs no such argument: `seam::write_bit_field` is the family's own write rule, so a bit field cannot disagree with the interpreter about a byte. The family hands `push_byte_field` the small value *sign-extended* to 64 bits (`small_value(field) as u64`), and the raw word's bit 63 **is** the small value's sign bit, so `sar` reproduces `(value as i64 as u64).to_be_bytes()`. An 8-byte field's top byte has shift count `60`, where a logical shift's zero fill would reach the stored low byte and write `-1` as `0F FF FF FF FF FF FF FF`; a non-negative field has bit 63 clear, so the two shifts agree byte for byte and `sar` is unconditionally right. The count peaks at `4 + 8*7 = 60`. Pinned by `../../bs_create_bin_tests.rs`'s 64-bit rows.
- **A `string` segment's bytes are baked as immediates, never as a `StrT` pointer**: a cached module's string area may be a different allocation, so a table offset would read a stranger's bytes. The bytes are copied out of the module at compile time.
- Declined, each handled by `emit_bitstr` (a slower path, never a wrong result): anything `append_plan` answers `None` for (a plain or later-position append, an append unit outside `1`/`2`/`4`/`8`, a `binary`/`float`/`utf*` segment — `binary all` only as the plan's last and only field is planned, and that shape is lowered by route (c) rather than declined — an `all` or runtime size, a `little`/`signed`/`native` flag, a zero-width or wider-than-a-machine-word field, an unresolvable `StrT` window, a plan with no fields); an accumulator or field value `Loc::of` cannot address (a literal-area operand, an out-of-bound x-register index, a `Y` index the emitted `lea`'s `disp32` could not address); a field width outside `1..=64` bits (`bits == 0` and `bits > 64` — a width that is a multiple of 8 is simply `Route::Aligned`, any other width `Route::BitGranular`); a `Route::BitGranular` plan carrying a `Field::ConstBytes` (`string`) field, since a constant copy at a non-byte-aligned position has no straight-line form; more than `MAX_FIELDS` fields or more than `MAX_TAIL_BYTES` tail bytes; a field list whose **bit** offsets do not sum to the plan's `tail_bits`; and at run time a non-small field value, a `Y` destination or accumulator slot outside the current frame, the route's own door (`jit_append_cursor` — whose inline term-shape proof precedes it — on the aligned route, `seam::open_append_any` on the bit-granular one, `jit_append_binary_all` on route (c)) answering `None` — no room, or a window end the plan's `unit` does not position-gate — or any `jit_write_bit_field` refusing a bit-granular field.
## Constraints
- **Rule 0 — never a wrong result, only a slower one.** A shape that cannot be proven belongs on the family helper; the only two outcomes of a lowering are its exact value or an interpreter step.
- **No destination is written on a rejected path.** Every guard that can reject a destination write (`Loc::guard_store` for a `Y` destination, the match-context guard) is emitted **before** that write, so a rejection leaves the machine bit-identical to the pre-instruction state.
- **The commit order follows the shape.** A single-instruction shape (`bs_get_integer2`, `bs_get_utf32`, `bs_get_utf16`, `bs_get_utf8`) commits the context `start` word **before** writing the destination, because `Dst` may be the context register itself — `beam_asm:filter_essentials/1` compiles `ctx == dst == x(3)`; each of the three UTF get forms emits its bind after its one commit block, so the write ordering is the same and there is still exactly one commit site and one store site per execution.
  The two context-only mutating shapes (`bs_set_position`, `bs_skip_bits2`) have no destination at all, so they cannot violate this order; `bs_match` commits `start` **once**, after its whole command list, and therefore accepts a destination that aliases the context slot only as its **last** command.
- **A `fallback` is a deopt, so every sequence must be re-execution idempotent.** `emit_step_and_continue` runs one interpreter step that re-executes the **whole** instruction with the same operands, so any guard that can reach `fallback` must run while the machine is still un-mutated: `bs_match` writes `start` exactly once on the accepted path and once on `fail_arm` (where `rsi` already holds the **last successful** command's position, which reproduces `families::bitstrings::matching::commands`' per-command `commit` on the fail path), and its predicate declines a **mid-list** `integer` whose destination is the context slot. The failure this closes: `<<_:2, Field:6>>` over a **1-byte** subject — the per-character body of `emqx_base62:decode/2`, `BsCreateBin` → `BsStartMatch4` fresh → `BsMatch [{ensure_exactly,8},{skip,2},{integer,2,[],6,1,Dst}]` — where a per-command commit made the post-`skip` deopt re-run `ensure_exactly 8` against an already-shortened window and reject a match the family accepts.
- **Only the fifteen match-context shapes are position-store-free.** None of them allocates or raises, so the position the driver parks on stays the block's, and a `fallback` step stores its own position through the normal deopt.
  The **construction** shape is the one exception: it publishes the instruction's own `(func, pc)` before its route's door — inline, through `create_door::emit_append_cursor`'s position store on the aligned route, through `emit_positioned_helper_call` for `jit_open_append_bin_any`/`jit_open_append_bin_any_y` and for a `jit_write_bit_field` serving a wider-than-57-bit field, and for the whole-binary route's `jit_append_binary_all` — because a helper can be entered, and a `fallback` taken from the `test rax,rax` arm must park on this instruction rather than on the block entry.
- **`Y` operands are stack slots, never cached x-registers.** No shape's `registers()`/`reads()`/`writes()` includes a `Y` side; a `Y` operand is read and written through the guarded `emit/operands.rs` path, whose guard can only reject.
  Every `Y` **read** — the fifteen match-context shapes' destinations and the construction shape's accumulator and field values — goes through that same guarded read (`Loc::load`/`Loc::guard_load`).
  The construction shape is the one place a second, **unguarded** read of a `Y` slot follows a guarded one — the accumulator and a `Y` destination are re-read inline after the helper, and it is sound only because the guard was emitted up front and nothing between the two can move the frame (see the construction section).
- **Every byte read is bounded before it is read.** `emit_bit_extract`'s over-read guard (`j + W <= num_bytes`, or `j + 2 <= num_bytes` for the granular form) is emitted before the load it protects, and both loads are byte-wise and assembled most-significant byte first — an x86 multi-byte load is little-endian and would produce the byte-reversed value with no error surfaced.
- **The shape predicate is the single decision.** `emit/block.rs`'s arm, `emit/regalloc.rs`'s `cacheable_touches`/`cacheable_reads`/`cacheable_writes`/`is_inlined`, `emit/arith.rs::uses_y` and the refusal census all consult the same `*_shape` function, so a shape's emitted registers and its refusal cannot disagree with the code that runs.
- Errors are `beam_common::{Result, BeamError}` only; a raw `*mut Eterm` is never touched here — the emitters write bytes and the layout constants are the only view of the frozen words.
- Files stay near the ~1000-line guidance (`mod.rs` 669, `create.rs` 1032, `create_field.rs` 264, `create_door.rs` 237, `create_binary.rs` 110, `bs_match.rs` 514, `start_match.rs` 401, `match_string.rs` 398, `tail.rs` 356, `position.rs` 339, `integer.rs` 332, `utf8.rs` 783, `utf16.rs` 666, `utf32.rs` 536, `tests.rs` 122); the per-shape suites are `../../bitstr_inline_tests.rs`, `../../bs_match_deopt_tests.rs`, `../../bs_create_bin_tests.rs`, `match_string_tests.rs`, `utf32_tests.rs`, `utf16_tests.rs`, `utf16_get_tests.rs`, `utf8_tests.rs`, `utf8_get_tests.rs` and `create_field_store_tests.rs`.
- Apache-2.0 header on every `.rs` (byte-exact; the repo license scanner enforces it).
## Routing Table
- `mod.rs` → the module docs, the layout constants and the field-flag bits, the `#[cfg(test)]` per-shape instrument (`SHAPE_COUNT`/`SHAPE_*`/`inlined`), the four shared emitters (`emit_ctx_guard`, `emit_fallback_and_done`, `emit_bit_extract`, `emit_subject_view`) and the `mod`/re-export block the callers resolve through.
- `position.rs` → `GetPositionShape`/`get_position_shape`/`try_inline_bs_get_position` (the `start` word as a `make_small`, with a `MAX_SMALL` guard that falls back to the family's whole-context snapshot) and `SetPositionShape`/`PosSource`/`set_position_shape`/`try_inline_bs_set_position` (a context's `start` word or a non-negative small integer, committed as one word store).
- `tail.rs` → `TestTail2Shape`/`test_tail2_shape`/`try_inline_bs_test_tail2` (the remaining-window compare) and `SkipBits2Shape`/`skip_bits2_shape`/`try_inline_bs_skip_bits2` (a constant `size * unit` skip with `start.checked_add(nbits)`).

## `bs_create_bin`: the three sequential routes (`create.rs`, `create_binary.rs`)

`create.rs` owns the shape predicate (`CreateBinShape::of`), the field planning
(`prepare_fields` -> `PreparedField::{Bits, Const}`) and two of the three emitted sequences
(`try_inline_bs_create_bin` -> `emit_aligned_fields` / `emit_bit_fields`); the third,
`create_binary::emit_binary_all`, is its own sibling module.
`CreateBinShape` carries `source`, `dst`, `unit`, `tail_bits`, `fields`, `field_bit_offsets` and
`binary_all`; `source_slot()` names the accumulator slot for the helper call and
`route()` returns `Route::{Aligned, BitGranular}`.
`binary_all` is branched on **before** `route()`, which answers `Aligned` for it vacuously
(`tail_bits == 0` and no fields: the seam accepts the segment only as the plan's last and only
field, so a `binary all` plan carries no static field at all).

`route()` is `Aligned` iff `tail_bits % 8 == 0` **and** every field's width is a multiple of 8
(a `ConstBytes` field always is); anything else is `BitGranular`.
The three routes share the guard prefix and the accumulator-into-destination phase, and differ in
the append door, in the write sequence and in who commits the window end:

```text
  ; --- shared prefix ---------------------------------------------------------
  guard dst frame window      -> fallback        (Loc::guard_store)
  guard source when it is Y   -> fallback        (Loc::guard_load, SOURCE_GUARD_SCRATCH)
  guard the `binary all` source when it is Y -> fallback   (only on the (c) route)
  per Field::Bits: load + is_small -> fallback   (IMMED1_MASK / SMALL_TAG)
  ; --- (a) Aligned door (`create_door::emit_append_cursor`): the term SHAPE is
  ;     proved inline as refusal-only branches — no store, no call, until the last step
  load the accumulator from its x-register      -> rax
                    or from its Y slot          -> rax   (emit_y_slot_value, no second guard)
  is_boxed_term:  not boxed, not a bare header  -> fallback   (NOT_BOXED_MASK, PRIMARY_MASK)
  header == HEADER_SUB_BITS                     -> fallback
  orig (word 4) is a BinRef: boxed, not header, *(u64*)orig == BIN_REF_HEADER -> fallback
  start (word 2) == 0                           -> fallback
  base = [acc + SUB_BITS_BASE_DISP] & !FLAGS, non-null        -> fallback
  end  = [acc + SUB_BITS_END_DISP], end % 8 == 0               -> fallback
  mov rdi,rt ; <position store> ; movabs rcx,tail_bits
  movabs r11,jit_append_cursor ; call r11        ; the machine-private half, one call
  test rax,rax ; je fallback                     ; 0 = refuse, rax = byte cursor base+end/8
  ; --- (a) Aligned writes ---------------------------------------------------
  per field: movabs rdx,value ; sar_ri rdx, imm ; mov byte [rax + offset_bits/8], dl
  ; --- (b) BitGranular door -------------------------------------------------
  mov rdi,rt ; movabs rsi,src_slot ; movabs rdx,tail_bits ; movabs rcx,unit
  movabs r11,jit_open_append_bin_any[_y] ; call r11
  test rax,rax ; je fallback                     ; 0 = refuse, rax = payload base
  ; --- (b) BitGranular writes -----------------------------------------------
  ;     every field at most MAX_INLINE_FIELD_BITS (57) bits: straight-line
  ;     stores at the absolute bit end + field_offset_bits, no call
  per field: mov byte [payload + (end + offset_bits + k) / 8], ...
  ;     any field WIDER than 57 bits: one positioned call for that field
  per field: mov rdi,rt ; movabs rsi,src_slot ; movabs rdx,field_offset_bits
             movabs rcx,value_slot ; movabs r8,nbits ; movabs r9,flags
             movabs r11,jit_write_bit_field ; call r11
             test rax,rax ; je fallback          ; one room check per field  ; --- (c) the `binary all` tail: ONE positioned call, no field phase --------
  mov rdi,rt ; movabs rsi,acc_slot ; movabs rdx,src_slot ; movabs rcx,flags
  movabs r11,jit_append_binary_all ; call r11   ; the copy AND the build's only commit
  test rax,rax ; je fallback                     ; 0 = refuse, rax = the accumulator term
  ; --- shared commit of (a)/(b) (their ONLY mutation) ------------------------
  add dword [rdx + SUB_BITS_END_DISP], tail_bits
  ; accumulator re-read into dst, then fallback/done
```

Route (c) is the plan's **`binary all` tail** — the compiler's accumulator with one whole-binary
segment (`<<Acc/binary, B/binary>>`, `seam::AppendPlan::binary_all`, e.g. `emqx_base62:encode/2`).
Its source width is a run-time figure, so it has neither a static field offset nor a static tail
width: the whole instruction is one positioned `jit_append_binary_all` call whose three arguments
are `movabs` immediates — the accumulator's slot, the source's slot and the
[`WRITE_ACC_IN_Y`]/[`WRITE_VALUE_IN_Y`] flags naming which machine file holds each term — followed
by `test rax, rax ; je fallback`, and then the shared accumulator-into-`dst` phase.
There is **no tier-side field phase and no tier-side window-end commit** on this route: the helper
performs the single `ErlSubBits.end` store itself, after its own guards, so a refusal writes
nothing and the `fallback` interpreter step stays idempotent.

The aligned door's proof reads five frozen words of the accumulator's own block and is therefore **refusal-only**: every branch above jumps to `fallback` and stores nothing, so the interpreter step that takes it sees an accumulator the block has not touched.
Only the **machine-private** part is left as a call — [`jit_append_cursor`] answers the **byte cursor** `base + end_bits / 8`, or `0` when the proven payload base is not one this machine registered writable or `end + tail` does not fit its capacity (it is a read-only `&Machine` query, and it re-checks `end % 8` so it agrees with the seam on every input).
The bit-granular door is unchanged: `jit_open_append_bin_any`/`jit_open_append_bin_any_y` take the accumulator's **slot index** plus `movabs` immediates (tail width and the plan's `unit`), answer the payload base, and apply C's append-position gate for that unit.
The bit-granular sequence's field writes are inline stores whenever every field is at most
`MAX_INLINE_FIELD_BITS` (57) bits, and a positioned `jit_write_bit_field` call per field otherwise, each of which asks the
seam for room for `field_offset_bits + nbits` bits and then writes that field's bits.
The aligned and bit-granular sequences commit the window end exactly once, after every write, which is what keeps a
`fallback` (one whole-instruction interpreter step) re-execution safe; route (c) re-executes only through its own single guard.

- **The bit-granular route's field stores are INLINE whenever every field of the plan is at most `MAX_INLINE_FIELD_BITS` (57) bits** (`create_field.rs`'s `emit_bit_field_store`, driven by `emit_bit_fields_inline`): the payload base the general door answered stays in a register, the window end is derived from the accumulator term once, and each field's bytes are straight-line stores at the absolute bit `end + field_offset_bits` — no helper call and no per-field room re-query (the door's whole-plan `tail_bits` check is the only admission point). **A plan with any field wider than 57 bits keeps the per-field `jit_write_bit_field` loop shown above**, because such a field cannot be left-aligned in one 64-bit register at every window offset; `#[cfg(test)] CreateBinShape::inline_field_plans()` is the compile-time counter that tells the two forms apart, pinned with its end-to-end tier-parity rows in `../../bs_create_bin_tests.rs` and with an exhaustive emitted-vs-`seam::write_bit_field` sweep (every width 1..=57 × offset 0..=64 × window end 0..=40 over a pre-filled payload) in `create_field_store_tests.rs`.

## Deliberate refusals (structural, not gaps)

- **`binary all` in any other position.** The seam accepts the segment only as the plan's **last and only** field: a `binary all` preceded by a field, or followed by another segment, stays on `jit_bitstr`, because a run-time width fixes no static offset for anything after it.
  Accepted as the last and only one, its own bit offset is `0` (it starts at the accumulator's window end), so the destination position it lands on is static and route (c) lowers it.
  No unproven shape can write a byte on that route: the door refuses at run time, in this order and with nothing written — a slot index that is not a `u32`, a target that is not this machine's writable accumulator, a window end that is not a whole number of bytes (`end_bits % 8 != 0`, C's `unit == 8` position gate), a source that is not a readable bitstring (`raw::heap_bits`: a non-bitstring, an engine match context or a bare `BinRef`), a null source base, a source window whose start is not byte-aligned, a source size that is not a multiple of 8 bits, an `end + size` overflow, a room shortfall against the payload's capacity, and source/destination byte ranges that overlap (a source that is a sub-binary of the accumulator's own payload).
The source gate is **any byte-aligned bitstring window** — an on-heap `ErlHeapBits` and an off-heap refc binary alike — because the door reads the source's parts through `raw::heap_bits`, the very accessor the family's own `binary all` body uses (`create::segments::segment_source`), so the served copy and the `fallback` step share one definition of the source's bytes.
- **A fresh non-append `[integer 8]`** (e.g. `emqx_base62:decode/2`'s temp `<<DecodeChar>>`):
  `raw::make_binary` **allocates** a fresh result (an on-heap `ErlHeapBits` or the refc pair)
  through the rooted seam, which a straight-line helper-free sequence cannot do without an
  admission point. It stays on `jit_bitstr`.
- **`BitGranular` + `ConstBytes`** in one plan: refused by the predicate (`CreateBinShape::of`
  -> `None`), because the aligned half would commit a window end before the bit fields have
  passed their own room check.
