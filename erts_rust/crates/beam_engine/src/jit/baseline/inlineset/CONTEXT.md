# `baseline/inlineset` — the baseline tier's inline set

## Intent
The authoritative per-shape record of what the baseline tier lowers **in-block** (no interpreter step): which instruction groups `emit_block` claims, the run-time guards each shape carries, which shapes are deliberately refused, and the invariants any new fast path must keep.
This node owns the *decisions* only: emitted sequences live in `../emit/CONTEXT.md`, `../emit/shapes/CONTEXT.md` and `../emit/bitstr_inline/CONTEXT.md`, the block ABI/driver/helper inventory in `../CONTEXT.md` and `../runtime/CONTEXT.md`, and every measured figure in `../measure/CONTEXT.md` and `../census/CONTEXT.md`.

## THE invariant: a `fallback` is a deopt, so every arm must be re-execution idempotent
`fallback` is not a local bail-out but `jit_step_one`, which runs `Machine::step_instruction_with_entry` for the **whole instruction with the same operands** and re-reads the machine's live state.
So no arm may commit **any** partial state before its **last possible** fallback: every guard that can reach `fallback` runs while the machine is still un-mutated, and every door called on a fallback-capable path mutates nothing (`&Machine` only).
An arm that would **allocate or root inside the instruction** must **decline** at compile time instead of inlining, because a moving collection relocates terms and a raw `*mut Eterm` taken before the admission point names freed or reused words after it.
Concretely: `bs_match` commits its context's `start` word exactly once per path (never per command), and the construction shape commits its accumulator's window end **last**, after every payload store.
Pins: `../bs_match_deopt_tests.rs`, `../bs_create_bin_tests.rs`, `../bitstr_shapes_deopt_tests.rs`, `../foreign_kernel_tests.rs`.

## API Surface — the inline set
The single dispatch decision is the per-instruction `match instr` in `../emit/block.rs::emit_block`; anything it does not claim falls to the `_` arm's deopt (`jit_step_one`), which makes the tier interpreter-identical for **every** supported opcode.
Inlined groups, by arm:
- **Metadata no-ops**; `Move` (in-bound x-register, addressable `Y` slot either side behind the frame-window guard, constant word, or literal-area term behind the literal guard), `Swap` (two `Loc`s), `InitYregs`.
- **`Test`** — word-level predicates and boxed-term header kinds, `Y`-slot source accepted; a comparison the word/header subset declines goes to `test_helper.rs::jit_test`, not to `jit_step_one`.
- **`SelectVal`** (all-immediate alternatives, `Y` scrutinee), **`SelectTupleArity`**, the cons readers **`GetList`**/**`GetHd`**/**`GetTl`**, **`GetTupleElement`** and the destructive **`SetTupleElement`** (all over `Loc` operands).
- **Small-int `gc_bif` arithmetic** — `+`/`-`/`*`, `band`/`bor`/`bsr`, `div`/`rem` over an x-register **or `Y`** operand/destination behind the frame-window guard (`emit/arith.rs::fast_arith`); `intdiv/2` stays on the BIF because it floors.
- **The 8 comparison BIFs** and the named-BIF accessors `erlang:hd/1`, `element/2` (compile-time index `>= 1`), `tuple_size/1`, `erlang:byte_size/1`, `length/1` (`emit/bif.rs`).
- **`Jump`**; `CallLast` (`emit_tail_exit` for a compiled successor, `emit_tail_exit_to_driver` for a resolved-but-uncompiled one); `CallOnly` (`emit_exit`); the frame-preserving local `Call` (`jit_call_store` + the `CALL_STORED` compare, then `emit_exit` or `emit_in_block_call` for the lazy cross-function shape).
- **`CallExt`**/**`CallExtOnly`**/**`CallExtLast`** via `emit_ext_call` — natively executed, with the module transfer a driver round-trip by design.
- **The receive family** `Send`/`LoopRec`/`LoopRecEnd`/`Wait`/`WaitTimeout`/`Timeout`/`RemoveMessage` (`receive.rs::jit_receive`), and **the whole family-owned surface** — `put_list`/`put_tuple2`, the native-record set, `make_fun3`/`call_fun`/`call_fun2`/`apply`/`apply_last`, the try/catch/raise set, floats, maps, `recv_marker_*` — via `family.rs::jit_family`.
- **The bitstring family** (`crate::families::bitstrings::claimed`) via `bitstr.rs::jit_bitstr`; **sixteen** of its shapes are lowered in-block instead (below).
- **The frame-discipline trio** `Deallocate`/`Return`/`DeallocateReturn` and **the heap / frame-admission four** `allocate`/`allocate_heap`/`test_heap`/`trim`.
- **Everything else is the `_` arm.** `FuncInfo` is deliberately there: it is the failed-head-clause `error:function_clause` raise, not a metadata no-op, so it must deopt.

Three roster rules:
- **The family arm is one call to the interpreter's own dispatch.** `jit_family` runs the identical `crate::families::dispatch` its per-instruction step runs, so it is interpreter-identical by construction; the emitted sequence is the shared helper contract.
- **The heap / frame-admission four are non-terminating** (the interpreter's arm returns `Step::Next`): each continues in-block on the helper's `encode_target(func, pc + 1)` word and leaves the block otherwise, always the `ERROR` of a failed admission or trim.
  `allocate`/`trim` touch no x-register and emit **no** refill (`emit_frame_change_continue` takes no `Allocation`: the helper wrote no x-register and re-publishes the Y window itself, being the frame change); `allocate_heap`/`test_heap` reach the host's heap-admission door, where a **collecting** host rewrites `machine.x` in place, so they refill — `allocate_heap` through `emit_continue_check_helper_refresh` and `test_heap` through `emit_continue_check` (its gated `jit_refresh_y` survives, it changes no frame). Each reaches that door **exactly once** per execution, with the instruction's own `heap_need`/`live`.
- **The bitstring arm stores its own position.** `jit_bitstr` performs no position store, so `emit/family.rs::emit_bitstr` publishes the instruction's own `(func, pc)` inline before the call (`emit_positioned_helper_call` → `emit_position_store`), still naming the instruction rather than the block **before** it runs, so a pre-emption or suspension parks exactly there (`../tests.rs::the_bitstring_arm_stores_the_instruction_position_inline`).

## Shared machinery an arm inherits
Full detail in `../CONTEXT.md` (`## Key facts`), `../runtime/CONTEXT.md` and `../emit/CONTEXT.md`; the facts an arm's author must hold:
- **Block ABI.** One `i64`: a packed `encode_target(func, pc) = (func << 32) | pc` continuation (non-negative for every `func < 2^31`) or a negative sentinel — `HALT` `-1`, `ERROR` `-2`, `ENTER` `-3`, `LOCAL_DECLINE` `-4`, `SUSPEND` `-5` — plus the `WAIT_BIT` sign marker on a suspending `receive`'s resume word.
  `CALL_STORED` (`-5`) is consumed **inside** the emitted block and never reaches the driver's decoder, which is why it may reuse the `SUSPEND` value; `ENTER`/`SUSPEND` are *driver* actions, the latter carrying the **un-applied** instruction's address in the driver-only `JitRuntime::suspend` side channel.
- **Deopt.** `emit_step_and_continue` = `emit_helper_call` (spills first, `rdi` = the `rt` slot, arguments in `rsi`/`rdx`/`rcx`/`r8`/`r9`) + `emit_continue_check` (`cmp rax, encode_target(func, pc + 1)`; equal ⇒ fill and fall through, else exit to `done`); every compile-time refusal routes through `emit_deopt`, which records the static-census deopt (test builds) then runs that pair.
- **Register cache — `CACHE_REGISTERS` = 5** (`r12`, `r13`, `r14`, `r15`, `rbp`; `rbx` = the `machine.x` base, `rsp`+`RUNTIME_SLOT_DISP` = the `rt` slot, `r10`/`r11` = within-instruction scratch).
  A block caches a **fixed** `Allocation::slots` for its whole duration, so an x-register is either *always* in its machine register or *never* cached; non-cached x-registers are addressed directly in `machine.x`.
  Spill and fill are both partial (dirty set at that pc; `(live ∪ written) ∩ slots`; the prologue only the live-in set), and every helper-call site spills first. Detail: `../emit/regs/CONTEXT.md`.
- **`Y` slots.** The top frame's `[y_base, y_end)` is published into `JitRuntime::{y_base,y_end}`; the emitted guard is a **pure rejection** and a null window rejects every slot, so the worst reachable state is "not yet published" (a deopt), never a stale window; an index the emitted `lea … disp32` cannot address is refused at **compile** time, and a Y slot is never charged to the register cache. Detail: `../emit/prologue/CONTEXT.md`.
- **Never trace.** A **traced** run (`ctx.trace_enabled()`) **refuses native entry** and hands the whole slice to `Machine::drive`: native code emits no trace events and a traced run must stay byte-identical.
- **Driver pre-emption.** One charge per driver-loop **iteration** (block entry), with the position published first, so a refusal parks exactly there; it is the native tiers' only pre-emption point, which is why the call-resolution/BIF seams stay **spend-only**. A natively linked tail-call chain never returns to the driver and is priced once (`../tests/jit_reductions.rs`).
- **In-block transfers.** One resolver, `runtime.rs::enter_in_block`, serves the return side and the declined-`call` side, reproduces the skipped driver iteration in the driver's own order, and is a **tail** transfer; every decline leaves `resume_entry` null and the pre-existing `encode_target` word in `rax`, with the continuation stored **exactly once**.
- **Continuation sub-blocks.** A continuation address (`pc + 1` of a frame-preserving call) generally lies inside a block; both layouts cover it with one sub-block emitted through the same `emit_block` (interpreter-identical by construction), probing `entries` first and `sub_entries` second, each deriving **its own** `Allocation`. Detail: `../emit/CONTEXT.md`.
- **Literal-source `Move`** is lowered behind a run-time check against `JitRuntime::literals_end`, never a baked pointer, because a cached block can outlive the `Arc<Module>` it was compiled against.

## The bitstring inline set (sixteen shapes)
Sixteen `Bs*` shapes are lowered **natively in-block, with no interpreter step** by `../emit/bitstr_inline/`, which owns the file layout and shared emitters: fifteen match-context shapes that call no helper at all, plus the `bs_create_bin` construction shape.
The sixteen arms in `emit/block.rs` sit **above** the `_ if bitstrings::claimed(instr) => emit_bitstr(...)` guard arm, and each `try_inline_bs_*` answers `Ok(false)` having emitted **zero bytes** when its `*_shape` predicate declines, so a decline falls through to `bitstr.rs::jit_bitstr`, the behaviour every other `Bs*` variant keeps.
The **shape predicate is the single decision**: `emit/block.rs`, `emit/regalloc.rs`'s `cacheable_touches`/`cacheable_reads`/`cacheable_writes`/`is_inlined`, `emit/arith.rs::uses_y` and `emit/test/refusal_census.rs` all consult the same `*_shape` function, so an emitted register set and its refusal cannot disagree with the code that runs.
Each shape carries a `#[cfg(test)]` compile-time counter — `inlined(SHAPE_*)` in `../emit/bitstr_inline/mod.rs` (`SHAPE_COUNT = 16`) — because what an arm needs pinning is its **emission decision**, and the fifteen match-context shapes call no helper that could observe them otherwise.

Shared rules for all sixteen; the per-shape entries give only what deviates:
- **No sequence allocates and none raises**, so no moving collection can interleave inside one; the fifteen match-context shapes read the context block base once and reuse it.
- **The standard guard chain**, in order: the `Y` destination's frame-window guard; the match-context guard (`is_boxed`, then `*boxed_val == HEADER_SUB_BITS`); the shape's remaining-window test, which must `fail_arm`; the subject classification (`emit_subject_view`); `start % 8 != 0`; the over-read test. All but the third deopt.
- **The standard fallback set**: a non-context `ctx`, a non-byte-aligned `start`, a subject `emit_subject_view` refuses (a **refc window** — an `ErlSubBits` over a `BinRef` —, a match context, a bare `BinRef`, a literal-area subject, any non-bitstring), an over-read on the taken path, and `NO_FAIL` or an unresolved fail label.
- **Every guard that can reject a write precedes that write**, and a single-instruction shape commits its context `start` word **before** the destination register, because `Dst` may be the context register itself (`beam_asm:filter_essentials/1` compiles `ctx == dst == x(3)`).
- **One commit site per execution**, even with several mutually exclusive success paths: each path materialises its own bit length into `rcx` and jumps to a single `commit` block holding the `start` write (plus, get form only, the bind), so "commits exactly once" is structural.
- **A `fail` transfer mutates nothing**, matching the family's own `fail_step`, so the resolved label's code observes the context exactly as the interpreter leaves it.
- **The fallback is one interpreter step**, so the top-of-file invariant governs every shape; `NO_FAIL` is refused at compile time wherever the shape has no `MatchFail::Family` arm, because the raise's reason allocates.

### `bs_get_position { ctx, dst }` — `position.rs::try_inline_bs_get_position`
- Predicate `get_position_shape`: `ctx`/`dst` a `Loc` (`Loc::of`), nothing else. Guards: `dst`'s Y-window guard, the match-context guard, `start > MAX_SMALL` → `fallback`.
- Lowering: `make_small([ctx+16])` stored to `dst`. Fallback: the family's whole-context snapshot, its only allocating `position_term` arm.

### `bs_set_position { ctx, pos }` — `position.rs::try_inline_bs_set_position`
- Predicate `set_position_shape`: `ctx` a `Loc`; `pos` a `Loc`, or a **constant** `Operand::Integer` in `0..=MAX_SMALL`/`Operand::Character` (`PosSource::{Loc, Constant}`; a constant outside that range is `position_of`'s typed error).
- Guards: the match-context guard; for a `Loc` source, `pos` must be a match context (header `== HEADER_SUB_BITS`, new start `[pos+16]`) or a non-negative small integer, else `fallback`.
- Commit: **one** word store to `[ctx+16]`, after every read (`ctx` may alias `pos`), with no destination register. Fallback: the family's typed raise for a non-position term.

### `bs_test_tail2 { fail, ctx, bits }` — `tail.rs::try_inline_bs_test_tail2`
- Predicate `test_tail2_shape`: `ctx` a `Loc`; `fail` not `NO_FAIL` and resolved (the miss transfer needs its `(func, pc)`).
- Guards: the match-context guard → `fallback`; `end.saturating_sub(start) != bits` → `fail_arm`, the linker's exit to the resolved label with `ExitSpill::Required`, a terminator on that path only while the hitting path continues in-block.
- Fallback: the family's `{badmatch,…}` raise, whose reason allocates — exactly why `NO_FAIL` is refused at compile time.

### `bs_skip_bits2 { fail, ctx, size, unit, flags }` — `tail.rs::try_inline_bs_skip_bits2`
- Predicate `skip_bits2_shape`: `ctx` a `Loc`; `size` a **constant** `Operand::Integer` in `0..=MAX_SMALL`/`Operand::Character`; `size * unit` fits both `usize` and an `i64` immediate; `fail` not `NO_FAIL` and resolved; `flags` ignored because the family ignores it.
- Guards: the match-context guard; `start.checked_add(nbits)` overflow (the carry flag) → `fail_arm`; `next > end` (**not** `>=`) → `fail_arm`. Commit: one word store to `[ctx+16]`, no destination register. Fallback: a runtime `size`/`unit` (a register compare the sequence does not have) or a `NO_FAIL` raise.

### `bs_start_match3 { fail, bin, live, dst }` — `start_match.rs::try_inline_bs_start_match3`
- Predicate `start_match3_shape`: `bin`/`dst` a `Loc`; `fail` classifies as `MatchFail::{Label, Family}` — `NO_FAIL` is `Family` (its `{badmatch, Subject}` reason allocates) and an unresolved label refuses.
- Guards: `dst`'s Y-window guard **first**, then the subject classification: non-boxed → `miss`; header `== HEADER_SUB_BITS` → the `orig` check (a non-boxed `orig` is the hit; a boxed `orig` whose header is `HEADER_BIN_REF` is a refc window → `fallback`; anything else is the hit); header masked to `BITSTRING_TAG_MASK == HEAP_BITS_SUBTAG` → `fallback` (a fresh subject the family re-wraps through `make_ctx`); every other header → `miss`.
- Lowering: a plain move of the subject word into `dst`, with no reservation, because the family's hit arm is `write_operand(dst, value)`. `miss` takes the resolved label's linker exit; a `MatchFail::Family` miss is the `fallback` step.

### `bs_start_match4 { fail, live, src, dst }` — `start_match.rs::try_inline_bs_start_match4`
- Predicate `start_match4_shape`: the same `Loc` requirement; `fail` decoded exactly as `resolve_match4_fail` decodes it — `Operand::Label` (`NO_FAIL` → `Family`, else resolved → `Label`), atom `"no_fail"` → `Family`, atom `"resume"` → `Resume`; any other atom, an unnameable atom id or another operand kind refuses.
- Guards: the same `emit_start_match` body, except a `Resume` shape has the **short** form (a single `header == HEADER_SUB_BITS` compare) whose miss is the `fallback` step. Fallback: one interpreter step.

### `bs_get_integer2 { fail, ctx, live, size, unit, flags, dst }` — `integer.rs::try_inline_bs_get_integer2`
- Predicate `get_integer2_shape`: `ctx`/`dst` a `Loc`; `size` a **constant**; `nbits = size * unit` passes `field_width_supported` and `flags` passes `field_is_unsupported`; `fail` not `NO_FAIL` and resolved.
- Guards: the standard chain, with `remaining < nbits` → `fail_arm` (the family's `fail_step`, never a raise). Commit: `start + nbits` to `[ctx+16]` **before** `dst`, then `make_small` (at most 32 bits, so nothing allocates). Fallback: the standard set plus the tier's width rule (a 17..=59-bit or 64-bit field — see *Deliberately left*).

### `bs_match_string { fail, ctx, bits, offset }` — `match_string.rs::try_inline_bs_match_string`
- Predicate `match_string_shape` = `MatchStringShape::of(module, ctx, bits, offset)` + the fail half. `of` is label-free, so `arith::uses_y` derives the same answer: `ctx` a `Loc`; `Offset` names a byte **inside** the string table (an out-of-range offset is the family's own typed `unsupported`, which a predicate must not pre-empt); the compared pattern is at most `MAX_MATCH_BYTES` (64) bytes, budgeted by `BS_MATCH_STRING_PATH_BYTES`; `Bits` does not exceed the table's remaining bits, because `size > pattern.len() * 8` is the family's own always-fails branch.
- The `ceil(Bits / 8)` pattern bytes are **copied out** of the string table at compile time, never a pointer or a bare offset, because a cached module's string area may be a different allocation.
- Guards: the standard chain, with `remaining < Bits` → `fail_arm` and the over-read `start / 8 + ceil(Bits / 8) > num_bytes` → `fallback`. Lowering: per **whole** pattern byte a `movzx` load, a `cmp` against the compile-time byte and a `jne fail_arm`, then for a `Bits` that is not a multiple of 8 one final byte compared through a `Bits % 8` **high**-bits mask applied to both sides, then the single `start += Bits` commit; no destination, since `writes()` is empty and the commit is a heap store into the context block.
- Fallback: the standard set, a non-byte-aligned `start` being the shape a preceding sub-byte `bs_skip_bits2`/`bs_get_integer2` produces. `fail_arm` writes nothing.

### `bs_skip_utf32` / `bs_get_utf32 { fail, ctx, live, flags [, dst] }` — `utf32.rs::try_inline_bs_{skip,get}_utf32`
- Predicate `skip_utf32_shape` = `Utf32Shape::of(ctx, flags)` + the fail half; the get form adds only `dst` a `Loc`. `of`: `ctx` a `Loc`; `flags` does **not** ask for little/native endianness (`field_is_little`, i.e. `BSF_LITTLE` 2 or `BSF_NATIVE` 16 on this little-endian target), because this arm emits the big-endian read only and the interpreter's own byte-swapping reader stays that form's one implementation; `BSF_ALIGNED`/`BSF_EXACT`/`BSF_SIGNED` are lowered, since `decode_utf32` branches on endianness alone.
- Guards: the standard chain, with `remaining < 32` → `fail_arm` and the over-read `start / 8 + 4 > num_bytes` → `fallback`; the get form runs `dst`'s frame-window guard **first**.
- Lowering (sequence: `../emit/bitstr_inline/CONTEXT.md`): four `movzx` loads assembled most-significant byte first, two validity tests (`value > 0x10FFFF`; `value - 0xD800 <= 0x7FF` for the surrogate range), then the single `start += 32` commit; the get form then binds `make_small(value)` (at most 21 bits) — after the commit, through the block pointer the match-context guard left in `MOVE_SCRATCH` rather than a re-read of the now-overwritten operand. `fail_arm` covers both family rejections (fewer than 32 bits; an out-of-range or surrogate scalar) and writes nothing.
- Fallback: the standard set, plus a `Y` destination outside the published frame window.

### `bs_skip_utf16` / `bs_get_utf16 { fail, ctx, live, flags [, dst] }` — `utf16.rs::try_inline_bs_{skip,get}_utf16`
- Predicate `skip_utf16_shape` = `Utf16Shape::of(ctx, flags)` + the fail half; the get form adds only `dst` a `Loc`. `of`: `ctx` a `Loc`; big-endian, so `BSF_ALIGNED`/`BSF_EXACT`/`BSF_SIGNED` are lowered and only `field_is_little` refuses.
- A character is **one or two** 16-bit words: a word outside `0xD800..=0xDFFF` is BMP and consumes 16 bits, while a **high** surrogate (`0xD800..=0xDBFF`) consumes 16 more by requiring a following **low** one (`0xDC00..=0xDFFF`), decoding to `((w1 & 0x3FF) << 10 | (w2 & 0x3FF)) + 0x10000`.
- Guards: the standard chain, with `remaining < 16` → `fail_arm` and the over-read `start / 8 + 2 > num_bytes` → `fallback`; then **on the surrogate path only**, `remaining < 32` → `fail_arm` and `start / 8 + 4 > num_bytes` → `fallback`, so a BMP character at the very end of a subject is not forced to deopt because a *pair* would not have fit. The get form runs `dst`'s frame-window guard **first**.
- Lowering: two mutually exclusive paths — BMP (`len = 16`) and surrogate pair (`len = 32`) — converging on **one** `commit` block holding the single `start += len` write; the get form's `commit` also holds the bind (`make_small` of the BMP word or the composed astral scalar, at most 21 bits), so there is one commit site and one bind site per execution. `fail_arm` covers all four malformed characters (fewer than 16 bits, a lone **low** surrogate, a high surrogate with fewer than 32 bits left, and a high surrogate not followed by a low one) and writes nothing.
- Fallback: the standard set, plus a `Y` destination outside the published frame window.

### `bs_skip_utf8` / `bs_get_utf8 { fail, ctx, live, flags [, dst] }` — `utf8.rs::try_inline_bs_{skip,get}_utf8`
- Predicate `skip_utf8_shape` = `Utf8Shape::of(ctx)` + the fail half; the get form adds only `dst` a `Loc`. `of` takes **no** flags: `decode_utf8` has no endianness to select and both UTF-8 family arms destructure `flags: _`, so **every** flags word is lowered.
- A character is one to four bytes and the **lead byte decides**: `0x00..=0x7F` is ASCII and stands alone, `0xC0..=0xDF` announces one continuation byte, `0xE0..=0xEF` two and `0xF0..=0xF4` three; `0x80..=0xBF` and `0xF5..=0xFF` can never lead.
- Guards: the standard chain, with `remaining < 8` → `fail_arm` and the lead byte's own `start / 8 + 1 <= num_bytes` → `fallback`; then the taken path's `<len>*8` window check → `fail_arm` and its `start / 8 + len <= num_bytes` guard → `fallback`. The get form runs `dst`'s frame-window guard **first**.
- Lowering (sequence per route: `../emit/bitstr_inline/CONTEXT.md`): the lead byte is read once and classified into **four static paths** (0/1/2/3 continuation bytes) by a compare chain; each path runs its own fixed-count reads with **static** shifts, masks and validity tests and materialises its bit length into `rcx` before jumping to the single `commit` block, the one dynamic figure `total` driving the window check, the over-read guard and the commit. The get form's `commit` also holds the bind (`make_small` of the decoded scalar, at most 21 bits).
- `fail_arm` covers all ten malformed characters `decode_utf8` rejects — a truncated lead byte, a continuation byte as the lead or a byte above `0xF4`, a sequence shorter than its lead announces, a non-continuation byte where one is required, an overlong form (`0xC0 0x80`, `0xE0 0x80 0x80`, `0xF0 0x80 0x80 0x80`), a surrogate code point and a value above `0x10FFFF` — and writes nothing, never traps.
- Fallback: the standard set, plus a `Y` destination outside the published frame window.

### `bs_match { fail, ctx, commands }` — `bs_match.rs::try_inline_bs_match`
- Predicate `bs_match_shape`: a **fully static** command list of `ensure_at_least`/`ensure_exactly`/`skip`/`integer`, every size/unit/stride a compile-time constant, every `ensure_at_least` unit a power of two, every `integer` field passing the width and flag rules, at most one `Y` destination, and no `integer` destination that **is** the context slot except as the **last** command — mid-list it would overwrite the context term the fallback's re-execution re-reads, while as the last it is `beam_asm:filter_essentials/1`'s elided-context shape; `ctx` a `Loc`, `fail` not `NO_FAIL` and resolved.
- Guards: each accepted `Y` destination's window guard first (at most one), the match-context guard, then per command in order — `remaining % unit == 0` (masked) and `remaining >= size`, `remaining == stride`, `checked_add` overflow then `> end`, and each `integer` repeating `bs_get_integer2`'s remaining/subject/extract guards. The running position lives in `rsi`, so every guard runs while the context is untouched.
- Commit: `start` exactly once on the accepted path after the last command, and once on `fail_arm`, where `rsi` already holds the **last successful** command's position — the family's own partial-progress state. Fallback: one interpreter step for the whole instruction, which is why no command may mutate the context before the last fallback-capable guard.

### `bs_create_bin { dst, segments }` — `create.rs::try_inline_bs_create_bin`
The construction shape and its three routes: the authoritative section below.

## `bs_create_bin` — three routes, one predicate (authoritative)
The arm lowers the compiler's linear accumulator build (`bs_init_writable` + a single `bs_create_bin` whose first segment is `private_append`, i.e. the writable accumulator and `binary all`).
Its predicate `CreateBinShape::of(module, dst, segments)` is **label-free** (no `LabelMap`, no fail label) and purely syntactic over the construction seam's `seam::append_plan`: the first segment a `private_append` of the accumulator itself, the remaining segments constant-width unsigned big-endian `integer` fields and/or `string` constants, and the plan's field bit offsets summing exactly to `tail_bits`.
`dst`, `source` and every `Field::Bits` value resolve to a `Loc` — an in-bound x-register **or an addressable `Y` slot** — so `uses_y()` is `source.is_y() || dst.is_y() || any field value is a Y Loc`.
A plan with more than `MAX_FIELDS` (16) fields or more than `MAX_TAIL_BYTES` (256) tail bytes refuses, the sequence being straight-line code; the width range is `1..=64` bits (`bits == 0` moves no cursor, `bits > 64` exceeds the one word the writer masks into the field) and there is no "whole-byte only" rule.
`route()` picks the field sequence, and the `binary_all` member picks the third route ahead of that split: a plan whose only segment after the accumulator is a whole-binary `binary all` tail is the **whole-binary** route; otherwise **aligned** iff `tail_bits % 8 == 0` **and** every field's width is a multiple of 8 (`ConstBytes` always is); everything else — including a width below one byte and a non-multiple above one byte — is **bit-granular**. The static-field route is a function of the widths alone, so an exact byte-multiple width provably never leaves the aligned sequence.

### The three routes' helpers (all `&Machine`, all mutate nothing, contention reported as `0`)
- **Aligned**: the block proves the accumulator's term shape itself as refusal-only branches over five frozen words (`create_door.rs::emit_append_cursor`), then makes one `jit_append_cursor` call for the machine-private half (the cursor is `payload base + tail_bits/8`; `0` = refuse). `seam::open_append` is `#[cfg(test)]`, the reference answer that door is pinned against.
- **Bit-granular**: `jit_open_append_bin_any`/`_any_y` return the payload base, take the plan's `unit` and apply C's append-position gate (`append_unit_allows`: `unit == 8` needs `end_bits % 8 == 0`, any other `unit > 1` needs `end_bits % unit == 0`, `unit <= 1` ungated); then the fields are **in-block stores** (`create_field.rs::emit_bit_field_store`) whenever every field is at most `MAX_INLINE_FIELD_BITS` (57) bits, while a plan carrying any wider field sends **every** field, narrow ones included, through one `jit_write_bit_field(acc_slot, field_offset_bits, value_slot, nbits, flags) -> 1/0` call each, the flags words `WRITE_ACC_IN_Y`/`WRITE_VALUE_IN_Y` naming which machine file holds each term.
- **Whole-binary**: one `jit_append_binary_all(acc_slot, src_slot, flags) -> accumulator/0` call which copies the source and performs the build's **only** `ErlSubBits.end` store itself, so that route has no field phase and no tier-side commit.

### The guard order
(1) the destination's frame window (`Loc::guard_store`, so a rejected destination writes nothing); (2) the `Y` accumulator's frame window (`Loc::guard_load`), **guard only** and before every write, because the post-helper re-reads of that slot address `y_base + k*8` directly (plus, on the whole-binary route, the appended source's); (3) per `Field::Bits` value one guarded load plus one `is_small` guard (a bignum is legal in a wide field and a non-integer is the family's `badarg`); (4) the route's own positioned door call, whose `test rax, rax; jz fallback` is the **last up-front** guard; (5) on the bit-granular route each `jit_write_bit_field` write of a plan carrying a wider field, whose own `test rax, rax; je fallback` re-checks the room the seam just granted — a defensive duplicate, kept because the helper is the sole authority on writability.
Every guard precedes every mutation, and the accumulator crosses the block ABI as a **slot index**, because `emit_helper_invoke` adds `movabs` immediates only — which is exactly what makes a `Y`-slot accumulator expressible.

### The mutation order is the whole correctness argument
The family's build performs exactly one mutation beyond the field bytes, C's `sb->end = new_position`; committing that word *before* the payload stores would make the `fallback` append the tail a **second** time, because the window would already cover the bytes — a wrong result.
So on the aligned and bit-granular routes the single window-end commit (`mov_mr` of `old_end + tail_bits` into `SUB_BITS_END_DISP`) is emitted **inline and last**, after which nothing may fail; on the whole-binary route the commit is the helper's own last act, after its own guards.
Every append door and every `jit_write_bit_field` call mutates nothing, so every guard that can reach `fallback` runs against the state the interpreter step will see, and the payload bytes land at the same offsets with the same values on every attempt — a post-payload deopt re-produces them.
Field values are **re-read after the helper** (it clobbers every caller-saved register): an x-register from `machine.x`, a `Y` slot through its **unguarded** four-instruction address re-derivation (once per field, not per byte), sound because the up-front guard already proved the slot in frame and nothing between can move the frame. The last phase writes the accumulator word into `dst` (its cache register, charged in `cacheable_writes`) and continues in-block.

### The aligned route's field extraction is arithmetic (`sar_ri`), never logical (`shr_ri`)
The bit-granular route needs no such argument: `seam::write_bit_field` *is* the family's own write rule, bit for bit, so a bit field cannot disagree with the interpreter about a byte.
The family hands `push_byte_field` the small value **sign-extended** to 64 bits (`small_value(field) as u64`), and the raw word's bit 63 is the small value's sign bit, so `sar` reproduces `(value as i64 as u64).to_be_bytes()`.
An 8-byte field's top byte has shift count `60`, where a logical shift's zero fill would reach the stored low byte and write `-1` as `0F FF FF FF FF FF FF FF`; a non-negative field has bit 63 clear, so the two agree byte for byte and `sar` is unconditionally right (the count peaks at `4 + 8*7 = 60`, a one-byte immediate).
Aligned-route stores sit at `cursor + field_offset` (`sar_ri` then a byte store per field byte; a `ConstBytes` field stores **copies** of compile-time constants, never a `StrT` pointer).
The bit-granular route has no byte cursor at all: with every field `<= MAX_INLINE_FIELD_BITS` it keeps the door's payload base in a register, derives the window end from the accumulator term once, and stores each field straight-line at the absolute bit `end + field_offset_bits` with no per-field room re-query, the door's whole-plan `tail_bits` check being the only admission point.

### Refusals of the construction shape
`BitGranular` + `ConstBytes` is refused by the predicate: there is no constant-bytes store on the bit-granular sequence, and mixing one would commit a window end from the aligned half before the bit fields' room check.
There is **no fail arm**: `bs_create_bin`'s `fail`-vs-`NO_FAIL` discrimination stays in the family, whose own value, fail transfer or raise is what the process observes; the fallback is one interpreter step for the **whole** instruction.
The refusal vocabulary is **closed**: a refused plan emits zero bytes, records no static deopt and is the family's own path; no new typed error exists on this arm.

## Deliberately left on `jit_bitstr`
Each is the tier's normal discipline, not a gap: a refused shape emits zero bytes, records **zero** static deopts (a claimed shape falls through to the family route, not to the `_` deopt arm) and yields the interpreter's own result.
- **A `bs_match` command list containing `binary`, `get_tail` or `=:=`** declines the **whole** instruction: each builds a fresh term (`raw::make_binary` reserves unconditionally), so a moving collection could relocate the context block mid-list and the once-read block base would go stale.
  `binary` matters most — its command group has the **same width** as `integer`'s, so a fall-through would read it as an integer field and bind an integer where a sub-binary is due, a wrong value rather than a refusal.
- **A width `field_width_supported` refuses** — outside `nbits <= 16 || nbits == 32` (`emit_bit_extract` covers aligned 8/16/32 plus a bit-granular field under 16 bits) — so a 17..=59-bit or 64-bit field stays on the family.
- **A runtime (non-constant) `size`/`unit`/`stride`** (a register compare the sequence does not have); an `ensure_at_least` **unit that is not a power of two** (`remaining % unit` no longer lowers to a mask, and `unit == 0` is a division by zero).
- **A subject `emit_subject_view` refuses** — literal-area, refc window, match context, bare `BinRef`, non-bitstring.
- **A signed, little-endian, or `native`-on-a-little-endian-host `flags` word** — the family's `erts_bs_get_integer_2` general reader, which sign-extends or byte-swaps.
- **`NO_FAIL`** wherever the shape has no `MatchFail::Family` arm (every field-extracting shape), because the raise's reason allocates; and an **unresolved** fail label, keeping its exact `unknown_label`.
- **A `bs_match` list with more than one `Y` destination**, because the sequence keeps one live Y address.
- **`bs_create_bin` forms other than the private-append construction shape.** `emit/test/refusal_census.rs::create_bin_refusal` attributes these with a closed two-value vocabulary — `"literal-area subject"` when any operand is `Operand::Literal(_)`, else `"other"`, the honest catch-all, because the shape predicate answers a single `None`.
  Behind `"other"`: anything `seam::append_plan` answers `None` for (a plain or later-position append, an append unit outside `1`/`2`/`4`/`8`, a `binary` segment that is not a whole-binary `all` tail, a `float`/`utf*` segment, a non-static size/unit, a `little`/`signed`/`native` flag, a zero-width or wider-than-a-word field, an unresolvable `StrT` window, no fields); a fresh non-append `[integer 8]` shape (no private append means it allocates); an un-addressable accumulator, field value or `dst`; more than `MAX_FIELDS`/`MAX_TAIL_BYTES`; bit offsets not summing to `tail_bits` (the commit would publish a window over unwritten bits); a `BitGranular` plan carrying a `ConstBytes` field.
  At run time: a non-small field value, a `Y` slot outside the published frame window (and `Machine::y` answering `None`), an accumulator or source the route's own door refuses (want of room, a target that is not this machine's writable accumulator, or a `unit`-position-gated window end), and a per-field `jit_write_bit_field` refusal — every one of those doors answers `0`.
- **`binary all` in any position but the plan's last and only field** stays on the family, because a runtime length fixes no static offset for itself or any later field; as the last and only one its bit offset is `0` (it starts at the accumulator's window end), so the position is static and the whole-binary route lowers it.
- **`bs_get_binary2`** is a deliberate refusal, not pending work: it builds a sub-binary through `raw::make_binary`'s rooted reserve-then-write seam, whose two parts must be the two objects `beam_gc::copy` sizes and moves separately (one contiguous block would write past the allocation). A specialized helper buys nothing either, since `jit_bitstr` already reaches `crate::families::bitstrings::exec` **directly** rather than through `crate::families::dispatch`.
- **`bs_get_float2`** boxes the decoded float (`make_float_rooted`) and rebinds the context in the same instruction, refused for the same allocating reason; **`bs_get_tail`**, **`bs_init_writable`**, **`bs_put_float`** and **`bs_get_float`** have **no arm at all**.
- **A fresh non-append `[integer 8]`** (`emqx_base62:decode/2`'s temp `<<DecodeChar>>`) stays on `jit_bitstr`: `raw::make_binary` **allocates** a fresh result (an on-heap `ErlHeapBits`, or above `ERL_ONHEAP_BINARY_LIMIT` the refc pair) through the rooted seam, which a straight-line helper-free sequence cannot do without an admission point.
A future arm for any of these would need the shape the construction arm already models: every guard first, one **positioned** helper call performing the rooted reserve → re-read → commit → write-`dst` discipline, and a fail path that mutates nothing.
Which refusals occur in the corpus is **measured**, not asserted here: `emit/test/refusal_census.rs` attributes every `Bs*` instance to inlined / refused-by-reason / no-arm, and `../census/CONTEXT.md` owns the closed reason vocabulary and the accounting pin.

## Constraints
- **Never a wrong result, never a panic.** A shape that cannot be lowered correctly is refused at compile time (zero bytes) or deopted at run time, never approximated, and **the deopt-idempotency invariant governs every arm** (top of this file).
- **A shape predicate is a pure function of the module image plus the operands' kinds** — no register allocation, no run-time state — because `emit_block`, `emit/regalloc.rs` and `emit/arith.rs::uses_y` evaluate it independently and must agree.
- **A predicate must not pre-empt a family typed error**: an out-of-range string-table offset or a missing pattern stays the family's own `unsupported`, so the shape declines rather than reporting it.
- **Compile-time pattern bytes and constant stores are copies, never pointers**, because a cached block can outlive the `Arc<Module>` whose string/literal area it was compiled against.
- **`CACHE_REGISTERS` is 5**; `rbx` is the `machine.x` base, `rsp`+`RUNTIME_SLOT_DISP` the `rt` slot, `r10`/`r11` within-instruction scratch only.
- **This node adds no `unsafe`**; the emitter modules keep their `// SAFETY:` rationales. Files ~1000 lines, and a legitimately long one documents why at its top.

## Test Strategy
Tier agreement is asserted **beside** the oracle comparison, never instead of it: a deopted instruction is executed by the interpreter on both sides, so agreement alone cannot prove an arm native.
Three instruments are needed in combination: (1) the `#[cfg(test)]` emission counter `inlined(SHAPE_*)` read back over a **cache-free** compile (`../bitstr_inline_tests.rs::emitted_shapes_for`, because a warmed `CodeCache` re-emits nothing); (2) the static-deopt census `static_deopts` over the same compile's counter snapshot, which must show **zero** deopts for that instruction; (3) the value/outcome against the interpreter **and** the live `erl`.
The deopt-idempotency pin (`../bs_match_deopt_tests.rs`) runs the real `<<_:2, F:6>>`-over-a-one-byte-subject decoder character (`emqx_base62:decode/2`'s per-character body) on both tiers with the value, the emission counter and zero static deopts, plus a live `erl` row.
The construction arm's 33 rows (`../bs_create_bin_tests.rs`) cover the per-width field values incl. the 64-bit sign-extension and two's-complement rows; the 1..64-bit width sweep with its route assertion and trailing-zero residue check; the mid-byte second-build rows with the unit-8 refusal; the capacity rows (exact, one short, mid-plan) and the boundaries; the bit-granular deopt-idempotency and mixed-plan-refusal rows; the `Y` accumulator / `Y` field value / `Y`+`Y` mix; the out-of-frame destination slot that rejects with the interpreter's own error; the declined shapes staying on the family; and the built binary's usability as a heap term afterwards.
`../foreign_kernel_tests.rs` compares the four `foreign` bench kernels' **outputs** on both tiers and against the live `erl`, staged from their read-only checkouts, plus the two append-arm attribution rows.
`../bitstr_tests.rs` pins the shared claim-set assertion (emitted set == router ownership == the family's `Ok(None)` contract), the decline-reaches-`jit_step_one` pin, tier agreement and that the helper ran; the `match_string`/`utf8`/`utf16`/`utf32`/`create_field_store` suites pin their own shape rows.
Gate: `erts_rust/scripts/cargo.sh test --manifest-path erts_rust/Cargo.toml -p beam_engine --lib`.
A green run without the system `erl` proves nothing about corpus parity, because the oracle-backed suites skip loudly. The censuses and their gate commands: `../census/CONTEXT.md`; the in-node suite enumeration: `../testing/CONTEXT.md`.

## Notes for Agents
- **The generic inline-set lever is largely spent.** The residual and every per-lever "do not re-open" verdict are `../measure/CONTEXT.md`'s and `../../CONTEXT.md`'s; do not add an arm expecting throughput, only for a correctness or semantics reason or with an instrument showing the arm is reached.
- **`FuncInfo` must never be inlined** — it is the failed-head-clause `function_clause` raise (`emu/ops.tab`'s `i_func_info_IaaI`), and inlining it would silently accept a bad head clause.
- **`call_ext*` keeps its driver round-trip by design** — the module-context switch, the label-map/literal-area rebinding and per-callee artifact publication all live in the driver, and `JitRuntime::module`/`labels` are baked for one module.
- **A traced run takes `Machine::drive`:** native code never emits a trace event, and a traced slice must never enter a block.
- **Check the counter, not the diff** — an arm that silently stops lowering still "agrees" with the interpreter.
- Emitted-byte arithmetic: `../CONTEXT.md`; per-kind measured bytes: `../census/CONTEXT.md`.
