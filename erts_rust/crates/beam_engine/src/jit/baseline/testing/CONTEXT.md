# `baseline/testing` — the native baseline tier's test enumeration

## Intent
The enumeration of what the baseline tier's own suites pin: the crate-internal tests under
`src/jit/baseline/` (all `#[cfg(test)]`, most as `#[path]` submodules of `../tests.rs` so they share its
fixtures and helpers) plus the one submodule of `../emit/test.rs`.
This node owns the *enumeration* only.
The instruments' tables and gate commands are `../census/CONTEXT.md`; every measured figure is `../measure/CONTEXT.md`; the tier's contract and inline set are `../CONTEXT.md` and `../emit/CONTEXT.md`.

## Cross-module tier equivalence is NOT here
Tier equivalence on real modules lives in the crate's `tests/jit*.rs` (see `../../../CONTEXT.md`), which drive the **lazy** path through `Machine::run_with_tier`.
These suites are the in-node pins: the block ABI/layout, the per-lowering agreement, and each lever's structural claim.

## `../tests.rs` (the ABI, layout and per-lowering pins)
Unit-tests the ABI encoding, the `#[repr(C)]` runtime layout, regalloc, the fast-path constants/arithmetic, the deopt/yield folding (a deopted `wait` folds to `RunOutcome::Wait`), and that a collecting `test_heap` reaches the host's admission door exactly once and reloads the cached registers afterwards.
- The **heap / frame-admission** family's own pins: tier agreement for `allocate` (both `HeapNeed` encodings) / `allocate_heap` / `test_heap` / `trim`; an over-trim raising the interpreter's own typed diagnostic on both tiers; the exactly-once admission (with the instruction's own `heap_need`/`live`) for the two heap-admitting members on each tier; and the structural claim that none of the four records a static or a run-time deopt.
- It also pins that the comparison-`test` lowering leaves no `Test` entry in the two-process copy-bound probe's per-opcode `jit_step_one` table.
- `the_y_window_traffic_of_the_committed_fixtures_is_measured` first pins the Y-traffic instrument on a synthetic shape with known traffic (2 loads / 2 stores / 2 same-block slot reuses), then counts the committed `erlc` fixtures: **17 guarded Y accesses over 224 013 emitted bytes**, **14** `Y`-touching blocks (**6** of them publishing the window in their prologue, so **8** dead publishes elided), **19** invalidation sites and **1** same-block slot reuse — the measured bound on what a per-block single-slot Y-value cache could save.
- `the_two_process_copy_bound_shape_is_measured_on_both_tiers` and `the_entry_module_priming_is_measured_on_both_tiers` are the measurement probes whose figures are in `../measure/CONTEXT.md` (the latter asserts the `module_fingerprint` counts only).

## `../call_tests.rs` (the frame-preserving local `Call`)
`the_frame_preserving_local_call_agrees_with_the_interpreter` (a two-argument and a nested chain), `the_frame_preserving_local_call_records_no_static_deopt`, `the_lowered_call_still_gives_its_continuation_a_native_sub_block`, an undefined-label deopt, no register touch/write, and `the_call_store_sentinel_is_disjoint_from_every_other_block_word`.
- `the_eager_sub_block_reads_the_call_result_out_of_machine_x` is the **eager-layout** pin (helpers `call_result_passthrough_case`/`eager_sub_block_context`): on the `f(A,B) -> g(B)` shape — a mid-block frame-preserving `call` followed by two **unguarded** inlined `move`s that carry the result across the continuation — it compiles the **eager** artifact through `JitBackend::{compile, run_compiled}` on `BaselineJit` (the tier entries go through `cache::run_baseline_cached*`, i.e. the **lazy** artifact, so they cannot reach the eager sub-block layout at all) and asserts the result equals both the interpreter's `Machine::run_export` and the hand-computed value; the callee is cache-free (a non-lowered `bif`) so no callee register can mask a stale one.
  It first pins the premise that the containing IR block's allocation and the sub-range allocation differ — `containing.slot(0).is_some() && sub_range.slot(0).is_some()`, `!containing.entry_loads(0)`, `sub_range.entry_loads(0)` — so a re-collapse of the eager pass onto one allocation fails on the shape itself, not only on the value.
- The in-block **transfer** is pinned by `a_lazy_cross_function_call_is_transferred_in_block` (transfer taken, no decline, fewer round-trips), `deep_cross_function_non_tail_recursion_does_not_grow_the_native_stack` (20 000-deep mutual non-tail recursion, both tiers return the same value — the tail transfer's reason), `a_refused_preemption_charge_parks_at_the_callee_entry_and_resumes_exactly_once` (parked at the **callee** entry, resume yields the value, `reduce` hooks fire `(1,1)`), `a_served_local_call_is_never_transferred` (`in_block_calls == 0`, the BIF value delivered) and `an_uncompilable_callee_declines_to_the_driver` (a function with no IR blocks → `in_block_call_declines > 0`, the driver's word path).

## `../raise_tier_tests.rs` (the frame-discipline pin)
`a_raise_at_its_own_pc_plus_one_reads_the_enclosing_frames_y_slot`: `allocate 2` (frame A) → `y(0) := 11` → `try` → `allocate 1` (frame B) → `case_end` raising → the handler at the raise's **own `pc + 1`** → `try_case` → `y(0) → x(0)`.
Asserts this tier returns `11` (not the destroyed frame's word), `step_one == 0` (nothing is masked by an interpreter step), and interpreter/baseline agreement.
`fold_step` encodes `Step::Next` and `Step::Goto { pc: pc + 1 }` identically, so the raising block links straight into the handler block with **no** driver iteration between the unwind and the handler; the read is correct only because both emitted window derivations are unconditional (see `../measure/CONTEXT.md` and `../emit/prologue/CONTEXT.md`).

## `../bs_match_deopt_tests.rs` (the `bs_match` arm's re-execution idempotency)
`the_decoder_character_shape_agrees_with_the_interpreter_and_stays_native` — the exact `<<_:2, F:6>>`-over-a-**1-byte**-subject shape on both tiers with the value asserted, then a cache-free compile proving `inlined(SHAPE_BS_MATCH) > 0` with **zero** `BsMatch` static deopts, so the arm cannot regress into a silent deopt.
`the_decoder_character_shape_matches_the_system_oracle` — the same row against the live `erl` (loud skip when absent).
`an_ensure_exactly_rejection_takes_the_fail_label_in_both_directions` (remaining > stride and remaining < stride), `a_skip_to_the_exact_end_then_a_zero_width_field_succeeds` (`skip 8` plus a `size 0` field, in both the `unit 1` and the `unit 8` form), `a_skip_past_the_end_takes_the_fail_label`, `a_zero_length_segment_mid_list_agrees`.
`a_no_fail_match_raises_the_badmatch_reason_with_the_exact_subject` pins class `error`, the reason's arity, its `badmatch` atom and the subject's bit-window size over two subject bit lengths (the reason's second element is a live match context, which `beam_term` cannot compare or read — `../../CONTEXT.md`'s Known Issues), and pins beside it that `bs_match_shape` refuses `NO_FAIL`, so the row runs through the family.
`a_legitimately_deopting_shape_is_still_idempotent` is the root-cause pin: `ensure_exactly 24` + `skip 2` + `integer 16` over a 3-byte subject really does take the fallback, and must answer the interpreter's value — a reintroduced pre-fallback commit turns that into a fail-label exit.

## `../bs_create_bin_tests.rs` (the construction arm)
26 rows over hand-built synthetic IR — no `.beam` fixture and no `erl`/`erlc`; the byte oracle is a local two's-complement big-endian truncation helper (`big_endian`), and `with_both_tiers` runs each row on `Tier::Interpreter` and `Tier::BaselineJit` and asserts tier equality before the bytes.
- Field values: `an_integer_8_field_is_written_as_one_big_endian_byte`, `an_integer_16_field_is_written_as_two_big_endian_bytes`, `an_integer_24_field_is_written_as_three_big_endian_bytes`, `an_integer_32_field_is_written_as_four_big_endian_bytes`, `an_integer_64_field_is_written_as_eight_big_endian_bytes`, `a_sixty_four_bit_field_writes_all_eight_bytes`, `a_negative_and_an_oversized_value_are_truncated_to_the_field_width` (the `sar_ri` sign-extension rows), `a_string_constant_field_writes_its_literal_bytes`, `a_mixed_integer_8_and_string_shape_writes_both_fields_in_order`, `a_string_longer_than_eight_bytes_uses_the_chunk_and_tail_path`, `an_empty_result_is_the_empty_binary`, `a_zero_length_string_beside_a_real_field_does_not_shift_the_offsets`, `the_built_binary_is_usable_as_a_heap_term_afterwards`.
- The `Y` forms: `a_y_slot_accumulator_is_lowered_and_writes_the_same_bytes` (the aligned route's inline proof loads the term out of its `Y` slot and passes the proven payload base and window end to `jit_append_cursor`; `registers()` must not charge the slot), `a_y_slot_field_value_is_lowered_and_writes_the_same_bytes`, and `a_y_accumulator_with_two_y_field_values_writes_every_field_in_order` (every offset form at once, nothing in the register cache).
- Emission: `every_in_scope_construction_shape_stays_native_on_a_cache_free_compile` proves `inlined(SHAPE_CREATE_BIN) > 0` with zero `BsCreateBin` static deopts around a cache-free `compile_function`, so the arm cannot regress into a silent deopt.
- Capacity boundaries and idempotency: `an_accumulator_reaching_its_capacity_exactly_stays_native`, `an_accumulator_one_byte_short_falls_back_and_is_correct`, `an_accumulator_crossing_its_capacity_mid_build_falls_back_and_is_correct`, `a_one_byte_short_capacity_declines_and_is_idempotent`, `a_plain_binary_accumulator_declines_and_is_idempotent`, `a_copied_off_heap_accumulator_declines_and_is_idempotent`, and `a_y_slot_accumulator_one_byte_short_declines_and_is_idempotent` (the `Y` accumulator's short capacity: the fallback re-executes against a slot nothing wrote).
- A destination outside the frame: `an_out_of_frame_destination_slot_rejects_and_raises_the_interpreters_error` — the predicate accepts it (addressability is a compile-time fact, the frame is a run-time one), the arm emits, and the emitted guard's `fallback` reproduces the interpreter's own raise.
- Refusals: `declined_shapes_emit_nothing_and_run_on_the_family` walks the declined forms (`binary`/`binary all`, bit-granular fields, floats, `utf*`, a dynamic size/unit, an un-addressable `Loc`) and pins that each emits **zero bytes** and answers the family's own value.

## `../foreign_kernel_tests.rs` (the four `foreign` bench kernels' outputs)
One row per kernel plus a whole-input-vector row and three attribution rows: `cowboy_to_lower_agrees_on_both_tiers_and_with_the_oracle`, `cowboy_capitalize_token_agrees_on_both_tiers_and_with_the_oracle`, `emqx_base62_encode_agrees_on_both_tiers_and_with_the_oracle`, `emqx_base62_decode_agrees_on_both_tiers_and_with_the_oracle`, `the_whole_bench_input_vector_set_agrees_on_both_tiers_and_with_the_oracle`, `the_base62_decode_match_arm_is_emitted_and_not_deopted`, `the_cowboy_capitalize_token_append_arm_is_emitted_and_not_deopted` and `the_to_lower_append_construction_lowers_its_y_slot_accumulator`.
Each row stages the **unmodified upstream source** read-only from `BENCH_COWBOY_REPO`/`BENCH_EMQX_REPO` (defaults `/home/bill/Source/{cowboy,emqx}`), compiles it at test time with the system `erlc`, runs the kernel on `Tier::Interpreter` and `Tier::BaselineJit` with a fresh `Machine`+host per tier, and asserts tier equality first, then the concrete expected bytes, then the live `erl` oracle.
A missing checkout, a missing source or an unusable `erlc`/`erl` is a loud `SKIP <name>: …` that still passes the row (`ERTS_ORACLE=<bad path>` therefore skips only the oracle legs); the input vectors and expected outputs are the ones `tools/bench/src/workloads/foreign.rs` drives, so a row here and a bench figure there describe the same call.
Its host wrapper adds a small **closed** BIF floor (`iolist_to_binary/1`, `bit_size/1`, `'+'`/`'-'`/`'*'`/`div`/`rem`/`abs`) because a `MinimalContext` `BifHook` gets no heap; every other dispatch keeps the inner context's typed `unsupported_bif`, so a kernel needing more skips loudly instead of producing a shaped value.
`the_base62_decode_match_arm_is_emitted_and_not_deopted` reads `bitstr_inline_tests::emitted_shapes_for` around a cache-free compile of the decode function, so the arm the output rows depend on cannot be deopted away.
`the_cowboy_capitalize_token_append_arm_is_emitted_and_not_deopted` is the same pin for the construction arm — it proves `inlined(SHAPE_CREATE_BIN) > 0` with zero `BsCreateBin` static deopts on `cowboy_bstr:capitalize_token/1`'s append loop; `the_to_lower_append_construction_lowers_its_y_slot_accumulator` pins the `Y` form on real compiler output: the comprehension loop `-to_lower/1-lbc$^0/2-0-/2` builds once, its accumulator is a frame slot, and the arm emits with zero static deopts, on both tiers and against the oracle.

## Constraints
- Every suite here is `#[cfg(test)]` and in-node; none may change a production result.
- Tests needing the system toolchain or `erl` skip loudly when it is absent, so a green run without it proves nothing about corpus parity.
- Run through the wrapper (`$HOME` is read-only in the sandbox): `erts_rust/scripts/cargo.sh test --manifest-path erts_rust/Cargo.toml -p beam_engine --lib` for this node's suites.
