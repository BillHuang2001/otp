`machine::registers` (the x/FR files and their bounds — `set_x`/`set_fr`/`get_fr`, `MAX_REGISTER`/`MAX_FLOAT_REGISTER`, the `reset` refill); `machine::frames` (frame push/pop/return, `trim`, Y-slot scoping, `y`/`y_mut` bounds, `ensure_heap`'s root-set forwarding, `resumption_addresses`, `raise_snapshot`); `machine::catch` (the catch-frame stack, the throw/unwind/landing paths, `pending_exception`/`pending_class`, and the `with_uncaught_frames`/`raise_stacktrace` funnel — it attaches only to an empty raise, leaves an engine diagnostic unframed, and resolves each frame in its own module context); `machine::run` (`run_export`/`run_label`, `RunOutcome`, the blocked-receive fold and `resume_outcome`); `machine::drive` (the per-instruction reduction charge and the slice counter); `machine::location` (the `wait_deadline`/`timeout_delay` accessors over a literal and a Y-register delay); `predicates` (the `beam_term` boxed-term predicate wrappers, incl. native-record vs tuple); `terms` (every constructor↔reader round-trip through `MinimalContext` — incl. `make_map` across the 32-key flat/hashmap boundary, the `slack_carves_a_multi_node_graph_out_of_one_reservation` carve — raw-word layout proofs, the flat-map and HAMT readers over hand-built nodes, and the error cases: `make_flatmap` >32 / fun field >255 / binary >64 → `unsupported`/`SystemLimit`, wrong-type readers → `BadArg`); `terms::alloc_tests` (the **rooted-allocation** suite: a counting context proves the `*_rooted` builders fire the rooted hook and never the unrooted one; a semi-space **moving** collector proves the reserve → read → write ordering; and a peak-word table contrasts the never-freeing arena with the collecting one); `operand` (read/write each supported operand kind incl. `FloatReg`↔FR file + out-of-range, `Literal` via `Machine::literal`, and a missing/unbound literal → typed error; `Label`/`List`/`Allocation` → unsupported); `interpreter` (the label map + resolution, and — in `src/interpreter/tests.rs` — the `NO_FAIL` guard raises: a failed `test`/`select_val` with `fail == NO_FAIL` raises class `error` with the bare atom `function_clause`, once through `step_instruction` and once through `run_label`, landing in a live `try` frame, while a module that cannot name the atom is the typed `unsupported_opcode: <site>: no 'function_clause' atom in the module`); `jit` (the roster invariants — interpreter first, `"baseline-jit"` always present, `"jit-cranelift"` iff the feature is on, the roster is a `Tier::ALL` prefix; `Tier::name`↔`from_name` round-trips + unknown/empty/miscased names ⇒ `None`; `run_with_tier` on the reused `slice.beam` fixture — `Interpreter` equals `run_export`, `BaselineJit` equals it too, `Cranelift` is a typed error); `jit::baseline` (block-target `encode_target`/`decode_target` round-trips and `HALT`/`ERROR` sentinel distinctness, the `JitRuntime` field offsets generated code relies on, that cached slots index the x-register array rather than the `Machine` struct, the cached/directly-addressed register allocation and its bound, and the `constant_word`/`x_register` operand forms); `jit::baseline::emit::link` (the direct cross-block `jmp` linkage — an emitted `jmp rel32` landing on the successor's compiled entry, the `rt` reload on a linked exit, and the cached-slot spill); `jit::baseline::emit::test` (the `test_plan` inline/refuse decision: the word tests plus the boxed-term `TestKind`s it lowers, and the refusals — `NO_FAIL`, an unresolved label, an `arity == 0` tagged tuple, a missing `true`/`false` for `is_boolean`); `jit::cache` (the content-keyed compiled-block cache — `module_fingerprint` stability across reloads, same-name/different-content non-collision, `get_or_compile` reuse, and `clear`); `jit::emitter` (the encoder is proven by *executing* what it emits: `add(a,b)`, a six-argument sum through `r8`/`r9`, `r12`- and `rsp`-based addressing, `lea`, `max` via `cmp`+`jcc`, an indirect `call_r` into a second buffer, forward/backward/conditional label patching, `seal` flips `/proc/self/maps` from `rw-p` to `r-xp`, plus the error paths — unbound label at `seal`, emit-after-`seal`, foreign/double-bound label, exhausted capacity, repeated map/seal/drop); `jit::tiering` (the cold/warm/hot boundaries, the `hot ≥ baseline` clamp, a zero baseline threshold, equal thresholds skipping the baseline rung, `Default`, `is_hot`, and that `select` never names a tier outside `available_tiers` — `Cranelift` exactly when the feature is on); `jit::cranelift` (the feature-gated backend's own tests — tier name/availability, one native entry per non-empty function, the empty module, and a **direct call into a compiled entry** proving native execution); `families::*` (per-family unit tests, plus the `families::dispatch` tests in `families/mod.rs` — `families::{bitstrings/{create,matching,raw,run_tests},exceptions,floats,funs,maps,receive,records}`, and the split families group their suites further: `families::exceptions::tests::{handlers,raising,stacktrace,end_to_end}` (the `stacktrace` sub-suite cooks the non-`NIL` arm from the **raise-time snapshot** — an already-unwound caller is still named, and a snapshot frame resolves in its own registered module context, skipping a context-`0` frame observed from a non-zero handler) and `families::records::tests::{native,elements,update,access,field}`; `families::funs::tests` also owns the four `apply`/`apply_last` cross-module-seam tests — the `apply` `Step::Enter` + caller return address, the cross-module receive suspend/resume, the `Ok(None)` sync-path fallback, and `apply_last` popping its frame first; the `records::tests::update` suite also covers `put_record`'s **create** form (`Src = nil`), whose two typed-`unsupported` id cases are a record name the running module does not define, and an id naming a **foreign** module); `families::bitstrings::run_tests` is the family's end-to-end + oracle suite (all driven through `Machine::run_label`/`run_export`, never a family helper): a refc subject whose window is **not** byte-aligned read bit-for-bit through `bs_start_match3`/`bs_get_tail`/`bs_get_integer2`, an `append` segment in a **non-first** position (`bs_create_bin` concatenating the source's bits at the point it appears), and a live `erlc`/`erl` cross-check that compiles an inline module at test time and compares it with the system `erl` on the same bytes (the whole suite skips loudly without `erlc`/`erl`); `families::maps::tests` pins the read instructions' `NO_FAIL` raise (`get_map_elements`/`has_map_fields` with a missing key and `fail == NO_FAIL` raise the bare atom `function_clause` — both landed in a live `try` frame and uncaught — while a module that cannot name the atom is the typed `unsupported_opcode: maps: no 'function_clause' atom in the module`), beside the unchanged `{badmap,_}`/`{badkey,_}` write-path raises).

## Synthetic-module opcode tests (`tests/opcodes.rs`)
Hand-built `Module`s (the loader is not involved) covering the rest of the executed subset — every `TestKind` (success and failure), `SelectVal`, the frame instructions (`Allocate`/`AllocateHeap`/`TestHeap`/`Deallocate`/`Trim`), the call family (`Call`/`CallLast`/`CallOnly`/`CallExt`/`CallExtOnly`/`CallExtLast`), the `GcBif` guard-fail/raise paths, the catch-frame landing of a raising BIF (`gc_bif`/`bif`/`bif0`/`call_ext*` with no fail label inside a live `try`), the module-level no-op markers (`NifStart`/`OnLoad` between two labels do not disturb control flow), the typed `Instr::IsAnyNativeRecord` guard (`is_any_native_record` falls through on a record, branches to `fail` on a non-record — `NIL`, a small integer **and a tuple**, since `is_record/1` is a native-record header test, not a tuple test), the `is_any_native_record/no_fail` typed error, a residual `Instr::Generic` opcode keeping its named `unsupported` (`is_native_record`), and the documented error paths; a comprehensive test module, legitimately long.

## Integration tests
- **Vertical slice** (`tests/slice.rs`): load the committed fixture `../beam_loader/tests/fixtures/slice.beam` (reused, **not duplicated**, via `concat!(env!("CARGO_MANIFEST_DIR"), "/../beam_loader/tests/fixtures/slice.beam")`), build a `MinimalContext` whose hook implements `erlang:'+'/2` and `erlang:'-'/2` over small ints, and assert `slice:add(2,3) == 5`, `slice:fib(10) == 55`, `slice:pick(a) == 1`, `slice:pick(b) == 2`.
- **Broad fixture end-to-end** (`tests/coverage.rs`): the whole executed subset over the sibling loader fixture `beam_loader/tests/fixtures/coverage.beam`.
- **Baseline-JIT integration** (`tests/jit.rs`): drives the same slice fixture through **both** tiers via a `MinimalContext` BIF hook — `available_tiers` contains `"baseline-jit"`, `compile` emits one native entry per non-empty block (all inside the code mapping, unique), `add`/`fib`/`pick` agree across tiers, the two tiers agree on the typed error for a raising BIF and a missing export, and they agree across register-file sizes (`Machine::with_max_register(2|3|8|MAX_REGISTER)`, exercising the `native_ok` guard). It also proves the compile-once / run-many split (`a_compiled_artifact_can_be_run_more_than_once`): one `compile`d artifact is run twice on fresh machines via `JitBackend::run_compiled` and matches the interpreter, a missing export there is a typed error, and the provided one-shot `run_export` agrees — for the baseline tier always and the Cranelift tier when the feature is on. It also covers the guarded tuple readers (`get_tuple_element`/`select_tuple_arity`): a non-tuple source or a too-short tuple deopts to the helper and both tiers agree — a non-tuple arity switch takes its `fail` branch, and an exhaustive `NO_FAIL` switch raises `{badmatch, Tuple}`.
- **Baseline-JIT tier equivalence** (`tests/jit_coverage.rs`): the same two-tier agreement over the broad `coverage.beam` fixture, reusing `MinimalContext`'s public hooks: small-int arithmetic BIF hook + the `'-make_adder/1-fun-0-'` apply hook, with boxed float arguments built through `terms`. Covers the helper's whole `Step` surface — `Next` (`gc_bif` arithmetic), `Goto` to other labels/functions (`select_tuple_arity`, case guards, recursion, `call_fun2`), the **`badarith` raise landing in a live catch frame**, `Done` (`call_ext`), the supported bitstring match path, and the `bs_create_bin` `append` segment (both tiers produce the rotated `<<2,3,1>>`).
- **Baseline-JIT cross-run cache** (`tests/jit_cache.rs`): the content-keyed compiled-block cache (`beam_engine::jit::cache`) over the reused `slice.beam` — a second run reuses the artifact (a real compile counter and the code mapping's `code_address_range` show no recompile), a freshly loaded copy of the same content hits the cache, `clear` resets it, the cached native run stays interpreter-identical, and the identity is **sound**: `module_fingerprint` is stable across separate loads and same-name/different-content modules get a distinct entry. Also drives `CodeCache::get_or_compile` explicitly, many runs on separate `Machine`s.
- **Baseline-JIT direct block linking** (`tests/jit_linking.rs`): the cross-block `jmp` linkage (`src/jit/baseline/emit/link.rs`) over `slice.beam` plus hand-built linking modules — a `jmp rel32` inside a compiled block whose landing address (read out of the sealed mapping) is the successor block's compiled entry, the `rt` reload a linked exit needs, the cached-slot spill so a produced value reaches `machine.x`, that linking leaves the block table and `block_count()` unchanged, and the deopt floor (a shape the tier may not lower still yields the interpreter's exact typed error, never a wrong result).
- **Baseline-JIT comparison fast path** (`tests/jit_compare.rs`): the eight `erlang` comparison BIFs (`=:=`/`=/=`/`==`/`/=`/`<`/`=<`/`>`/`>=`, `src/jit/baseline/emit/compare.rs`) and the two-small-register `is_eq_exact`/`is_ne_exact` (`emit/test.rs`), against `Tier::Interpreter` as the oracle over hand-built modules — interpreter-identity of every inlined shape across a small-int boundary sweep (`MIN_SMALL`/`MAX_SMALL` included), the guard-rejection/refusal deopts (a boxed float, a bignum constant, an atom/`nil` under an ordering operator, a `Y`/float-register/literal operand) landing on the interpreter's exact typed error, and the inlining evidence (a counting BIF floor shows the inlined shape consults the hook zero times; `CompiledModule::highest_native_register` is set for a comparison-only block and `None` for one that stays on the helper).
- **JIT code-range surface** (`tests/jit_code_map.rs`): `jit::cache::baseline_code_map` over `slice.beam` — every region non-empty, inside the same artifact's `code_address_range()`, ascending, disjoint and contiguous (reaching the mapping's end), and its `start` the exact `CompiledModule::entry(func, pc)` its `<module>:<function>/<arity>/<pc>` name parses back to; the cached entry reporting the same blocks as an explicit `compile`, an artifact with no compiled block reporting an **empty** map (never an invented range), stability across recompiles of the same content, and a host describing the code it just ran on the baseline tier.
- **JIT micro-benchmark** (`tests/jit_bench.rs`): a thin driver over `beam_engine::jit::bench` (the crate's single JIT-measurement module — `pub mod bench`, not test-gated). Its two entry points are the fast agreement test (in the ordinary suite) and the `#[ignore]`d measurement table. Nine workloads, split by lowering story: the shapes the baseline **deopts** — `build/0` (`put_tuple2`/`put_list`), `map/2`, `select/1`, `walk/2` — and the shapes it **inlines** — `slice:fib/1` (a real `.beam` fixture), `kernel/2`, `wide/2`, `aggr/2`, `cmp/2`. A native tier compiles **once outside** the timed loop and the loop only ever calls `run_compiled`; the test prints `ns/op`/`ops/s` and asserts **only correctness** (every tier equals the interpreter, and the value is the one the workload should compute), never speed. Workload set, method and caveats are in `src/jit/bench/CONTEXT.md`; figures in `MEASURED.md`.
- **Interpreter micro-benchmark** (`tests/engine_bench.rs`): the dependency-free `ns`/interpreted-instruction harness over `Machine::run_export` (no `criterion`, no new dependency, no `#[ignore]`), one `#[test]` so the workloads never run concurrently. It prints its table under `--nocapture` and asserts only **correctness** + **structural** invariants, never a performance threshold. Each row is one hand-built synthetic `Module` (or the committed `fixtures/tailcall.beam`) with a single export, run once untimed then `SAMPLES = 5` times for that row's `iterations` runs each; `ns/instruction = elapsed_ns / (iterations * instructions_per_run)` on the **median** sample (best sample in brackets). - **Per-application execution breadth** (`tests/apps_lists.rs`): the widened oracle-checked sweep over OTP applications *beyond* `stdlib`/`kernel`/`compiler`, through a host whose search path is **every** installed application (`support::all_otp_ebins`) — `syntax_tools`/`erl_syntax`, `xmerl` (`xmerl_ucs`/`xmerl_lib`), `inets`/`httpd_util`, `edoc`/`edoc_lib`, `eunit`/`eunit_lib`, `dialyzer`/`dialyzer_utils`, `asn1`/`asn1ct_pretty_format`, `snmp` (`snmp_misc`/`snmp_pdus`) and `parsetools` (`leex`/`yecc:format_error/1`) — every expected value derived from the system `erl` oracle. `blocked_targets_report_their_typed_error` is the honest counterpart: targets the host cannot serve are asserted against their **exact** typed error (`asn1ct:use_legacy_types/0` and `get_bit_string_format/0` → the process-dictionary `badarg`; `httpd_util:module_validate/1` → the code-server `badarg`; `erl_syntax:atom_literal/1` and the atom-bearing `asn1ct_pretty_format:term/1` forms → the `persistent_term` NIF refusal; `httpd_util:create_etag/1` → the structured `{badrecord, V}` raise).
