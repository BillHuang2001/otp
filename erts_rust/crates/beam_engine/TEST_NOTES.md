# `beam_engine` — exhaustive test / fixture enumeration

Extracted from `CONTEXT.md` (which keeps only the strategy summary + the gate) so the
contract sections stay within the ~64 KB per-file budget. This file is documentation,
not a change log: it describes the tests that exist now.

## Per-module `#[cfg(test)]` unit tests
`context` (hook dispatch, default-hook unsupported, the `alloc_words` arena pointer stability/aliasing, `apply`/`apply_fun` forwarding and their defaults, the apply hook); `machine::registers` (the x/FR files and their bounds — `set_x`/`set_fr`/`get_fr`, `MAX_REGISTER`/`MAX_FLOAT_REGISTER`, the `reset` refill); `machine::frames` (frame push/pop/return, `trim`, Y-slot scoping, `ensure_heap`'s root-set forwarding, `resumption_addresses`); `machine::catch` (the catch-frame stack, the throw/unwind/landing paths, and `pending_exception`/`pending_class`); `machine::run` (`run_export`/`run_label`, `RunOutcome`, the blocked-receive fold and `resume_outcome`); `predicates` (the `beam_term` boxed-term predicate wrappers, incl. native-record vs tuple); `terms` (every constructor↔reader round-trip through `MinimalContext` — incl. `make_map` across the 32-key flat/hashmap boundary — raw-word layout proofs, the flat-map and HAMT readers over hand-built nodes, and the error cases: `make_flatmap` >32 / fun field >255 / binary >64 → `unsupported`/`SystemLimit`, wrong-type readers → `BadArg`); `operand` (read/write each supported operand kind incl. `FloatReg`↔FR file + out-of-range, `Literal` via `Machine::literal`, and a missing/unbound literal → typed error; `Label`/`List`/`Allocation` → unsupported); `interpreter` (the label map + resolution); `jit` (the roster invariants — interpreter first, `"baseline-jit"` always present, `"jit-cranelift"` iff the feature is on, the roster is a `Tier::ALL` prefix; `Tier::name`↔`from_name` round-trips + unknown/empty/miscased names ⇒ `None`; `run_with_tier` on the reused `slice.beam` fixture — `Interpreter` equals `run_export`, `BaselineJit` equals it too, `Cranelift` is a typed error); `jit::baseline` (block-target `encode_target`/`decode_target` round-trips and `HALT`/`ERROR` sentinel distinctness, the `JitRuntime` field offsets generated code relies on, that cached slots index the x-register array rather than the `Machine` struct, the cached/directly-addressed register allocation and its bound, and the `constant_word`/`x_register` operand forms); `jit::baseline::emit::link` (the direct cross-block `jmp` linkage — an emitted `jmp rel32` landing on the successor's compiled entry, the `rt` reload on a linked exit, and the cached-slot spill); `jit::cache` (the content-keyed compiled-block cache — `module_fingerprint` stability across reloads, same-name/different-content non-collision, `get_or_compile` reuse, and `clear`); `jit::emitter` (the encoder is proven by *executing* what it emits: `add(a,b)`, a six-argument sum through `r8`/`r9`, `r12`- and `rsp`-based addressing, `lea`, `max` via `cmp`+`jcc`, an indirect `call_r` into a second buffer, forward/backward/conditional label patching, `seal` flips `/proc/self/maps` from `rw-p` to `r-xp`, plus the error paths — unbound label at `seal`, emit-after-`seal`, foreign/double-bound label, exhausted capacity, repeated map/seal/drop); `jit::tiering` (the cold/warm/hot boundaries, the `hot ≥ baseline` clamp, a zero baseline threshold, equal thresholds skipping the baseline rung, `Default`, `is_hot`, and that `select` never names a tier outside `available_tiers` — `Cranelift` exactly when the feature is on); `jit::cranelift` (the feature-gated backend's own tests — tier name/availability, one native entry per non-empty function, the empty module, and a **direct call into a compiled entry** proving native execution); `families::*` (per-family unit tests, plus the `families::dispatch` tests in `families/mod.rs` — `families::{bitstrings/{create,matching,raw},exceptions,floats,funs,maps,receive,records}`, and the split families group their suites further: `families::exceptions::tests::{handlers,raising,stacktrace,end_to_end}` and `families::records::tests::{native,elements,update,access,field}` — the `records::tests::update` suite also covers `put_record`'s **create** form (`Src = nil`): its two remaining typed-`unsupported` id cases are a record name the running module does not define, and an id naming a **foreign** module).

## Per-family integration tests over committed real `.beam` fixtures
Produced by the system `erlc`, the differential oracle — see `tests/fixtures/README.md` for the regeneration recipe and the opcode coverage of each fixture:

## Synthetic-module opcode tests (`tests/opcodes.rs`)
Hand-built `Module`s (the loader is not involved) covering the rest of the executed subset — every `TestKind` (success and failure), `SelectVal`, the frame instructions (`Allocate`/`AllocateHeap`/`TestHeap`/`Deallocate`/`Trim`), the call family (`Call`/`CallLast`/`CallOnly`/`CallExt`/`CallExtOnly`/`CallExtLast`), the `GcBif` guard-fail/raise paths, the catch-frame landing of a raising BIF (`gc_bif`/`bif`/`bif0`/`call_ext*` with no fail label inside a live `try`), the module-level no-op markers (`NifStart`/`OnLoad` between two labels do not disturb control flow), the typed `Instr::IsAnyNativeRecord` guard (`is_any_native_record` falls through on a record, branches to `fail` on a non-record — `NIL`, a small integer **and a tuple**, since `is_record/1` is a native-record header test, not a tuple test), the `is_any_native_record/no_fail` typed error, a residual `Instr::Generic` opcode keeping its named `unsupported` (`is_native_record`), and the documented error paths; a comprehensive test module, legitimately long.

## Integration tests
- **Vertical slice** (`tests/slice.rs`): load the committed fixture `../beam_loader/tests/fixtures/slice.beam` (reused, **not duplicated**, via `concat!(env!("CARGO_MANIFEST_DIR"), "/../beam_loader/tests/fixtures/slice.beam")`), build a `MinimalContext` whose hook implements `erlang:'+'/2` and `erlang:'-'/2` over small ints, and assert `slice:add(2,3) == 5`, `slice:fib(10) == 55`, `slice:pick(a) == 1`, `slice:pick(b) == 2`.
- **Baseline-JIT integration** (`tests/jit.rs`): drives the same slice fixture through **both** tiers via a `MinimalContext` BIF hook (`erlang:'+'/2`/`'-'/2` over smalls) — `available_tiers` contains `"baseline-jit"`, `compile` emits one native entry per non-empty block (all inside the code mapping, unique), `add`/`fib`/`pick` agree across tiers, the two tiers agree on the typed error for a raising BIF and a missing export, and they agree across register-file sizes (`Machine::with_max_register(2|3|8|MAX_REGISTER)`, exercising the `native_ok` guard). It also proves the compile-once / run-many split (`a_compiled_artifact_can_be_run_more_than_once`): one `compile`d artifact is run twice on fresh machines via `JitBackend::run_compiled` and matches the interpreter, a missing export there is a typed error, and the provided one-shot `run_export` agrees — for the baseline tier always and the Cranelift tier when the feature is on. It also covers the guarded tuple readers (`get_tuple_element`/`select_tuple_arity`): a non-tuple source or a too-short tuple deopts to the helper and both tiers agree — a non-tuple arity switch takes its `fail` branch, and an exhaustive `NO_FAIL` switch raises `{badmatch, Tuple}`.
- **Baseline-JIT tier equivalence** (`tests/jit_coverage.rs`): the same two-tier agreement over the broad `coverage.beam` fixture, reusing `MinimalContext`'s public hooks: small-int arithmetic BIF hook + the `'-make_adder/1-fun-0-'` apply hook, with boxed float arguments built through `terms`. Covers the helper's whole `Step` surface — `Next` (`gc_bif` arithmetic), `Goto` to other labels/functions (`select_tuple_arity`, case guards, recursion, `call_fun2`), the **`badarith` raise landing in a live catch frame**, `Done` (`call_ext`), the supported bitstring match path, and the `bs_create_bin` `append` segment (both tiers produce the rotated `<<2,3,1>>`).
- **Baseline-JIT cross-run cache** (`tests/jit_cache.rs`): the content-keyed compiled-block cache (`beam_engine::jit::cache`) over the reused `slice.beam` — a second run reuses the artifact (a real compile counter and the code mapping's `code_address_range` show no recompile), a freshly loaded copy of the same content hits the cache, `clear` resets it, the cached native run stays interpreter-identical, and the identity is **sound**: `module_fingerprint` is stable across separate loads and same-name/different-content modules get a distinct entry. Also drives `CodeCache::get_or_compile` explicitly, many runs on separate `Machine`s.
- **Baseline-JIT direct block linking** (`tests/jit_linking.rs`): the cross-block `jmp` linkage (`src/jit/baseline/emit/link.rs`) over `slice.beam` plus hand-built linking modules — a `jmp rel32` inside a compiled block whose landing address (read out of the sealed mapping) is the successor block's compiled entry, the `rt` reload a linked exit needs, the cached-slot spill so a produced value reaches `machine.x`, that linking leaves the block table and `block_count()` unchanged, and the deopt floor (a shape the tier may not lower still yields the interpreter's exact typed error, never a wrong result).
- **Baseline-JIT comparison fast path** (`tests/jit_compare.rs`): the eight `erlang` comparison BIFs (`=:=`/`=/=`/`==`/`/=`/`<`/`=<`/`>`/`>=`, `src/jit/baseline/emit/compare.rs`) and the two-small-register `is_eq_exact`/`is_ne_exact` (`emit/test.rs`), against `Tier::Interpreter` as the oracle over hand-built modules — interpreter-identity of every inlined shape across a small-int boundary sweep (`MIN_SMALL`/`MAX_SMALL` included), the guard-rejection/refusal deopts (a boxed float, a bignum constant, an atom/`nil` under an ordering operator, a `Y`/float-register/literal operand) landing on the interpreter's exact typed error, and the inlining evidence (a counting BIF floor shows the inlined shape consults the hook zero times; `CompiledModule::highest_native_register` is set for a comparison-only block and `None` for one that stays on the helper).
- **Feature-gated Cranelift tier** (`tests/jit_cranelift.rs`, the whole file is `#![cfg(feature = "jit-cranelift")]`): the `available_tiers`/`JitBackend` roster, one native entry per function, and `add`/`fib`/`pick` agreeing with the interpreter (and the baseline tier) on the reused `slice.beam`, plus the raising-BIF/missing-export typed-error parity. Its shape fixtures also cover the guarded tuple readers: `get_tuple_element`/`select_tuple_arity` inline, a non-tuple source deopts to the helper and takes the `fail` arm (`0`), and an exhaustive `NO_FAIL` arity switch deopts as a whole (a matching tuple still answers, an unmatching one raises `{badmatch, Tuple}`).
- **Native-tier micro-benchmark** (`tests/jit_bench.rs`): interpreter-vs-JIT `ns/op` over five workloads — the real `slice.beam` `fib/1(20)` short tail-recursive chain; the synthetic 256-`gc_bif '+'/2` straight-line `kernel/2`; the synthetic straight-line `wide/2` (`WIDE_REGISTERS = 8` x-registers, `WIDE_OPS = 256` `move`+`add` steps — more registers than the cache holds); the synthetic straight-line `aggr/2` (`AGGR_STEPS = 128` steps of `get_list`/`get_hd`/`get_tl`/`get_tuple_element`/`select_tuple_arity` reads fed into a small-int `'*'` chain — the aggregate inlines); and the synthetic straight-line `cmp/2` (`CMP_OPS = 64` rounds of the eight comparison operators over two small-int x-registers — the comparison fast path). A native tier compiles the module **once outside the timed loop**, then `N=5000` timed `run_compiled`/`run_export` executions (the `aggr`/`cmp` shapes use `N=2500`); the test prints `ns/op` (and `ops/s`) and asserts **only correctness** (every tier's result equals the interpreter's), never speed. See `CONTEXT.md` §Measured for the numbers.

- **Interpreter micro-benchmark** (`tests/engine_bench.rs`): the dependency-free `ns`/interpreted-instruction harness over `Machine::run_export` (no `criterion`, no new dependency, no `#[ignore]`), one `#[test]` so the workloads never run concurrently. It prints its table under `--nocapture` and asserts only **correctness** + **structural** invariants, never a performance threshold. Each row is one hand-built synthetic `Module` (or the committed `fixtures/tailcall.beam`) with a single export, run once untimed then `SAMPLES = 5` times for that row's `iterations` runs each; `ns/instruction = elapsed_ns / (iterations * instructions_per_run)` on the **median** sample (best sample in brackets). Rows, in report order: `setup/empty` (the per-run floor: `label;return`), `dispatch/noop (shared label)` (`KIND_OPS = 2048` redundant `label`s on one shared label, so the per-run label map stays 2 entries wide), `dispatch/many-labels` (the same body with `KIND_OPS` **distinct** labels — the difference is `build_label_map`'s per-label cost), `move/2`, `test/2 (no branch)`, `gc_bif` `'+'/2` (the `STACK_ARGS` path), `ctrl/2` (a `call;return` chain), `gate/call+return`, `branch-loop/2` (taken test + `jump` back-edge), `tail-loop/2` (test + `call_only`), `gate/call_only` (the two `gate/*` rows are same-body twins of the `ctrl`/`tail-loop` rows with tracing OFF, so the latch costs ~0), **`list-walk/1 (recursive)`** — the BIF-free 1,000,000-element recursive list walk (`sum([H|T]) -> H + sum(T); sum([]) -> 0.` in the post-fusion shape the loader produces, `7 * N + 6` instructions/run, one small-int `'+'/2` per element, no term built and no heap requested; the list is built once in a `beam_term::Heap` arena that outlives every timed run, and the result is asserted to be `LIST_WALK_N`) — and `real tailcall:even/1 (340)` (the committed `tailcall.beam`, driven through a `CountingHost` that counts BIF calls so the instruction divisor is measured rather than assumed). After the table it prints a per-instruction-kind **attribution** (each row minus the `dispatch/noop` baseline, floor-adjusted by `setup/empty`) and the label-map-build decomposition. `list-walk/1` is the most sensitive row for the per-instruction/per-call path. **Measurement discipline:** the host is heavily oversubscribed, so a single sample (and a sequential before/after) is meaningless — read a range over 3-4 runs on the harness's median, and for a before/after comparison interleave the two binaries back-to-back. See `CONTEXT.md` §Measured for the numbers.
- **The headline stdlib integration tests** (`tests/stdlib_lists.rs` + `tests/stdlib_more.rs` + the shared `tests/support/mod.rs` host): load **real system stdlib `.beam` modules** (located at test time from `$ERTS_STDLIB_DIR` or `erl -noshell -eval 'code:lib_dir(stdlib)'`; every test **skips loudly** when stdlib is absent) and assert exact oracle results. The host re-runs the loader's public pipeline (`container::parse` → `chunk::parse` → `decode::decode_stream` → `lower::build_module`) with **one shared `AtomTable`** so cross-module atom identity (`true`/`false`/`undefined`) holds, keeps **one shared term arena** (`MinimalContext`), dispatches `call_ext*` from `call_bif` (local BIF floor → external module load + `run_export`), and resolves `call_fun`/`call_fun2` to the defining module through `apply_fun` (fun `uniq`+`index` → `Module::funs()`, entry run with `free ++ args`). `stdlib_lists.rs` proves `lists:reverse/1`, `lists:seq/2`, `lists:map/2`, `lists:sort/1`, `lists:filter/2`; `ordsets:from_list/union/intersection/subtract/is_element`; `proplists:get_value/2,3`, `proplists:lookup_all/2`, `proplists:get_bool/2`; plus the committed `stdlists_harness` fixture's `reverse/1`, `seq/2`, `map_double/1`, `sort/1`, `filter_pos/1` (the last two build an anonymous fun and drive it through `lists:map`/`lists:filter` — the cross-module closure path). `stdlib_more.rs` adds real `orddict`, `queue`, `gb_trees`, `gb_sets`, `ordsets` and further `lists`/`proplists` functions through the `stdlib_more_harness` fixture. The BIF floor those modules needed: `erlang:'+'/'-'/'*'/div`, `==`/`/=`/`=:=`/`=/=`/`<`/`=<`/`>`/`>=`, `element/2`, `tuple_size/1`, `length/1`, `++/2`, `lists:reverse/2` (a NIF in `lists.beam`), `error/1..3`/`nif_error/1` (typed `Err` — reached only on invalid-argument paths the tests avoid); `stdlib_more` adds `erlang:'--'/2`, `bsl/2`, `bsr/2`, `max/2`, `min/2` and `lists:member/2` (exact `=:=` for `--`/`member`; arithmetic ordering for `max`/`min`, returning `args[0]` on equality). The floor also serves the `erlang:is_*` type-test guards (`is_atom`/`is_binary`/`is_bitstring`/`is_float`/`is_function`/`is_integer`/`is_list`/`is_map`/`is_number`/`is_pid`/`is_port`/`is_reference`/`is_tuple`), `erlang:integer_to_list/1`, `erlang:list_to_atom/1` and `lists:keyfind/3`, and refuses `persistent_term:get/1,2` with a typed `unsupported` that **names** the missing capability (`PERSISTENT_TERM_CAPABILITY`, the unloaded NIF library).
- **The real-module sweep** (`tests/stdlib_sweep.rs` + the discovery helpers in `tests/support/mod.rs`): the `sweep_loads_every_installed_beam` test loads **every** `.beam` under the whole installed OTP lib root — `support::otp_lib_root` → `all_otp_beams` walks each application directory recursively (its `ebin` modules plus any compiled examples it ships), generic discovery with **no** allowlist — and **all 1366** `.beam` over **34** applications load, each yielding ≥1 function with a non-empty label map, through the same shared-atom host. It **asserts** it (`loaded == total`; any load failure is printed with its exact typed error and fails the test). It then executes a curated, **oracle-derived** set of pure functions: `lists` (recursion/list building + `lists:zip/2`), `calendar`, `filename`, `string`, `array`, `ordsets`, `dict` (`store`/`lookup` plus insertion past the expansion threshold — the captured-variable closure path), plus `maps:new/0` and `erl_scan:reserved_word/1`. Where a mechanism is still blocked the test asserts its exact typed error and never a wrong result (`base64:encode/1` **works** — `sweep_base64_builds_an_off_heap_binary`: a 60-byte input → the 80-byte oracle string, an off-heap refc result; `maps:from_list/1`, `maps:size/1`/`get/2`/`keys/1`/`put/3`, `unicode:characters_to_binary/1`, `unicode:characters_to_list/1`, `ets:new/2`, `code:which/1`, `io:format/2` → `BadArg`, and `code_server:call/1` → the typed `unsupported_opcode: receive_marker_reserve`). Every test skips loudly when the system Erlang is absent.
- **Per-application execution breadth** (`tests/apps_lists.rs`): the widened oracle-checked sweep over OTP applications *beyond* `stdlib`/`kernel`/`compiler`, through a host whose search path is **every** installed application (`support::all_otp_ebins`) — the same evidence as the stdlib suites, pushed into the rest of the install. It executes real pure-Erlang exports: `syntax_tools`/`erl_syntax` (`type`/`atom_value`/`integer_value`/`float_value`/`concrete`/`variable_literal`/`string`, the `#tree{}` round-trips), `xmerl` (`xmerl_ucs:to_utf8`/`from_utf8`/`is_ascii`/`is_latin1` + `xmerl_lib:is_letter`/`is_name`/`is_char`/`to_lower`), `inets`/`httpd_util` (`month`/`day`/`reason_phrase`/`collapse_slashes`/`uniq`), `edoc`/`edoc_lib` (`escape_uri`/`count`/`is_space`/`get_first_sentence`), `eunit`/`eunit_lib` (`uniq`/`is_not_test`/`split_node`/`trie_new`), `dialyzer`/`dialyzer_utils` (`family`/`src_compiler_opts`), `asn1`/`asn1ct_pretty_format:term/1` (the integer form), `snmp` (`snmp_misc:is_oid`/`is_string`/`str_xor` + `snmp_pdus:get_encoded_length/1`) and `parsetools` (`leex`/`yecc:format_error/1`) — every expected value derived from the system `erl` oracle. `blocked_targets_report_their_typed_error` is the honest counterpart: targets the host cannot serve are asserted against their **exact** typed error (`asn1ct:use_legacy_types/0` and `get_bit_string_format/0` → the process-dictionary `badarg`; `httpd_util:module_validate/1` → the code-server `badarg`; `erl_syntax:atom_literal/1` and the atom-bearing `asn1ct_pretty_format:term/1` forms → the `persistent_term` NIF refusal; `httpd_util:create_etag/1` → the structured `{badrecord, V}` raise).
- **Receive/message family** (`tests/receive.rs`) — `fixtures/recv.{erl,beam}` (oracle-built, 7 exports) driven through a `MinimalContext` whose `Mailbox` is a tiny in-memory implementation (`Vec` of messages + scan position + marker table). 17 tests: the export smoke check; `send`-then-observe (`bomb/1`); the plain `receive` (`wait/0`, incl. `remove_message` emptying the mailbox); the selective receive both ways (`sel/0` literal `foo` ⇒ `a`, catch-all ⇒ the value); scanning past a non-matching head (`scan/0` with `42` before `{bar,7}` — the head survives); `after 0` (`afterzero/0`) and a **runtime** zero `wait_timeout` (`aftervar(0)`) falling through to `timeout`; a non-zero `wait_timeout` reporting `RunOutcome::Wait`; `wait` on an empty mailbox reporting `Wait` + the plain `run_export`'s typed `unsupported_opcode: run: process blocked (no message available)`; resumption via `Machine::resume_outcome` at the reported `(func, pc)` with the call frame intact; the full `recv_marker_*` prologue (`marked/0`); the marker/scan contract on the mailbox directly; the typed `unsupported_opcode: receive_next` with no mailbox installed; and a missing export's typed error. Every expected value is oracle-derived (`erl -noshell -pa "$TMPDIR/fixgen" -eval '<expr>, halt().'`); the one deliberate divergence is a non-zero `after` (`aftervar(5)` reports `Wait` where the oracle returns `empty` after 5 ms — no host timer at M1).
- **Compiled bignum arithmetic** (`tests/bignum_compiled.rs`) — `fixtures/bignum.{erl,beam}` (oracle-built) exports out-of-range integer literals (2^59 / 2^61 / ±10^18, `MAX_SMALL`, `MIN_SMALL` ± 1) and the arithmetic functions (`add`/`sub`/`mul`, `add_to_big`/`big_minus`/`scale_big`); 7 tests build an **exact-integer** BIF tower in the harness and assert the *representation* (immediate vs bignum, via `is_small`/`signed_value`) and the value, on the interpreter and on **every tier in the roster** (`NATIVE_TIERS`: baseline always, Cranelift with the feature). Skips loudly if the fixture is absent.

- **Cross-module call seam** (`tests/external_call.rs`) — the `resolve_external_call` seam over two hand-built synthetic `Module`s (caller `m` `call_ext`s callee `c`; the seam passes strings, so only the callee's own `AtomTable` is needed). A custom `ExecutionContext` implements the seam (returns `Some((Arc<Module>, export label))` for a designated callee export, `Ok(None)` otherwise) plus a small in-memory mailbox; 9 tests: **(a)** a `receive` inside a cross-module callee on an EMPTY mailbox reports `RunOutcome::Wait` at the callee's own `(func, pc)` — NOT `Err(error::blocked())`; **(b)** the same call with a message available completes with the expected returned term and the frame popped back to the caller (the cross-module return path); **(c)** the callee's `call_ext_last erlang:error/1` with a **stale `Deallocate`** surfaces the callee's **own** reason (a term-carrying `Raise`, class `error`, live-reason `Eterm`) — never a frame/deallocate artifact; **(d)** a host **without** the seam is unchanged (the synchronous call result, and the typed `unsupported_opcode: run: process blocked (no message available)` when a `call_ext` callee would block); plus `a_minimal_context_without_the_seam_keeps_the_synchronous_bif_path`. Also: a `Wait` inside the callee is resumable via `resume_outcome(entry_module, func, pc, ctx)` with a message now available → `Returned`; `run_export_outcome_with_tier(..., Tier::Interpreter)` reports the same suspend; and `Tier::BaselineJit` reports the typed `unsupported_opcode: jit: module context switch outside the interpreter driver` (the seam is interpreter-only). - **The `apply`/`apply_last` route through the cross-module seam** (`src/families/funs/tests.rs`, 4 tests on hand-built synthetic `Module`s) — the fun family's half of the same seam (`tests/external_call.rs` covers `call_ext*`). `apply_enters_a_resolved_callee_in_the_same_machine`: a resolver answering `c:g/2` makes `Instr::Apply` report `Step::Enter { context: 1, func: 0, pc: 0 }` (the callee's registered context) and store the **caller's** return address `(func, pc + 1)` in the live frame. `apply_into_a_cross_module_receive_suspends_and_resumes`: end to end through `run_label_outcome`, the callee's bare `receive` on an EMPTY mailbox is `RunOutcome::Wait { func: 0, pc: 0 }` — NOT `Err(error::blocked())` — and a message queued afterwards makes `resume_outcome(entry_module, 0, 0, ctx)` return `RunOutcome::Returned(42)`, the callee's `return` unwinding into the caller's frame. `apply_without_the_seam_keeps_the_synchronous_bif_path`: the `Ok(None)` default leaves the previous behaviour byte-identical (the applied result in `x(0)`, `Step::Next`, the frame's continuation untouched). `apply_last_pops_its_frame_then_enters_a_resolved_callee`: the tail discipline — the frame is popped FIRST, the callee is entered as `Step::Enter` with no return address stored, and the caller's continuation survives for the callee's `return`. - **`func_info` raise frames** (`tests/func_info_stacktrace.rs`, 3 tests + 1 live-oracle cross-check) — a failed head clause JUMPs to the function's `func_info` label, which raises class `error` with the **bare atom** `function_clause` (call args ride in the stacktrace, never in the reason). The raise carries the frames `Machine::raise_stacktrace` derives from the live call frames (`Machine::throw_with_stacktrace`), so an uncaught `function_clause` names the **raising** function in its innermost frame (`{m,f,1}`) and, for a non-tail caller, `f/1` then `g/0` — the order C's `build_stacktrace` produces. A matching head clause returns normally (the `func_info` label is reachable only from a failed clause), and the oracle cross-check runs `proplists:get_value(a, undefined)` under the system `erl` and asserts the innermost raw-stacktrace item is `{proplists,get_value,3}` (skips loudly when no `erl` is on `PATH`).

- **Module identity on a cross-module entry** (`tests/current_module.rs`, 7 tests) — the `Step::Enter` half of `tests/external_call.rs`: the same hand-built `m:run/0 -> c:recv/0` chain (suspended at the callee's own `(func, pc)` on an empty mailbox) proves the machine's **module-identity state follows the entry**: `Machine::current_module()` is `None` while the run is in the entry module (context `0`, borrowed by the driver) and `Arc::ptr_eq`-identical to the callee's handle once the seam entered `c` — including *after* a `resume_outcome`; `current_function`/`current_location` name the CALLEE's `{c,recv,0}` / `{c,recv,0,[]}` while `initial_call` still names the entry `{m,run,0}` (the `$initial_call` analogue); `current_stacktrace` is `[{c,recv,0,[]},{m,run,0,[]}]` — each frame resolved in **its own** module context (`Machine::resumption_contexts`), so no frame is fabricated; and a run that completes entirely in the entry module still reports `current_module() == None`. Oracle shapes are the ones `tests/process_info.rs` captured from the system `erl`.
- **Per-instruction reductions** (`tests/reductions.rs`, 5 tests) — a hand-built module whose body is a TIGHT NON-ALLOCATING loop (no `Allocate`/`TestHeap`, so `ensure_heap` — the engine's only other charging point — is never reached) is driven through `Machine::run_export_outcome`: `Machine::reductions()` is `0` before any run and equals the **exact** number of interpreted instructions in the slice, `reset_reductions()` returns the discarded count and zeroes it, and a host `ExecutionContext` that overrides the defaulted `reduce(n)` hook records one charge per instruction (`n == 1`) and can PRE-EMPT the loop by returning its own typed error (asserted to fire after exactly N charges, with the run returning that error). `MinimalContext` keeps the no-op default (byte-identical behaviour) while still counting.
- **Parked-receive deadline & `recv_marker_*` rejection** (`tests/wait_deadline.rs`, 10 tests) — the `after T` shapes the compiler emits (`loop_rec Fail, Dst … Fail: wait_timeout ScanLabel, Time; timeout`): `Machine::wait_deadline` returns `Some(WaitDeadline { delay_ms: Some(20), resume: (func, pc+1) })` for `Operand::Integer(20)` (asserting `resume` is really the `timeout` instruction), reads a **Y-register** delay through the now-public `Machine::y`/`y_mut` (`delay_ms: Some(20)`), yields `delay_ms: None` (but a usable `resume`) for an `infinity`/non-integer delay, is `None` for a bare `Wait` (`after infinity`) and before any run — while `wait_timeout` with the small-int `0` **falls through** to the `timeout` instruction (no suspend, C's `$NEXT0()` path). Plus the named marker rejection: every `recv_marker_*` opcode on a host that does not serve markers is the typed `unsupported_opcode: recv_marker_<op>: the host does not serve receive markers` (never a hang, never a silently skipped marker), a marker-capable host's own error survives verbatim, and a successful marker call leaves the register written and the run continuing.
