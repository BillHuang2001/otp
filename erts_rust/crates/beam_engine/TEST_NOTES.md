# `beam_engine` — exhaustive test / fixture enumeration

Extracted from `CONTEXT.md` (which keeps only the strategy summary + the gate) so the
contract sections stay within the ~64 KB per-file budget. This file is documentation,
not a change log: it describes the tests that exist now.

## Per-module `#[cfg(test)]` unit tests
`context` (hook dispatch, default-hook unsupported, the `alloc_words` arena pointer stability/aliasing, `apply`/`apply_fun` forwarding and their defaults, the apply hook); `machine` (x/stack/FR accessors, frame push/pop/return, `MAX_REGISTER` bound, catch-frame push/pop and the throw/unwind/landing paths, `pending_exception`/`pending_class`, `resumption_addresses`); `step`; `terms` (every constructor↔reader round-trip through `MinimalContext` — incl. `make_map` across the 32-key flat/hashmap boundary — raw-word layout proofs, the flat-map and HAMT readers over hand-built nodes, and the error cases: `make_flatmap` >32 / fun field >255 / binary >64 → `unsupported`/`SystemLimit`, wrong-type readers → `BadArg`); `operand` (read/write each supported operand kind incl. `FloatReg`↔FR file + out-of-range, `Literal` via `Machine::literal`, and a missing/unbound literal → typed error; `Label`/`List`/`Allocation` → unsupported); `interpreter` (the label map + resolution); `jit` (the roster invariants — interpreter first, `"baseline-jit"` always present, `"jit-cranelift"` iff the feature is on, the roster is a `Tier::ALL` prefix; `Tier::name`↔`from_name` round-trips + unknown/empty/miscased names ⇒ `None`; `run_with_tier` on the reused `slice.beam` fixture — `Interpreter` equals `run_export`, `BaselineJit` equals it too, `Cranelift` is a typed error); `jit::baseline` (block-target `encode_target`/`decode_target` round-trips and `HALT`/`ERROR` sentinel distinctness, the `JitRuntime` field offsets generated code relies on, that cached slots index the x-register array rather than the `Machine` struct, the cached/directly-addressed register allocation and its bound, and the `constant_word`/`x_register` operand forms); `jit::emitter` (the encoder is proven by *executing* what it emits: `add(a,b)`, a six-argument sum through `r8`/`r9`, `r12`- and `rsp`-based addressing, `lea`, `max` via `cmp`+`jcc`, an indirect `call_r` into a second buffer, forward/backward/conditional label patching, `seal` flips `/proc/self/maps` from `rw-p` to `r-xp`, plus the error paths — unbound label at `seal`, emit-after-`seal`, foreign/double-bound label, exhausted capacity, repeated map/seal/drop); `jit::tiering` (the cold/warm/hot boundaries, the `hot ≥ baseline` clamp, a zero baseline threshold, equal thresholds skipping the baseline rung, `Default`, `is_hot`, and that `select` never names a tier outside `available_tiers` — `Cranelift` exactly when the feature is on); `jit::cranelift` (the feature-gated backend's own tests — tier name/availability, one native entry per non-empty function, the empty module, and a **direct call into a compiled entry** proving native execution); `families/*` (per-family unit tests alongside each family body).

## Per-family integration tests over committed real `.beam` fixtures
Produced by the system `erlc`, the differential oracle — see `tests/fixtures/README.md` for the regeneration recipe and the opcode coverage of each fixture:
- `tests/tuples_lists.rs` — `fixtures/{tuples,lists}.beam` (`put_tuple2`/`get_tuple_element`/`select_tuple_arity`, `put_list`/`get_list`/`get_hd`/`get_tl`) plus synthetic modules for the failure paths.
- `tests/exceptions.rs` — `fixtures/{exceptions,stacktrace}.beam` (`try`/`catch`/`try_case`/`try_end`/`catch_end`/`badmatch`/`case_end`/`try_case_end`/`if_end`, nested `try`, a cross-frame unwind, plus `build_stacktrace`/`raw_raise` over the `stacktrace` fixture).
- `tests/floats.rs` — `fixtures/floats.beam` (`fmove`/`fconv`/`fadd`/`fsub`/`fmul`/`fdiv`/`fnegate`, float literals, FR temporaries, the `badarith` cases incl. the bignum→`f64` conversion and its over-range `badarith`).
- `tests/funs.rs` — `fixtures/funs.beam` (`make_fun3` with/without free vars, `call_fun`, `call_fun2`, `apply`, `apply_last`), driven through the context's **apply hook** and BIF hook.
- `tests/maps.rs` — `fixtures/mapfx.beam` (`get_map_elements`/`has_map_fields`/`put_map_assoc`/`put_map_exact`, incl. the `{badkey, a}` case and construction past the 32-key flat/hashmap boundary) plus hand-built frozen-layout HAMT terms for the hashmap read path.
- `tests/records.rs` — `fixtures/records.beam` (`update_record` under the `reuse`/`copy`/`inplace` hints, `dst` ≠ src and dst-aliasing, the `badrecord` raise, the `is_any_native_record` guard) plus synthetic modules for the failure paths (non-tuple source, size/arity mismatch, offset 0 / out of range).
- `tests/bitstrings.rs` — `fixtures/bitstrings.beam` (`bs_create_bin` integer/binary/string segments, the match side, the position ops).
- `tests/bitstrings_extra_create.rs` — `fixtures/bscreate.beam` (`bs_create_bin` float 16/32/64 BE+LE, utf8/utf16/utf32 segments, and the invalid-size / non-scalar-code-point rejections).
- `tests/bitstrings_extra_match.rs` — `fixtures/bsmatch.beam` (`bs_match_string`, the `=:=` command, `bs_get_float2` 16/32/64 BE+LE, the UTF reads/skips + their malformed-input failures).
- `tests/bitstrings_extra_big.rs` — `fixtures/bsbig.beam` (integer fields wider than 64 bits on both the match and the create side: 65/68/72/128/256 bits, signed/unsigned, BE/LE) — every expected value oracle-derived.
- `tests/bitstrings_extra_string.rs` — `fixtures/bsstring.beam` (`bs_create_bin` **`string`** segments: prefix/suffix/duplicate/empty literals, a string written at a non-byte-aligned bit offset, and a string after a 12-bit tail) — every expected value oracle-derived from the real system `erl`.

## Synthetic-module opcode tests (`tests/opcodes.rs`)
Hand-built `Module`s (the loader is not involved) covering the rest of the executed subset — every `TestKind` (success and failure), `SelectVal`, the frame instructions (`Allocate`/`AllocateHeap`/`TestHeap`/`Deallocate`/`Trim`), the call family (`Call`/`CallLast`/`CallOnly`/`CallExt`/`CallExtOnly`/`CallExtLast`), the `GcBif` guard-fail/raise paths, the catch-frame landing of a raising BIF (`gc_bif`/`bif`/`bif0`/`call_ext*` with no fail label inside a live `try`), the module-level no-op markers (`NifStart`/`OnLoad` between two labels do not disturb control flow), the typed `Instr::IsAnyNativeRecord` guard (`is_any_native_record` falls through on a record, branches to `fail` on a non-record — `NIL`, a small integer **and a tuple**, since `is_record/1` is a native-record header test, not a tuple test), the `is_any_native_record/no_fail` typed error, a residual `Instr::Generic` opcode keeping its named `unsupported` (`is_native_record`), and the documented error paths; a comprehensive test module, legitimately long.

## Integration tests
- **Vertical slice** (`tests/slice.rs`): load the committed fixture `../beam_loader/tests/fixtures/slice.beam` (reused, **not duplicated**, via `concat!(env!("CARGO_MANIFEST_DIR"), "/../beam_loader/tests/fixtures/slice.beam")`), build a `MinimalContext` whose hook implements `erlang:'+'/2` and `erlang:'-'/2` over small ints, and assert `slice:add(2,3) == 5`, `slice:fib(10) == 55`, `slice:pick(a) == 1`, `slice:pick(b) == 2`.
- **Baseline-JIT integration** (`tests/jit.rs`): drives the same slice fixture through **both** tiers via a `MinimalContext` BIF hook (`erlang:'+'/2`/`'-'/2` over smalls) — `available_tiers` contains `"baseline-jit"`, `compile` emits one native entry per non-empty block (all inside the code mapping, unique), `add`/`fib`/`pick` agree across tiers, the two tiers agree on the typed error for a raising BIF and a missing export, and they agree across register-file sizes (`Machine::with_max_register(2|3|8|MAX_REGISTER)`, exercising the `native_ok` guard). It also proves the compile-once / run-many split (`a_compiled_artifact_can_be_run_more_than_once`): one `compile`d artifact is run twice on fresh machines via `JitBackend::run_compiled` and matches the interpreter, a missing export there is a typed error, and the provided one-shot `run_export` agrees — for the baseline tier always and the Cranelift tier when the feature is on.
- **Baseline-JIT tier equivalence** (`tests/jit_coverage.rs`): the same two-tier agreement over the broad `coverage.beam` fixture, reusing `MinimalContext`'s public hooks: small-int arithmetic BIF hook + the `'-make_adder/1-fun-0-'` apply hook, with boxed float arguments built through `terms`. Covers the helper's whole `Step` surface — `Next` (`gc_bif` arithmetic), `Goto` to other labels/functions (`select_tuple_arity`, case guards, recursion, `call_fun2`), the **`badarith` raise landing in a live catch frame**, `Done` (`call_ext`), the supported bitstring match path, and the `bs_create_bin` `append` segment (both tiers produce the rotated `<<2,3,1>>`).
- **Feature-gated Cranelift tier** (`tests/jit_cranelift.rs`, the whole file is `#![cfg(feature = "jit-cranelift")]`): the `available_tiers`/`JitBackend` roster, one native entry per function, and `add`/`fib`/`pick` agreeing with the interpreter (and the baseline tier) on the reused `slice.beam`, plus the raising-BIF/missing-export typed-error parity.
- **Native-tier micro-benchmark** (`tests/jit_bench.rs`): interpreter-vs-JIT `ns/op` over three shapes — the real `slice.beam` `fib/1(20)` short tail-recursive chain, the synthetic 256-`gc_bif '+'/2` straight-line `kernel/2`, and the synthetic straight-line `wide/2` (`WIDE_REGISTERS = 8` x-registers, `WIDE_OPS = 256` `move`+`add` steps — more registers than the cache holds). A native tier compiles the module **once outside the timed loop**, then `N=5000` timed `run_compiled`/`run_export` executions; the test prints `ns/op` (and `ops/s`) and asserts **only correctness** (every tier's result equals the interpreter's), never speed. See `CONTEXT.md` §Measured for the numbers.
- **The headline stdlib integration tests** (`tests/stdlib_lists.rs` + `tests/stdlib_more.rs` + the shared `tests/support/mod.rs` host): load **real system stdlib `.beam` modules** (located at test time from `$ERTS_STDLIB_DIR` or `erl -noshell -eval 'code:lib_dir(stdlib)'`; every test **skips loudly** when stdlib is absent) and assert exact oracle results. The host re-runs the loader's public pipeline (`container::parse` → `chunk::parse` → `decode::decode_stream` → `lower::build_module`) with **one shared `AtomTable`** so cross-module atom identity (`true`/`false`/`undefined`) holds, keeps **one shared term arena** (`MinimalContext`), dispatches `call_ext*` from `call_bif` (local BIF floor → external module load + `run_export`), and resolves `call_fun`/`call_fun2` to the defining module through `apply_fun` (fun `uniq`+`index` → `Module::funs()`, entry run with `free ++ args`). `stdlib_lists.rs` proves `lists:reverse/1`, `lists:seq/2`, `lists:map/2`, `lists:sort/1`, `lists:filter/2`; `ordsets:from_list/union/intersection/subtract/is_element`; `proplists:get_value/2,3`, `proplists:lookup_all/2`, `proplists:get_bool/2`; plus the committed `stdlists_harness` fixture's `reverse/1`, `seq/2`, `map_double/1`, `sort/1`, `filter_pos/1` (the last two build an anonymous fun and drive it through `lists:map`/`lists:filter` — the cross-module closure path). `stdlib_more.rs` adds real `orddict`, `queue`, `gb_trees`, `gb_sets`, `ordsets` and further `lists`/`proplists` functions through the `stdlib_more_harness` fixture. The BIF floor those modules needed: `erlang:'+'/'-'/'*'/div`, `==`/`/=`/`=:=`/`=/=`/`<`/`=<`/`>`/`>=`, `element/2`, `tuple_size/1`, `length/1`, `++/2`, `lists:reverse/2` (a NIF in `lists.beam`), `error/1..3`/`nif_error/1` (typed `Err` — reached only on invalid-argument paths the tests avoid); `stdlib_more` adds `erlang:'--'/2`, `bsl/2`, `bsr/2`, `max/2`, `min/2` and `lists:member/2` (exact `=:=` for `--`/`member`; arithmetic ordering for `max`/`min`, returning `args[0]` on equality).
- **The real-module sweep** (`tests/stdlib_sweep.rs` + additive helpers in `tests/support/mod.rs`): loads **every** `.beam` in the installed stdlib (98), kernel (104) and compiler (59) `ebin` directories — **all 261** modules load, each yielding ≥1 function with a non-empty label map — through the same shared-atom host, and **asserts** it (`loaded == total`; any load failure is printed with its exact typed error and fails the test — there is no allowlist). It then executes a curated, **oracle-derived** set of pure functions: `lists`, `calendar`, `filename`, `string`, `array`, `ordsets` (recursion, list building, tuples/records, cross-module calls) plus `maps:new/0`, `erl_scan:reserved_word/1`. Where a mechanism is still blocked the test asserts its exact typed error and never a wrong result (`base64:encode/1` **works** — `sweep_base64_builds_an_off_heap_binary`: a 60-byte input → the 80-byte oracle string, an off-heap refc result; `maps:from_list/1`, `unicode:characters_to_binary/1`, `string:split/2`, `lists:member/2`, `lists:keyfind/3` → `BadArg`, their BIFs absent from the harness floor). Every test skips loudly when the system Erlang is absent.
- **Receive/message family** (`tests/receive.rs`) — `fixtures/recv.{erl,beam}` (oracle-built, 7 exports) driven through a `MinimalContext` whose `Mailbox` is a tiny in-memory implementation (`Vec` of messages + scan position + marker table). 17 tests: the export smoke check; `send`-then-observe (`bomb/1`); the plain `receive` (`wait/0`, incl. `remove_message` emptying the mailbox); the selective receive both ways (`sel/0` literal `foo` ⇒ `a`, catch-all ⇒ the value); scanning past a non-matching head (`scan/0` with `42` before `{bar,7}` — the head survives); `after 0` (`afterzero/0`) and a **runtime** zero `wait_timeout` (`aftervar(0)`) falling through to `timeout`; a non-zero `wait_timeout` reporting `RunOutcome::Wait`; `wait` on an empty mailbox reporting `Wait` + the plain `run_export`'s typed `unsupported_opcode: run: process blocked (no message available)`; resumption via `Machine::resume_outcome` at the reported `(func, pc)` with the call frame intact; the full `recv_marker_*` prologue (`marked/0`); the marker/scan contract on the mailbox directly; the typed `unsupported_opcode: receive_next` with no mailbox installed; and a missing export's typed error. Every expected value is oracle-derived (`erl -noshell -pa "$TMPDIR/fixgen" -eval '<expr>, halt().'`); the one deliberate divergence is a non-zero `after` (`aftervar(5)` reports `Wait` where the oracle returns `empty` after 5 ms — no host timer at M1).
- **Compiled bignum arithmetic** (`tests/bignum_compiled.rs`) — `fixtures/bignum.{erl,beam}` (oracle-built) exports out-of-range integer literals (2^59 / 2^61 / ±10^18, `MAX_SMALL`, `MIN_SMALL` ± 1) and the arithmetic functions (`add`/`sub`/`mul`, `add_to_big`/`big_minus`/`scale_big`); 7 tests build an **exact-integer** BIF tower in the harness and assert the *representation* (immediate vs bignum, via `is_small`/`signed_value`) and the value, on the interpreter and on **every tier in the roster** (`NATIVE_TIERS`: baseline always, Cranelift with the feature). Skips loudly if the fixture is absent.
