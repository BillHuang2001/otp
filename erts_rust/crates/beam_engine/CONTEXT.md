# `beam_engine` -- Typed-IR Execution Engine (interpreter + JIT tiers)

## Intent
Executes the **frozen typed IR** from `beam_loader` behind a three-tier execution seam: a direct-threaded **interpreter**, a **native x86-64 baseline tier** (the default for every process entry), and an optional **Cranelift hot tier** (`jit-cranelift` feature, default OFF).
Stage-1 engine half of Part II §H (IR contract §E, interpreter/JIT trade-offs §F; `../../CONTEXT.md` §4), on the critical path of the vertical slice: it loads a real `.beam` and runs it end to end.
It depends only on `beam_loader`/`beam_term`/`beam_common`/`beam_alloc`/`beam_gc`, never on the Stage-5 runtime core -- BIF dispatch, fun application, heap/GC, process limits and pre-emption all sit behind `ExecutionContext` (implemented by `beam_rt`), which keeps the DAG acyclic and the engine testable with `MinimalContext`.
**Compile latency is a first-class correctness constraint**: every tier is a measurement-gated, correctness-first *mechanism*, never an optimiser that may change a result.
Ground truth (read-only): `../../erts/emulator/beam/emu/beam_emu.c`, `emu/*.tab`, and `beam_common.c`'s call/return/allocate/error/`next_catch` conventions.

**Where the detail lives.** This file is the crate-level contract. `INSTRUCTION_SURFACE.md` owns the exhaustive instruction surface, design decisions and the full known-gap/handoff lists; `MEASURED.md`/`PERF.md` own every measured figure; `TEST_NOTES.md` owns the test enumeration; each child `CONTEXT.md` owns its subsystem. Never restate their numbers here.

## API Surface (FROZEN -- the runtime and tests design against this)
Root re-exports; the seams, the machine and the tier roster also via `beam_engine::prelude::*` (the arena's measurement/reclaim types stay crate-root only).
The crate embeds NO BIF table: computation goes through `ExecutionContext::call_bif`, an in-machine callee through the resolver seams, and `apply`/`apply_fun` are the value-returning fallbacks.

### The typed block-IR seam (`beam_loader`)
Backends consume only `Module`/`Function`/`Block`/`Instr`/`Operand`/`TestKind`/`HeapNeed`: typed, block-structured IR with BEAM types, safepoints, failure/branch semantics (a `fail` label vs `NO_FAIL`), catch info and line/range tables.
A backend may assume exactly the frozen `RootSet` and nothing else about machine layout -- **no frame liveness map exists** -- and no `Instr` carries a backend-specific encoding.
Every park/resume address, stacktrace frame and code-map range is a `(func, pc)` into the loaded `Module`.

### The context seam (`src/context.rs`)
One `pub trait ExecutionContext` of `&mut self` methods over `Eterm`; **`src/context.rs` is authoritative for the signatures**, every method is `Result`-returning except the pure-`&self` probes, and every method is **defaulted** except `call_bif` and `ensure_heap`.
Groups: the BIF doors (`call_bif`, `wants_bif_in_machine`/`call_bif_in_machine`, the outcome-aware `call_bif_outcome`/`call_bif_in_machine_outcome`); the GC doors (`ensure_heap`/`ensure_heap_full`, `alloc_words`/`alloc_words_rooted`); `heap_available` (introspection only); `apply`/`apply_fun`/`apply_fun_outcome`; `send_message_with_off_heap`; the resolvers `resolve_external_call`/`resolve_local_fun`/`resolve_local_call`/`atom_name`; `atoms`; `reduce`/`wants_reduce`; `foreign_record_definition`; `trace_enabled`/`trace_event`.
`RootSet<'a> { x, stack, fr, live }` (`live` clamped, `ALL_LIVE = u32::MAX`); `TraceEvent` reports `Call`/`ReturnFrom`/`ReturnTo`.
- **THE ROOT-SET CONTRACT (the hardest invariant).** A collecting host overrides both rooted doors and relocates every term reachable from `roots.x[..roots.live_len()]`, **the whole `roots.stack`** (**NO frame liveness maps** -- `../../CONTEXT.md` §4) and **the whole `roots.fr`** (which holds `Eterm` slots), writing the moved terms back; `live` is only a hint (`ALL_LIVE` is always *safe*) and **nothing outside the root set survives**, so a raw `*mut Eterm` from a previous allocation is dead after the next collecting allocation.
  The engine side is `Machine::with_roots`/`Machine::alloc_rooted` and **every in-crate construction arm routes through it**; `with_roots` also **parks the five loose `Eterm` fields at the stack tail** (two function-clause latches, the pending exception's reason, the two supplied-trace latches -- `LOOSE_HEAP_TERMS = 5`) and re-seats them, so `RootSet` plus the stack carries every term the machine holds.
  The narrow `ensure_heap(heap_need, live, x_regs, stack)` stays the frozen shape; `Machine::ensure_heap` calls the defaulted `ensure_heap_full(heap_need, roots)`, and `alloc_words_rooted` is the construction door defaulting to `alloc_words` with roots discarded. Detail: `src/terms/CONTEXT.md`, `src/machine/CONTEXT.md`.
- **The in-machine BIF door.** A host answering `true` to `wants_bif_in_machine` gets the live `Machine` and the run's **entry module** (context `0`) on every BIF dispatch, and **must** override `call_bif_in_machine` (+ `_outcome` if its BIFs can wait); the probe is latched once per run by **both** drivers, and the default `false` keeps the plain path byte-identical.
- **`reduce(n)`** (defaulted no-op) is charged by both drivers **before** the instruction body; a host pre-empts by returning a **typed error** that leaves the instruction **un-applied**, so `resume_outcome` applies it **exactly once**, and a host implementing `reduce` MUST keep `wants_reduce` true (there is **no `RunOutcome::Yield`**).
- **`apply`/`apply_fun`.** `apply` (default `call_bif`) has **no engine call site** and **no park channel**, since every park address is a `(func, pc)` into a loaded `Module`; `apply_fun` is the `call_fun`/`call_fun2` fallback, entering with `x(0..arity)` = **arguments first, free variables after** (C's `call_fun` order), and both route errors into the caller's live `try`/`catch`.
- **`resolve_external_call`** (`call_ext*`, dynamic `apply`): `Some((callee_module, entry_label))` runs the callee **in this machine** and must name the **shared** `Arc<Module>` (contexts dedup by `Arc::ptr_eq`); default `Ok(None)` keeps `call_bif`.
- **`resolve_local_fun`** (`call_fun`/`call_fun2`), consulted **first**, enters the lambda body copying free variables into `x(arity..)` as `Step::Enter`; the target is **re-read after the seam**, which makes the copy sound under a collecting host.
- **`atom_name`/`atoms`** -- the atom *value* and *namespace* seams: `atom_name` answers **owned** `Option<String>` for `apply(M,F,A)` (a non-atom or unnameable id is `BadArg`, never a substituted atom), while `atoms` backs **every** comparison and every raise's reason/class atom -- the default `&module.atom_table` is the load-time snapshot, a host owning ONE live namespace overrides it and gets order matching the `<` BIF, and `fn atoms<'m>` borrows `*ctx` **immutably**.
- **`resolve_local_call`** -- a local call served *as* a BIF: the **only** route by which a module's non-exported NIF stubs reach `call_bif`, consulted **once per distinct callee per run**, so it must be a pure function of `(module, function, arity)`.
- **`call_ext*` special cases.** Only `erlang:apply/3` is special-cased: past `MAX_ARG = 255` is `error:system_limit`, a non-proper tail the catchable `badarg`; `erlang:send/2`/`'!'/2` go through `send_message_with_off_heap`.
- **`foreign_record_definition`, the A.8 trace seam and the root-enumeration doors**: the first builds `PutRecord`'s *create* form only when `def.is_exported` (else `error:{badrecord, Id}`; an unloaded module is its own `Ok(None)`), the second **reports only**, and `for_each_root`/`for_each_root_mut` are ONE `with_roots` hand-off so census and relocation cannot disagree.
- **`MinimalContext`** -- the test/embedding context: an unbounded, pointer-stable **reserved-heap** arena (**grown in place**, so every handed-out pointer stays valid and unmoved), a pluggable BIF hook (`new()` rejects every BIF), optional apply hook, resolvers and mailbox. Signatures and pins: `src/CONTEXT.md`.

### The supplied-stacktrace encoder (`src/supplied_stacktrace.rs`)
The **public** `beam_common::StackTrace` -> `Eterm` encoder for a host rendering a raise's explicitly **supplied** symbolic frames without a compiled handler (the tree-walking `-eval` route): `encode_supplied_stacktrace(module, ctx, frames)` and its `Machine::` twin.
Both cook `frames` into the oracle's `[{Module,Function,Arity,Location}]` list (innermost first; `Location` = `[{file,File},{line,N}]`, else `[]`) as ONE rooted reservation carved node-by-node.
**The atom source is the passed `module`'s table, by lookup only** (nothing is interned), so a shared-namespace host must pass a `Module` carrying that table; an unresolvable name is `error::unsupported`. Pinned by `src/families/exceptions/tests/encoder.rs`.

### The BIF suspend channel (host contract for a waiting BIF)
`call_bif_outcome`/`call_bif_in_machine_outcome` are the outcome-aware doors, both `Result<BifOutcome>` and both **defaulting** to the value as `BifOutcome::Return`, so a pre-channel host stays byte-identical; `Machine::dispatch_bif_call` takes exactly one per run, and a host that said `true` to `wants_bif_in_machine` must override the in-machine twin.
`Suspend` means the BIF did **not** complete and the instruction was **not** applied (no register written, no guard branch, no frame effect). The engine reports `RunOutcome::Suspend { func, pc }` **at the BIF instruction itself**; the host pumps its own waiting resource and the resume **re-executes the instruction with the same operands**, so the host must be re-execution safe (a suspending attempt must not consume a one-shot resource).
The engine holds **no** suspended state: the park is `(func, pc)` + registers + stack + FR file, exactly the frozen `RootSet`, so a moving collector may relocate the operands and the re-execution re-reads them (C's `c_arg_reg`/`arg_reg` equivalent).
A **non-blocking** entry folds a suspend into `error::suspended()` -- never `blocked()`, never a substituted value -- and **both native tiers report and resume it** (baseline: the `SUSPEND` (`-5`) block-ABI word; Cranelift: the same `run_native_resume_outcome` seam, where an address the artifact did not compile advances by the driver's per-instruction interpreter step). Gate: `tests/bif_suspend.rs`; the class-A/class-B rule (`erlang:apply/3` is the typed non-idempotent gap): `src/CONTEXT.md`.

### The closure-apply suspend channel
`apply_fun_outcome` returns `Result<FunOutcome>` (`Return(value)`/`Suspend`), **defaulting** to the value as `FunOutcome::Return` (an unimplemented `apply_fun` still answers `unsupported("apply_fun")`); it exists for a host that **interprets** the closure itself and cannot park its caller through a value-returning door.
`Suspend` means the application did not complete and the instruction was not applied; the engine parks on the `call_fun`/`call_fun2` instruction and the resume **re-consults this door with the same `fun` and `args`**, so the host must **continue** the pending application, never restart it. Gate: `tests/fun_suspend.rs`.

### The mailbox seam (receive/message family)
The mailbox lives in the Stage-5 runtime, never here. `pub trait Mailbox` is exactly nine `Result`-returning methods: `send_message`; the scan position `receive_next` (`None` = exhausted), `receive_skip` (`loop_rec_end`), `receive_remove` (`remove_message`), `receive_reset` (`timeout`); and `receive_marker_reserve`/`_bind`/`_use`/`_clear`.
`ExecutionContext` carries the **same nine names as defaulted methods** (`error::unsupported(...)`), so every implementor compiles unchanged. The engine **never inspects** a message or a marker (selection is the compiled code's job; a marker is opaque and only a separate *reference* reaches `_use`/`_clear`), and installing a mailbox does **not** change the non-blocking entries, which still surface `error::blocked`.
**`send_message_with_off_heap(to, message, src_binaries)`** is the `Instr::Send` entry *and* the `call_ext*` send entry: a tenth defaulted method whose default discards the source off-heap table the receiver-side copy needs for an engine-built refc binary.
**Ordering invariant:** the position calls take no candidate argument, so driving is correct only while the host's position is stable between the producing `loop_rec` and the consuming `remove_message`/`loop_rec_end`; a `receive` reaches `wait`/`wait_timeout` only via `loop_rec`'s `None` arm, so a re-entry sees only messages appended since. Host contract: FIFO with a **saturating** index (`beam_message::QueueCursor`, `beam_rt::MailboxState`). Full contract: `src/families/CONTEXT.md`; evidence: `tests/receive.rs`.

### The machine (`src/machine/*.rs`)
`Machine` is the process-state core: the x-register file (`MAX_REGISTER = 1024`), the FR file (`MAX_FLOAT_REGISTER = 1024`, holding `Eterm` slots), the Erlang stack, the call-frame and catch-frame stacks, the `refc_binaries` arena (never cleared by `reset`, host-prunable via `retain_refc_binaries`), the literal area, the **module-context registry** (one `ModuleContext { module: Arc<Module>, labels, verdicts }` per module, deduped by `Arc::ptr_eq`; context `0` = entry module + `entry_verdicts`), the reduction counter, `raise_snapshot`, the latched `trace_on` and the label-map cache.
The call/return path owns no allocation, lookup or unpacking: three buffers reserved up front (`STACK_RESERVE_WORDS`/`FRAMES_RESERVE`/`CATCH_FRAMES_RESERVE` = 256/256/8), `push_frame_window(y_count)` hands back the frame base and the new Y window in one step (what the baseline tier publishes through `JitRuntime::publish_y_window`), `pop_frame_checked` reads the frame top once, and the executing `(func, pc)` is one packed `u64`.
Run entries: `run_export`/`run_label` (non-blocking) and `run_export_outcome`/`run_label_outcome`/`resume_outcome` returning `RunOutcome { Returned(Eterm), Wait { func, pc }, Suspend { func, pc } }`, plus the tier-aware quartet.
The **uniform raise funnel**: `throw*` rebuilds the raise-time snapshot *before* any unwind, and an **uncaught** raise's symbolic `StackTrace` is attached by `Machine::with_uncaught_frames(err, entry_module, func, pc)` as it leaves the machine, so every raise kind gets the same frames.
Per-file roles and the full introspection roster (`pending_exception`/`pending_class`, `resumption_addresses`/`resumption_contexts`, `wait_deadline`, `reductions`, the execution-position accessors): `src/machine/CONTEXT.md`.

### The `Step` protocol (`src/step.rs`)
`Step { Next, Goto { func, pc }, Enter { context, func, pc }, Wait { func, pc }, Suspend { func, pc }, Done }` -- a body returns the `Step` and never mutates the loop's `func`/`pc`/context.
`Next` = `pc + 1`; `Goto` = jump within the module; `Enter` = transfer into another module context (cross-module `call_ext*`, a `return` onto a `Continuation::Address`, or a raise landing in another context's catch frame) -- the driver switches context and re-binds the literal area exactly there; `Done` = yield `x(0)`.
`Wait` = the receive suspend -> `RunOutcome::Wait` (the JIT driver and `jit_step_one` fold it into `error::blocked()`); `Suspend` = the BIF suspend, whose reported address is the instruction itself (the JIT driver folds it into `error::suspended()`).
A raise is **not** a `Step`: it stays an `Err(BeamError)`, or the exception layer folds it into a `Goto`/`Enter` to a live catch handler.

### The families seam (`src/families/`)
Every `Instr` the core loop does not execute natively goes to `families::dispatch(...) -> Result<Step>`, which routes by the instruction's own variant to the single owning family; ownership is **disjoint and variant-complete** -- each of the **77** claimed variants has exactly one owner (`tuples`, `records`, `lists`, `funs`, `exceptions`, `floats`, `maps`, `bitstrings`, `receive`).
`exec(...) -> Result<Option<Step>>`: `Ok(Some(step))` = executed, `Ok(None)` = not its variant, `Err` = it raised; an unowned or declined variant falls to `error::unsupported("widened opcode not yet executed: <ops.tab name>")`, so an unclaimed opcode is diagnosable from the error alone. Detail: `src/families/CONTEXT.md` and its children.

### Term helpers (`src/terms/`) -- the SAFETY-annotated builder/reader
The crate's **single point of raw-heap access**, over the `alloc_words`/`alloc_words_rooted` seam.
Each builder has a **classic** public form (`make_tuple`, `make_cons`, `make_list`, `badmatch_reason`, `make_heap_binary`, `make_float`, `make_integer`, `make_flatmap`, `make_map`, `make_fun`) allocating through plain `alloc_words` with materialized operands -- the frozen cross-crate signature `beam_rt`/`tests/**` consume, so **do not rename or re-signature** -- and a **`*_rooted` twin** reserving the block **before** reading operands (the reserve -> read -> write discipline). **Every in-crate construction arm uses the rooted twin**; `src/slack.rs` is the reserve/bump-carve and `src/sink.rs` the shape writer for a multi-node graph without a second allocation.
Readers take no `ctx` and answer `BadArg` on a wrong type or index, never panic; `make_map` builds any size (flat at/below `MAP_SMALL_MAP_LIMIT` = 32 distinct keys, else a HAMT, duplicates last-wins) and `map_entries` walks both layouts.
`fun_local_key` is the `(uniq, index)` identity **both** encodings of one lambda share (`BadArg` for an `EXPORT_EXT` fun), so a `make_fun3` closure and a `NEW_FUN_EXT` image resolve with ONE lookup; `fun_arity` is the saturating 8-bit header field, `fun_true_arity` an external fun's real arity. Full API: `src/terms/CONTEXT.md`.

### Literal-area words -- a literal is passed BY REFERENCE (`Operand::Literal`)
Every resolution is a **single-word read** out of the module-owned area; the engine never rebuilds or copies a literal. `beam_loader::LiteralArea` decodes the `LitT` payloads once at load into a private `beam_alloc::Heap`, ORing `TAG_LITERAL_PTR` into every BOXED/LIST word and root.
The doors are `Machine::literal` and `Module::literal`, bound per **module context** (`literals`/`entry_literals`, re-bound by `switch_context`/`enter_run`), because the operand carries only an index. Writing a literal word into a **new** object stores the tagged pointer verbatim; a literal is never a destination, and an in-place write into a literal-area object is refused by `beam_term::is_literal`.
The baseline JIT emits a guarded raw load behind the same bounds check, baking only the index and re-reading the base from the published `JitRuntime` (a cached module's area may be a different allocation); consumers test the bit, never a registry, and comparisons need none (`cmp` dereferences). Host-side, `copy_struct` **shares** a literal and both collectors leave a literal pointer verbatim **by address range**, while `beam_rt`'s root/walk classifier rejects it by the bit.

### The JIT tier seam (`src/jit/`)
- **Tier selection.** `Tier { Interpreter, BaselineJit, Cranelift }` (`Tier::ALL` = roster order, interpreter first) with `name()`/`from_name()`/`is_available()`; `available_tiers()` = `["interpreter", "baseline-jit"]` plus `"jit-cranelift"` with the feature.
  The **baseline tier is the default for every `beam_rt` process entry**, compiled lazily per function so a fresh process pays only the functions it enters; `BEAM_RT_TIER=interpreter` is the kill switch.
  Cranelift needs `BEAM_RT_TIER=cranelift` **together with** `beam_rt`'s `cranelift` feature; without the feature an explicit request is a typed refusal naming the feature, never a substitute tier.
- **`pub trait JitBackend`**: `type Compiled`; `name`/`available`; `compile(&mut self, &Module)`; `run_compiled(&self, &Compiled, machine, module, function: Atom, arity, args, ctx)` (artifact is caller-owned, hence `&self`); plus the provided `run_export`. The interpreter is deliberately **not** a `JitBackend`.
- `Machine::run_with_tier` is the non-blocking tier entry; the `*_with_tier` outcome/resume twins re-enter a suspended slice on the SAME tier (so the tier survives a `receive` park) and `resume_outcome_with_tier` resumes on **every** tier through the no-reset seam `jit::baseline::run_native_resume_outcome`.
- `jit-cranelift` (default OFF) gates the optional deps (off => **no Cranelift dependency at all**); `jit-beamasm` aliases the baseline tier; `tiering.rs`'s `TierPolicy` models *interpret -> baseline -> hot* escalation as a **policy only**.
- `src/jit/cache/` is the cross-run compiled-block cache keyed by `CacheKey` = `ModuleKey` (load-time MD5, else an IR fingerprint) **plus** `Module::atom_table.snapshot()`; two loaded copies of one `.beam` are two entries -- an extra compile at worst, never a wrong answer. `baseline_code_map(&Module)` feeds a host's `+JPperf` map.
- Block ABI, register picker, artifact layouts, continuation sub-blocks and the inlined shape set: `src/jit/CONTEXT.md`, `src/jit/baseline/CONTEXT.md`, `src/jit/baseline/inlineset/CONTEXT.md`, `src/jit/baseline/emit/CONTEXT.md` (all authoritative).

### The execution-census instrument (`src/exec_census.rs`)
**Measurement-only**: on no execution path, changing no result, one thread-local `bool` load per hook while disabled. Surface: `enable`/`disable`/`is_enabled`, `reset`, `snapshot()`, `write_dump(section)`, `variant_name(&Instr)`.
**One recording site:** `Machine::step_instruction_inner` (shared by the interpreter's `drive` and the native tiers' deopt helper) calls `on_instruction` before the body and `on_error` only on an `Err(BeamError)` -- so a raising instruction counts as both, a caught raise as executed only, a **natively-inlined JIT instruction is not observed** (pin `Tier::Interpreter`), and a pre-emption is an error of the instruction it parked on. Blind spots: `MEASURED.md`.

### Error interop (`src/error.rs`)
Constructors over `beam_common::BeamError` (never a crate-local enum): `unsupported(what)` (a `Raise` whose reason atom is `unsupported_opcode: <what>`), `bad_register(n)`/`unknown_label(l)` (`BadArg`), `blocked()` (what the non-blocking entries surface for a `receive` that would suspend) and `suspended()` (the same for a `BifOutcome::Suspend`).
`Step::Enter` runs on the native baseline tier as a **driver-mediated context switch**, a round-trip by design: a seal-time cross-module link is unsound (separate executable mappings, buffer-local `rel32` fixups, the entry module baked into `JitRuntime`).

## Execution model (frozen semantics -- reproduce, don't reinvent)
Per-instruction/per-operand/per-family detail with the `ops.tab`/`beam_emu.c` references: `INSTRUCTION_SURFACE.md`'s `## Execution model`.
- **Registers, stack & frames.** `x[0..MAX_REGISTER)`, args in `x[0..arity)`, result in `x(0)`, root set `x[0..live)`, plus the FR file; `allocate*` pushes a typed-`Continuation` CP slot then the Y slots, and a tail call pops its frame **after** the callee succeeds, so a raising callee unwinds from the live frame with its own reason.
- **The dispatch loop** owns the `(func, pc)` position, the module context and the literal binding, folds every `Step` back into it, and charges one reduction per instruction; every executed opcode has its own typed IR variant, and the residual `Instr::Generic` sentinel is a named typed error.
- **Failure semantics.** A `gc_bif`/`bif` error with a live `fail` label is a guard branch, with `NO_FAIL` a raise; `bif0`/`call_ext*` carry no fail label, so every error there is a raise. `FuncInfo` is **not** a no-op -- a failed head clause raises class `error` with the bare atom `function_clause` (C's `i_func_info_IaaI`).
- **Raising and catch frames.** `try`/`catch` push a `CatchFrame` (handler `(func, pc)` + owning call frame + module context); a raise records `pending_exception` and lands in the **innermost** live frame with C's `handle_error` convention (`x(0) = THE_NON_VALUE`, `x(1) = reason`, `x(2) = trace`, `x(3) = class atom`), reporting `Goto` or `Enter`; with no live frame or an unresolvable class atom it stays `Err(BeamError::Raise)`. A raise *reads* the entry but never pops it, and class atoms come from the running module's table via `atoms`.
- **A supplied trace is a TERM; a derived trace comes from `raise_snapshot`.** `sys_core_fold` rewrites `catch C:R:S -> erlang:raise(C,R,S)` into `Instr::RawRaise`, whose arm reads `x(2)` and hands it to `Machine::raise_supplied`, so a re-raised chain survives and **no re-raise-site frame is prepended**; `symbolic_stacktrace` returns an already-cooked list verbatim before falling back to the snapshot. Detail: `src/families/exceptions/CONTEXT.md`.
- **A frame's continuation slot is consumed by whoever follows the address**, so a derived stacktrace names a returned caller only while it is still live: `Machine::take_continuation` resets the CP slot to `Continuation::Halt` in the same step (C's `RETURN()`). Detail: `src/families/exceptions/CONTEXT.md`.
- **Every tier decorates an uncaught raise**: the funnel runs on the interpreter's `drive`, and the baseline tier's three raise-carrying helpers (`jit_family`, `jit_bitstr`, `jit_test`) run it **unconditionally** with the true `entry_module`.
- **No heap-admission memoisation exists**: `heap_available` has no call site and no `if need <= cached` fast path, so every `test_heap` crosses the host door unconditionally -- which is why `with_roots`'s no-loose-term path is kept minimal.

## Constraints
- **The ROOT-SET contract is the hardest invariant**: `x[0..live)` + **the whole Erlang stack** + the whole FR file + the five parked loose terms, **NO frame liveness maps**; nothing outside it survives a collecting allocation.
- **DEOPT IDEMPOTENCY (the baseline tier's inline set).** A `fallback` is a **deopt**: `jit_step_one` re-executes the whole instruction with the same operands, so no inline arm may commit **any** machine state before its last fallback, and an arm that allocates or roots *inside* the instruction must **decline** rather than allocate mid-instruction -- a collection relocates terms a raw `*mut Eterm` still names.
  Concretely `bs_match` commits the match context's `start` word exactly once per path (never per command), and `bs_create_bin` commits its accumulator's window end **last**, after every payload store, with every door it calls mutating nothing -- so a post-payload deopt re-writes the same bytes at the same offsets.
  Pinned by `src/jit/baseline/{bs_match_deopt_tests,bs_create_bin_tests,bitstr_shapes_deopt_tests}.rs` and by `foreign_kernel_tests.rs` comparing the four `foreign` kernels' **outputs** on both tiers and the live oracle.
- **`unsafe` confinement.** `#![deny(unsafe_code)]` (`#![warn(missing_docs)]`); the crate's own exception modules are `src/predicates.rs`, `src/terms/*`, `src/families/bitstrings/raw.rs`, `src/families/records/raw.rs`, `src/jit/emitter/mod.rs` (the crate's **only** executable-memory mapping), `src/jit/baseline/{mod,runtime}.rs` + `src/jit/baseline/emit/*`, feature-gated `src/jit/cranelift/mod.rs`, and `src/context.rs`'s region heap + `src/context/reclaim.rs` -- each `unsafe` block with a `// SAFETY:` rationale; the authoritative selector is `grep -rn 'allow(unsafe_code)' src`.

## Test Strategy
Per-module `#[cfg(test)]` unit tests plus integration tests over committed real `.beam` fixtures and synthetic `Module`s; suites needing the system stdlib **skip loudly** when absent. Enumeration: `TEST_NOTES.md`; layout: `tests/CONTEXT.md`.
- **Gate (GREEN required):** `erts_rust/scripts/cargo.sh test --manifest-path erts_rust/Cargo.toml -p beam_engine --no-fail-fast` (green, warning-free) and the same with `--workspace`; `--features jit-cranelift` adds `tests/jit_cranelift.rs` + `jit_cranelift_real.rs`; `cargo tree -p beam_engine` without the feature must list no `cranelift-*` crate. CI (`.github/workflows/erts_rust.yml`) builds `--all-targets`, runs the same command, a non-blocking clippy and the differential gate.
- **Oracle-checked = values baked at authoring time.** Most oracle suites embed oracle-derived expected values; only `process_info.rs`, `tailcall.rs`, `func_info_stacktrace.rs` re-invoke `erl`, so **a green run without `erl` proves nothing about corpus parity**.
- **Real-module evidence is oracle-checked on every tier:** one committed corpus (**504** stdlib-breadth rows over **171** modules + **223** error-path rows over **215** modules = **727**) runs on `Interpreter`, `BaselineJit` and `Cranelift` with **no row disagreeing**, and tier-vs-tier agreement is asserted beside the oracle comparison -- a mistake two tiers share still fails (the three `jit_*` suites).
- **The whole differential corpus is identical on all three tiers:** every `differential list` case, driven through `beam_rt` once per tier (`BEAM_RT_TIER=interpreter` / unset = baseline / `cranelift` on a `--features cranelift` build), gives the same line on all three passes (**`total=3439 agree=3438 mismatch=0 unsupported=1 skipped=0`**, ratchet allowed) -- `gate.sh` exit 0 on every tier, and `../tools/differential/gate.sh` is the project-level gate.
  `skipped=0` is part of the claim: the two-live-VM `dist`/`wire` and boot cases really ran on the Cranelift tier; the one `unsupported` is the recorded `wire/new_fun_ext_encode` gap, so **no case disagrees on any tier**. Recipe and corpus split: `TEST_NOTES.md`, `../tools/differential/CONTEXT.md`.
- **Headline suites** (per-file detail: `TEST_NOTES.md`): `slice.rs`, `stdlib_sweep.rs` (all 1366 installed `.beam` over 34 apps), the oracle-pinned `stdlib_*.rs`/`apps_lists.rs`, `no_fail.rs`, `gaps.rs` (each host gap's EXACT typed error), `census.rs`/`dynamic_census.rs`, the variant proofs, `bif_in_machine.rs`, `bif_suspend.rs`, the arena pins, `src/machine/root_tests.rs`.
- **Stacktrace rows** (`stacktrace_frames.rs` over the `erlc +deterministic` fixture): every row runs on **both** tiers and the two must derive byte-identical frames before either is compared with the oracle as a leading-prefix match (the oracle's trailing `erl_eval`/`init` callers lie outside this run); two entries are asserted by no row: `inhandler/0` (a fieldless `error:badarith` carries no frames -- a `beam_common` limitation) and `park/0` (`#[ignore]`d: no mailbox).

## Known Issues (each a typed result, never a wrong value, unless stated)
Item-by-item ground truth: `INSTRUCTION_SURFACE.md`'s `## Known Issues`.
- **Pre-emption exists; scheduling does not.** The `reduce` hook is charged by both drivers; run queues, the scheduler and trap handling are Stage 5 (`beam_process`).
- **Records -- two open divergences.** The whole native-record set executes and `PutRecord`'s create form works for the module's own `Recs` and for a foreign `{Module,Name}` id. Open: `is_record_accessible`'s wildcard arm compares the definition module against the `Scope` **operand** where `emu/ops.tab:1675` substitutes `$MODULE`, and `put_record`-update / `update_record_id` / `get_record_field` raise `function_clause` where the C's `NO_FAIL` path raises `{badfield,…}`/`{badrecord,…}`. Detail: `src/families/records/CONTEXT.md`.
- **Bitstrings.** `bs_init_writable` builds 0 bits over a capacity-carrying refc payload (the `x(0)` hint, else `DEFAULT_WRITABLE_SIZE = 1024`) registered writable on the machine; a first-position `private_append` appends **in place** and an outgrown payload grows (amortised); every other shape promotes to the byte-identical copy-rebuild. Residuals are typed only (no term-level `BIN_FLAG_WRITABLE`/`_ACTIVE_WRITER`, no shrink-on-escape, unmodelled `binary:referenced_byte_size/1`). Detail: `src/families/bitstrings/CONTEXT.md`.
- **The bitstring families execute a *prepared* program**, pre-resolved once per `(module image, function, code offset)` (a direct-mapped 64-slot cache keyed on the image's owner word); a declined shape is `Program::Generic` running the unchanged generic walk, so the typed-error surface is identical. The tables are machine-owned and reached through `Machine::with_bitstr_programs`.
- **Contract A.9 rung L4 compiles `beam_flatten.erl` with the tree's own OTP-30 `compile.beam`, and the emitted `Code` chunk is byte-identical to the OTP-29 `erlc` oracle's apart from one byte** (`beam_dict:highest_opcode`) plus the derived `-vsn`; the rung's "artifact DIFFERS" verdict is a rung-baseline artefact (two compiler versions compared byte-for-byte), not a runtime divergence.
- **L4's throughput, not its correctness, is the open A.9 blocker on this path:** in-process compiling the tree's own compiler sources is ~2 orders of magnitude too slow, and the larger sources exceed the 900 s `BLOCKING_PUMP_DEADLINE`. Records are not the cause, and `v3_core.erl` is not oracle-comparable (the OTP-29 `erlc` rejects it). Figures: `MEASURED.md`.
- **Printing a native record is the wrong debugging instrument here.** `io_lib:format/2,3` is a `beam_bifs` native fast path (no `io_lib` frames in a trace) and its renderer has no `RECORD_SUBTAG` arm -- it falls through to `Err(badarg())`, so `~w`/`~p`/`~P`/`~tp` of a **native record** raises a bare `badarg` even though the real `io_lib_pretty:print/4` renders it. Print a shallow tag (`element(1,E)`-style) instead.
- **Snapshot-style divergences are typed errors, never wrong results:** map enumeration order is storage order, and a `NO_FAIL` failure of `test`/`select_val`/a map read raises class `error` with the bare atom `function_clause` from the running module's own table. **A map `is_eq_exact` costs O(k log k) and two heap `Vec`s** (no map fast path in `eval_test`); detail `src/families/maps/CONTEXT.md`.
- **Small-int arithmetic (`+ - *`, `band`/`bor`/`bsr`) is inlined only by the native baseline tier**; the interpreter has no arithmetic fast path -- every `gc_bif` goes out through `exec_bif` -> `call_bif`. Compiled arithmetic is oracle-exact on overflow (`+ - * div rem` promote to exact bignums, as does an out-of-range integer operand).
- **A captured stacktrace is engine-derived unless the raise supplied one**, and nameable atoms are required (`catch_end` needs `EXIT`). **Uncaught** frames exist only for a `BeamError::Raise` -- `beam_common`'s fieldless reason variants carry no `StackTrace` slot.
- **A supplied EMPTY trace is indistinguishable from "no trace supplied"**, because `beam_common::Raise` carries no supplied-trace flag: `erlang:raise(error, boom, [])` equals a raise with no trace, so the engine cooks the derived chain where the oracle keeps `[]` (C's `is_raised_exc`). The fix is a `supplied_trace: bool` on `beam_common::Raise` plus two engine hunks; the engine plumbing is in place and the gap is **owned by the sibling `beam_common` node**. Pinned by `tests/raise_with_trace.rs::an_empty_supplied_trace_is_byte_identical_to_no_supplied_trace`.
- **The stdlib module corpus is bounded by the mock test host's BIF floor** (`tests/support/bifs.rs`), never by this crate's opcode coverage; those crates are `beam_bifs`/`beam_rt`.
- **A synthetic module's never-cached label map costs one `Arc` allocation per `run_*` entry** (~+16 % of the `engine_bench` `setup/empty` floor); a real module (load-time digest) never takes that route.
- **An engine-built off-heap (refc) binary reaches the host as a *handle*, never raw memory** (`refc_binaries` + `send_message_with_off_heap`); `retain_refc_binaries(keep)` drops the handles a reachability predicate rejects and `off_heap_overhead_bytes()` reports the bytes feeding `beam_gc::BinVheap::triggered`.

## Memory footprint & heap wiring (figures in `MEASURED.md`)
**Nothing is freed except by a `Drop`**, and the crate has exactly **one** outside test code: `jit::emitter::CodeBuffer` (`munmap`).
Neither `Machine` nor `ContextHeap`/`MinimalContext` has one, so a machine's buffers free only when the machine drops and the arena's grid only when its `MinimalContext` does; a machine's resident footprint is therefore the **high-water mark of the heaviest run** it has executed (every vector `clear`/`truncate`s and keeps capacity; both 1024-word register files are 8 KiB each, allocated eagerly).
The **largest resident accumulator is the per-thread `CODE_CACHE`**, which has **no eviction** and no production `clear_baseline_cache` caller, so emitted code grows monotonically on a long compile. Geometry and per-structure detail: `src/machine/CONTEXT.md`, `src/jit/cache/CONTEXT.md`.
The label-map LRU is 32 entries per machine (each pinning its `Arc<Module>`); `beam_loader`'s lowered IR is ~72-80 KB per 1000 `Instr` (64 B each) and a label map is 8 B per label, **built per machine**.

### Heap admission & allocation wiring (the exact engine->host doors)
- **Only two admission points:** `test_heap`/`allocate_heap` -> `Machine::ensure_heap` -> `ensure_heap_full` with the whole `RootSet` (x, stack **and fr**), reached from the interpreter's two arms and the native tier's `jit_allocate_heap`/`jit_test_heap` -- **the tiers do not differ**, so a collecting host sees one admission per execution with the same operands.
- **`Instr::Allocate` makes no heap request** (frame-only); `gc_bif`/`bif`/`bif0`/`call_ext*` likewise leave term allocation to the host's `call_bif`.
- **All term allocation goes through `terms::reserve` -> `Machine::alloc_rooted` -> `alloc_words_rooted`** with the same full `RootSet`; the JIT **never inlines an allocation** (family-owned, routed to `jit_family`).
- **The engine makes no collection decision**: latch, occupancy test and collector are `beam_rt`'s, and this crate's only capacity input is the `heap_need`/`n` it passes.
- **The off-heap `refc_binaries` resident figure is the host's reclamation cadence, in reductions**, released only by a host decision (`retain_refc_binaries` at `beam_rt`'s slice-boundary park); a natively-run block reaching no admission door is charged **nothing**, so the cheaper a loop becomes the **more iterations one slice spans** and the more a per-slice prune retains: a **bounded per-slice window, not a leak**, and no rooting rule may be relaxed to shrink it -- only the reachability walk needs the complete root set, which exists only at the host's park.

### The arena's reclaim tiers, and term/region lifetimes
Tier A `heap_rewind(mark)` drops every region above the mark and is the only path that releases a carrier `mmap`; Tier B `reclaim_heap(forward)` Cheney-copies into a destination reserved at the copy bound and installs the survivor as the sole region -- a post-copy memcpy would be **unsound**, because the relocator writes the destination address into every copied child slot.
Every refusal is decided **before the first copy**; an `Err` from the host's `forward` leaves the arena **defined empty**; both successes bump the epoch, which is why `reset` alone reclaims no RSS. Detail: `src/context/CONTEXT.md`.
- **`Machine::reset` is logical and only at a slice START** (`run_label_outcome`); `resume_outcome` resets nothing and an unwind only `truncate`s.
- **A returned `Eterm` may be a `TAG_LITERAL_PTR` word into the module's `Arc<LiteralArea>`**, so it stays valid only while some `Arc<Module>` clone survives; `reset` drops the machine's bindings and nothing here enforces that.
- **A term produced in a `MinimalContext` arena dies with that context** -- its carrier blocks return to `beam_alloc`'s PROCESS-GLOBAL segment pool, so reading it later is a use-after-free surfacing as a **wrong value** or the `invalid boxed header subtag` abort, never a typed error; a test comparing terms from two runs must keep **both** hosts alive.
- **The one production move-and-republish path is the writable-binary payload**: `republish_over` rewrites **exactly the two words naming the payload** (`BinRef.val`, `ErlSubBits.base_flags`) plus the registry key, and refuses when `payload_aliased_elsewhere` finds a second on-heap naming pair. Detail: `src/families/bitstrings/CONTEXT.md`.
