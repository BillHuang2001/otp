# `beam_rt` — Test Strategy

Companion to [`CONTEXT.md`](CONTEXT.md).
It holds the crate's current-state test strategy — per-suite scope and the fixtures each suite depends
on — split out so `CONTEXT.md` stays under the Context Tree per-file read limit.
It is documentation of the present state, not a change log.

## Test Strategy
* **Unit tests** (colocated `#[cfg(test)]`): the A.6 parser (every switch, `init_args`, the `run` grammar, the trailing-dot `-eval`, `+S/+P/+Q/-pa/-pz`); `system_info_value` per key + unknown-key `badarg`; `InfoValue`→`Eterm`; `PreloadedModules` + the boot-script reader; the evaluator + binary surface; `FunCaller`; `nif_error`'s live reason; the `DictBridge` BIFs; the error helpers incl. `enforce_term_heap_limit` (both `AllocKind` variants → `SystemLimit`); `Runtime::stabilize_term` on an oversized value → `SystemLimit` (a `MIN_HEAP_WORDS` runtime).
* **`src/codeserver.rs`**: atom-sharing/cache semantics (shared table, idempotent load, `loaded_path`), the shared-fallback probe argv, and the code-path resolution over synthetic installation trees under `$TMPDIR` (every layout shape; the `lists.beam` probe proof; the hard-stdlib/best-effort-kernel rule; the native probe == `system_ebins()` on this host). Each skips **loudly** without a discoverable installation.
* **`src/context/` + `src/mailbox.rs`**: the `uses_*` predicates (incl. the eight mutually-exclusive bridge predicates' pairwise disjointness and the `uses_memory_hook`/`uses_fun_identity` gates); `RecordBridge`; `NodeIdentity`'s internal-pid `NEW_PID_EXT`; `FunIdentityBridge`'s clean-miss contract; the nested-BIF seams; `PendingInterner`; the nine mailbox methods; the retained-payload families (`MailboxState::remove_at` retains refc binaries, MSO handles and node identities — pinned by `removing_a_message_retains_its_off_heap_handles`/`..._node_entries`/`the_copy_source_builder_includes_the_retained_off_heap_handles`); the heap-fragment path (an oversized delivery to a policy-bounded receiver wakes it and arrives **intact**); `test_support.rs`.
* **`src/context/{process_bridge,module_info,persistent_term,memory_hook}.rs`**: the `ProcessHook` methods over a real `Runtime` (incl. the already-borrowed `ports` typed gap, `process_flag/2`'s previous-value contract, `process_info`'s key list + `Value`/`Unknown`/`Dead`); the `ModuleInfo` decode + `Attr`/`CInf` remap; the persistent-term semantics incl. the nested-borrow typed gap; the `MemoryHook`'s nine keys in oracle order, `total == processes + system`.
* **Floor tests** (`src/native/*.rs` + `src/info.rs`): the `erlang`-core entries, `init:*`/boot status, every `code:*` entry, the process/reference/monitor/registry entries, the `application:*` entries + the `.app` parser (system-installation cases skip **loudly**), `process_info/1,2`, the timer BIFs, `erts_internal:*`/`prim_file:*`, the A.8 keys, the native `file_server_2` service's request/reply surface and errno mapping, and `src/error.rs`'s gap classifier + drift guard.
* **Ports / bit operators / timers** (`src/port/tests.rs` + the real-C-driver fixtures `src/port/driver/{ready_output,stop_select,control,hooks,fire,liveness,monitor}_tests.rs`, `src/eval/mod.rs`, `src/timers.rs`, `src/runtime/scheduler/tests.rs`): every `Name` form + options; empty name → `BadArg` with no port number consumed; the `port_info` vocabulary; `pump`'s once-only `{exit_status,…}`, the `next_deadline` clamp and `take_driver_outputs`; the read path; the six bit operators; the timer heap + receive-deadline behaviour over `recv_after.beam`.
* **Integration suites** (`tests/`), one per contract; fixtures compile **at test time** and skip **loudly** without the toolchain, and `tests/support/mod.rs` resolves the toolchain from the filesystem (never by running `erl`) and bounds every probe (`-s init stop` + a poll/kill at `PROBE_TIMEOUT`). Contract families: the `../beam_loader` slice (`slice.rs`/`cli.rs`/`eval.rs`; `add/2` → 5, `fib/1 10` → 55); `records.rs`/`nif.rs`/`driver.rs`/`trace_send_event.rs` (A.7/A.3/A.4/A.8); `trace_call.rs` (the end-to-end execution-trace path, 8 tests); `dist.rs`/`dist_delivery.rs` (A.5, a real `erl` peer completing the handshake); the `process_info/2` position items (`position.rs`); the three seams (`proc_seams.rs`/`module_info.rs`/`persistent_term.rs`) and the process-control family (`monitor.rs`/`alias.rs`/`exit.rs`/`node_cookie.rs`/`spawn_opts.rs`/`module_loaded.rs`/`process_info_items.rs`); `boot.rs` (the real `start.boot` to `{progress,started}`, CLI `-boot` exit **0**); `file_server.rs`; `io_scan.rs` (the library-level io-device read path + the `HOLD_AND_PRINT_FIRST_BODY` relocation-exemption probe); `etf_roundtrip_pid_ref.rs` (the local pid/reference ETF round-trip; refs asserted as `#Ref<…>` + a successful exit only); `compile_file.rs` (in-process `compile:file/2` byte-identical to the oracle); `eval_order.rs` (the `-eval` evaluator's left-to-right list-literal order); `eval_exempt_receiver_signal.rs` (a control signal to the relocation-exempt `-eval` root with a full nursery still arrives).
* **Seam / GC / owner-death suites** (`tests/`): `proc_lib_start.rs` (an OTP-behaviour child comes up and survives across a module boundary), `fun_entry_receive.rs` (a fun-bodied process entry parks in `receive` and resumes), `ets_owner.rs` (the four oracle ETS owner-death flows), `port_monitor_cleanup.rs` (a dead watcher's incoming port monitor is swept, a survivor's kept), `gc_collect.rs` (the collector really runs at the heap-admission point), `garbage_collect.rs` (the served `erlang:garbage_collect/0,1`: returns oracle-cross-checked + a **scheduled** call moves `gc_stats().collections`), `engine_off_heap_transport.rs` (an engine-built off-heap refc binary survives the transport copy out of a scheduled process — the `base64:encode(<<>>)` repro, the `exit(<<0:1200>>)` reason arm, and the send/received paths `engine_built_off_heap_binaries_survive_the_send_transport`/`received_off_heap_binaries_survive_the_transport_copy` — each oracle-cross-checked).
* **A.9 native-floor / heap-growth / pid-identity suites** (`tests/`): `a9_native_floor.rs` (the A.9 native-floor surface driven through a real `Runtime` *and* the built binary; 15 tests); `heap_growth.rs` (the admission point grows the nursery to fit a 401-word `test_heap`, durable across a loop; a `+hmax`-bounded policy the request cannot reach is untouched); `pid_roundtrip.rs` (the local pid round trip is an **identity**, plus the negative control that a local-node pid image decoded with no identity installed stays `is_external_pid`); `empty_binary_result.rs` (an on-heap `<<>>` prints; the off-heap-refc case is the `#[ignore]`d red Test B).
* **Mature-strategy selection (`tests/gc_strategy.rs`)**: runtimes built through the crate's own path (`Runtime::new` → `boot` → `load_module` of the committed `heap_growth.beam`/`gc_payload.beam`), the spawned child's collector read through the public `Runtime::processes()` accessor — the break-even constant (`IMMIX_BREAK_EVEN_WORDS == 2048`); the runtime default `MatureKind::Copying` (`MatureSource::Automatic`, 233 mature words, no override); a `HeapOptions` Immix policy selecting `MatureKind::Immix` through the **automatic rule** with no pin and no init argument; the boundary (`IMMIX_BREAK_EVEN_WORDS - 1` still copying); the same workload **run** on both runtimes with `fullsweep_after(0)` (clean counters); and its last case (`a_live_payload_survives_a_fullsweep_on_the_immix_path`) — `gc_payload:run/200` on an Immix-resolving `HeapOptions` at `fullsweep_after(0)`, asserting the process's collector was `Immix` **while holding a live payload across a fullsweep**, `fullsweeps > 0`, the payload intact (`support::check_gc_payload`) and the counters clean. No wall-clock asserted; a host `BEAM_RT_GC_STRATEGY=immix` makes the default cases skip **loudly**.
* **The measured Copying-vs-Immix verdict (`tests/gc_immix_payload.rs`)**: the same runtime-shaped workload (`gc_payload:run/2000`, `fullsweep_after = 2`) run twice under `Copying` and twice under `Immix`, differing only in `initial_mature_words` at the rule's boundary. It asserts **counts only** (payload intact, `collections > 0`/`major > 0`, every failure counter clean, each strategy's two runs identical, an equal collection count, the mark-region run reaching strictly more fullsweeps and larger mature occupancy/process memory) and prints the `GcStats`/`mature_used_words`/`minor_gcs`/`erlang:memory(processes)` table plus wall-clock as context. The file doc records the verdict: on this default-scale live set the mark-region space copies **1.146×** the words and **1.144×** the objects at **6.57×** the mature occupancy and **2.31×** the reported process memory (a loss regime), so **Copying stays the right default**. Timings are never asserted.
* **Per-call overhead regression harness** (`examples/perf_bif.rs`) — run command and figures in [`TRACE_AND_PERF.md`](TRACE_AND_PERF.md).
