# `beam_rt::context` — the concrete `ExecutionContext` glue

## Intent
The concrete `beam_engine::ExecutionContext` the runtime installs: it adapts the engine's seam types onto the real `beam_bifs` registry, the `beam_alloc` heap and the `beam_process` process/port tables, and installs **every** optional `beam_bifs` host seam.
It owns the BIF dispatch order (`try_call_nif` → `try_native` → `call_registered` → external-module load), the nine bridge arms, the atom-interner discipline (`PendingInterner`) and the caller-module tracking.
The nine `beam_engine::Mailbox` seam methods live one level up in [`../mailbox.rs`](../mailbox.rs); this node owns the `ExecutionContext` half of the glue, and the runtime-level scheduler/runner that drives it lives in [`../runtime/`](../runtime/CONTEXT.md).

## API Surface
### `context/` — the concrete `ExecutionContext` (the glue)
`RuntimeContext<'a>` carries the runtime borrow, the optional `output` sink (`SharedSink`, a cloneable `Rc<RefCell<..>>`; stdout when `None`), `mailbox_pid`/`mailbox_table`, `may_pump_scheduler`, `current_module` and `engines`; methods `new`, `with_output`, `heap_available()`, `for_process` (runs **as** the given pid — the scheduler seam), `pid()`, `eval_heap()`, `enter_module`, `run_export`.
`impl ExecutionContext`: `call_bif` serves, **in order**, `try_call_nif` (a loaded NIF wins — the BEAM's dispatch order) → `try_native` (the native floor) → `call_registered` (the `beam_bifs` registry) → for the `erlang` namespace, `is_known_unimplemented_bif` ? `unsupported:` : bare `error::undef` → else load the module file and `run_export` (`context/mod.rs::call_bif`).
**`resolve_external_call` — the in-machine cross-module call seam (adopted).** `RuntimeContext` overrides `ExecutionContext::resolve_external_call`, so a `call_ext`/`call_ext_only`/`call_ext_last` callee runs **in the caller's machine** (the engine stores the caller's return address then enters the callee's export label) instead of recursing through `call_bif` → `run_export`. That is what lets a `receive` inside a cross-module callee **suspend** — `proc_lib:start/4`/`proc_lib:start_link/4` answer `{ok,pid}` (`../tests/proc_lib_start.rs`) instead of folding into the uncatchable `error::blocked()`.
It returns `Some((arc, label))` only for an import runnable in this machine: `arc` is the **same** `Arc<Module>` held by `CodeServer::modules` (contexts dedupe by `Arc::ptr_eq`, so cloning the `Module` is a correctness bug) and `label` is `arc.export(atom, arity)` — the label *after* `func_info`; the call args are already in `x(0..arity)` and an unknown label is the typed `unknown_label`.
It performs `find_module_file` + `code_server.load` **on demand** for an uncached callee, and returns `Ok(None)` (preserving the synchronous `call_bif` path byte-for-byte) for a native-floor `FLOOR_MODULES` import, a NIF-loaded module (`beam_engine` owns that dispatch), a `beam_bifs` registry key, a module whose `ImpT` observes its own call site (`module_observes_its_call_site` — `erlang:load_nif/2`, `erlang:term_to_binary/1,2`, `erlang:external_size/1,2`; an in-machine callee never re-enters `RuntimeContext`, so `current_module` would stay the caller's), a foreign-pid/unknown export, and an unknown label.
**Resume contract:** `resume_outcome` takes the run's ENTRY module; the suspended `(func, pc)` live in `Machine::context` and `reset` — not `resume_outcome` — clears contexts. A fun-bodied process entry resolves its own `LocalFunTarget` once and enters via `run_label_outcome_with_tier` (`../tests/fun_entry_receive.rs`).
**The heap seams.** `alloc_words`/`heap_available` (`gc.rs`) serve a scheduled process from its **own** young heap and collect at the engine's heap-admission point (`ensure_heap`); every other context — and any request the young heap cannot serve — falls back to the pointer-stable runtime arena byte-for-byte as before.
**Registry precedence (gotcha for new `beam_bifs` registrations).** The native floor runs *before* the registry, so a `beam_bifs` entry for a key the floor already serves can never shadow it; the registry runs *before* the external-module load, so for a **non-`erlang`** name a registration **does** shadow the fallback while for an `erlang:*` name it flips the unregistered answer (bare `error::undef`, or `unsupported` when curated in `error::KNOWN_UNIMPLEMENTED_ERLANG_BIFS`) to whatever the BIF returns. `apply_fun` → external `fun M:F/A` via `call_bif` (the `-eval` closure `EVAL_FUN_UNIQ` via `apply_eval_closure`; else the module's `FunDescriptor{uniq,index}` then `Machine::run_label`). `send_message` copies into the receiver's heap (`deliver_simple`); an oversized payload retries through the **heap-fragment** model, and a genuine exhaustion (either heap class, after the retry) becomes the documented `error:system_limit`.

### `call_registered` — nine dispatch arms, the gated seam handles, the port provider
`call_registered` builds **one** `BifContext` and installs on **every** arm the cheap handles — the atom interner (`PendingInterner`), the port provider (`RuntimePorts`) and the `Copy` `NodeIdentity` hook; the shared `TableRegistry` is installed **unless** an argument is a fun (a fun argument can re-enter and reach `ets:*`, so the `RefCell` must stay free). Exactly **one** bridge is then selected, first-match, by its own `uses_*` predicate:
* **`DictBridge`** (`DictHook`; `uses_dict`) — the process dictionary over the **running process's** `beam_process::Dict` (the pass table, else the runtime's): `put/2`, `get/1`, `get/0`, `erase/1`, `erase/0`, `get_keys/0,1`; a missing pid is `error::no_mailbox`.
* **`ProcessBridge`** (`ProcessHook`; `uses_process_hook`) — nine BIFs (`whereis/1`, `register/2`, `unregister/1`, `registered/0`, `is_process_alive/1`, `processes/0`, `ports/0`, `process_flag/2`, `group_leader/0`; `process_info/1,2` is intercepted by the floor first) over the real `ProcessTable` + `Rc<RefCell<PortRegistry>>` (`src/context/process_bridge.rs`); the per-process `erlang:group_leader/2` and `erts_internal:group_leader/2,3` are served by the floor (`src/native/group_leader.rs`).
* **`NifBridge`** (`NifLoader`; `uses_nif_loader`) — `erlang:load_nif/2`, checked **before** the filesystem; a reload of an already-loaded module is `NifLoadError::Reload`; a load failure is mapped variant-for-variant and **returned**, never raised.
* **`RecordBridge`** (`RecordSource`; `uses_record_source`) — `records:get_definition/2` from the loaded module's `Recs` chunk (`Module::record_by_name`), field atoms name-resolved; an unloaded module or undeclared record ⇒ `Ok(None)` ⇒ the oracle's `badarg`; an unresolvable field atom is a typed `TermNotFound`.
* **`SendBridge`** (`SendHook`; `uses_send_hook`) — `erlang:send/2`/`erlang:'!'/2` delegating to `RuntimeContext::send_message` (the return value **is** the message term; a send to a pid with no process succeeds silently; a non-pid-like destination is `badarg`; a registered name is delivered).
* **`ModuleInfoBridge`** (`ModuleInfo`; `uses_module_info`) — `erlang:get_module_info/1,2` from the loaded module's IR.
* **`PersistentTermBridge`** (`PersistentTerm`; `uses_persistent_term`) — the seven `persistent_term:*` BIFs over the runtime's shared store; a cheap `Rc<RefCell<..>>` clone with **no** runtime borrow.
* **`RuntimeHooksBridge`** (`RuntimeHooks`; `uses_runtime_hooks`; `src/context/runtime_hooks.rs`) — serves ~46 keys of the 195-key roster: `start_timer/3,4` (delivers `{timeout, TRef, Msg}`), `send_after/4`, `cancel_timer/2`, `function_exported/3` (this runtime's loaded-module set **or** the live BIF registry), `link/1`/`unlink/1` (the `ProcessTable` link set; a remote pid is the typed gap), `os:set_signal/2` (`signal.rs`), `erlang:dt_spread_tag/1`/`dt_restore_tag/1` (identity with dynamic tracing off), the dynamic-tracing tag family (`dt_get_tag/0`/`dt_get_tag_data/0`/`dt_put_tag/1` ⇒ `undefined`; `dt_append_vm_tag_data/1`/`dt_prepend_vm_tag_data/1` ⇒ the argument), `system_profile/0`, `check_old_code/1`, `finish_loading/1`, the three on-load hooks (⇒ `badarg`), `erts_internal:is_system_process/1`/`is_process_executing_dirty/1` (⇒ `false`), `erts_internal:erase_persistent_terms/0` (⇒ `true`, and really clears the store), `erts_literal_area_collector:release_area_switch/0` (raises `error:notsup`), `erts_trace_cleaner:check/0` (⇒ `false`), `error_logger:warning_map/0` (⇒ `warning`), `code:coverage_support/0`/`get_coverage_mode/0`/`set_coverage_mode/1` and `erlang:statistics/1` (`run_queue`, `wall_clock`); every other roster key — incl. the `erl_ddll` registry family, `reductions`, `read_timer/1,2`, `alias/1`/`unalias/1` — is the typed `unsupported_bif` gap, and a key outside the roster is bare `error::undef` (the roster is per `(module, function, arity)`). It holds `&mut Runtime` **plus** a `&mut ProcessTable`, so it is its own arm. `timeout` is a `boot::CORE_ATOMS` seed (the bridge cannot intern: the shared table is borrowed immutably for the whole call).
* **`FunBridge`** (`FunCaller`; the fallback) — `RuntimeContext::apply_fun` over `&mut Runtime`, carrying a clone of the caller's `SharedSink`, the mailbox identity, the scheduler-pump permission and `current_module`, and **no** `TableRegistry`.
`NodeIdentity` answers the fixed `(nonode@nohost, creation 0)` for `beam_codec`'s `Encoder::with_local_node`, emitting `NEW_PID_EXT` (`88`) for an internal pid and `V4_PORT_EXT` (`120`) for an internal port.
`FunIdentityBridge` supplies the `NEW_FUN_EXT` (`112`) identity of a **compiled module's** local (`make_fun3`) fun from an owned, borrow-free snapshot (the caller module's `Arc<Module>` + `.beam` path + the node atom): `Ok(None)` — never an error — for a non-local-fun argument, a context with no calling module (the `-eval` evaluator) or an unreadable `.beam`, otherwise module atom + module MD5 + `old_index`/`old_uniq` from `FunT` + the fixed `<0.0.0>` creator (`bridges.rs::local_fun_identity`/`module_md5`). Built only on the `uses_fun_identity` arm (`erlang:term_to_binary/1,2`, `erlang:external_size/1,2`).
`RuntimeMemory` (the `MemoryHook`) is built only on the `uses_memory_hook` arm (`erlang:memory/0,1`); ungated its `code_bytes` snapshot (a `CodeServer::loaded()` clone+sort plus a `std::fs::metadata` per module) would cost ~13 µs on **every** registered call.

### `PendingInterner` · caller-module tracking · NIF dispatch
`PendingInterner` is `Clone` over `Rc<RefCell<{base, names}>>`: `new(base)` roots it at the shared table's length, `commit` interns the recorded names in order at their predicted indices, and `beam_bifs::AtomInterner` gives append-only prediction + in-call dedup (`binary_to_term`/`list_to_atom`/`binary_to_atom` are the BIF writers); `load_nif/2`'s two writers (the BIF, the C `load` callback via `enif_make_atom`) share the cell. `run_export` **sets** `current_module` (restoring it afterwards) and `FunBridge::call_fun` **inherits** it; it reaches the BIF through `BifContext::with_current_module` (`None` ⇒ `unsupported_bif`, never a guess).
`try_call_nif` is the **first statement of `call_bif`**, so a NIF replaces the Erlang stub of the same `{module,function,arity}` exactly as the BEAM's dispatch does; its term lives in the pointer-stable pooled BIF heap and the per-call `PendingInterner` is committed **after the registry borrow is released**. `NifCallError::Raised(reason)` → `error::nif_raised`; `UnknownFunction` → bare `error::undef`; a miss is `Ok(None)`. **Interception is at external dispatch only**: a *local* `call` inside the NIF's own module never reaches `call_bif`.

## Constraints
* **`unsafe`-free**: the crate is `#![deny(unsafe_code)]`; the glue uses only the safe peripheries of the lower crates (`Heap::cons/tuple`, `AtomTable::intern`, `BifRegistry::call`).
* **Return-based errors, no silent swallowing** ([`../../CONTEXT.md`](../../CONTEXT.md) §3): every fallible helper returns `beam_common::Result`; no `panic!`/`unwrap()` on runtime data.
* **Call down, never duplicate**: a BIF is served by `beam_bifs`/the native floor, never re-implemented here.
* **Dispatch cost is a first-class concern**: `call_registered` runs per call, so every handle built there must be gated by its own `uses_*`/`needs_*` predicate; measure with [`../../examples/perf_bif.rs`](../../examples/perf_bif.rs) before and after any change to the dispatch prologue (figures in [`../../TRACE_AND_PERF.md`](../../TRACE_AND_PERF.md)).

## Test Strategy
* Colocated units in `tests.rs` + the shared `test_support.rs`: the `uses_*` predicates (incl. the pairwise disjointness of the eight mutually-exclusive bridge predicates and the `uses_memory_hook`/`uses_fun_identity` gates), `RecordBridge` over a loaded module's `Recs`, `NodeIdentity`'s internal-pid `NEW_PID_EXT` encoding, `FunIdentityBridge`'s clean-miss contract, the nested-BIF seams and `PendingInterner`.
* Per-module units in `process_bridge.rs`, `module_info.rs`, `persistent_term.rs`, `memory_hook.rs`: the `ProcessHook` methods over a real `Runtime` (incl. the already-borrowed `ports` registry ⇒ typed gap, `process_flag/2`'s previous-value contract, `process_info`'s key list + `Value`/`Unknown`/`Dead` items), the `ModuleInfo` item decode + `Attr`/`CInf` remap, the persistent-term semantics incl. the nested-borrow typed gap, and the `MemoryHook`'s nine keys in oracle order (`total == processes + system`, live-oracle key-order comparison).
* Integration suites (in `../../tests/`): `proc_seams.rs`, `module_info.rs`, `persistent_term.rs`, `nif.rs`, `driver.rs`, `trace_call.rs`, `trace_send_event.rs` and the process-control family (`monitor.rs`/`exit.rs`/`node_cookie.rs`/`spawn_opts.rs`/`module_loaded.rs`/`process_info_items.rs`), each driven through `-eval` on the executable and cross-checked against the live oracle.

## Routing Table
* `mod.rs` → `RuntimeContext` (fields, `new`/`with_output`/`for_process`/`pid`/`eval_heap`/`enter_module`/`run_export`) + the **one** `impl ExecutionContext` (`call_bif`'s dispatch order, `call_registered`, `apply_fun`, `send_message`/`send_fragmented_message`, `alloc_words`/`heap_available`), plus the `uses_*` predicates.
* `bridges.rs` → the nine bridges (`DictBridge`/`ProcessBridge`/`NifBridge`/`RecordBridge`/`SendBridge`/`ModuleInfoBridge`/`PersistentTermBridge`/`RuntimeHooksBridge`/`FunBridge`) + `NodeIdentity` + `local_fun_identity`/`module_md5`.
* `fun_identity.rs` → `FunIdentityBridge`, the `NEW_FUN_EXT` (`112`) identity of a compiled module's local (`make_fun3`) fun.
* `gc.rs` → the engine's heap-admission point (`ExecutionContext::ensure_heap`) and the `alloc_words`/`heap_available` seams for a *scheduled* process; the runtime-level GC state/accounting/valves are [`../runtime/gc.rs`](../runtime/CONTEXT.md).
* `trace.rs` → the execution-trace seam (`call`/`return_from`/`return_to` over `ExecutionContext::trace_event`).
* `process_bridge.rs` → the `ProcessHook` arm over the real `ProcessTable` + `Rc<RefCell<PortRegistry>>`.
* `module_info.rs` → the `ModuleInfo` arm (`erlang:get_module_info/1,2` from the loaded module's IR).
* `persistent_term.rs` → the `PersistentTerm` arm (the seven `persistent_term:*` BIFs over the runtime's shared store).
* `runtime_hooks.rs` → the `RuntimeHooks` arm (`start_timer`/`send_after`/`cancel_timer`/`function_exported`/`link`/`unlink`/`dt_*`/`statistics`/`check_old_code`/`finish_loading`/the coverage-mode trio/…).
* `signal.rs` → the `os:set_signal/2` arm over one process-global `beam_io::SignalFacility` held in a `thread_local`; a caught signal's `{notify, Signal}` has no `erl_signal_server` recipient yet.
* `memory_hook.rs` → the `MemoryHook` arm + `RuntimeMemory` (`erlang:memory/0,1`).
* `tests.rs` / `test_support.rs` → the colocated unit suite + the shared test helpers.
* Sibling (not owned here): [`../mailbox.rs`](../mailbox.rs) (the nine `Mailbox` seam methods), [`../runtime/`](../runtime/CONTEXT.md) (the scheduler/runner that drives the session), [`../native/CONTEXT.md`](../native/CONTEXT.md) (the BIF floor `try_native` consults first).
