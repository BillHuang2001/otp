# `beam_rt` — Rust ERTS Runtime Binary (boot · CLI · `system_info` · runtime glue)

## Intent
Top of the workspace: produces the `beam_rt` executable and is the only crate that sees the whole picture. It owns:
* `main.rs` and the **CLI flag surface** — contract **A.6**;
* the **boot sequence** + the **preloaded-module registry skeleton** — **A.7**;
* **`system_info/1`** and the runtime introspection surface — **A.8**;
* the **concrete `ExecutionContext` glue** adapting the engine's seam types onto the real `beam_bifs` registry / `beam_alloc` heap / `beam_process` pid (the key deliverable);
* the **A.4 runtime side of ports**: `open_port/2`'s `Name`/`Options` term decoding + the `port_info` metadata, over `beam_io`'s one OS-child implementation (`SpawnDriver`), its port registry and its poller (`src/port.rs`). The child and its lifecycle are `beam_io`'s; this crate owns only the terms.

This crate is the vertical slice: the engine-level slice runs on a test-only `MinimalContext` (`../beam_engine/tests/slice.rs`); `beam_rt` makes the same thing happen through the real glue and the executable end to end (`Runtime::run_function`/`run_module`).

It depends on **all** other crates (wave 6) but must **call down, never duplicate**: BIFs → `beam_bifs`; terms/heaps → `beam_term`/`beam_alloc`; pids/process table → `beam_process`; modules → `beam_loader`; execution → `beam_engine`. Legacy C ground truth is `../../erts/emulator/sys/unix/sys.c` (`main`), `../../erts/etc/common/erlexec.c` (the `erl` flag wrapper), `erl_init.c` (boot), `erl_bif_info.c` (`system_info`), `erl_record.c` (`records:*` + the code-server record table) and `beam_common.c` (the `error_atom` table) — read-only.

## API Surface (FROZEN — the runtime façade; re-exported at the crate root and `beam_rt::prelude::*`)

### `runtime.rs` — the façade
`Runtime` fields: `config, registry, code_server, processes, mailboxes, preloaded, bif_heaps, scheduler, runner_state, arena, info_heap, eval_heap, tables, ports, nifs, self_pid, booted, halt, refs, references, eval_closures`.
* **boot/config**: `new(RuntimeConfig)`, `with_defaults()`, `boot()` (A.7, idempotent), `is_booted()`, `config()`, `load_module(path)`, `module(name)`, `preloaded()`.
* **the slice**: `run_function(path, function, arity, args) -> Result<Eterm>` (returns x(0)), `run_module(module, function, arity, args, out: &mut dyn OutputSink)`.
* **spawning/scheduling**: `spawn_process(module, function, args)`, `spawn_fun_process(fun, args)` (the `spawn/1` fun path), `enqueue_process(pid)` (idempotent), `run_one_slice()`, `run_slices(max)`, `run_scheduler()` (never hangs; send→wake→resume in one call), `process_result(pid)`, `process_exit(pid)` (the reason term once raised), `run_queue_len()`.
* **refs/introspection**: `refs_mut() -> &mut RefAllocator` (**THE** ref id space — `make_ref` + monitors), `system_info(key)`, `system_info_value(key)` (heap-free source of truth), `eval(expr)` (the A.6 `-eval`), `format_term(term, module)` (the `~p` printer).

### `runner.rs` — the `beam_process::ProcessRunner` (the scheduler's execution seam)
`RuntimeRunner<'a>{runtime, state}` implements `beam_process::ProcessRunner::run(pid, table, budget) -> Result<RunOutcome>`, mapping `Returned(v)` → record `v`, `Exit(normal)`; `Wait{func,pc}` → park + `Waiting` + `Wait`; `Err(e)` → record `exit_reason(e)`, `Exit(<reason term>)` (never panics). `RunnerState` holds an engine per pid plus the `results`/`exits` `HashMap<ProcessId,Eterm>`s. `budget` is accepted but not enforced (no reduction pre-emption ⇒ `Yield` never returned).

### `context/` — the concrete `ExecutionContext` (the glue module: `mod.rs` + `bridges.rs` + `tests.rs`)
`RuntimeContext<'a>` fields: `runtime, output: Option<SharedSink<'a>>, mailbox_pid, mailbox_table, may_pump_scheduler, current_module`; `SharedSink` is a cloneable `Rc<RefCell<..>>`-shared output handle (stdout when `None`). Methods: `new(runtime)`, `with_output(runtime, sink)`, `heap_available()`, `for_process(runtime, table, pid)` (runs **as** that pid — the scheduler seam), `pid()` (the mailbox owner / `self/0`), `pub(crate) eval_heap()` (the long-lived `-eval` heap), `run_export(module, function, arity, args)`.
`impl ExecutionContext`:
* `call_bif` → `try_call_nif` (NIF dispatch) → `try_native` (the floor) → `BifRegistry::contains` → `call` (a `BifContext` over shared atoms / pooled heap / self_pid / output / `PendingInterner` + a `RuntimePorts` + a `NodeIdentity` + exactly ONE of the four bridges); else `module=="erlang"` → `is_known_unimplemented_bif` ? `unsupported:` : bare `error::undef`; else load the module file → `code_server.load` → `run_export`.
* `apply_fun` → external `fun M:F/A` via `call_bif`; `-eval` closure (`EVAL_FUN_UNIQ`) via `apply_eval_closure`; else the module's `FunDescriptor{uniq,index}` then `Machine::run_label`.
* `ensure_heap` → `heap_available() >= heap_need` else `BeamError::SystemLimit` (no GC).
`call_bif` installs `RuntimePorts` + a `NodeIdentity` in **every** arm and exactly **one** bridge — the only place the engine's seam meets the Stage-5 core (keeps the Stage-1/Stage-5 DAG acyclic).

### The four host-seam bridges (`context/bridges.rs`)
`call_registered` installs exactly **one** of four bridges (each needs a borrow the others cannot co-exist with); `NodeIdentity` (no borrow) rides alongside:
* **`NifBridge`** (`beam_bifs::NifLoader`; `("erlang","load_nif",2)`) — checked **before** the filesystem, so a second `load_nif` for a module that already has a library is `NifLoadError::Reload` (the oracle's rule since OTP 20), not a `dlopen`; a load failure is mapped variant-for-variant by `map_load_error` and **returned**, never raised. Its host shares this call's `PendingInterner`, so a name the C `load` callback interns and one the BIF interns land in one predicted list.
* **`RecordBridge`** (`beam_bifs::RecordSource`; gated by `uses_record_source(module,function,arity) == ("records","get_definition",2)`) — answers from the **loaded module's** `Recs` chunk (a `&CodeServer` read): `Module::record_by_name` (`beam_loader::ir`), each field atom **name-resolved** through the module's own atom table (where `beam_loader` interned the `AtU8` names), the `default` term passed through. An unloaded module or an undeclared record ⇒ `Ok(None)` ⇒ the oracle's plain `badarg` (C: `erl_record.c:1342-1403`); an unresolvable field atom is a typed `TermNotFound`, never a fabricated name.
* **`DictBridge`** (`beam_bifs::DictHook`; the five process-dictionary BIFs) — over the **running process's** `beam_process::Dict` (the scheduler pass's table, else the runtime's); a pid the table lacks is `error::no_mailbox`, never a panic. Keys/values are the argument `Eterm`s; the pool/arena are pointer-stable (no GC), so a stored term cannot dangle.
* **`FunBridge`** (`beam_bifs::FunCaller`; every other call) — delegates to the **existing** `RuntimeContext::apply_fun` (the evaluator is never re-implemented) over `&mut Runtime`; carries a clone of the caller's `SharedSink` (a nested `io:format` reaches the caller's sink), inherits the mailbox identity, the scheduler-pump permission and `current_module`, and carries **no** `TableRegistry` (the outer call left the shared cell free for a nested `ets:*` — see `reentrancy_capable`).
* **`NodeIdentity`** (`beam_bifs::LocalNode`; installed in **every** arm) — the local node's `(atom, creation)` = the fixed `nonode@nohost`, creation `0` (resolved from the shared table before the context borrows it, so both fields are `Copy`). Feeds `beam_codec`'s `Encoder::with_local_node`, so `term_to_binary/1` of an **internal** pid emits `NEW_PID_EXT` (`88`) and of an internal port `V4_PORT_EXT` (`120`).

### `PendingInterner` · caller-module tracking · NIF dispatch
`PendingInterner` is `Clone` over `Rc<RefCell<{ base: usize, names: Vec<String> }>>`: `new(base)` roots it at the shared table's length before the call, `commit(&AtomTable)` interns the recorded names in order at their predicted indices, and `beam_bifs::AtomInterner` gives append-only prediction + in-call dedup (`binary_to_term`/`list_to_atom`/`binary_to_atom` are the BIF writers). `load_nif/2` has **two** writers that may interleave (the BIF, and the C `load` callback through `enif_make_atom`); the host holds a clone of the same cell, so one `commit` lands every name at `base + <names so far>` — no colliding indices. `run_export` **sets** `current_module` (restoring it afterwards) and `FunBridge::call_fun` **inherits** it into the nested context; it reaches the BIF through `BifContext::with_current_module` — how `load_nif/2` learns the owning module (`None` ⇒ `unsupported_bif`, never a guess).
`try_call_nif` is the **first statement of `call_bif`** (before the native floor and the registry), so a NIF replaces the Erlang stub of the same `{module,function,arity}` exactly as the BEAM's dispatch does; its term lives in the **pooled BIF heap** (pointer-stable — no GC in M1) and the per-call `PendingInterner` is committed **after the registry borrow is released**. `NifCallError::Raised(reason)` → `error::nif_raised` (a **live-reason-term** raise); `UnknownFunction` → bare `error::undef`; a miss is a perfect no-op (`Ok(None)`), so an ordinary function of a NIF-backed module is never intercepted. **Interception is at external dispatch only**: a *local* `call` inside the NIF's own module never reaches `call_bif` (no code patching in M1) — the `tests/nif.rs` caller is deliberately a *separate* module.

### `port.rs` — the `PortHook` provider (contract A.4)
Public: `PORT_INFO_ATOMS` (the `port_info` item vocabulary, seeded at boot), `PortName{Spawn,SpawnExecutable,Fd}`, `StreamType{List,Binary}` (list is the default), `RuntimePorts` (the `beam_bifs::PortHook` impl: `open_port/2`, `port_close/1`, `port_info/1,2`) built from `Rc<RefCell<PortRegistry>>` + the shared `Rc<AtomTable>` + the owning `ProcessId`.
`PortRegistry` (private `{poller, registry, meta: HashMap<u64,PortMeta>, heap}`): `new()`, `is_live(id)`/`contains(id)`, `write_command(id, bytes)` (`port_command/2,3`), `len()`/`is_empty()` (live ports = `system_info(port_count)`), `ids()` (live ports in port-number order = `erlang:ports/0`), `close(id)`; private `register(driver, meta)`, `pump(timeout) -> Vec<PortEvent>`, `take_due_exit_statuses`, `info`. `PortMeta`: `command, os_pid, stream, notify_exit, monitors, owner`; `PortEvent`: `Data{port,bytes,stream,owner}` | `Exited{port,status,owner}`. Consumers: `Runtime::deliver_port_messages(table, timeout) -> Result<usize>` (scheduler path) and the `-eval` inline trio `RuntimeContext::{poll_port_messages, port_data_message, port_exit_message}`.
`Runtime` owns it as an `Rc<RefCell<PortRegistry>>` (the ETS-tables pattern); `call_registered` builds a `RuntimePorts` from that handle + the shared atoms + the **owning pid**, so the port BIFs reach a real OS process without a `&mut Runtime` borrow. `SpawnDriver` is the **single** OS-child implementation; this crate owns only the **term decoding** of `open_port/2`'s `Name`/`Options` (into a term-free `SpawnSpec`/`SpawnOptions`) and the `PortMeta`.
`pump` is the single message producer: it polls in `PORT_POLL_SLICE` (25 ms) slices, each clamped by the earliest driver deadline (`beam_io::PortRegistry::next_deadline`), so a driver-declared timer fires **at** its deadline; it runs the scheduled port tasks and reports `PortEvent::{Data,Exited}`. `deliver_port_messages` DELIVERS each `{Port,{data,..}}`/`{Port,{exit_status,..}}` into the **owning** process's mailbox (`deliver_simple`) and returns the count (0 when no port is live — never sleeps). `close`/`PortHook::close_port` call `beam_io`'s `notify_port_exit(…, PortExitReason::Closed)` **before** `registry.close(...)` — the single port-exit path; either leg's failure reaches the caller.

### `nif.rs` — the live NIF libraries (contract A.3), and `build.rs`
`NifEntry{lib, host: Box<NifHostImpl>}` (**field order is load-bearing**) and `NifRegistry{libs: HashMap<String,NifEntry>}` are `!Send` (dlopen handles + an erased host pointer); the runtime is single-threaded. `NifRegistry`: `new()` (anchors the `enif_*` codegen unit — see `build.rs`), `is_loaded(module)` (the oracle's `reload` condition), `insert(module, entry)`, `lookup(module, function, arity) -> bool` (**the dispatch predicate**; a miss is a perfect no-op), `call(...) -> Result<Eterm, NifCallError>` (miss ⇒ `UnknownFunction`). `NifHostImpl{heap, atoms: Rc<AtomTable>, interner, self_pid}` implements `beam_abi::NifHost`; `map_load_error` maps `beam_abi`'s `NifLoadError` → `beam_bifs`'s variant-for-variant. `Runtime` owns **one** registry: `nifs: Rc<RefCell<NifRegistry>>` (the ETS/ports pattern).
**Field order is load-bearing:** Rust drops in declaration order, so `lib` (whose `Drop` runs the C `unload` against the erased host pointer, `*mut dyn NifHost`) drops *before* the boxed `NifHostImpl` it was loaded against. The **load-time host** (boxed in the entry) is the `unload` context; a NIF **call** runs against a **fresh** per-call `NifHostImpl`. Both own their `Heap` (stable address) and share the runtime's **one** `Rc<AtomTable>` and the in-flight `PendingInterner`.
`build.rs` emits `cargo::rustc-link-arg-bins=-Wl,--export-dynamic` **and** `…-tests=…` (legal: `beam_rt` has a `[[bin]]`), so the binary and test executables publish their dynamic symbol table; `NifRegistry::new` also anchors `beam_abi`'s `enif_*` codegen unit (`black_box(beam_abi::nif::enif::enif_api_table())`). Without either half, `dlopen(RTLD_NOW)` of a real NIF fails on an unresolved symbol (proof: `tests/nif.rs::the_binary_exports_the_enif_symbols_a_nif_imports`, via `nm -D`/`readelf --dyn-syms`). **Typed gaps:** the host leaves `term_to_binary`/`binary_to_term`/`make_ref` at the `NifHost` defaults (`None`), so those `enif_*` calls report failure rather than fabricating a term.

### `config.rs`, `cli.rs`, `boot.rs`, `info.rs`, `format.rs`
`config.rs`: `EmulatorConfig = beam_common::config::RuntimeConfig`; `RuntimeConfig{emulator, code_paths, heap_words, action, init_args}` with `Action{Boot,Version,Eval,String,Apply,Run,RunFile}`, `ArgTerm{Int,Atom,Str,List}` and `InitArgs` (ordered flag → occurrences). `cli.rs`: `USAGE`, `EXIT_OK/EXIT_RUNTIME/EXIT_USAGE/EXIT_UNSUPPORTED` (= 0/1/2/3), `parse(&[String])` (excludes argv[0]), `run(Vec<String>) -> i32`. `boot.rs` (A.7): `PreloadedModules`. `info.rs` (A.8): `SUPPORTED_KEYS` (the 13 keys), `INFO_ATOMS`, `InfoValue::to_eterm(heap, atoms)`, `system_info_value(key, rt)`. `format.rs`: `term_to_string`/`term_to_string_w` (drives `io:format/2`).

## The runtime-native BIF floor (`src/native/`)
The floor is the BIFs that are really *runtime* operations — they read/write the runtime's own state (process/port tables, code server, atom table, application view, parsed command line) — served **before** the `beam_bifs` registry from `RuntimeContext::try_native` (a directory module; `try_native`'s dispatch table is the source of truth for what is native):
* `native.rs` — module docs, `try_native`, the shared helpers (`string_list`/`atom_name`/`atom`/`charlist`/`render`/`write_output`/`chars_to_string`), plus the `erlang`-core entries `halt/0,1`, `display/1`, `io:put_chars/1,2`, `erlang:apply/2,3`, `erlang:system_info/1`, `os:cmd/1`.
* `native/init.rs` — `init:get_argument/1`, `get_arguments/0`, `get_plain_arguments/0`, `get_status/0` (→ `{starting, started}`).
* `native/code.rs` — `code:get_path/0`, `all_loaded/0`, `which/1`, `is_loaded/1` (→ `{file,Path}` / atom `preloaded` / atom `false`; a module loaded from bytes with no path reports `""`), `is_sticky/1` (bool; `/2` is `error:undef` — the release has none), `ensure_loaded/1` (→ `{module,Mod}` / `{error,nofile}`), `lib_dir/0,1`, `root_dir/0`.
* `native/process.rs` — the `erlang` process/registry/reference entries: `self/0`, `make_ref/0`, `monitor/2` + `demonitor/1,2` (over `beam_process`'s monitor machinery + `Runtime::refs_mut`), `spawn/1,2,3`, `spawn_link/1,2,3`, `spawn_opt/2,3,4` (a fun entry or an `M:F/A` export), `ports/0`, `processes/0`, `pre_loaded/0` (the oracle's exact list *and* order), `group_leader/0`, `whereis/1`, `register/2`, `unregister/1`, `module_loaded/1`. `whereis(init)` is the runtime's own root process (oracle `<0.0.0>`).
* `native/port.rs` — `port_command/2,3` (the port's write stream: the child's `stdin`, or the adopted duplex descriptor of a `{fd,N}` port; binary / char list / nested iolist; `[force]` → `error:notsup`) and the `port_info/1,2` item mapping (`undefined` for unknown/closed).
* `native/application.rs` — `application:get_env/1,2,3`, `get_all_env/1`, `get_key/2`, `loaded_applications/0`, `which_applications/0`, over a minimal native app view (the `.app` files through the `CodeServer` + a recursive-descent `.app` term-text parser). **Honest deviation:** `get_all_env(kernel)` reports the `.app`'s **declared** env only — seven pairs (oracle: nine; `logger`/`connect_all` are injected by kernel's app start and are *not* fabricated); the pairs agree key-for-key, order differs; `erts` is deliberately not reported loaded.
* `native/test_support.rs` — the floor's shared test fixtures.

`beam_bifs` owns the *registry* surface (`bif.tab`: arithmetic, comparison, type tests, term ops, `lists`/`maps`/`binary`, `io:format`, `ets`, `records`, …); a native entry must never duplicate one, and a call the floor does not claim returns `None` and falls through.

### `code:` is the native floor, not a live `code_server`
`code:*`, `init:*` and `application:*` are **preloaded-module surface** (A.7): the oracle serves them from `init.beam`/`code.beam`/`application.beam`, which are written against process/message machinery M1 does not run. `beam_rt` ships **no** live `code_server.beam`: OTP's real one needs `monitor/2`+`demonitor`, `register`/`whereis`/`process_flag(trap_exit)`, `spawn_link`, a working `send`, a host **timer** for `after T`, `make_ref/0`, named-ETS resolution, `persistent_term:*`, `filename:*`, `erl_prim_loader:*` and `pre_loaded/0` — all outside this crate — and its *state* already lives in `CodeServer`. The `boot/*` differential cases touching `code:*` are **shape-only** (`is_list`/`is_atom`) and already satisfy; a future live server must reproduce the `{code_call, From, Req}` → `{code_server, Reply}` wire (the OTP `code_server:call/1` protocol; `beam_engine` rejects its `recv_marker_*`/`send` by opcode). **`src/native/code.rs`'s `code:*` behaviour must not change** — it keeps the currently-agreeing cases green.

### `erlang`-namespace fallback and the known-unimplemented list
`call_bif` consults the floor, then the `beam_bifs` registry, then falls back for the `erlang` namespace. A **known** unimplemented OTP `erlang` BIF (`error::is_known_unimplemented_bif`) raises the capability gap `unsupported: erlang:X/Y …` (exit 3); any other unclaimed name raises the bare `error::undef` the oracle does (`error::undef()` is the single constructor — `run_export`, `call_bif`, `codeserver` not-found and `spawn_process` alike). The **effective** gap set is the curated static list (`error::KNOWN_UNIMPLEMENTED_ERLANG_BIFS`) **intersected with what the live registry does not own**, computed at use time, so a later `beam_bifs` change that registers a listed name can never shadow the registry or turn a served BIF into a gap (e.g. `erlang:phash2/1,2` are registered and therefore not classified here). Drift guard: `error::tests::the_effective_gap_set_never_shadows_the_registry`.

## CLI subset (contract A.6 — the *exact* supported surface; anything else is *unsupported*, exit 3)
| Switch | Meaning in `beam_rt` |
|---|---|
| `-version`, `--version` | print the version banner (OTP `30.0-rc0` / erts `17.1`) and exit 0 |
| `-noshell` | run head-less (M1 default; accepted, no interactive shell exists) |
| `-eval Expr` | evaluate a **general Erlang expression** (`erl_eval`-style) and print **nothing**; one trailing `.` is tolerated and stripped |
| `-s Mod Func [Args...]` | apply `Mod:Func(a, b, …)` (Arguments are **atoms**); the result is **discarded**; exit 0 on success |
| `-run Mod Func [Args...]` | same, but Arguments are plain **strings** (Erlang char lists); result **discarded** |
| `-pa Dir` / `-pz Dir` | add `Dir` to the code path (before / after `-pz` dirs) |
| `+S N[:N]` | normal scheduler count → `emulator.schedulers` (first number); M1 runs single-threaded |
| `+A N` | async-thread pool size → preserved verbatim in `emulator.extra_emulator_flags` |
| `+P N` | max process count → `emulator.max_processes` |
| `-name N` / `-sname N` | node name → `emulator.node_name` (distribution M1 = skeleton) |
| `run <file.beam> <mod>:<func>/<arity> [int-arg…]` | **the vertical slice**: load the file, run, **print** the result |

* `-eval` grammar (`src/eval/{parse,ast,mod}.rs`): the Erlang **expression** subset — literals in every base, lists/tuples/maps/binaries, the full operator set with Erlang precedence, `case`/`if`/`begin`/`try`/`catch`/`receive`, `fun`s, and list/map/**binary** comprehensions (incl. a **binary generator**, `<<Seg || <<X>> <= Bin>>`). An `erl_eval`-style tree-walk evaluates it, dispatching arithmetic/comparison/**bit operators** (`band`/`bor`/`bxor`/`bsl`/`bsr`/`bnot`, arbitrary precision) to the **`beam_bifs` `erlang` registry** (only `and`/`or`/`xor`/`not`/`andalso`/`orelse`/`++`/`--` stay special forms). Binary segments accumulate a bit buffer, so construction need not be byte-aligned; a byte-aligned result is a **binary**, a non-byte-aligned one a **bitstring** (`beam_codec::term::make_bitstring` on the long-lived `eval_heap`). A map literal uses the sorted `beam_engine::terms::make_map`. An expression outside the grammar is a **capability gap** (exit 3), not a genuine error.
* **Every command-line flag is an init argument.** Each recognized switch *and* each unrecognized `-flag`/`+flag` (name = the flag with the leading run of `-`/`+` removed; values = the following non-flag tokens) is recorded as an `InitArgs` occurrence — the source of `init:get_argument/1` (`-noshell` ⇒ `{ok,[[]]}`, `-pa /a -pa /b` ⇒ `{ok,[["/a"],["/b"]]}`). An unmodeled switch is **data, not a usage error** (real `erl -noshell --nope -eval 'halt(0).'` exits 0); only a **stray positional argument** (outside `run`) is a usage error (exit 2).
* `run` argument grammar (each `ARG` token): a **signed integer** (`42`) → `ArgTerm::Int`; a **double-quoted string** (`"a\n"`, escapes `\n \t \r \\ \"`) → `ArgTerm::Str` (an Erlang char list); a **list** (`[1, atom, "x"]`) → `ArgTerm::List`; otherwise a bare atom name → `ArgTerm::Atom`. The materialized count must equal the arity (else exit 2); a `-`/`+`-prefixed non-integer token is a usage error. `run`, `-s` and `-run` resolve modules through `code_paths` (`-pa`/`-pz`) + the system stdlib and the file argument (M1 searches for `<Mod>.beam`).

## Exit codes & the `unsupported` signal (the stable external contract)
The CLI exposes **four** exit codes; the differential harness keys off this mapping.

| Code | Meaning | stderr |
|---|---|---|
| `0` (`EXIT_OK`) | success | — |
| `1` (`EXIT_RUNTIME`) | genuine runtime error (a load/execute/BIF failure, e.g. a missing `.beam`, an `undef`, BIF `system_limit`) | `beam_rt: <error>` |
| `2` (`EXIT_USAGE`) | malformed invocation / usage error (a missing operand of a *known* switch, a malformed `run` spec, a stray positional argument, a malformed numeric switch value) | `beam_rt: <error>` then [`USAGE`] |
| `3` (`EXIT_UNSUPPORTED`) | **unsupported** — a Milestone-1 capability gap | exactly one line: `beam_rt: unsupported: <reason>` (no [`USAGE`]) |

Unsupported is emitted for a `-eval` expression outside the grammar (`src/eval/parse.rs`), a BEAM-engine capability gap (reason atom starts with `unsupported_opcode`), or a `beam_bifs` capability gap (reason atom `unsupported_bif`). A capability gap is **uncatchable**: `src/eval/mod.rs`'s `flow_from_error` turns it into `Flow::Fatal` (like `halt`), so the self-terminating `try (EXPR) of … catch C:R -> … end` probe the harness wraps expressions in **cannot** swallow it; it escapes to `cli::run` as the exit-3 line — an unimplemented feature is honestly `unsupported`, never a false `error`. The convention is a raise whose **reason atom starts with `unsupported`**; `src/error.rs::unsupported_reason` is the **single** interpreter of it (strips the leading token and any following `:`/`_`/space), and classification must go through it (it reads `ExitReason::as_atom`) rather than `BeamError::as_atom`, which returns `None` for atoms backed by an **owned** `String`.
**Structured raise reasons are rendered as the real term.** A raise may carry an opaque live reason whose payload is an `Eterm` (the `beam_common::Raise` convention); `src/error.rs::live_reason_term` recovers it and renders it through `format_term_w`. `src/runner.rs::exit_reason` uses it as the process's exit reason, `src/cli.rs::run_file` (via `reported_reason`) for the CLI diagnostic; an escaping raise in `src/context/mod.rs::run_export` also passes through `error::name_atom_raise`, which recovers a bare-atom reason so it is still classified by name. So `beam_rt run <m>.beam m:badkey/0` → `beam_rt: error {badkey,nokey}` (exit 1), never a placeholder.

## Constraints
* **Errors are return-based, workspace-wide** (`../CONTEXT.md` §3): every fallible API returns `beam_common::Result`. **No crate-local error enum**, **no `panic!`/`unwrap()` on runtime data**, **no silent swallowing**. CLI diagnostics are `BeamError::Raise(Raise::error(ExitReason::atom(msg)))`.
* **`unsafe`-free.** The whole crate is `#![deny(unsafe_code)]`; the glue uses only the safe peripheries of the lower crates (`Heap::cons/tuple`, `AtomTable::intern`, `BifRegistry::call`).
* **Call down, never duplicate.** The `~p` printer is **not** re-implemented — `format.rs` drives the registered `io:format/2` BIF.
* **Frozen term layout** (`../CONTEXT.md` §2): terms are built/inspected only through `beam_term`.
* **Files ~1000 lines**, split by responsibility; `#![warn(missing_docs)]`, every public item documented. `src/context/{mod (887), bridges (431), tests (578)}.rs` are each below the baseline; `src/port.rs` (~2290 lines) exceeds it only through its colocated `#[cfg(test)] mod tests` (production half ~1175) — pre-existing, not restructured.

## Design Decisions
* **One shared atom table (the code server's).** No module-local/global split: `CodeServer` owns **one** `AtomTable` (in an `Rc`, copy-on-write on intern), every module it loads is interned into it, and `call_bif` hands `BifContext` that same table — so an atom a BIF builds is an index the engine compares against and the printer names, for **every** loaded module. Indices are insertion-ordered and never renumber.
* **Heap lifetime.** `Runtime` **owns** the process heap so a returned `Eterm` stays valid after `run_*` returns (`RuntimeContext` only borrows it). `system_info`/`format_term` use a separate `info_heap`, `reset()` per call — their term is valid only until the next such call.
* **`ensure_heap` without GC.** M1 has no engine collector: `ensure_heap` checks capacity and returns `BeamError::SystemLimit` when short (default `heap_words` = 64 Ki words); growth-by-collection is Stage 4 (`beam_gc`).
* **CLI is a documented subset, never a silent no-op.** Unmodeled emulator flags are **preserved verbatim** in `emulator.extra_emulator_flags`; `-eval` and `run` reuse the BIF registry rather than re-implementing arithmetic/printing. **`main.rs` is a thin shim** over `cli::run(argv)`. `system_info` returns `Eterm` via `InfoValue`, computed heap-independently and materialized once, so the keys are unit-testable without a heap.
* **The scheduler moves the table (and the runner state) out of the `Runtime`.** A pass needs `&mut Runtime` **and** `&mut ProcessTable` at once, and the table is a *field* of the runtime (the crate is `#![deny(unsafe_code)]`, may not alias). `Runtime::run_pass` **moves** both out (`take_processes`/`put_processes`, a `std::mem::replace` with a fresh `ProcessTable`), runs the scheduler with the owned values, then puts both back whatever the outcome; the runner also takes the pid's `Machine` **out of** its `HashMap` for the slice and puts it back unless the process finished. `Runtime::scheduler` persists across passes, so `run_one_slice` followed by `run_scheduler` continues where the slice left off.
* **A process's exit reason is not its return value.** BEAM terminates a normally-returning process with `normal`, discarding `x(0)`; the runner **records** the final `Returned` value per pid in `RunnerState::results` (`Runtime::process_result`) and returns `RunOutcome::Exit(normal)`. The value is first copied onto the runtime's pointer-stable arena by `Runtime::stabilize_term` (`beam_message::copy_struct_simple` onto `eval_heap`, never reset) — an immediate is shared, a container/binary is copied, because a value taken from a process's mailbox points into that process's own heap and would dangle once it terminates. A process that **raises** records the mapped reason term in `RunnerState::exits` (`Runtime::process_exit`) and exits with that very term.
* **The port subsystem: one poller, one `beam_io` registry, `SpawnDriver` — this crate owns only the terms.** The state travels as an `Rc<RefCell<PortRegistry>>` because `call_registered`'s `FunBridge` needs `&mut Runtime` at the same time; a nested borrow is a typed capability gap, never a panic.
* **The host seams: the four bridges + `NodeIdentity`.** `FunBridge` delegates to the **existing** `RuntimeContext::apply_fun`, so `lists:map(fun(X) -> X*X end, [1,2,3])` → `[1,4,9]`. Because the `BifContext` holds no runtime borrow, **every** its resource is a non-runtime-borrowing clone: `Rc<BifRegistry>`, an `Rc<AtomTable>` handle, an `Rc<RefCell<TableRegistry>>`, a **pooled** `beam_alloc::Heap` (`take_bif_heap`/`put_bif_heap`, stack discipline) and the disjoint `output` field.
* **`nif_error` raises the live reason term.** `beam_bifs`' `erlang:nif_error/1,2` build a `Structured` reason carrying no `Eterm`; `src/eval/mod.rs` therefore intercepts them and raises `Flow::Raise { class: Error, reason: <the argument term> }`, so the **exact** term survives (`nif_error(foo)` → `exception error foo`) and the raise stays catchable. The same term-carrying path serves `error`/`exit`/`throw` with a live reason.

## Known Issues / Intentional M1 gaps
* **No interactive shell, no distribution, no node.** `-noshell` is the only mode; `-name`/`-sname` are parsed and stored but distribution (A.5) is not started.
* **Preloaded modules are a name-set skeleton.** Boot does **not** load preloaded `.beam`s; the shared atom table is seeded with `CORE_ATOMS` + `INFO_ATOMS` (not the full `atom.names` ordering), so positional atom indices for preloaded code are not reproduced. The erts app's `ebin` **is** on the code path, so `init`, `persistent_term`, … can be loaded from disk on demand; the registry (the oracle's exact `erlang:pre_loaded/0` list *and* order) is in place.
* **Answers that read *this* runtime's own state differ from the oracle by construction** — not bugs, and must not be "fixed" to a run-time figure: `erlang:processes/0`, `erlang:ports/0`, `system_info(port_count)` (the live `PortRegistry`, empty until something opens a port) and `erlang:module_loaded/1`. `erlang:whereis(init)` **does** agree (the root process; oracle `<0.0.0>`); `erlang:registered/0` is on the known-unimplemented list.
* **`-eval` results that are not byte-aligned cannot be *printed*.** Construction and `bit_size/1` work for a non-byte-aligned bitstring, but the registered `beam_bifs` `io:format` `~w`/`~p` printer rejects one with `badarg` — a **`beam_bifs` printer gap outside this crate** (the corpus probes read such a value through `bit_size/1`, so they are unaffected). The same printer also rejects a container wider than its ~80-column limit (`io:format("~p~n",[code:is_loaded(lists)])` → `badarg` where the oracle prints `{file,"…/lists.beam"}`), visible on `code:*` answers because they embed an installation path. Remaining honest limits: a construction **or** pattern segment wider than 64 bits is *unsupported*; a value needing a bignum is `system_limit`.
* **Scheduler is single-threaded; a few M1 process gaps.** Spawned processes run and a blocked receiver **is** resumed by a sender (send→wake→resume via `resume_woken`). Remaining gaps: **no reduction pre-emption** (`budget` not enforced; `Yield` never returned; a process runs to its next `return`/`wait`); a non-zero `receive ... after T` **suspends (`Wait`) instead of timing out** on the *scheduler/runner* path (no host timer; only the `-eval` path advances, by polling ports); a **capability gap is uncatchable** on the runner path; a raising process terminates with the real reason term where carryable (else the mapped atom / `Display` text).
* **No live `code_server`.** `code:*` on the receive path is the native floor in `src/native/code.rs`, not a running `code_server` process (see that section for why).
* **`-eval`/`-s`/`-run` are documented subsets** (`-s` uses atoms + discards the result, `-run` uses strings; `-eval` evaluates the expression subset and prints nothing). An expression outside the grammar is *unsupported* (exit 3). Supported: the `!` **send operator** and a **bare `receive`** that drives a spawned sender. Remaining gaps (all typed errors in `src/eval/mod.rs`): a bare `receive` that never receives a message, a `receive` inside a spawned process, and `after infinity`. Real `erl` start-script processing, `-init_debug` and the rest are absent — like any unmodeled switch, recorded as init arguments rather than acted on.
* **NIF loading is live, with honest typed gaps (A.3).** `erlang:load_nif/2` really `dlopen`s the shared object, binds its entry points, registers the module in `Runtime.nifs`, and a call then runs the C NIF through `try_call_nif`; a load failure is the oracle's **returned** `{error, {Reason, Text}}` (never a raise). Typed gaps: the host leaves `term_to_binary`/`binary_to_term`/`make_ref` at the `NifHost` defaults (`None`); a second `load_nif` for a module that already has a library is `reload`. See the API section for the external-dispatch-only interception rule.
* **A lambda has no faithful `NEW_FUN_EXT` image.** `fun M:F/A` builds a real `FunKind::External` term (`term_to_binary` → `EXPORT_EXT`), but a lambda (`fun() -> ok end`) is an evaluator closure (`EVAL_FUN_UNIQ` + an index into `Runtime::eval_closures`) — a `Local` fun the ETF codec cannot encode, so `term_to_binary(fun() -> ok end)` is the honest typed `unsupported: local_fun` (the `wire/new_fun_ext_encode` corpus case). A byte-exact `NEW_FUN_EXT` would need `erl_eval`'s own 16-byte MD5 uniq, fun index, creator pid and expression env; no wrong encoding is emitted.
* **Nested-BIF re-entrancy is handled — with one limitation.** `call_registered` installs the `TableRegistry` **only for a call that cannot apply a fun argument**, so the outer call leaves the shared `RefCell` free for a nested `ets:*`; a `fun`-taking `lists:*`/`maps:*` BIF calling back through `FunBridge` gets a **fresh pooled heap** and shares the caller's sink through a `SharedSink` clone. Limitation: a BIF needing ETS *and* applying a fun argument would not get tables — none exists in M1. Output sharing gives `RuntimeContext` a destructor, so a caller keeping a context alive cannot reuse the `Runtime` binding until it goes out of scope.
* **Ports match the oracle's observable shape.** `open_port/2` really spawns the OS process: `{spawn, Cmd}` runs through `/bin/sh -c "exec Cmd"` (the shell replaces itself, so builtins / `VAR=x` / compound lines behave like the shell and a missing command exits 127 — matching the oracle); `{spawn_executable, Path}` runs the path directly with `{args, …}`; `{fd, N}` **adopts** the caller's descriptor (**duplex**: the same descriptor reads and writes). An **empty** name (`{spawn,""}` / `{spawn_executable,""}`) is `error:badarg` (the oracle's `Name` validation, before any driver — while `{spawn," "}` is accepted). The port gets a real `beam_process::PortId` from `beam_io`'s registry and metadata recorded; `port_close/1` kills/reaps the child and releases the id.
  **`port_info/1` answers the oracle's seven-item set in oracle order** — `{name, …}`, `{links, [Owner]}`, `{id, N}` (a **bare small integer**), `{connected, Owner}`, `{input, 0}`, `{output, 0}`, `{os_pid, N|undefined}`; `port_info/2` returns `{Item, Value}` and additionally answers `monitors`; `stream` is **not** an item (oracle: `error:badarg`); an unknown/closed port is the atom `undefined`; `input`/`output` are always `0`; `port_command/3` with `[force]` raises `error:notsup` (no `ERL_DRV_FLAG_SOFT_BUSY`); `open_port(_, [list])` raises `badarg`; `port_command/2,3` writes to the port's write stream and returns `true` (`BadArg` for a non-port or an unknown/closed id) — a `{fd,N}` port writes to its **adopted duplex descriptor** on the same path.
  Remaining honest gaps: only **stdout** is polled (stderr is discarded by the driver) and the read is **one** `Read::read` per readiness; `connected` flips to `false` only at `port_close/1`, not when the child exits by itself; `exit_status` is honored (a reap emits exactly one `{Port, {exit_status, Status}}` — `Status` = the exit `code()` else `128 + signal()` — handed out **once** by `pump`); `eof` is inert; a self-exiting child is reaped by a later poll or by `port_close/1`/runtime exit; `{spawn_executable, Missing}` is `BeamError::Io` where the oracle gives `error:enoent`; a `binary`-stream read wider than 64 bytes is the typed *unsupported* gap. `os:cmd/1` remains the runtime-native host spawn.
* **Heap has no GC** — a runaway allocation returns `SystemLimit`.
* **No memory introspection.** `erlang:memory/0,1`, `erlang:process_info/1,2` and `erlang:statistics/1` are **not** registered BIFs (`beam_bifs` raises `… is not a BIF`, exit 1) and no answered `system_info/1` key reports memory. The registered `ets:info(T, memory)` is the only memory number available.
