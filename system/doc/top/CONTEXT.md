# system/doc/top/ — OTP Top-Level Documentation Index (ex_doc "app")

## Intent
Builds the landing page of the published OTP documentation (`$(ERL_TOP)/doc/index.html`) plus the flat per-application / per-system-guide redirect pages.
It is a self-contained ex_doc invocation, not an OTP application: its ex_doc app id is `:index` (see `docs.exs`), which `make/ex_doc.exs` special-cases.
Output goes to `$(HTMLDIR)` = `../../../doc` (i.e. `$(ERL_TOP)/doc`, git-ignored by root `.gitignore:/doc`) — NOT to `system/doc/html`.
Installed layout by `release_docs` is `<release_root>/{erts-<vsn>,lib/<app>-<vsn>,doc}`, with the index at `<release_root>/doc/index.html` (`RELSYS_HTMLDIR=$(RELEASE_PATH)/doc`).

## API Surface
Tracked (authored) files — everything else here is a build output:
- `Makefile` — group lists, stub rules, `HTML_DEPS`, `EPUB=false`; includes `$(ERL_TOP)/make/doc.mk`.
- `docs.exs` — ex_doc config: extras, `main: "readme"`, `api_reference: false`, redirects, sidebar groups.
- `README.md.in` — template of the front page.
- `src/otp_man_index.erl` — EEP-48 based module index generator.
- `.gitignore` — ignores `core database oam interfaces tools testing documentation system man_index.md README.md`.

### Inputs → generated files
| Input | Generator | Output |
|---|---|---|
| `README.md.in`, `../../../OTP_VERSION` | `sed` rule (`%OTP-VSN%` ← `$(VSN)` = `OTP_VERSION` content, e.g. `30.0-rc0`) | `README.md` |
| `src/otp_man_index.erl` | `erlc -o src +warn_unused_vars`, then `erl +pc unicode -noshell -pa src -s otp_man_index gen man_index.md -s erlang halt` | `src/otp_man_index.beam`, `man_index.md` |
| `../guides` (one `name:Title` per line) | `system/%.md` rule (`grep` title → `echo "# $TITLE"`) | `system/<guide>.md` (stub, **title only**; content lives in the sibling `system` doc app) |
| group vars in `Makefile` (`CORE`…`DOCUMENTATION`) | explicit `core/erts.md` rule (`# erts`) and the catch-all `%.md` disclaimer rule | `{core,database,oam,interfaces,tools,testing,documentation}/<app>.md` |
| all of the above + `docs.exs` | `make/ex_doc_wrapper` (see below) | `$(ERL_TOP)/doc/**` (`index.html`, `readme.html`, `<app>.html`/`<guide>.html` redirect pages, `.md` copies) |

ex_doc command (`make/doc.mk:136-140`), `$(ERL_TOP)/doc/index.html` depends on `HTML_DEPS = README.md man_index.md ../guides $(REDIRECTS)`:
```
EX_DOC_WARNINGS_AS_ERRORS=$(...) ERL_FLAGS="-pz $(ERL_TOP)/erts/ebin" \
  $(ERL_TOP)/make/ex_doc_wrapper $(EX_DOC_FORMATS) --homepage-url "./index.html" \
  "Erlang/OTP" $(VSN) ../../../lib/erl_interface/ebin -o "../../../doc" -c $(ERL_TOP)/make/ex_doc.exs
```
`$(EX_DOC_FORMATS)` comes from `make/get_ex_doc_formats_no_epub.sh` because `EPUB=false`: `-f html -f markdown` (ex_doc ≥ 0.40), `-f html` otherwise.
`APP_DIR=../../../lib/erl_interface` only exists to give `doc.mk` a valid app dir/ebin (no `.erl` in it ⇒ `DOC_TARGETS` = `html` only, no man pages).
Entry points from this dir: `make docs` (= `check_ex_doc` + `html`), `make html`, `make release_docs`, `make clean_docs`.

## Application group assignment (where it lives)
`Makefile:36-43` — the authoritative app→group map; every one of the 35 dirs in `lib/` plus `erts` appears exactly once:
- `CORE=compiler erts kernel sasl stdlib`, `DATABASE=mnesia odbc`, `OAM=os_mon snmp`,
  `INTERFACES=asn1 crypto diameter eldap erl_interface ftp inets jinterface megaco public_key ssh ssl tftp wx xmerl`,
  `TOOLS=debugger dialyzer et observer parsetools reltool runtime_tools syntax_tools tools`, `TESTING=common_test eunit`, `DOCUMENTATION=edoc`.
The *directory* names above are also the sidebar group keys: `docs.exs` `groups_for_extras` maps regexes (`~r/core/`, `Core:`, `Database:`, `"Operations & Maintenance"`, `"Interfaces & Communication"`, `Tools:`, `Test:`, `Documentation:`) plus `"System Documentation": ~r{system}` for the guide stubs.
`../guides` is the likewise authoritative guide list (`SYSTEM:=$(shell awk -F: '{print $$1}' ../guides)`); it needs no edit here when a guide is added.

## Constraints
- **Build order**: run `make docs`/`release_docs` from `ERL_TOP`; `Makefile.in:437-455` recurses `lib` → `erts` → `system/doc` → `system/doc/top`. Necessary because (a) `otp_man_index` reads EEP-48 chunks from the built `erts/ebin` + `lib/*/ebin` beams, (b) `make/ex_doc.exs` links every `lib/*/ebin` as a dep at `../lib/<app>/doc/html`, (c) the `../general_info/{deprecations,removed,scheduled_for_removal}.md` extras are *generated by the sibling `system/doc` Makefile* (only `upcoming_incompatibilities.md` is authored), and (d) redirect targets `../lib/<app>/doc/html/index` and `../system/doc/html/<guide>` must exist.
- **Generated vs authored**: never edit `README.md`, `man_index.md`, any `<group>/*.md`, `system/*.md` or anything under `../../../doc` — edit `README.md.in`, `src/otp_man_index.erl`, `Makefile` or `docs.exs` instead. All of them are git-ignored build outputs.
- **Add an OTP application to the index**: put its app-dir name in the right group variable in `Makefile` (and create a new `<group>=` var + stub-dir rule + a matching `groups_for_extras` entry in `docs.exs` only if a *new* sidebar group is wanted). A listed-but-unbuilt app automatically gets the disclaimer stub (“…skipped during the source build”), so the index never breaks on a missing doc.
- **Add a system guide**: add `name:Title` to `../guides`; the stub page and redirect are derived automatically here. The guide's own content/config still has to be added under `../` (`system/doc/docs.exs`, `system/doc/Makefile`).
- `ERL_TOP` must be set, absolute and match the code path used to build — otherwise `otp_man_index:module_path_to_app_vsn/1` exits with `ERL_TOP environment variable doesn't match the PATH`.
- Module paths are matched as `lib/<app>/...`; `preloaded` modules are attributed to `erts`.

## Design Decisions
- A separate ex_doc app (rather than part of the `system` doc app) because the top index must aggregate *all* app docs, the system guides and the general-info pages, and its output belongs in `<release_root>/doc`, next to (not inside) the app docs.
- The `:index` app id is recognised in `make/ex_doc.exs`: root offset `../../../`, dep/doc links `../lib/<app>/doc/html` + `../../{doc,erts/doc/html,system/doc/html}`, source-URL prefix `system/doc/top/`, and it is exempt from the "cwd must be a `doc` directory" assertion.
- Redirects + placeholder stubs instead of failing builds: `docs.exs` `redirects:` yields `<app>.html` / `<guide>.html` pages pointing at the real doc, and `Makefile` emits a stub `.md` for every listed app so the sidebar always has a page.
- Version-ized/relocated links (`lib/x/doc/html` → `lib/x-<vsn>/doc/html`, `system/doc/html` → `doc/system`) are applied only at install time by `make/fixup_doc_links.sh` (`make/doc.mk:185-188`), so the in-tree HTML keeps source-tree-relative paths. For this app `$(RELSYS_HTMLDIR)/*.html` is `<release_root>/doc/*.html` (dirname basename is `doc`, not `system`), i.e. the top-level `index.html` and the redirect stubs ARE rewritten.

## Known Issues
- Only `lib/SKIP-APPLICATIONS` is honoured (read by `docs.exs`, entries downcased) and `configure` writes it **only** for apps disabled via `--without-<app>`; apps skipped because their own `lib/<app>/SKIP` file exists (failed configure / missing deps — see `make/otp_subdir.mk`, which skips the whole subdir for every target including `docs`) are *not* excluded. Their `doc/<app>.html` redirect is still generated and points to a `../lib/<app>/doc/html/index` that was never built. (The `docs.exs` comment claiming the file holds “all apps not built for various reasons” is inaccurate for this reason.)
- The skip filter is applied only to `redirects`; `extras` uses an unfiltered `Path.wildcard("{core,...}/*.md")`, so skipped apps still get a disclaimer page. Intentional-looking, but easy to misread.
- `man_index.md` prerequisites (`$(wildcard $(ERL_TOP)/erts/ebin/*.beam)` / `lib/*/ebin/*.beam`) are expanded when the Makefile is parsed: if the system is not built yet the list is empty, so an existing `man_index.md` is never refreshed by later `make` runs (only recreated if missing).
- `%.md: %.md.in` also substitutes `%EX_DOC_VSN%` and `%OTP-REL%`, but neither `EX_DOC_VSN` nor `OTP_REL` is defined in this Makefile (unlike the per-app/doc Makefiles) — those placeholders would silently expand to nothing; only `%OTP-VSN%` is actually used in `README.md.in`.
- `make clean`/`clean_docs` here removes nothing of the generated output: `EXTRA_FILES` is unset and `doc.mk` only provides `clean_html`; the stub dirs, `man_index.md` and `README.md` survive a clean (`git clean -X` / root `clean_docs` handle them).
- The guide/app stub pages contain a single heading (e.g. `# erts`, `# Installation Guide`), so their “View Source” link (prefix `system/doc/top/`, overridable via `BASE_URL`) points at an untracked generated file.

## Notes for Agents
- The 5 tracked files are the whole source of truth; `git ls-files system/doc/top` is the checklist.
- Quick local rebuild: `make docs` in this directory (needs `ex_doc` in `PATH` — `make/check_ex_doc` offers to run `./otp_build download_ex_doc`; the version is pinned in `make/ex_doc_vsn`, currently `v0.40.4`). A failed ex_doc run is re-triggered by `make/ex_doc_wrapper.in` touching `docs.exs`.
- `src/otp_man_index.beam` is covered by the root `*.beam` ignore rule.
- Module index content: only modules whose EEP-48 doc chunk (`text/markdown` or `application/erlang+html`) has a `module_doc` appear; the first doc line becomes the description.
- `otp_patch_apply` also runs `release_docs` in this directory when building a patched release.

## Test Strategy
- No test suite; correctness is checked by CI (`.github/workflows/reusable-documentation.yaml`): `make release docs release_docs` + `make install-docs`, then a second `make release_docs DOC_TARGETS='html man' RELEASE_ROOT=<dir>` whose `doc/` tree (including `index.html`, the redirect stubs and the stub dirs) is tarred as `otp_doc_html.tar.gz` and validated by `scripts/otp_check_html_links.exs` (Floki-based link/anchor check). Warnings from ex_doc are errors by default (`EX_DOC_WARNINGS_AS_ERRORS=default`, auto-disabled by the wrapper when any `lib/*/ebin` lacks a `.app`).

## Routing Table
- `./src/` → `otp_man_index.erl`, the single helper that generates `man_index.md` (file-level detail only; no further CONTEXT.md below the file level).
- Sibling/parent (read-only from here — escalate writes to `../`):
  - `../` (`system/doc`) → the `system` doc app: `guides` list, `docs.exs`, `Makefile`, guide sources and the generated `general_info/*.md`
  - `../../../make/` → shared doc tooling (`doc.mk`, `ex_doc.exs`, `ex_doc_wrapper.in`, `ex_doc_vsn`, `fixup_doc_links.sh`, `check_ex_doc`, `get_ex_doc_formats_no_epub.sh`)
  - `../../../Makefile.in` → `docs` / `release_docs` / `install-docs` orchestration and build order
  - `../../../lib/`, `../../../erts/` → app/erts beams (input to `man_index.md`) and app HTML docs (redirect targets)
